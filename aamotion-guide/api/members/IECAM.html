    ECAM_ConfigureTable¶

    void ECAM_ConfigureTable(int startIndex, int endIndex, int startCycIndex, int endCycIndex, int cycles, int masterKeyword, int gap, int tableNum = 1, int masterIni = 0)

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable 生成直线或正弦表写入 GenData；ECAM_SetTableData 写入自己计算的表（从 ECAMStart 写到 ECAMEnd）。ECAM_ConfigureTable 一次设置表范围、循环、主轴、间距和主轴起始补偿；也可以用 SetTableRange、SetMaster、SetGap、SetCycleParams、SetMasterIni 分别设置。

    生成和配置凸轮表

    SDK 说明： Configure ECAM table parameters for electronic cam motion.

    参数 类型 方向 默认值 说明
    startIndex int 输入（值传递） 必传 表在 GenData 中的起始下标
    endIndex int 输入（值传递） 必传 表在 GenData 中的结束下标
    startCycIndex int 输入（值传递） 必传 循环部分的起始下标
    endCycIndex int 输入（值传递） 必传 循环部分的结束下标
    cycles int 输入（值传递） 必传 循环次数：正数单向，负数往返，int.MaxValue（2147483647）无限
    masterKeyword int 输入（值传递） 必传 主轴关键字的 CAN 编号，用 c.GetKeywordCANCode(eKeyword.PosRef) 读取。C 接口没有查询 CAN 编号的函数，只能写定值：AGM800 上 PosRef 为 24、Pos 为 2，其它产品查关键字手册
    gap int 输入（值传递） 必传 主轴每多少计数对应表中一个点；负数表示反方向
    tableNum int 输入（值传递） 1 凸轮表编号，1–10（C# 可省略，默认 1；C 必须给出）
    masterIni int 输入（值传递） 0 主轴起始位置补偿

    返回类型： void

    补充说明（SDK 原文）： This method configures all the necessary parameters for ECAM motion. The ECAM table data should be stored in GenData array from startIndex to endIndex.

    ECAM_SetTableData¶

    void ECAM_SetTableData(int[] data, int tableNum = 1)

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable 生成直线或正弦表写入 GenData；ECAM_SetTableData 写入自己计算的表（从 ECAMStart 写到 ECAMEnd）。ECAM_ConfigureTable 一次设置表范围、循环、主轴、间距和主轴起始补偿；也可以用 SetTableRange、SetMaster、SetGap、SetCycleParams、SetMasterIni 分别设置。

    生成和配置凸轮表

    SDK 说明： Set ECAM table data using GenData array. The points are written from ECAMStart[tableNum] up to and including ECAMEnd[tableNum] or the last GenData index, whichever comes first; surplus values are ignored.

    参数 类型 方向 默认值 说明
    data int[] 输入（值传递） 必传 表数据（从轴位置，计数）
    tableNum int 输入（值传递） 1 凸轮表编号，1–10（C# 可省略，默认 1；C 必须给出）

    返回类型： void

    补充说明（SDK 原文）： The data array will be written to the GenData array starting from the configured start index, up to and including ECAMEnd[tableNum] or the GenData array's last index, whichever comes first. A range that starts below the GenData array's first index is rejected without writing anything. Make sure the data array size matches the configured table range.

    ECAM_Start¶

    bool ECAM_Start(int tableNum = 1)

    ECAM_Start 让从轴按指定的表开始跟随主轴；之后移动主轴，从轴就跟着动。ECAM_Stop 结束凸轮运动，ECAM_IsActive 判断是否正在凸轮运动，ECAM_GetCycleCount 读已完成的循环次数。

    启动、停止与状态

    SDK 说明： Start ECAM motion with specified table.

    参数 类型 方向 默认值 说明
    tableNum int 输入（值传递） 1 凸轮表编号，1–10（C# 可省略，默认 1；C 必须给出）

    返回类型： bool

    返回说明： Returns true if ECAM motion started successfully, otherwise false.

    ECAM_Start / ECAM_Stop 命令被接受返回 true；ECAM_IsActive 运动中返回 true；ECAM_GetCycleCount 返回次数。

    补充说明（SDK 原文）： Before starting ECAM motion, ensure that: 1. ECAM table is properly configured with ECAM_ConfigureTable 2. ECAM table data is set with ECAM_SetTableData 3. Master axis is properly configured This writes ECAMTableNum, sets MotionMode to 7 (ECAM direct), writes MotorOn = 1, and then sends Begin. A refused Begin leaves the axis enabled; turn the motor off explicitly if the motion did not start.

    ECAMMaster¶

    AAValueArray<double> ECAMMaster { get; }

    SDK 说明： Composite CAN code of the master source for each ECAM table. Bits 0-9 carry the keyword's CAN code, bits 10-14 the master axis (0 = axis A) and bits 16-31 the array index. A bare 2 therefore means axis A's Pos, not Pos on any axis. Use MotionController.GetKeywordCANCode to resolve a keyword on a chosen axis; PCSuite's ECAM master picker writes the same code.

    对应关键字、单位与取值说明

    访问： get;

    值类型： AAValueArray<double>
