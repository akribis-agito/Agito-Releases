CNCAEncRatio 

This parameter is axis-related and should be set individually for each member axis.


It defines the ratio between the resolution of one axis and other axes, used for more accurate CNC motion calculation when member axes have inconsistent physical resolutions.


Currently, this parameter is reserved for future use.

int CNCAEncRatio { get; set; }

Property Value

int

CNCAPercents 

Scale factor for user adjustment of speed (and acceleration/deceleration) along the CNC path.


By affecting speed and acceleration/deceleration, CNCAPercents actually influences the time required to complete CNC motion.


CNCAPercents can be greater than 100% and can be dynamically adjusted at any time.


Users should consider the value of CNCAPercents before starting CNC motion.

int CNCAPercents { get; set; }

Property Value

int

CNCAPosRef

CNCAPosRef represents the expected position along the CNC path (starting from zero, reaching CNCAAbsTrgt at the end of the motion segment).

int CNCAPosRef { get; }

Property Value

int

CNCAStatus 

Containing CNC-related status data. The meaning of each index is as follows:


Index 1: Oldest command


Index 2: Last pushed command


Index 3: Last segment command


Index 4: Total number of parameters in the last segment


Index 5: Last segment requires multiple parameters to be pushed


Index 6: Motion segment input


Index 7: Available space


Index 8: Last used ID


Index 9: ID in motion


Index 10: CNC FIFO motion status

<ul><li>BIT_0: CNC in motion</li><li>BIT_3: CNC stop request issued</li><li>BIT_4: CNC accelerating</li><li>BIT_5: CNC decelerating</li><li>BIT_6: CNC waiting for end smoothing</li><li>BIT_9: CNC waiting for input</li><li>BIT_12: CNC in CNC stop state</li><li>BIT_13: CNC waiting for first segment</li><li>BIT_14: CNC controlled stop request issued</li></ul>

Index 11: CNC FIFO member axes


Index 12: CNC FIFO involved axes


Index 13: Maximum acceleration counter


Index 14: Maximum velocity fluctuation counter


When the status is invalid, its value is -1 (when the status is valid, -1 is not a valid value for any status).

AAValueArray<int> CNCAStatus { get; }

Property Value

AAValueArray<int>
