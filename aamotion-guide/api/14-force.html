    力控与电流控制¶

    压装、按压测试这类应用需要控制力而不是位置。典型流程：快速接近 → 换速慢速接近 → 到达阈值后切换到力控（或电流控制）→ 按力指令曲线保持 → 回退。这一组函数把各步参数写进控制器，切换在控制器里按阈值自动完成，不依赖通信速度。

    先在 PCSuite 中调好

    力控的参数（力传感器的模拟输入、PID、阈值）和具体机械相关。请先在 PCSuite 的力控工具中调好并验证，再把参数用到程序中。下面示例中的数值只说明调用方式。

    各参数的含义见关键字 力控运行模式 和 电流运行模式。

    切换控制模式¶

    立即把轴切换到力控、电流控制或位置控制。和下面的自动切换不同，这里是程序直接发命令切换。当前模式可以读 OperationMode（见枚举）。

    独立小 Demo：切换控制模式

    什么时候用

    在程序中直接切换控制模式（例如测试电流环）。

    函数原型

    // AAMotionAPI
// Switch to force control mode
// controller: 控制器对象 / 句柄
// axis: 一个轴
// 返回值: Returns true if switched successfully, otherwise false
static bool GoToForceMode(MotionController controller, AxisRef axis);

// Switch to current mode
// controller: 控制器对象 / 句柄
// axis: 一个轴
// 返回值: Returns true if switched successfully, otherwise false
static bool GoToCurrMode(MotionController controller, AxisRef axis);

// Switch to position mode
// controller: 控制器对象 / 句柄
// axis: 一个轴
// 返回值: Returns true if switched successfully, otherwise false
static bool GoToPosMode(MotionController controller, AxisRef axis);

// ISingleAxis
// Switch to force control mode.
// 返回值: Returns true if switched to force control mode successfully, otherwise false.
bool GoToForceMode();

// Switch to current control mode.
// 返回值: Returns true if switched to current control mode successfully, otherwise false.
bool GoToCurrMode();

// Switch to position control mode.
// 返回值: Returns true if switched to position control mode successfully, otherwise false.
bool GoToPosMode();

    // Switches the axis to force control.
// controller: 控制器对象 / 句柄
// axis: 一个轴
bool aamotion_go_to_force_mode(aamotion_controller controller, int axis);

// Switches the axis to current control.
// controller: 控制器对象 / 句柄
// axis: 一个轴
bool aamotion_go_to_curr_mode(aamotion_controller controller, int axis);

// The force_curr_set_* calls return nothing: failures reach the error callback only. Switches the axis to position control.
// controller: 控制器对象 / 句柄
// axis: 一个轴
bool aamotion_go_to_pos_mode(aamotion_controller controller, int axis);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    axis AxisRef / int 一个轴

    实际发送的命令

    {Axis}GoToForceMode

    返回值

    命令被接受返回 true。

    示例

    AAMotionAPI.GoToForceMode(c, AxisRef.A);   // force loop
AAMotionAPI.GoToCurrMode(c, AxisRef.A);    // current loop only
AAMotionAPI.GoToPosMode(c, AxisRef.A);     // back to position control

    aamotion_go_to_force_mode(h, AAMOTION_AXIS_REF_A);
aamotion_go_to_curr_mode(h, AAMOTION_AXIS_REF_A);
aamotion_go_to_pos_mode(h, AAMOTION_AXIS_REF_A);
aamotion_set_position(h, AAMOTION_AXIS_REF_A, 0);      /* counts */

    力控流程参数¶

    函数 写入的关键字 作用
    ForceCurr_SetMotion MotionMode=1、AbsTrgt、RelTrgt、Speed… 接近运动
    ForceCurr_SetSlowApproach SpeedChgNew、SpeedChgPos、SpeedChgDir、SpeedChgOn 到某位置后换慢速
    ForceCurr_SetCurrModeSWTrigSrc CurrPosTh、CurrPosThDir、ForcePosErrTh、ForceAInTh 切换到力 / 电流控制的触发条件
    ForceCurr_SetForceCmdSource ForceCmdSrc、ForceCmdSlope[]、ForceCmdVal[]、ForceCmdHTime[] 力指令曲线：每段的斜率、目标值、保持时间
    ForceCurr_SetForceTunePID ForceGain、ForceKi、ForceKd、ForceFFW、ForceVelFFW 力环参数
    ForceCurr_SetRetractMotion RetractTarget、RetractSpeed、BeginOnToPos 完成后的回退
    ForceCurr_SetPosThForAutoSwToPosMode PosPosFlag、PosPosTh 自动切回位置控制的条件

    写好参数后 Begin 开始整个流程。C# 中可选参数不传时不写对应关键字；C 中每个参数都会写入。

    独立小 Demo：压装流程

    什么时候用

    压装、按压测试、恒力接触：接近、换力控、保持、回退整套流程在控制器里自动完成。

    函数原型

    // AAMotionAPI
// Set force control motion parameters
// controller: 控制器对象 / 句柄
// axis: 一个轴
// absTrgt: 接近运动的绝对目标
// relTrgt: 相对目标（0 表示用绝对目标）
// speed: 接近速度
// accel: 加速度
// decel: 减速度
static void ForceCurr_SetMotion(MotionController controller, AxisRef axis, double absTrgt, double? relTrgt = null, double? speed = null, double? accel = null, double? decel = null);

// Set slow approach parameters
// controller: 控制器对象 / 句柄
// axis: 一个轴
// speedChgNew: 换速后的慢速
// speedChgPos: 换速位置
// speedChgDir: 穿过换速点的方向：0 正向，1 反向
// speedChgOn: 1 启用换速
static void ForceCurr_SetSlowApproach(MotionController controller, AxisRef axis, double speedChgNew, double speedChgPos, int speedChgDir, int speedChgOn);

// Set current mode software trigger source parameters
// controller: 控制器对象 / 句柄
// axis: 一个轴
// currPosTh: 切换到力 / 电流控制的位置阈值
// currPosThDir: 阈值的方向
// forcePosErrTh: 按位置误差切换的阈值（可选）
// forceAInTh: 按模拟输入（力传感器）切换的阈值（可选）
static void ForceCurr_SetCurrModeSWTrigSrc(MotionController controller, AxisRef axis, double currPosTh, int currPosThDir, double? forcePosErrTh = null, double? forceAInTh = null);

// Set force control command source parameters
// controller: 控制器对象 / 句柄
// axis: 一个轴
// forceCmdSrc: 力指令来源
// forceCurrSlope: 各段的斜率
// forceCmdHTime: 各段的保持时间
// forceCmdVal: 各段的力指令值
static void ForceCurr_SetForceCmdSource(MotionController controller, AxisRef axis, int forceCmdSrc, double[] forceCurrSlope, int[] forceCmdHTime, double[] forceCmdVal);

// Set force control debug PID parameters
// controller: 控制器对象 / 句柄
// axis: 一个轴
// fForceGain: 力环增益（可选）
// fForceKi: 力环积分（可选）
// fForceKd: 力环微分（可选）
// fForceFFW: 力前馈（可选）
// fForceVelFFW: 速度前馈（可选）
static void ForceCurr_SetForceTunePID(MotionController controller, AxisRef axis, double? fForceGain = null, double? fForceKi = null, double? fForceKd = null, double? fForceFFW = null, double? fForceVelFFW = null);

// Set retract motion parameters
// controller: 控制器对象 / 句柄
// axis: 一个轴
// fRetractTarget: 回退目标位置
// fRetractSpeed: 回退速度
// fBeginOnToPos: 回退开始的条件（可选）
static void ForceCurr_SetRetractMotion(MotionController controller, AxisRef axis, double fRetractTarget, double fRetractSpeed, int? fBeginOnToPos = null);

// Set threshold parameters for automatic switch to position mode
// controller: 控制器对象 / 句柄
// axis: 一个轴
// posPosFlag: 自动切回位置控制的方式
// posPosTh: 切回位置控制的阈值
static void ForceCurr_SetPosThForAutoSwToPosMode(MotionController controller, AxisRef axis, int posPosFlag, double posPosTh);

// ISingleAxis
// Set force/current motion parameters.
// absTrgt: 接近运动的绝对目标
// relTrgt: 相对目标（0 表示用绝对目标）
// speed: 接近速度
// accel: 加速度
// decel: 减速度
void ForceCurr_SetMotion(double absTrgt, double? relTrgt = null, double? speed = null, double? accel = null, double? decel = null);

// Set slow approach parameters for force control.
// speedChgNew: 换速后的慢速
// speedChgPos: 换速位置
// speedChgDir: 穿过换速点的方向：0 正向，1 反向
// speedChgOn: 1 启用换速
void ForceCurr_SetSlowApproach(double speedChgNew, double speedChgPos, int speedChgDir, int speedChgOn);

// Set software trigger source for current mode.
// currPosTh: 切换到力 / 电流控制的位置阈值
// currPosThDir: 阈值的方向
// forcePosErrTh: 按位置误差切换的阈值（可选）
// forceAInTh: 按模拟输入（力传感器）切换的阈值（可选）
void ForceCurr_SetCurrModeSWTrigSrc(double currPosTh, int currPosThDir, double? forcePosErrTh = null, double? forceAInTh = null);

// Set force/current command source: writes `ForceCmdSrc`, then element `i + 1` of `ForceCmdSlope`, `ForceCmdVal` and `ForceCmdHTime` for each array element.
// forceCmdSrc: 力指令来源
// forceCurrSlope: 各段的斜率
// forceCmdHTime: 各段的保持时间
// forceCmdVal: 各段的力指令值
// 返回值: True once every value is written; a refused write throws.
bool ForceCurr_SetForceCmdSource(int forceCmdSrc, double[] forceCurrSlope, int[] forceCmdHTime, double[] forceCmdVal);

// Set force control PID parameters.
// fForceGain: 力环增益（可选）
// fForceKi: 力环积分（可选）
// fForceKd: 力环微分（可选）
// fForceFFW: 力前馈（可选）
// fForceVelFFW: 速度前馈（可选）
void ForceCurr_SetForceTunePID(double? fForceGain = null, double? fForceKi = null, double? fForceKd = null, double? fForceFFW = null, double? fForceVelFFW = null);

// Set retract motion parameters. In force control mode, retract motion is a special motion to return to the target position using position mode.
// fRetractTarget: 回退目标位置
// fRetractSpeed: 回退速度
// fBeginOnToPos: 回退开始的条件（可选）
void ForceCurr_SetRetractMotion(double fRetractTarget, double fRetractSpeed, int? fBeginOnToPos = null);

// Automatically switch to position mode at position threshold. (Force control protection function)
// posPosFlag: 自动切回位置控制的方式
// posPosTh: 切回位置控制的阈值
void ForceCurr_SetPosThForAutoSwToPosMode(int posPosFlag, double posPosTh);

    // Sets the force/current motion: absolute or relative target, speed, acceleration and deceleration.

// axis: 一个轴

// currPosThDir: 阈值的方向

// Sets the force/current command source: writes ForceCmdSrc, then element i+1 of ForceCmdSlope, ForceCmdVal and ForceCmdHTime for each i. @param forceCurrSlope, forceCmdHTime, forceCmdVal arraySize elements each (slope, hold time, command value).

// forceCurrSlope: 各段的斜率

    设定当前位置¶

    把当前位置设为指定值（SetPosition），不产生运动。常用于不回零时直接定义零点，或在力控结束后重新定义坐标。

    独立小 Demo：设定当前位置

    什么时候用

    不回零直接定义零点；或者力控结束后重新定义坐标。

    函数原型

    // AAMotionAPI
// Set the current position of the axis
// controller: 控制器对象 / 句柄
// axis: 一个轴
// value: 新的位置，**计数**，不按用户单位换算
// 返回值: Returns true if set successfully, otherwise false
static bool SetPosition(MotionController controller, AxisRef axis, double value);

// ISingleAxis
// Set the current position. Resets the current position to the specified value. `ISingleAxis.Pos`
// value: 新的位置，**计数**，不按用户单位换算
// 返回值: Returns true if the position is set successfully, otherwise false.
bool SetPosition(double value);

    // Redefines the current position as value without moving (SetPosition). @param value In the units Pos reads in: position User Units when enabled, otherwise counts.
// controller: 控制器对象 / 句柄
// axis: 一个轴
// value: 新的位置，**计数**，不按用户单位换算
bool aamotion_set_position(aamotion_controller controller, int axis, double value);

    参数

    参数 类型 说明 写入的关键字
    controller MotionController / aamotion_controller 控制器对象 / 句柄 —
    axis AxisRef / int 一个轴 —
    value double 新的位置，计数，不按用户单位换算 SetPosition

    实际发送的命令

    {Axis}SetPosition={value}

    返回值

    成功返回 true。

    注意

    • 在启用了用户单位的轴上，把 a.Pos 读到的值（用户单位）直接写回 SetPosition 不会得到同一个位置，要先换算成计数。

    示例

    // declare the current position to be 0; the value is in counts, never User Units
AAMotionAPI.SetPosition(c, AxisRef.A, 0);

    aamotion_go_to_force_mode(h, AAMOTION_AXIS_REF_A);
aamotion_go_to_curr_mode(h, AAMOTION_AXIS_REF_A);
aamotion_go_to_pos_mode(h, AAMOTION_AXIS_REF_A);
aamotion_set_position(h, AAMOTION_AXIS_REF_A, 0);      /* counts */
    SDK 原文注释（英文）
    • SetPosition(MotionController, AxisRef, double) — Set the current position of the axis Returns: Returns true if set successfully, otherwise false {Axis}SetPosition={value} See ISingleAxis.SetPosition for the units contract.
    • SetPosition(double) — Set the current position. Resets the current position to the specified value. ISingleAxis.Pos Returns: Returns true if the position is set successfully, otherwise false. The actual command sequence sent to the back end: {Axis}SetPosition={value} The controller lists this parameter in its position User Units group, so the argument is scaled exactly like ISingleAxis.Pos: SetPosition(Pos) is a round trip, and a value finer than one count is rounded to the nearest count. With MotionController.UseUserUnits set to false, both are in counts.
    • aamotion_set_position — Redefines the current position as value without moving (SetPosition). @param value In the units Pos reads in: position User Units when enabled, otherwise counts.
