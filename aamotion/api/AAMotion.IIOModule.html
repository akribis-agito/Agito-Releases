Properties

AInDB 

Analog input deadband (unit: mV).


If the input voltage is between (-AInDB) and AInDB, the reading is 0;


If it exceeds AInDB, the reading is (actual voltage - AInDB);


If it is below (-AInDB), the reading is (actual voltage + AInDB).


- Old firmware (int type): Integer deadband values in millivolts.


- New firmware (float type): Float deadband values in millivolts.


Returns dynamic type to support both int (old firmware) and float (new firmware).

AInFilt[i] determines the filter coefficient for the i-th analog input.

AInPort 

Read-only array containing processed and raw values of analog input ports.


The first half: processed values (filtered, offset, deadband, gain applied) for each channel;


The second half: raw input values for each channel (unprocessed).


- Old firmware (int type): Integer values representing raw ADC counts.


- New firmware (float type): Float values representing actual voltage/processed values.


Returns dynamic type to support both int (old firmware) and float (new firmware).

AOutMode 

AOutMode determines the parameter monitored by each analog output channel.


AOutMode[i] specifies the parameter reflected by the i-th analog output.


The structure of AOutMode (32-bit integer):


- Bits 0~9 (LSB, 10 bits): CAN code of the parameter


- Bits 10~12 (3 bits): Axis number (0 is the first axis)


- Bits 16~31 (16 bits): Array index (ignored if not used)

AOutShifts 

Analog output shift factor.


AOutShifts[i] is used to adjust the dynamic range of the i-th analog output (in conjunction with the parameter monitored by AOutMode).


If AOutShifts is negative, right shift (divide by 2 to the power of |AOutShifts|); if positive, left shift (multiply by 2 to the power of AOutShifts).

DOutMode 

Digital output mode configuration array. Each element defines the special function of the corresponding output point.


Value and function:


0  - Normal output (controlled by DOutPort)


1  - Dedicated hardware function (not used)


2  - Servo enable (reflects MotorOn status)


3  - In motion (reflects MotionStat status)


4  - Accelerating (reflects MotionStat acceleration bit, only valid in built-in analyzer mode)


5  - Decelerating (reflects MotionStat deceleration bit, only valid in built-in analyzer mode)


6  - Constant speed (reflects MotionStat constant speed bit, only valid in built-in analyzer mode)


7  - Motion end (not used)


8  - Target reached (reflects InTargetStat=4)


9  - Fault/alarm (reflects ConFlt status)


10 - Last motion warning (not used)


11 - Last motion saturation (not used)


12 - RLS/FLS active (reflects LimitsStat status)


13 - Out of travel (RevPLim, FwdPLim)


14 - Regeneration active


15 - Dynamic brake active


16 - Motor brake active (can be used with DInMode[i]=13)


If multiple outputs are assigned the same special function, the output with the higher number has priority.
