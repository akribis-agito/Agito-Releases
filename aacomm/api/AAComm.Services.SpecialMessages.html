AAComm.dll
Centralized constants for controller command/parameter mnemonic strings.


These are the bare mnemonics — the axis prefix (e.g. 'A') is added at the call site.


Example usage: <code>$"A{SpecialMessages.About}"</code> sends the About command for axis A.
