    DataLogger（高速数据记录）¶

    控制器内置的数据记录器（示波器）在控制周期里采样，最快每个周期一次（约 0.061 ms），记录在控制器内存中，结束后上传。和 PCSuite 的示波器是同一个功能。

    步骤 C# C
    查询容量 GetDataRecordingCapacity aamotion_data_rec_capacity
    一次完成：配置、启动、等待、上传 RecordData aamotion_data_rec_record
    分步：配置并启动 ConfigureDataLogger —
    等待结束 WaitForDataRecordingToEnd —
    上传 UploadDataLoggerData* aamotion_data_rec_info / _vector_* / _time
    保存 CSV GenerateCsvFile 自己写文件

    可同时记录的参数个数和总样本数由控制器决定：每个参数最多 maxArraySize / 参数个数 个样本。

    一次完成的记录¶

    按配置启动记录，等待触发和记录结束，然后上传，返回每个参数的数据和时间轴。C 版本把结果保存在句柄里，再用 _info、_vector_info、_vector_values、_time 取出。

    触发类型（RecTrigTyp）：

    值 触发条件
    0 立即触发
    1 / 2 / 3 / 4 源值大于 / 等于 / 不等于 / 小于 触发值
    5 / 6 源值上升越过 / 下降跌破 触发值
    7 只能手动触发（ForceDataLoggerTrigger）
    8 源值与记录开始时不同
    9 / 10 源值在 / 不在 (Value, MaxValue) 范围内
    11 / 12 源值进入 / 离开 (Value, MaxValue) 范围

    独立小 Demo：记录一次运动

    什么时候用

    调试和验证运动性能：一次运动的位置、误差、速度曲线。

    函数原型

    // MotionController
// Convenience method to perform a complete recording cycle: configure, start, wait, and upload.
// config: 记录配置：`ParamsToRecord`（如 `"APos"`、`"AVel[1]"`）、`DurationSec`、`GapMs`、`TriggerPosition`（触发前数据占的百分比，默认 20）、`Trigger`（null 表示立即记录）
// result: 记录结果：`Vectors`（每个参数的名称、CAN 编号、数值）、`TimeSec`（时间轴）、`RecGap`、`RecLength`
// forceTrigger: 启动后立即强制触发
// timeoutMs: 等待记录结束的超时，毫秒
// 返回值: Error string if failed, empty string on success
string RecordData(MotionController.DataLoggerConfiguration config, out MotionController.DataLoggerResult result, bool forceTrigger = false, uint timeoutMs = 10000);

// Generates a CSV file and saves all recorded DataLogger data.
// result: 记录结果：`Vectors`（每个参数的名称、CAN 编号、数值）、`TimeSec`（时间轴）、`RecGap`、`RecLength`
// filePath: CSV 文件路径或目录；目录时自动生成带时间的文件名；空则用当前目录
// 返回值: The generated CSV file full path
static string GenerateCsvFile(MotionController.DataLoggerResult result, string filePath = null);

    // Configures, starts, waits for and uploads one recording. @param parameters Comma-separated names, e.g. "APos,ASpeed,AMotorCurr". @param durationSec Recording length in seconds. @param gapMs Sampling interval in milliseconds (typically at least 0.061). @param triggerPosition 1..100: the percentage of the recording before the trigger. @param triggerType 0 none, 1 greater than, 2 equal, 3 not equal, 4 smaller than, 5 rising edge, 6 falling edge, 7 forced, 8 on change. @param triggerSource The parameter watched, e.g. "APos"; NULL or "" records at once. @param triggerValue Threshold. @param triggerMask Bits of the source compared; -1 for all. @param forceTrigger true to trigger at once after starting. @param timeoutMs How long to wait for the recording to finish.
// controller: 控制器对象 / 句柄
// parameters: C：逗号分隔的参数名，如 `"APos,AVel[1]"`
// durationSec: 记录时长，秒
// gapMs: 采样间隔，毫秒
// triggerPosition: 触发前数据的百分比（1–100）
// triggerType: 触发类型，见上表
// triggerSource: 触发源参数，如 `"AMotionStat"`；NULL 或空字符串表示立即记录
// triggerValue: 触发值
// triggerMask: 触发源的位掩码，0 表示不屏蔽
// forceTrigger: 启动后立即强制触发
// timeoutMs: 等待记录结束的超时，毫秒
bool aamotion_data_rec_record(aamotion_controller controller, const char* parameters, double durationSec, double gapMs, int triggerPosition, int triggerType, const char* triggerSource, double triggerValue, int triggerMask, bool forceTrigger, unsigned int timeoutMs);

// The shape of the last recording: *recLength, *recGap, *vectorCount parameters and *sampleCount time points.
// controller: 控制器对象 / 句柄
// recLength: 每个参数的样本数
// recGap: 采样间隔（周期数）
// vectorCount: 参数个数
// sampleCount: 时间轴的样本数
bool aamotion_data_rec_info(aamotion_controller controller, int* recLength, int* recGap, int* vectorCount, int* sampleCount);

// Name, CAN code and sample count of one recorded parameter. @param vectorIndex From 0.
// controller: 控制器对象 / 句柄
// vectorIndex: 参数序号，从 0 开始
// name: 参数名缓冲区
// nameSize: 缓冲区字节数
// canCode: 参数的 CAN 编号
// valueCount: 这个参数的样本数
bool aamotion_data_rec_vector_info(aamotion_controller controller, int vectorIndex, char* name, int nameSize, int* canCode, int* valueCount);

// Copies one parameter's samples into values. All or nothing: *copied always receives the parameter's length, and a maxValues below it writes nothing and returns false, so a short buffer is never mistaken for a shorter recording. Size the buffer from aamotion_data_rec_vector_info's valueCount.
// controller: 控制器对象 / 句柄
// vectorIndex: 参数序号，从 0 开始
// values: 接收样本的数组
// maxValues: 数组容量
// copied: 实际样本数（总是返回长度；容量不足时不复制并返回 false）
bool aamotion_data_rec_vector_values(aamotion_controller controller, int vectorIndex, double* values, int maxValues, int* copied);

// Copies the time axis, in seconds, into seconds; same all-or-nothing rule. Size the buffer from aamotion_data_rec_info's sampleCount.
// controller: 控制器对象 / 句柄
// seconds: 接收时间轴（秒）的数组
// maxValues: 数组容量
// copied: 实际样本数（总是返回长度；容量不足时不复制并返回 false）
bool aamotion_data_rec_time(aamotion_controller controller, double* seconds, int maxValues, int* copied);

    参数

    参数 类型 说明
    config MotionController.DataLoggerConfiguration 记录配置：ParamsToRecord（如 "APos"、"AVel[1]"）、DurationSec、GapMs、TriggerPosition（触发前数据占的百分比，默认 20）、Trigger（null 表示立即记录）
    result MotionController.DataLoggerResult 记录结果：Vectors（每个参数的名称、CAN 编号、数值）、TimeSec（时间轴）、RecGap、RecLength
    forceTrigger bool 启动后立即强制触发
    timeoutMs uint / unsigned int 等待记录结束的超时，毫秒
    filePath string CSV 文件路径或目录；目录时自动生成带时间的文件名；空则用当前目录
    controller aamotion_controller 控制器对象 / 句柄
    parameters const char* C：逗号分隔的参数名，如 "APos,AVel[1]"
    durationSec double 记录时长，秒
    gapMs double 采样间隔，毫秒
    triggerPosition int 触发前数据的百分比（1–100）
    triggerType int 触发类型，见上表
    triggerSource const char* 触发源参数，如 "AMotionStat"；NULL 或空字符串表示立即记录
    triggerValue double 触发值
    triggerMask int 触发源的位掩码，0 表示不屏蔽
    recLength int* 每个参数的样本数
    recGap int* 采样间隔（周期数）
    vectorCount int* 参数个数
    sampleCount int* 时间轴的样本数
    vectorIndex int 参数序号，从 0 开始
    name char* 参数名缓冲区
    nameSize int 缓冲区字节数
    canCode int* 参数的 CAN 编号
    valueCount int* 这个参数的样本数
    values double* 接收样本的数组
    maxValues int 数组容量
    copied int* 实际样本数（总是返回长度；容量不足时不复制并返回 false）
    seconds double* 接收时间轴（秒）的数组

    返回值

    C# RecordData 成功返回空字符串，失败返回错误说明；C 版本成功返回 true。

    注意

    • 数组关键字必须带下标（"AVel[1]"），否则控制器回复 ERR 24。
    • C 的 _vector_values / _time 是“全部或不复制”：缓冲区不够时不写入并返回 false，copied 仍给出所需长度。

    示例

    var cfg = new MotionController.DataLoggerConfiguration
{
    DurationSec = 0.5,          // 0.5 s of data
    GapMs = 0.25,               // one sample every 0.25 ms
    TriggerPosition = 10,       // 10 % of the buffer before the trigger
    Trigger = new MotionController.DataLoggerTrigger
    {
        Type = 5,               // RecTrigTyp 5: rising edge above Value
        Source = "AMotionStat", // watch axis A's motion status
        Value = 0,            // fires when the axis starts moving
    },
};
cfg.ParamsToRecord.Add("APos");
cfg.ParamsToRecord.Add("AVel[1]");      // an array keyword needs its index
cfg.ParamsToRecord.Add("APosErr");

// configure, start, wait for the trigger and the end, upload
// start a move shortly after the recording is armed, so the trigger has something to catch
System.Threading.Tasks.Task.Delay(200).ContinueWith(_ => c.GetAxis(AxisRef.A).MoveRel(50000, 20000));
string err = c.RecordData(cfg, out MotionController.DataLoggerResult result, false, 5000);
if (err.Length > 0) { Console.WriteLine("recording failed: " + err); return; }

foreach (MotionController.DataLoggerVector v in result.Vectors)
    Console.WriteLine($"{v.Parameter}: {v.Values.Count} samples");
string csv = MotionController.GenerateCsvFile(result, @"C:\data");   // timestamped file name

    /* 0.5 s every 0.25 ms; trigger: rising edge of AMotionStat above zero (RecTrigTyp 5), 10 % pre-trigger */
if (!aamotion_data_rec_record(h, "APos,AVel[1],APosErr", 0.5, 0.25, 10, 5, "AMotionStat", 0, 0, false, 5000))
{
    fprintf(stderr, "recording failed (see the error hook)\n");
    return;
}
int recLength, recGap, vectors, samples;
aamotion_data_rec_info(h, &recLength, &recGap, &vectors, &samples);

double* t = malloc(sizeof(double) * samples);
double* v = malloc(sizeof(double) * samples);
int copied;
aamotion_data_rec_time(h, t, samples, &copied);
for (int k = 0; k < vectors; ++k)
{
    char name[64];
    int can, count;
    aamotion_data_rec_vector_info(h, k, name, sizeof name, &can, &count);
    if (count <= samples && aamotion_data_rec_vector_values(h, k, v, samples, &copied))
        printf("%s: %d samples, first %g at t=%g s\n", name, copied, v[0], t[0]);
}
free(t);
free(v);

    分步记录与上传¶

    先用 ConfigureDataLogger 配置，再用 StartDataRecording 启动。用 GetDataRecordingStatus 查看记录状态，或用 WaitForDataRecordingToEnd 等待记录结束。拿到完整记录后再上传。

    见 PCSuite DataLogger 控件与参数对照。

    状态值 含义
    0 无有效记录
    1 正在填充预触发数据
    2 预触发区已填满，等待触发
    3 已触发，正在采集
    4 完整采集，正常结束
    5 采集中被停止
    6 触发前被停止
    C# 上传接口 何时使用
    UploadDataLoggerData 一次性上传，期间占用通信。适合数据量小或固件不支持分包时。
    UploadDataLoggerDataNonblocking 分包上传，其他命令可在包之间穿插。调用方仍会等到上传结束或超时。
    StartUploadDataLoggerDataNonblocking 后台分包上传，通过回调收结果。适合调用方需要立即继续工作的场合。

    采集过程中可用 GetDataLoggerTotalDataCount 查询总量，用 ReadDataLoggerIncrementalData(out int dataCount) 查询控制器报告的增量计数。该重载只返回计数和错误文本，波形值由上传接口提供。

    独立小 Demo：立即记录并上传

    什么时候用

    记录期间程序还要做别的事；或者需要边记录边读取。

    函数原型

    // MotionController
// Configures a data recording session; `MotionController.StartDataRecording` starts it.
// config: 记录配置
// 返回值: Error string if failed, empty string on success
string ConfigureDataLogger(MotionController.DataLoggerConfiguration config);

// Starts data recording. AGD155 and AGD155-EC require RecStart[1] command syntax (firmware v2.3+).
// 返回值: Error string if failed, empty string on success
string StartDataRecording();

// Stops data recording.
// 返回值: Error string if failed, empty string on success
string StopDataRecording();

// Forces a trigger event manually (for testing or immediate triggering).
// 返回值: Error string if failed, empty string on success
string ForceDataLoggerTrigger();

// Waits for recording to complete.
// timeoutMs: 超时，毫秒
// 返回值: Error string if failed, empty string on success
string WaitForDataRecordingToEnd(uint timeoutMs = 10000);

// Gets the current recording status (ARecStat[1] or ARecStat for AGD155). A status below 4 is a recording that is not complete (armed on its trigger, or running); 4 and above is complete and its data can be uploaded. `MotionController.WaitForDataRecordingToEnd` polls on that boundary.
// status: 记录状态
// 返回值: Error string if failed, empty string on success
string GetDataRecordingStatus(out int status);

// Gets the maximum data recording capacity information from the controller.
// maxVectors: 最多同时记录的参数个数
// maxArraySize: 所有参数的样本总数上限
// 返回值: Error string if failed, empty string on success
string GetDataRecordingCapacity(out int maxVectors, out int maxArraySize);

// Uploads the recorded data from the controller.
// result: 记录结果
// 返回值: Error string if failed, empty string on success
string UploadDataLoggerData(out MotionController.DataLoggerResult result);

// Non-blocking upload: Uploads recorded data using the RecUploadNext protocol. Unlike `MotionController.UploadDataLoggerData`, this method does not block the communication channel, instead receiving data in sequential packets, allowing other commands to be interleaved. Suitable for multi-controller parallel upload scenarios, greatly improving overall throughput.
// result: 记录结果
// progressCallback: 进度回调：已收到的样本数
// timeoutMs: 超时，毫秒
// 返回值: Error string if failed, empty string on success
string UploadDataLoggerDataNonblocking(out MotionController.DataLoggerResult result, Action<int> progressCallback = null, int timeoutMs = 10000);

// Asynchronous non-blocking upload: Uploads recorded data using the RecUploadNext protocol. Fully asynchronous version, suitable for maximum concurrency scenarios. On completion, triggers OnUploadRecData event; On error, triggers OnError event.
// onComplete: 完成回调
// progressCallback: 进度回调：已收到的样本数
// onError: 出错回调
// timeoutMs: 超时，毫秒
// 返回值: True if upload started successfully, false if failed (check error events)
bool StartUploadDataLoggerDataNonblocking(Action<MotionController.DataLoggerResult> onComplete = null, Action<int> progressCallback = null, Action<string> onError = null, int timeoutMs = 10000);

// Reads incremental data from the controller (ARecDataA[3]). This is used for streaming data reading while recording is in progress.
// dataCount: 数据量
// 返回值: Error string if failed, empty string on success
string ReadDataLoggerIncrementalData(out int dataCount);

// Gets the total available data count (ARecDataA[1]).
// dataCount: 数据量
// 返回值: Error string if failed, empty string on success
string GetDataLoggerTotalDataCount(out int dataCount);

    // Records chosen parameters at a fixed interval into the controller's buffer, then uploads them. The result stays on the session; the accessors read the LAST recording. Reads the recorder's limits: *maxVectors parameters at once, and *maxArraySize samples in total (parameters x samples per parameter must stay within it).
// controller: 控制器句柄
// maxVectors: 最多同时记录的参数个数
// maxArraySize: 所有参数的样本总数上限
bool aamotion_data_rec_capacity(aamotion_controller controller, int* maxVectors, int* maxArraySize);

    参数

    参数 类型 说明
    config MotionController.DataLoggerConfiguration 记录配置
    timeoutMs int / uint 超时，毫秒
    status int 记录状态
    maxVectors int* / int 最多同时记录的参数个数
    maxArraySize int* / int 所有参数的样本总数上限
    result MotionController.DataLoggerResult 记录结果
    progressCallback Action<int> 进度回调：已收到的样本数
    onComplete Action<MotionController.DataLoggerResult> 完成回调
    onError Action<string> 出错回调
    dataCount int 数据量
    controller aamotion_controller 控制器句柄

    返回值

    返回字符串的方法成功时返回空字符串，失败时返回错误说明；StartUploadDataLoggerDataNonblocking 启动成功返回 true。

    注意

    • 使用运动等事件触发时，先确认状态为 2，再发出会触发采样的动作。预触发缓冲区未填满时，事件可能被忽略。
    • WaitForDataRecordingToEnd 把 4、5、6 都视为记录已结束。业务要求完整采集时，再读状态并确认是 4。
    • 两种分包接口都要求固件支持 RecUploadNext。提示不支持时使用 UploadDataLoggerData。
    • AGD155 / AGD155-EC 的命令格式不同（RecStart[1]、RecStat 不带下标），SDK 会自动处理。

    示例

    var cfg = new MotionController.DataLoggerConfiguration { DurationSec = 1, GapMs = 1 };
cfg.ParamsToRecord.Add("APos");
string err = c.ConfigureDataLogger(cfg);
if (!string.IsNullOrEmpty(err)) { Console.WriteLine(err); return; }
err = c.StartDataRecording();
if (!string.IsNullOrEmpty(err)) { Console.WriteLine(err); return; }
err = c.WaitForDataRecordingToEnd(3000);
if (!string.IsNullOrEmpty(err)) { Console.WriteLine(err); return; }
err = c.GetDataRecordingStatus(out int status);
if (!string.IsNullOrEmpty(err)) { Console.WriteLine(err); return; }
if (status != 4) { Console.WriteLine($"Recording stopped, status {status}"); return; }

err = c.UploadDataLoggerData(out MotionController.DataLoggerResult result);
if (!string.IsNullOrEmpty(err)) { Console.WriteLine(err); return; }
Console.WriteLine($"{result.Vectors[0].Values.Count} samples");

    int maxVectors, maxArraySize;
if (aamotion_data_rec_capacity(h, &maxVectors, &maxArraySize))
    printf("up to %d parameters, %d samples in total\n", maxVectors, maxArraySize);

    • WaitForDataRecordingToEnd(uint) — Waits for recording to complete. Returns: Error string if failed, empty string on success

Returns: Error string if failed, empty string on success Maximum recording length per parameter = maxArraySize / number_of_parameters For example: if maxArraySize = 100000 and you record 3 parameters, maximum RecLength per parameter = 100000 / 3 ≈ 33333 data points
    • UploadDataLoggerData(MotionController.DataLoggerResult) — Uploads the recorded data from the controller. Returns: Error string if failed, empty string on success
    • UploadDataLoggerDataNonblocking(MotionController.DataLoggerResult, Action<int>, int) — Non-blocking upload: Uploads recorded data using the RecUploadNext protocol. Unlike MotionController.UploadDataLoggerData, this method does not block the communication channel, instead receiving data in sequential packets, allowing other commands to be interleaved. Suitable for multi-controller parallel upload scenarios, greatly improving overall throughput. Returns: Error string if failed, empty string on success
    • StartUploadDataLoggerDataNonblocking(Action<MotionController.DataLoggerResult>, Action<int>, Action<string>, int) — Asynchronous non-blocking upload: Uploads recorded data using the RecUploadNext protocol. Fully asynchronous version, suitable for maximum concurrency scenarios. On completion, triggers OnUploadRecData event; On error, triggers OnError event. Returns: True if upload started successfully, false if failed (check error events)
    • ReadDataLoggerIncrementalData(int) — Reads incremental data from the controller (ARecDataA[3]). This is used for streaming data reading while recording is in progress. Returns: Error string if failed, empty string on success
    • GetDataLoggerTotalDataCount(int) — Gets the total available data count (ARecDataA[1]). Returns: Error string if failed, empty string on success
    • aamotion_data_rec_capacity — Records chosen parameters at a fixed interval into the controller's buffer, then uploads them. The result stays on the session; the accessors read the LAST recording. Reads the recorder's limits: *maxVectors parameters at once, and *maxArraySize samples in total (parameters x samples per parameter must stay within it).
