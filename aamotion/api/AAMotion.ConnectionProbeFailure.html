ControllerError = 3

The reply is an error: the controller's ERR, or one the SDK reported for the command.

InvalidReply = 4

The reply is not a number.

None = 0

The controller answered.

NotConnected = 1

The link was down before the probe, so nothing was sent, or it was torn down while the probe waited, by something other than the probe's own timeout.

Timeout = 2

No reply within the timeout. Like any command timeout, one that reached the controller tears the connection down; one that expired still queued behind other commands was never sent and leaves it up.
