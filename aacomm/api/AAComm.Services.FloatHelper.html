Central floating-point resolution for hardware-uploaded data.


Controller parameters may be transmitted as bit-masked int/long values representing IEEE 754 float/double.


This class resolves those raw values to their correct floating-point representation.

ResolveFloatingPoint(MessageData, long, bool, bool) 

Resolves raw integer/long values to their correct floating-point representation.


When doubleSupported, both float and double params are 64-bit encoded (LongToDouble).


When !doubleSupported and floatSupport, float params use 32-bit encoding (IntToFloat).


floatSupport is false for AllStat_64bit protocols that have no 32-bit float encoding.

public static double ResolveFloatingPoint(MessageData md, long val, bool doubleSupported, bool floatSupport)
