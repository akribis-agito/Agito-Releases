    Demo¶

    One small project per function, in C#, C++ and Python: open samples/single/csharp/AAMotionDemos.sln for C#, "Open a local folder" on samples/single/cpp in Visual Studio for C++, and run the scripts in samples/single/python for Python. The target is at the top of each program; the default is the controller IP 172.1.1.101.
