Enum LongOperationType

Namespace
AAComm.Shared
Assembly
AAComm.dll

Identifies controller operations that freeze firmware for a significant duration, used by OnLongOperationStarted / OnLongOperationEnded to bracket the busy window.

public enum LongOperationType

Fields

EventCorrect = 4

Event-table correction (AEventCorrect) — runs the controller's event-correction pass.

Load = 2

Load from non-volatile memory (ALoad) — restores the parameter set from controller flash.

Reset = 0

Controller reset (AReset) — reboots the controller; firmware is unresponsive through the reboot and the post-reset recovery window.

Save = 1

Save to non-volatile memory (ASave) — persists the active parameter set to controller flash.

SaveUser = 3

Save user program (ASaveUser) — persists the downloaded user program and its variables to controller flash.
