    CNC 插补¶

    CNC 让 2–3 个轴沿直线和圆弧组成的路径协调运动。程序先把一段段路径（段）写进控制器的缓冲区，再 Begin 启动；控制器按段连续执行，每段的终点速度决定段与段之间是否停下。

    概念 说明
    组 CNC 组 A（c.GetGroup(AxisRef.A)）或组 B；AAMotionAPI 和 C 接口的静态函数都使用组 A
    坐标 X、Y、Z 分别是组里的 A、B、C 轴
    单位 段的位置、速度都是整数计数，不按用户单位换算
    速度 每段给出巡航速度 velCruise 和终点速度 velEnd；velEnd = 0 表示在段末停下
    缓冲区 段可以在运动中继续写入；ClearBuffer 清空

    段的类型见枚举：CNC 段类型，控制器侧的详细机制见关键字 CNC 概述。

    先确认固件支持 CNC¶

    SDK 有 CNC 方法不代表当前控制器固件支持。先在 PCSuite 的 CNC 界面配置相同轴组、确认换相和使能，以低速运行一段允许范围内的直线。检查是否能下载并执行、坐标方向与终点是否正确。若 PCSuite 也提示不支持或命令被拒绝，先核对型号、固件和 CNC 功能，再运行本章的 Demo；普通点位能运动不能证明 CNC 可用。

    从一条直线到连续路径¶

    1. 确认参与轴都已先换相再使能，路径起点与机械位置一致，核对轴组映射与单位。SetStartPositions 设置路径起点，不是让轴自动移动到起点。
    2. 停止旧任务后清理旧缓冲区，设置起点及 SetMotionProfile 的倍率、加减速与平滑参数。不要在仍执行旧路径时清空缓冲区。
    3. 先下载一个小范围 LinearAbsoluteXY，末端速度设 0；核对各终点参数、velCruise 和 velEnd。逐段检查发送结果/异常，下载失败时不要继续 Begin。
    4. Begin 启动已下载路径；段写入成功或 Begin 返回不等于路径完成。带超时轮询 IsCNCCompleted，同时保存错误报告；超时请求组 Stop 并核对实际状态。
    5. 单直线验收后再加入圆弧和连续段。圆弧的终点、绝对圆心、平面和方向必须一致，先在 PCSuite/仿真中验证方向。非零 velEnd 用于连续段衔接，最后一段设 0；转角能力仍受固件轨迹规则约束。

    与多轴点位批量启动不同，CNC 由控制器按路径协调各轴。PC 端轮询只观察结果，不承担插补。详见本章 Demo。

    首段规则与圆弧排查¶

    推段方式¶

    每个推段函数都用普通命令推一段，与 PCSuite 相同：先发 CNCAPushType 加段头，再为每个字段发一条 CNCAPushParam（组 B 为 CNCBPush…）。参数不按用户单位换算。某条命令被拒绝时推段中止，触发错误钩子，函数返回 false；这时段已打开但没有写完，之后的推段都会被拒绝，直到 ClearBuffer。

    启动前确认运动模式¶

    参与轴的 MotionMode 应与 CNC 组一致。CNCA 用 11，CNCB 用 17。普通 Begin 按控制器当前模式执行，调用 SDK 的 CNC Begin 不会替你切换模式。先结束旧运动，再更改模式。

    第一段怎样写¶

    • 使用 SetStartPositions 时，它必须是空队列里的第一条，连 SetMotionProfile 也要排在后面。这条只声明路径起点。XY 路径选择 X、Y 两轴，填入两轴实际的当前坐标。
    • 省略 SetStartPositions 时，首个运动段必须是直线。直接把圆弧放在最前面可能得到 ERR 139。直线目标要和起点有实际距离。
    • ERR 140 表示起点设置放错位置。 ERR 141 检查起点所选轴是否与运动组吻合。 ERR 142 检查轴是否已经到达所声明的起点。需要先定位时，在写 CNC 路径前完成定位并确认到位。

    如何算对圆心¶

    下例用绝对终点和绝对圆心。圆弧的起点来自上一段的终点，所以从直线接圆弧时，以直线终点为准。

    项目 XY 坐标（counts）
    直线终点，也是圆弧起点 (50 000, 0)
    预期圆心 (50 000, 50 000)
    圆弧终点 (100 000, 50 000)
    传给 ArcXY 的 iPos、jPos (50 000, 50 000)

    圆心正下方是起点，正右方是终点，两边的半径都是 50 000 counts。按 PCSuite 约定用 dir = 0 逆时针走四分之一圈。从 G 代码转换时，把 I、J 分别加到本段起点，得到 SDK 所需的绝对圆心。半径不一致会报 ERR 143。

    一段失败之后怎样处理¶

    • 在默认连续性规则下，圆弧后接 Delay 或等待输入，须把圆弧的 velEnd 设为 0。不同轴组合之间也可能需要在前一段以 0 结束，否则下一段可能因 ERR 204 被拒绝。
    • 半径、距离和速度校验失败时，固件可能已写入部分数据。离线下发整条路径时，任何一段失败都应停止下发。确认组已停，再清缓冲区并从首段重建。
    • Begin 成功但轴没动时，检查 CNC 状态字。组 A 的 CNCAStatus[10] 位 13 表示等待首个运动段。确认队列中有完整且可执行的运动段，然后核对轴组、使能和相关错误。

    启动、暂停、停止与清空¶

    Begin 开始执行缓冲区中的段（AAMotionAPI.Begin(c) 不带轴的重载就是 CNC 启动）；Pause 沿路径减速并保持在路径上，Resume 从原处继续；GroupStop / Stop 停止 CNC 运动；ClearBuffer 清空尚未执行的段。开始写新路径前先 ClearBuffer。

    速度曲线、拐角与起点¶

    这些也是写进缓冲区的段，在执行到它们时生效，所以可以在路径中途改变设置：

    • 'SetMotionProfile：速度百分比、加速度、减速度、平滑系数。'
    • 'SetCornerParams / AutoCorner：拐角的处理方式（圆角半径或允许误差、最小角度、加速度限制），AutoCorner 在当前两轴直线段和下一段之间插入平滑圆弧。'
    • 'SetStartPositions：路径的起点坐标；SetCurrPositions：把当前位置设为指定坐标。'
    • 'SetMaxVelJumpParams / SetMaxAccelParams：各轴允许的最大速度跳变和最大加速度，用于限制拐角处的冲击。'

    什么时候用

    调整整条路径的速度和拐角效果，减少拐角处的冲击和过切。

    路径上的动作¶

    在路径中间插入动作段，执行到这里时由控制器完成，时刻准确：延时（Delay）、写数字输出（整口或按位掩码）、写 GenData / UserParam、等待 GenData / UserParam 满足条件后再继续（和用户程序同步），以及一次写多个值。

    运行 CNC 程序文件¶

    RunCNCProgramFromFile 读取 PCSuite CNC 工具生成的程序文件，按文件顺序下发命令。IsCNCCompleted 实时读取 CNC 状态字的运动位，位 0 清零时返回 true。启动前、正常结束、停止或中断之后都有可能读到 true。要确认整条路径成功执行，还要检查下发结果、运行期间的错误以及末端位置。
