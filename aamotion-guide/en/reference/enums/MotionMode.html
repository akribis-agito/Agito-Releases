    Motion mode MotionMode¶

    Keyword MotionMode, how Begin moves the axis. AAMotion's motion functions set it for you; when you send raw commands, set it before Begin.
    C# type AAMotion.MotionMode
    C type aamotion_motion_mode_t
    Keyword MotionMode
    To text EnumPropertyHelper.GetMotionModeDes(int) · aamotion_get_motion_mode_des()

    Read and decode¶

    int v = (int)c.GetValue(AxisRef.A, eKeyword.MotionMode);
MotionMode e = (MotionMode)v;
string text = EnumPropertyHelper.GetMotionModeDes(v);

    double v;
if (aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_MOTION_MODE, 0, &v)) {
    char text[256];
    aamotion_get_motion_mode_des((int)v, text, sizeof text);
    printf("%d: %s\n", (int)v, text);
}

    v = int(am.get_value(h, am.AXIS_A, am.KEYWORD_MOTION_MODE))
print(v, am.describe("motion_mode", v))
    Value C# name C constant Meaning Run-time text
    0 Jog AAMOTION_MOTION_MODE_JOG Jog motion The motor will accelerate to reach the constant speed specified by Speed and maintain at such speed until Stop command is received. The jog direction is determined by the sign of Speed keyword. Related keywords: Speed, Accel, Decel, JerkMode, JerkInAcc, JerkInDec Jog: The motor moves continuously at the speed set by Speed until a Stop command is received. Acceleration and deceleration are controlled by Accel and Decel, and can be smoothed by Jerk.
    1 PTP AAMOTION_MOTION_MODE_PTP Point to point motion If RelTrgt = 0, axis moves to the position defined by AbsTrgt. Otherwise, axis moves relative to the initial position according to RelTrgt. The motion profile generated will stay within the maximum kinematic limits of Speed, Accel, Decel, and optionally JerkInAcc and JerkInDec. Related keywords: RelTrgt, AbsTrgt, Speed, Accel, Decel, JerkMode, JerkInAcc, JerkInDec PTP: Point-to-point motion, moves to the position specified by RelTrgt or AbsTrgt (if RelTrgt=0, then AbsTrgt). Parameters are controlled by Accel, Speed, Decel, and Jerk.
    2 PTPRepeat AAMOTION_MOTION_MODE_PTPREPEAT Point to point repetitive motion If RelTrgt = 0, axis moves to the position defined by AbsTrgt and then moves back to the initial position. Otherwise, axis moves relative to the initial position according to RelTrgt and then moves back to the initial position. Repetitive motion will continue indefinitely until either StopRep is commanded or RptCounter equals to user defined RptCycles. Axis will dwell for RptWait in between each motion. The motion profile generated will stay within the maximum kinematic limits of Speed, Accel, Decel, and optionally JerkInAcc and JerkInDec. Related keywords: RelTrgt, AbsTrgt, Speed, Accel, Decel, JerkMode, JerkInAcc, JerkInDec PTP Repeat: Reciprocating motion between current and target position, waits RptWait time at each end, use StopRep to stop.
    3 PulseDirDirect AAMOTION_MOTION_MODE_PULSE_DIR_DIRECT Pulse and direction (PD) motion – direct mode Axis will follow the profile generated from the pulse-direction inputs. Please refer to Motion mode – Pulse and direction for more information. Pulse/Direction Direct Mode: Position loop reference is directly from pulse/direction input.
    4 PulseDirIndirect AAMOTION_MOTION_MODE_PULSE_DIR_INDIRECT Pulse and direction (PD) motion - indirect mode Axis will follow the second order profile generated from the pulse-direction inputs, subject to limitations by the specified acceleration and speed values. Please refer to Motion mode – Pulse and direction for more information. Pulse/Direction Indirect Mode: Pulses are accumulated to the target, the analyzer generates a smooth trajectory according to Accel, Decel, Speed, and Jerk.
    5 GearDirect AAMOTION_MOTION_MODE_GEAR_DIRECT Gear motion – direct mode Axis will follow the profile which tracks proportionally to the master variable. Please refer to Motion mode – Gear motion for more information. Gear Direct Motion
    6 GearIndirect AAMOTION_MOTION_MODE_GEAR_INDIRECT Gear motion – indirect mode Axis will follow the second order motion profile (subject to limitations by the specified acceleration and speed values), where the generated profile tracks proportionally to the change in master variable. Please refer to Motion mode – Gear motion for more information. Gear Indirect Motion
    7 ECAMDirect AAMOTION_MOTION_MODE_ECAMDIRECT Electronic cam (ECAM) motion - direct mode Axis will undergo perpetual relative motion, in which the relative position reference (relative to its initial position upon the Begin command) depends on a master variable. The relative position reference is obtained at every controller cycle from a customisable array that maps to a user-defined and evenly spaced master position range. It is analogous to mechanical cam-follower motion. Please refer to Motion mode – ECAM motion for more information. ECAM Direct Motion
    8 ECAMIndirect AAMOTION_MOTION_MODE_ECAMINDIRECT Electronic cam (ECAM) motion - indirect mode This motion mode is reserved for internal use. ECAM Indirect Motion
    9 FIFOMotion AAMOTION_MOTION_MODE_FIFOMOTION FIFO motion FIFO Motion
    10 FollowerPositionReference AAMOTION_MOTION_MODE_FOLLOWER_POSITION_REFERENCE Direct slave motion Axis A's position reference is driven directly from the change in axis B's position reference each control cycle, scaled by the configured MasterFact / MasterFactDen ratio. This is a separate, narrower mechanism from gear motion (it does not use GearMaster, MasterPos or MasterFilt). Available on multi-axis builds only. Please refer to MotionMode10 for more information. Follower Position Reference
    11 CNCGroupA AAMOTION_MOTION_MODE_CNCGROUP_A CNCA motion CNC Group A Motion
    12 JoystickDirectPosition AAMOTION_MOTION_MODE_JOYSTICK_DIRECT_POSITION Joystick position direct mode Joystick Direct Motion (analog signal as position reference)
    13 JoystickIndirectPosition AAMOTION_MOTION_MODE_JOYSTICK_INDIRECT_POSITION Joystick position indirect mode Joystick Indirect Motion (analog signal as position reference, analyzer customizable)
    14 JoystickDirectSpeed AAMOTION_MOTION_MODE_JOYSTICK_DIRECT_SPEED Joystick velocity direct mode Joystick Direct Motion (analog signal as speed reference)
    15 JoystickIndirectSpeed AAMOTION_MOTION_MODE_JOYSTICK_INDIRECT_SPEED Joystick velocity indirect mode Joystick Indirect Motion (analog signal as speed reference, analyzer customizable)
    16 VectorMotion AAMOTION_MOTION_MODE_VECTOR_MOTION Vector motion Vector Motion
    17 CNCGroupB AAMOTION_MOTION_MODE_CNCGROUP_B CNCB motion CNC Group B Motion
    18 SplineBufferMotion AAMOTION_MOTION_MODE_SPLINE_BUFFER_MOTION Spline buffer Spline Buffer Motion
    19 FIFOPositionTracking AAMOTION_MOTION_MODE_FIFOPOSITION_TRACKING FIFO position tracking FIFO Position Tracking: the axis follows the position targets pushed into its position-tracking FIFO, one every FIFOPosCycle samples
    20 SinePTP AAMOTION_MOTION_MODE_SINE_PTP Sine PTP: single point-to-point motion on a sinusoidal acceleration profile, driven by Speed, Accel, Decel, JerkInAcc and JerkInDec Sine PTP: point-to-point motion on a sinusoidal acceleration profile
    21 SinePTPRepeat AAMOTION_MOTION_MODE_SINE_PTPREPEAT Sine PTP repeat: reciprocating motion on a sinusoidal acceleration profile, stopped with StopRep Sine PTP Repeat: reciprocating motion on a sinusoidal acceleration profile
    22 PVAJ AAMOTION_MOTION_MODE_PVAJ PVAJ: the axis follows its PVAJList, one position, velocity, acceleration and jerk per point; Begin is refused until the list has passed PVAJValidate PVAJ: the axis follows its validated and armed PVAJ list of position, velocity, acceleration and jerk
    23 MultiAxisPVAJ AAMOTION_MOTION_MODE_MULTI_AXIS_PVAJ Multi-axis PVAJ: Begin starts every axis in this mode as one group, each on its own PVAJList, and is refused unless every member is armed and motor on Multi-axis PVAJ: Begin starts every armed axis in this mode as one group, each on its own PVAJ list

    "Run-time text" is what EnumPropertyHelper.GetMotionModeDes returns.
