    错误处理¶

    控制器拒绝一条命令时回复 ERR n；SDK 在发送前就发现问题时（参数越界、未连接、超时等）报 PC Suite: ERR n。两种错误都会：

    1. 调用错误钩子（C# 的 ErrorOccurred 事件 / C 的回调），参数是错误码、发出去的命令和格式化好的说明；
    2. 让这次调用失败：C# 抛 ControllerCommandException（返回 bool 的方法返回 false），C 函数返回 false（返回 int 的函数返回 0）。

    每个错误码的说明见附录：错误码。用仿真器或故障注入测试错误路径，见仿真器。

    错误钩子与 try/catch 怎么选¶

    两者是互补的错误处理机制，不是两种错误钩子。注册 ErrorOccurred 用于集中记录错误码、命令和说明，也能接收后台报告；try/catch 处理当前 C# 调用抛出的异常并决定中断、清理或返回。返回 bool 的调用还必须检查 false；返回错误字符串的调用必须检查其约定。外层 try/catch 不能捕获后台回调或另一线程的异常。推荐注册钩子，同时在调用边界检查返回值、捕获实际会抛出的异常。C ABI 不把 .NET 异常传播给 C/C++，按返回值和回调处理。

    错误钩子¶

    注册 / 取消一个函数，控制器（或 SDK）报告错误时调用它。建议连接前就注册：连接过程中的错误也会报告。一个程序里集中记录错误日志，最方便的就是这个钩子。

    有两种钩子，覆盖同样的错误：

    • ErrorOccurred（C：aamotion_set_error_occurred_handler）：错误码、发出去的命令和格式化好的说明。
    • ErrorReported（C：aamotion_set_error_reported_handler）：紧跟在 ErrorOccurred 之后、在同一线程上触发，错误码相同，另外说明错误来自哪里（枚举：错误来源：应用自己的调用、发送前的检查、快速读缓存的后台读取），以及失败命令对应的轴和关键字。C# 的 ControllerErrorEventArgs 还带有命令和说明、应用调用的 AAMotion 成员（Method，例如 SingleAxis.MoveAbs 或 SingleAxis.Speed (set)）、Timestamp、ThreadId 和 Controller。C 回调只收到错误码、来源、轴和关键字；说明文字仍来自 aamotion_error_occurred_cb。Method、Timestamp、ThreadId 和 Controller 只有 C# 提供。

    独立小 Demo：错误钩子

    什么时候用

    每个程序都应该挂 ErrorOccurred：集中记录所有错误，界面上显示最近的错误。连接之前就挂上。需要按调用、轴或来源分类错误时再加 ErrorReported。

    函数原型

    // AAMotionAPI
// Raised when a communication error occurs on the specified controller.
// controller: 控制器对象 / 句柄
// handler: C# 处理函数。`ErrorOccurred`：`(errorCode, messageSent, errorMessage)`，错误码、发出去的命令、格式化好的说明（多行，用 `\n` 分隔）。`ErrorReported`：`EventHandler<ControllerErrorEventArgs>`，`sender` 是这个控制器。取消时必须传同一个委托实例。
static void SetErrorOccurredHandler(MotionController controller, Action<int, string, string> handler);

// Remove the error occurred handler from the specified controller.
// controller: 控制器对象 / 句柄
// handler: C# 处理函数。`ErrorOccurred`：`(errorCode, messageSent, errorMessage)`，错误码、发出去的命令、格式化好的说明（多行，用 `\n` 分隔）。`ErrorReported`：`EventHandler<ControllerErrorEventArgs>`，`sender` 是这个控制器。取消时必须传同一个委托实例。
static void ClearErrorOccurredHandler(MotionController controller, Action<int, string, string> handler);

// Add a handler to `MotionController.ErrorReported`: every controller error, with the AAMotion member that was called, the axis and parameter, where it came from, and when.
// controller: 控制器对象 / 句柄
// handler: C# 处理函数。`ErrorOccurred`：`(errorCode, messageSent, errorMessage)`，错误码、发出去的命令、格式化好的说明（多行，用 `\n` 分隔）。`ErrorReported`：`EventHandler<ControllerErrorEventArgs>`，`sender` 是这个控制器。取消时必须传同一个委托实例。
static void SetErrorReportedHandler(MotionController controller, EventHandler<ControllerErrorEventArgs> handler);

// Remove a handler from `MotionController.ErrorReported`.
// controller: 控制器对象 / 句柄
// handler: C# 处理函数。`ErrorOccurred`：`(errorCode, messageSent, errorMessage)`，错误码、发出去的命令、格式化好的说明（多行，用 `\n` 分隔）。`ErrorReported`：`EventHandler<ControllerErrorEventArgs>`，`sender` 是这个控制器。取消时必须传同一个委托实例。

// Event triggered when an error occurs. Event parameters include error code, sent command, and error message.
event Action<int, string, string> ErrorOccurred;

// Raised for every error `MotionController.ErrorOccurred` is raised for, right after it, on the same thread and with the same code, command and text, plus which AAMotion member the application called, the axis and parameter the command names, where the error came from, and when and on which thread it was raised (`ControllerErrorEventArgs`). The sender is this controller.
event EventHandler<ControllerErrorEventArgs> ErrorReported;

// callback: C 回调。`aamotion_error_occurred_cb` 为 `void (*)(int errorCode, const char* message, const char* exception, void* user)`：`message` 是发出去的命令，`exception` 是说明（英文）。`aamotion_error_reported_cb` 为 `void (*)(int errorCode, int source, int axis, int keyword, void* user)`。

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    handler Action<int, string, string> / EventHandler<ControllerErrorEventArgs> C# 处理函数。ErrorOccurred：(errorCode, messageSent, errorMessage)，错误码、发出去的命令、格式化好的说明（多行，用 \n 分隔）。ErrorReported：EventHandler<ControllerErrorEventArgs>，sender 是这个控制器。取消时必须传同一个委托实例。
    callback aamotion_error_occurred_cb / aamotion_error_reported_cb C 回调。aamotion_error_occurred_cb 为 void (*)(int errorCode, const char* message, const char* exception, void* user)：message 是发出去的命令，exception 是说明（英文）。aamotion_error_reported_cb 为 void (*)(int errorCode, int source, int axis, int keyword, void* user)。
    user void* 用户指针，SDK 在每次回调时原样传回；不需要时传 NULL。在可能仍在执行的回调返回之前，它指向的内容要保持有效。

    注意

    • 回调在引发错误的线程上执行：控制器对你的命令回复 ERR 时，回调就在你的线程上、在那次调用内部同步执行；快速读缓存的后台读取会在后台线程上触发。不要假定它在界面线程，界面代码可以用 ThreadId 判断是否需要 Invoke。回调中记录信息并尽快返回，不做耗时等待。
    • 处理函数抛出的异常会传给调用方，ErrorOccurred 和 ErrorReported 都是如此。不订阅 ErrorReported 的程序不需要为它付出任何开销。
    • C# 的说明语言由 LocaleProvider.Instance.Locale 决定（"zh-CN" 或 "en-US"）；C 接口固定是英文。
    • C 回调收到的字符串只在回调期间有效，要保存请复制。
    • 每个句柄每种 C 回调只有一个，再次注册会替换前一个。aamotion_clear_* 和 aamotion_release 不会等待另一线程上正在执行的回调，回调用到的资源要等它返回后再释放。

    示例

    LocaleProvider.Instance.Locale = "zh-CN";   // descriptions in Chinese; "en-US" for English

Action<int, string, string> onError = (code, sent, text) =>
    Console.WriteLine($"[ERR {code}] {sent} | {text.Replace("\n", " | ")}");

AAMotionAPI.SetErrorOccurredHandler(c, onError);   // same as c.ErrorOccurred += onError
// ...
AAMotionAPI.ClearErrorOccurredHandler(c, onError); // the same delegate instance
// the same errors as ErrorOccurred, with the AAMotion member that was called
EventHandler<ControllerErrorEventArgs> onReport = (sender, e) =>
    Console.WriteLine($"[{e.Source}] {e.Method ?? "-"} {e.Axis} {e.Keyword}: ERR {e.ErrorCode} {e.Command}");

AAMotionAPI.SetErrorReportedHandler(c, onReport);   // same as c.ErrorReported += onReport
// ...
AAMotionAPI.ClearErrorReportedHandler(c, onReport);

    static char g_last_error[512];

/* called on the SDK's thread; the strings are valid only during the call */
static void on_error(int code, const char* message, const char* exception,
                     void* user)
{
    (void)user;   /* the pointer passed to aamotion_set_error_occurred_handler */
    snprintf(g_last_error, sizeof g_last_error, "ERR %d | %s | %s",
             code, message ? message : "", exception ? exception : "");
    fprintf(stderr, "%s\n", g_last_error);
}

void example_hook(aamotion_controller h)
{
    aamotion_set_error_occurred_handler(h, on_error, NULL);
    /* ... */
    aamotion_clear_error_occurred_handler(h);
}
/* where each error came from; the text arrives through the error-occurred callback */
static void on_error_reported(int code, int source, int axis, int keyword,
                              void* user)
{
    (void)user;
    if (source == AAMOTION_CONTROLLER_ERROR_SOURCE_FAST_READ_REFRESH)
        printf("ERR %d in a cache refresh (axis %d, keyword %d)\n",
               code, axis, keyword);
}

void example_error_reported(aamotion_controller h)
{
    aamotion_set_error_reported_handler(h, on_error_reported, NULL);
    /* ... */
    aamotion_clear_error_reported_handler(h);
}

    • ClearErrorOccurredHandler(MotionController, Action<int, string, string>) — Remove the error occurred handler from the specified controller.
    • ErrorOccurred() — Event triggered when an error occurs. Event parameters include error code, sent command, and error message.
    • SetErrorReportedHandler(MotionController, EventHandler<ControllerErrorEventArgs>) — Add a handler to MotionController.ErrorReported: every controller error, with the AAMotion member that was called, the axis and parameter, where it came from, and when.
    • ClearErrorReportedHandler(MotionController, EventHandler<ControllerErrorEventArgs>) — Remove a handler from MotionController.ErrorReported.
    • ErrorReported() — Raised for every error MotionController.ErrorOccurred is raised for, right after it, on the same thread and with the same code, command and text, plus which AAMotion member the application called, the axis and parameter the command names, where the error came from, and when and on which thread it was raised (ControllerErrorEventArgs). The sender is this controller. The member is read from the call stack only when this event has a handler, so an application that does not subscribe pays nothing for it. With AAMotionConfig.FastReadEnabled on, the cache's background reads raise it on their own threads (ControllerErrorEventArgs.Source); UI code marshals to its thread. An exception a handler throws reaches the caller, as one from an MotionController.ErrorOccurred handler does.
    • aamotion_set_error_occurred_handler — Installs the error callback for this session, replacing any previous one. Install it right after aamotion_initialize: a controller ERR otherwise shows up only as a false return.
    • aamotion_clear_error_occurred_handler — Removes the error callback.

    失败的调用¶

    在 C# 里，读写属性（如 a.MotorOn = 1）和返回数值的方法在控制器拒绝时抛 ControllerCommandException。它的 ErrorCode 是控制器的 ERR 编号；不是控制器回复的失败（超时、断线等）为 ControllerCommandException.NoControllerCode（-1）。Command 是发出的命令，Keyword 是对应的关键字。不想处理异常时，读取可以用 TryGetValue，失败返回 false，原因在 LastReadError。C 接口里每个函数都用返回值表示成功与否，再从错误钩子拿到具体原因。

    独立小 Demo：捕获被拒绝的命令

    独立小 Demo：安全读取

    什么时候用

    在 C# 中，需要知道某一步为什么失败时捕获 ControllerCommandException；只想要成功 / 失败时用 TryGetValue / TryRead。

    注意

    • 发送运动或写入命令后等回复超时，执行结果可能未知。先检查运动状态、目标或写入值，再决定如何恢复。对相对移动或 CNC 追加段直接重发，可能造成重复移动或重复入队。
    • C 里返回 int 的读取函数（aamotion_read_gen_data、aamotion_get_d_in_port 等）失败时返回 0，和真实的 0 无法区分。0 有意义时，改用 aamotion_send_command_string 读，并检查它的返回值。

    示例

    ISingleAxis a = c.GetAxis(AxisRef.A);
try
{
    a.MotorOn = 1;
}
catch (ControllerCommandException ex)
{
    // ErrorCode: the controller's ERR number, or ControllerCommandException.NoControllerCode (-1)
    // when the failure did not come from the controller (timeout, link lost, ...)
    Console.WriteLine($"{ex.Command} refused: ERR {ex.ErrorCode} ({ex.Keyword}) {ex.Message}");
}

    char reply[256];
if (!aamotion_send_command_string(h, "AMotorOn=1", reply, sizeof reply))
{
    /* the hook has already been called with the code and the text */
    fprintf(stderr, "motor on refused: %s\n", g_last_error);
}

    错误码转成文字¶

    把错误码转成说明文字，和错误钩子收到的文字相同。C# 用 LocaleProvider.Instance.GetError(code)，语言跟随 Locale；C 接口返回英文。

    独立小 Demo：错误码转成文字

    什么时候用

    日志里只有错误码，需要给用户显示说明时。

    函数原型

    // Writes the description of a controller error code (the n of "ERR n") into description (UTF-8, truncated on a character boundary, NUL-terminated). Needs no session. @return false for a NULL buffer, a non-positive size or an unknown code.
// errorCode: 错误码（控制器的 ERR 编号，或 SDK 的 PC Suite 错误码）
// description: 接收文字的缓冲区，结果以 NUL 结尾，过长时按字符边界截断
// descriptionSize: 缓冲区字节数
bool aamotion_get_error_description_by_code(int errorCode, char* description, int descriptionSize);

    参数

    参数 类型 说明
    errorCode int 错误码（控制器的 ERR 编号，或 SDK 的 PC Suite 错误码）
    description char* 接收文字的缓冲区，结果以 NUL 结尾，过长时按字符边界截断
    descriptionSize int 缓冲区字节数

    返回值

    成功返回 true。

    示例

    LocaleProvider.Instance.Locale = "zh-CN";
string text = LocaleProvider.Instance.GetError(31);   // the same text the error hook receives
Console.WriteLine("ERR 31: " + text);

    char text[512];
if (aamotion_get_error_description_by_code(31, text, sizeof text))
    printf("ERR 31: %s\n", text);   /* English */
    SDK 原文注释（英文）
    • aamotion_get_error_description_by_code — Writes the description of a controller error code (the n of "ERR n") into description (UTF-8, truncated on a character boundary, NUL-terminated). Needs no session. @return false for a NULL buffer, a non-positive size or an unknown code.
