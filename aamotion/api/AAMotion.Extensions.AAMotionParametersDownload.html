Asynchronously downloads (writes) controller parameters from a .par file.


"Download" in this context follows the PCSuite convention: a local .par file's contents are written to the controller.


Mirrors the PCSuite "Parameters Download" tool: reads the .par file, validates parameters against the connected
controller, then sends each as a SET command.


Ethernet connections use Bulk messages (up to 50 per packet); other channels send one by one.


After successful download, optionally sends "Save" plus per-axis "CalcFilters" to persist parameters to flash.
