    位置事件输出与位置锁存¶

    两个方向相反的硬件功能，都由控制器在每个控制周期里完成，精度不受通信延迟影响：

    功能 方向 典型用途
    PEG 位置事件输出 位置 → 输出脉冲 飞拍时触发相机、激光打标、点胶
    Lock 位置锁存 输入信号 → 记录位置 测量工件边沿、对位、标记检测

    PEG 有三种比较方式（EventType）：单点（0）、等间距（1）、表格（任意位置列表）。每种方式的细节见关键字 EventType。

    单点事件¶

    轴经过 eventBegPos 时输出一个脉冲。函数写好参数后直接使能事件（EventOn=1）。EventEnable / EventDisEnable 单独打开或关闭事件输出。

    独立小 Demo：单点位置事件

    什么时候用

    运动到某一点时输出一个脉冲（触发一次拍照、一次动作）。

    函数原型

// controller: 控制器对象 / 句柄

    实际发送的命令

    {Axis}EventPulseRes={eventPulseRes} (if eventPulseRes is not null)

    返回值

    C# 和 C 版本都没有返回值，失败通过错误钩子报告（C 版本不抛出任何错误）。

    注意

    • C 接口每个参数都会写入，没有“沿用当前值”，脉宽单位和脉宽要传实际值（例如 0 和 50）。
    • 单点事件触发后 EventOn 自动变为 0。再次运行前先回到首个触发点之前，再调用配置函数，或者保留原参数并调用 EventEnable。

    示例

    // one pulse when axis A passes 50000, on the output chosen by eventSelect
AAMotionAPI.SetSingleEventPEG(c, AxisRef.A, eventBegPos: 50000, eventSelect: 1);
AAMotionAPI.MoveAbs(c, AxisRef.A, 100000, 20000);
// ...
AAMotionAPI.EventDisEnable(c, AxisRef.A);

    等间距事件¶

    从 eventBegPos 到 eventEndPos，每隔 eventGap 输出一个脉冲（EventType=1）。正向可用起点 10000、终点 90000、间隔 1000。反向交换起止点并传 -1000。轴从首个触发点前方沿配置方向通过整个窗口时，两种配置都计划输出 81 个脉冲。

    独立小 Demo：等间距位置事件

    什么时候用

    运动中等间距触发（飞拍、等间距打标、扫描）。

    函数原型

// eventEndPos: 最后一个脉冲的位置
// eventSelect: 输出到哪一路（0–7）
// eventPulseRes: 脉宽单位：0 微秒，1 纳秒
// eventPulseWid: 脉宽
static void SetEventFixedGapPEG(MotionController controller, AxisRef axis, double eventBegPos, double eventGap, double eventEndPos, int eventSelect, int? eventPulseRes = null, int? eventPulseWid = null);

// ISingleAxis

// eventBegPos: 第一个脉冲的位置
// eventGap: 脉冲间距

    eventEndPos double 最后一个脉冲的位置 EventEndPos

    eventPulseWid int? / int 脉宽 EventPulseWid

    实际发送的命令

    {Axis}EventPulseRes={eventPulseRes} (if eventPulseRes is not null)
{Axis}EventPulseWid={eventPulseWid} (if eventPulseWid is not null)

{Axis}EventEndPos={eventEndPos}
{Axis}EventSelect={eventSelect}

    注意

    • 有限序列使用 EventAlwaysOn = 0。间隔不能为 0，且方向要指向终点，错误的符号可能在使能时得到 ERR 14。
    • 脉冲间隔约为间距的绝对值除以运动速度。用同一套位置单位计算，再与输出脉宽及相机所需的最短脉冲间隔比较。发生漏拍时同时检查输出路、脉宽单位和信号端实际波形。

    示例

AAMotionAPI.MoveAbs(c, AxisRef.A, 100000, 20000);

    表格事件¶

    普通表格事件（EventType = 2）适合按工件的非等距特征点触发。先停用事件，再按运动方向排列触发位置并写入 EventTable，设置表项的输出路、脉宽及起止下标，最后在首个触发点之前使能。EventCorrect 用于生成校正位置，按实际配置决定使用哪组坐标。

    Central-i 验证点表¶

    AAMotion 的 .NET 工厂 c.CreateEventTableClient('A') 绑定当前连接和轴。使用前确认主控固件报告验证点表能力（Identity[62] 的 0x200 位）、远端驱动镜像受支持、编码器和事件源已调试，并确认 LockEventStat = 1。

    1. LoadAsync 上传、回读并等待控制器确认 Ready。随后调用 ArmAsync。进入 Armed 后，用 WaitForCompletionAsync 确认本次表执行完毕。很短的序列可能在轮询看到 Running 之前就完成。
    2. 正常完成后仍需调用 AbortAsync 并确认 Aborted，再确认释放到 Empty。存在保留错误时，先读取并处理该次错误，再调用对应的 AcknowledgeAsync。
    3. 取消等待或释放客户端只结束上位机操作。控制器端是否停止要单独确认。断线后旧连接上的 Ready 已失效。RecoverAsync 只允许在原连接仍有效且符合接管条件时确认中止。重连后须查明控制器实际状态，不能自动续跑或重发。

    位置锁存¶

    输入信号的边沿到来时，控制器记录下当时的编码器位置：LockCntr 加 1，LockVal 是最近一次的位置，LockValTable / LockTimeTable 依次保存每次的位置和时间。SetLock 设定使能、信号极性和信号源（写 LockEn、LockSrc）。

    实际发送的命令

    {Axis}LockEn={enableLock ? 1 : 0}
{Axis}LockSrc={lockSignalPolarity == 0 ? -lockSource : lockSource}

    注意

    • LockSrc 保存在 Flash 中，断电后保留。锁存表写满时溢出到 B 表（LockValTabB），见关键字页面。
    • 使能后先读一次 LockCntr 作为基线。收到信号后重新读计数，确认有新事件再用 LockVal。高速连续边沿需要读取控制器支持的锁存表，单读 LockVal 只能取得最近一次。
    • 在共享同一硬件引脚的独立驱动上，使能 PEG 会关闭 Lock，反过来也一样。Central-i 远端驱动使用独立硬件时，按对应型号的引脚定义接线。

        Console.WriteLine($"Captured position: {a.LockVal}");
    else
        Console.WriteLine("No new capture.");
}
finally
{
    AAMotionAPI.LockDisEnable(c, AxisRef.A);
}
