    StartSpiralScan¶

    void StartSpiralScan()

    仅适用于与 SDK 内置映射一致的找光固件。两步：先写配置（螺旋扫描用 SpiralConfig，单轴扫描用 SingleAxisConfig），再启动。启动后立即返回，扫描在控制器里进行；轮询结果码，不为 0 后读结果。EmergencyStop 写 AGenData[501]，立即停止并退出找光逻辑。C 接口用完后调用 aamotion_optical_coupling_release 释放句柄（控制器句柄释放时也会一并释放）。

    创建、配置与启动

    SDK 说明： Start the spiral scan light-finding process (2 steps: parameter configuration → start)

    参数： 无。

    返回类型： void

    C# 的配置和启动函数没有返回值；CreateOpticalCouplingLightFinding 返回找光对象。C 的 create 返回句柄，失败返回 NULL；启动函数成功返回 true。

    SDK 说明： Apply spiral scan configuration

    参数 类型 方向 默认值 说明

    ApplySingleAxisConfig¶

    void ApplySingleAxisConfig(SingleAxisConfig config)

    仅适用于与 SDK 内置映射一致的找光固件。两步：先写配置（螺旋扫描用 SpiralConfig，单轴扫描用 SingleAxisConfig），再启动。启动后立即返回，扫描在控制器里进行；轮询结果码，不为 0 后读结果。EmergencyStop 写 AGenData[501]，立即停止并退出找光逻辑。C 接口用完后调用 aamotion_optical_coupling_release 释放句柄（控制器句柄释放时也会一并释放）。

    SyncAllGenData¶

    仅适用于与 SDK 内置映射一致的找光固件。扫描过程中每个采样点的位置和各通道功率保存在 GenData 中：

    数据 螺旋扫描 单轴扫描

    通道 1 功率 6000–8499 4000–6999
    通道 2 功率 8500–10999 7000–9999
    通道 3 功率 11000–13499 10000–12999
    通道 4 功率 13500–15999 13000–15999

    先用 SyncAllGenData 把 GenData 批量读到本地，再用各个 *Array 函数取出需要的区间，比逐个读取快得多。有效长度由结果中的 LastSampleIndex 给出。
