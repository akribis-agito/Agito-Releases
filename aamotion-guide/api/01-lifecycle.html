    初始化与连接¶

    一个程序和控制器打交道的完整生命周期：创建控制器对象 → 连接 → 使用 → 断开 → 释放。C# 里控制器是 MotionController 对象，AAMotionAPI 的静态方法和对象自己的方法做同样的事，选一种风格即可；C 接口里控制器是一个句柄 aamotion_controller。

    这些步骤背后发生了什么，见连接过程。

    检查 ABI 版本¶

    返回原生库的 ABI 版本号。只在接口发生不兼容变化时才增加。程序启动时把它和头文件里的 AAMOTION_ABI_VERSION 比较，不相等说明 aamotion.h 和 aamotion.dll 来自不同版本的 SDK，函数参数可能对不上，应当立即退出。

    什么时候用

    C/C++ 程序启动时第一件事；升级 SDK 后忘了换头文件或库时，它能立刻发现。C# 不需要。

    函数原型

    // The breaking-generation number of this library's C ABI. It changes ONLY on a breaking change (signature, layout, callback or behaviour); additive changes never change it. At load time, require an EXACT match with AAMOTION_ABI_VERSION from aamotion_enums.h.
int32_t aamotion_abi_version(void);

    返回值

    ABI 版本号。与同一 SDK 的头文件中的 AAMOTION_ABI_VERSION 相等。

    示例

    if (aamotion_abi_version() != AAMOTION_ABI_VERSION)
{
    fprintf(stderr, "aamotion.h and the aamotion library are from different SDK versions\n");
    return NULL;
}
aamotion_controller h = aamotion_initialize(AAMOTION_CONTROLLER_TYPE_AGM800);
if (h == NULL)
{
    /* unknown controller type, or AACommServerNative could not be started (is it beside the library?) */
    fprintf(stderr, "initialize failed\n");
    return NULL;
}
    SDK 原文注释（英文）
    • aamotion_abi_version — The breaking-generation number of this library's C ABI. It changes ONLY on a breaking change (signature, layout, callback or behaviour); additive changes never change it. At load time, require an EXACT match with AAMOTION_ABI_VERSION from aamotion_enums.h.

    创建控制器对象¶

    按控制器型号创建控制器对象，并确保本机的 AACommServer 在运行（没有运行就启动它）。这一步还没有连接控制器。每台控制器对应一个对象；同时控制多台控制器就创建多个对象。

    什么时候用

    每台控制器在程序里只调用一次，得到的对象 / 句柄一直用到程序结束。不要每次操作都重新初始化。

    函数原型

    // AAMotionAPI
// Initialize the motion controller
// controllerType: 控制器型号（`ControllerType` / `AAMOTION_CONTROLLER_TYPE_*`），必须和实际连接的控制器一致，连接时会核对。见[枚举：控制器型号](../reference/enums/ControllerType.md)。
// 返回值: Returns the MotionController instance of the corresponding type
static MotionController Initialize(ControllerType controllerType);

    // Creates a session for one controller of the given type and makes sure the shared AACommServer is running. May block a few seconds while the server starts; if the server can never start (missing sidecar, blocked port) the internal retries can block for MINUTES, so call it off any latency-sensitive thread. @param controllerType The controller model; an aamotion_controller_type_t value. @return The session handle, or NULL for an unknown controllerType or when the server could not be started or reached. A non-NULL handle means the server is up, so a later aamotion_connect failure is a connection problem, not an environment one.
// controllerType: 控制器型号（`ControllerType` / `AAMOTION_CONTROLLER_TYPE_*`），必须和实际连接的控制器一致，连接时会核对。见[枚举：控制器型号](../reference/enums/ControllerType.md)。
aamotion_controller aamotion_initialize(aamotion_controller_type_t controllerType);

    参数

    参数 类型 说明
    controllerType ControllerType / aamotion_controller_type_t 控制器型号（ControllerType / AAMOTION_CONTROLLER_TYPE_*），必须和实际连接的控制器一致，连接时会核对。见枚举：控制器型号。

    返回值

    C#：控制器对象。C：控制器句柄；型号无效或服务器无法启动时返回 NULL。

    注意

    • 可能阻塞几秒（启动服务器）；服务器始终无法启动时最坏会阻塞数分钟。图形界面程序不要在界面线程里调用。
    • C 接口返回 NULL 只有两种原因：型号无效，或者服务器起不来（AACommServerNative 不在库旁边、端口被占用）。拿到非 NULL 句柄说明服务器已经在运行，之后连接失败就是网络或控制器的问题。
    • C# 里传入未知型号不会报错，会按 AGD301 创建；服务器启动失败也不会报错（约 3 秒后放弃），要确认服务器在运行可以调用 EnsureAACommServerRunning。

    示例

    MotionController c = AAMotionAPI.Initialize(ControllerType.AGM800);
// c is ready to connect; the AACommServer has been started if it was not running

    if (aamotion_abi_version() != AAMOTION_ABI_VERSION)
{
    fprintf(stderr, "aamotion.h and the aamotion library are from different SDK versions\n");
    return NULL;
}
aamotion_controller h = aamotion_initialize(AAMOTION_CONTROLLER_TYPE_AGM800);
if (h == NULL)
{
    /* unknown controller type, or AACommServerNative could not be started (is it beside the library?) */
    fprintf(stderr, "initialize failed\n");
    return NULL;
}
    SDK 原文注释（英文）
    • Initialize(ControllerType) — Initialize the motion controller Returns: Returns the MotionController instance of the corresponding type
    • aamotion_initialize — Creates a session for one controller of the given type and makes sure the shared AACommServer is running. May block a few seconds while the server starts; if the server can never start (missing sidecar, blocked port) the internal retries can block for MINUTES, so call it off any latency-sensitive thread. @param controllerType The controller model; an aamotion_controller_type_t value. @return The session handle, or NULL for an unknown controllerType or when the server could not be started or reached. A non-NULL handle means the server is up, so a later aamotion_connect failure is a connection problem, not an environment one.

    启动 AACommServer¶

    确保 AACommServer 在运行：没有运行就启动它，已经运行就什么也不做。通常不需要单独调用，Initialize 已经做过；连接仿真器之前要调用一次（仿真连接要求服务器已经就绪）。OpenAACommServer(path) 和 EnsureAACommServerRunning(path) 用指定路径的服务器程序启动，并返回服务器是否已经在监听端口。

    什么时候用

    连接仿真器之前；或者程序要自己指定服务器程序的位置时。连接真机前一般不需要。

    函数原型

    // AAMotionAPI
// Start AACommServer
// controller: 控制器对象 / 句柄
static void Init(MotionController controller);

// Ensures AACommServer is running. If already running, does nothing. Uses the internal default startup method. Every call checks the server's port, so a server that exited after an earlier call is started again.
static void OpenAACommServer();

// Checks if AACommServer is already running; if not, launches it from the specified executable path. Every call checks the server's port, so a server that exited after an earlier call is started again. Delegates to `AAComm.CommAPI.StartAACommServer` — the spawn contract lives there (headless args, its own standard streams, server working directory, socket-ready polling with a child-death probe).
// serverExePath: AACommServer 可执行文件的绝对路径。`EnsureAACommServerRunning` 传空字符串时不启动任何程序，只报告是否已有服务器在运行。
// 返回值: ConnectResult.Success if the server is serving its port; otherwise an error result.
static ConnectResult OpenAACommServer(string serverExePath);

// MotionController
// Opens the AACommServer.
void Init();

// Ensures an AACommServer is serving its port, starting `serverExePath` if none is, and reports whether one is serving when it returns. Readiness is the port, so a server of any build — `AACommServer` or `AACommServerNative` — counts, and a process that has not bound its port yet does not.
// serverExePath: AACommServer 可执行文件的绝对路径。`EnsureAACommServerRunning` 传空字符串时不启动任何程序，只报告是否已有服务器在运行。
// 返回值: True if an AACommServer is serving the port.
bool EnsureAACommServerRunning(string serverExePath);

    // Starts the shared AACommServer if it is not already running.
// controller: 控制器对象 / 句柄
bool aamotion_init(aamotion_controller controller);

// Starts AACommServer unless it is already serving its port. Every call checks the port, so a server that exited after an earlier call is started again. @param serverExePath Full path to the server executable, or NULL for the default location. @return true when the server is serving its port. With NULL the default start cannot report a failure, so false then means only that the call itself failed.
// serverExePath: AACommServer 可执行文件的绝对路径。`EnsureAACommServerRunning` 传空字符串时不启动任何程序，只报告是否已有服务器在运行。
bool aamotion_open_aacomm_server(const char* serverExePath);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    serverExePath const char* / string AACommServer 可执行文件的绝对路径。EnsureAACommServerRunning 传空字符串时不启动任何程序，只报告是否已有服务器在运行。

    返回值

    Init 无返回值（C 版本返回是否成功）。OpenAACommServer(path) 返回 ConnectResult.Success 表示服务器在服务；EnsureAACommServerRunning 返回 true 表示有服务器在监听端口（任何版本的服务器都算）。

    示例

    c.Init();   // start AACommServer if it is not running; does nothing if it is

// or start a specific server executable and know whether it is serving
bool serving = c.EnsureAACommServerRunning(@"C:\MyApp\aacommserver\AACommServer.exe");

    if (!aamotion_init(h))
    fprintf(stderr, "could not start AACommServer\n");
/* start AACommServer once per process; NULL = the default location */
if (!aamotion_open_aacomm_server(NULL))
    printf("starting the server failed\n");

    • Init(MotionController) — Start AACommServer
    • Init() — Opens the AACommServer.
    • OpenAACommServer() — Ensures AACommServer is running. If already running, does nothing. Uses the internal default startup method. Every call checks the server's port, so a server that exited after an earlier call is started again.
    • OpenAACommServer(string) — Checks if AACommServer is already running; if not, launches it from the specified executable path. Every call checks the server's port, so a server that exited after an earlier call is started again. Delegates to AAComm.CommAPI.StartAACommServer — the spawn contract lives there (headless args, its own standard streams, server working directory, socket-ready polling with a child-death probe). Returns: ConnectResult.Success if the server is serving its port; otherwise an error result.
    • EnsureAACommServerRunning(string) — Ensures an AACommServer is serving its port, starting serverExePath if none is, and reports whether one is serving when it returns. Readiness is the port, so a server of any build — AACommServer or AACommServerNative — counts, and a process that has not bound its port yet does not. Returns: True if an AACommServer is serving the port.
    • aamotion_init — Starts the shared AACommServer if it is not already running.
    • aamotion_open_aacomm_server — Starts AACommServer unless it is already serving its port. Every call checks the port, so a server that exited after an earlier call is started again. @param serverExePath Full path to the server executable, or NULL for the default location. @return true when the server is serving its port.     连接控制器¶

    通过以太网连接控制器。连接过程中 SDK 会读取控制器型号（与初始化时的型号核对）、固件版本、命令表和用户单位；同一固件第二次连接时命令表从本机缓存读取，所以更快。不带 IP 的重载连接默认地址 172.1.1.101。

    独立小 Demo：连接与断开

    什么时候用

    连接真实控制器。需要大量读写、回复数据大时，传 fastArk = false 打开立即确认。

    函数原型

    // AAMotionAPI
// Connect to the motion controller, default IP is 172.1.1.101
// controller: 控制器对象 / 句柄
// 返回值: Returns true if connection is successful, otherwise false
static bool Connect(MotionController controller);

// Connect to the motion controller with specified IP
// controller: 控制器对象 / 句柄
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// 返回值: Returns true if connection is successful, otherwise false
static bool Connect(MotionController controller, string deviceAddress);

// controller: 控制器对象 / 句柄
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// fastArk: 名字和效果相反：`true` = **不**开启 PC 端 TCP 立即确认；`false` = 开启。指令多、回复大的场合开启它能明显提速，见 [fastArk](../concepts/connecting.md#fastark)。
static bool Connect(MotionController controller, string deviceAddress, bool fastArk);

// Connect to the motion controller with specified IP and auto-reconnect option
// controller: 控制器对象 / 句柄
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// fastArk: 名字和效果相反：`true` = **不**开启 PC 端 TCP 立即确认；`false` = 开启。指令多、回复大的场合开启它能明显提速，见 [fastArk](../concepts/connecting.md#fastark)。
// enableAutoReconnect: 只是记录下来，**目前不会自动重连**。需要重连时自己调用 `TryReconnect`。
// 返回值: Returns true if connection is successful, otherwise false
static bool Connect(MotionController controller, string deviceAddress, bool fastArk, bool enableAutoReconnect);

// Connect to the motion controller with specified IP, port, and auto-reconnect option
// controller: 控制器对象 / 句柄
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// port: 控制器的以太网端口，默认 50000。
// noAck: 同 `fastArk`：true 不开启立即确认（默认），false 开启。
// enableAutoReconnect: 只是记录下来，**目前不会自动重连**。需要重连时自己调用 `TryReconnect`。
// 返回值: Returns true if connection is successful, otherwise false
static bool Connect(MotionController controller, string deviceAddress, int port, bool noAck = true, bool enableAutoReconnect = false);

// MotionController
// Connects to the controller using an IP address.
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// noAck: 同 `fastArk`：true 不开启立即确认（默认），false 开启。
// enableAutoReconnect: 只是记录下来，**目前不会自动重连**。需要重连时自己调用 `TryReconnect`。
// 返回值: True if connection is successful; otherwise false.
bool Connect(string deviceAddress, bool noAck = true, bool enableAutoReconnect = false);

// Connects to the controller using an IP address and port.
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// port: 控制器的以太网端口，默认 50000。
// noAck: 同 `fastArk`：true 不开启立即确认（默认），false 开启。
// enableAutoReconnect: 只是记录下来，**目前不会自动重连**。需要重连时自己调用 `TryReconnect`。
// 返回值: True if connection is successful; otherwise false.
bool Connect(string deviceAddress, int port, bool noAck = true, bool enableAutoReconnect = false);

    // Connects the session to a controller over Ethernet, serial or CAN. @param deviceAddress The controller's address, e.g. "172.1.1.101". @param fastArk Fast acknowledge mode. @param enableAutoReconnect Recorded but currently has no effect: nothing reconnects on its own; call aamotion_try_reconnect. @return true when connected.
// controller: 控制器对象 / 句柄
// deviceAddress: 控制器 IP 地址，例如 `"172.1.1.101"`。不是合法的 IP 时直接返回 false。
// fastArk: 名字和效果相反：`true` = **不**开启 PC 端 TCP 立即确认；`false` = 开启。指令多、回复大的场合开启它能明显提速，见 [fastArk](../concepts/connecting.md#fastark)。
// enableAutoReconnect: 只是记录下来，**目前不会自动重连**。需要重连时自己调用 `TryReconnect`。
bool aamotion_connect(aamotion_controller controller, const char* deviceAddress, bool fastArk, bool enableAutoReconnect);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    deviceAddress const char* / string 控制器 IP 地址，例如 "172.1.1.101"。不是合法的 IP 时直接返回 false。
    fastArk bool 名字和效果相反：true = 不开启 PC 端 TCP 立即确认；false = 开启。指令多、回复大的场合开启它能明显提速，见 fastArk。
    enableAutoReconnect bool 只是记录下来，目前不会自动重连。需要重连时自己调用 TryReconnect。
    port int 控制器的以太网端口，默认 50000。
    noAck bool 同 fastArk：true 不开启立即确认（默认），false 开启。

    返回值

    连接成功返回 true；失败返回 false，不抛异常。失败原因在错误回调和日志中。

    注意

    • 以太网连接超时 10 秒。图形界面程序请在后台线程里连接。
    • 网络通、但连接返回 false，最常见的原因是控制器型号和 Initialize 时选的不一致。
    • 同一个对象已经连着时不要再连一次；要换地址，先 Disconnect。

    示例

    bool ok = AAMotionAPI.Connect(c, "172.1.1.101");
if (!ok)
{
    Console.WriteLine("Connect failed: check IP, cable, subnet and the AACommServer log");
    return false;
}

// with PC-side TCP immediate ACK enabled (third argument false)
// bool ok2 = AAMotionAPI.Connect(c, "172.1.1.101", false, false);

    /* third argument false: PC-side TCP immediate ACK ON */
bool ok = aamotion_connect(h, "172.1.1.101", false, false);
if (!ok)
    fprintf(stderr, "connect failed: check IP, cable, subnet and the AACommServer log\n");

    • Connect(MotionController) — Connect to the motion controller, default IP is 172.1.1.101 Returns: Returns true if connection is successful, otherwise false
    • Connect(MotionController, string) — Connect to the motion controller with specified IP Returns: Returns true if connection is successful, otherwise false
    • Connect(MotionController, string, bool, bool) — Connect to the motion controller with specified IP and auto-reconnect option Returns: Returns true if connection is successful, otherwise false
    • Connect(MotionController, string, int, bool, bool) — Connect to the motion controller with specified IP, port, and auto-reconnect option Returns: Returns true if connection is successful, otherwise false
    • Connect(string, bool, bool) — Connects to the controller using an IP address. Returns: True if connection is successful; otherwise false.
    • Connect(string, int, bool, bool) — Connects to the controller using an IP address and port. Returns: True if connection is successful; otherwise false.
    • aamotion_connect — Connects the session to a controller over Ethernet, serial or CAN. @param deviceAddress The controller's address, e.g. "172.1.1.101". @param fastArk Fast acknowledge mode. @param enableAutoReconnect Recorded but currently has no effect: nothing reconnects on its own; call aamotion_try_reconnect. @return true when connected.

    连接仿真器¶

    启动固件仿真器 firmware_sim.exe 并连接它。服务器为每次连接新建一个临时目录 %TEMP%\aasim-<随机号>\ 运行仿真，断开时整个目录删除，所以仿真上保存的参数不会保留。详见仿真器。

    什么时候用

    没有硬件时开发和测试，或者在自动化测试里复现问题。

    函数原型

    // AAMotionAPI

    检测控制器是否可达、是否在应答¶

    两种检测，回答的问题不同：

    • CheckConnection / aamotion_check_connection 用 ICMP ping 控制器的网络地址，判断网络上能不能到达它。仿真、串口、CAN 连接没有 IP 地址，不发 ping，返回 SDK 记录的连接状态。
    • ProbeConnection / aamotion_probe_connection 发一条命令（实时读取控制器的 Time，不经过快速读缓存）并等待回复，证明控制器本身此刻在应答。它走和所有读写相同的通道，适用于以太网、串口、CAN 和仿真。结果包括往返时间、没有应答的原因（枚举：连接探测失败原因），以及控制器自上一次成功探测以来是否重启过（Time 变小）。

    两者都只报告结果，不会自动重连。IsConnected 只说明 SDK 是否还持有这条连接，不能代替它们。

        Console.WriteLine(back ? "Reconnected" : "Controller still unreachable");
    }
}

Unlike MotionController.IsConnected, this always sends a probe and can block for up to ~1 second — call it deliberately (a background timer, a manual health check), never from a binding or a property-style hot path. Two independent probes are sent; either succeeding counts as reachable, so a single blocked or rate-limited ICMP packet is not mistaken for a dead link. For a connection made over a non-IP channel (Simulation, serial, CAN), or before any address is known, ICMP has nothing to probe and this reports the logical state instead — the same value MotionController.IsConnected would return. This never disconnects or reconnects anything by itself. Call MotionController.TryReconnect to recover a link this reports as down. A reachable address does not prove the controller answers commands; MotionController.ProbeConnection does.
    • ProbeConnection(MotionController, int?) — Sends one command to the controller and waits for its reply, to tell whether the controller is answering right now, how long the round trip took, and when it is not, why — see MotionController.ProbeConnection. A timeout tears the connection down , as any command timeout does; the probe never reconnects. Returns: The probe's outcome; ConnectionProbeFailure.NotConnected when controller is null
    • ProbeConnection(int?) — Sends one command to the controller and waits for its reply, to tell whether the controller is answering right now — the same path every read and write takes. The command reads Time (seconds since power-on) live, never through the fast read cache, and works on every channel: Ethernet, serial, CAN and simulation. Use it from a dedicated thread, as a heartbeat or before deciding to reconnect. Unlike MotionController.IsConnected, which only reports whether the SDK still holds the connection, and MotionController.CheckConnection, which pings the network address, this proves the controller itself answers, says why it did not, and notices a controller restart. A timeout on the wire tears the connection down , as any command timeout does: the server closes the controller's channel for every client on it. Keep timeoutMs above the longest reply the controller can take while busy. A probe that times out still queued behind other commands was never sent and leaves the connection up; MotionController.IsConnected tells the two apart. The probe never reconnects: when it reports the link down, call MotionController.TryReconnect on Ethernet, or MotionController.Disconnect and ConnectSimulation on a simulation. A probe that is sent and fails raises MotionController.ErrorOccurred and MotionController.ErrorReported like any other command; one refused because the link is already down raises neither. Concurrent probes on one controller run one at a time. Returns: Whether the controller answered, the round-trip time, the controller's Time, whether it restarted since the previous successful probe, and the reason for a failure.
    • aamotion_check_connection — Pings the connected controller (ICMP), blocking up to about one second. A link with no IP address (simulation, serial, CAN) is not pinged and reports its logical state. Never disconnects or reconnects. @return false when not connected or not answering.
    • aamotion_probe_connection — Sends one command (a live read of the controller's Time) and waits for the reply, to tell whether the controller is answering right now on any channel. A timeout on a command that reached the controller tears the connection down, like any command timeout. @param timeoutMs 0 for the default timeout, else 10..60000. @param failure Receives an aamotion_connection_probe_failure_t; NONE when the controller answered. Required. @param roundTripMs Optional (may be NULL): milliseconds from the call to the reply or failure, 0 when the link was down and nothing was sent. @param controllerTime Optional: the controller's Time (seconds since power-on), -1 without a reply. @param controllerRestarted Optional: true when that Time is lower than at the previous successful probe on this connection, so the controller restarted in between. @param message Optional: the error text when the probe failed, empty when it succeeded. @return true when the probe ran (read *failure for the outcome); false, nothing written, for a bad handle or timeoutMs or a NULL failure.

    关闭 AACommServer¶

    先断开这个控制器，再请求共享的 AACommServer 退出。服务器还有其他客户端（例如 PCSuite）时会忽略这个请求。一般不需要调用：最后一个客户端离开后服务器会自己退出。

    SDK 原文注释（英文）
    • Dispose(MotionController) — Releases all resources used by the controller, including communication channels. After calling this method, the controller instance should not be used.
    • Dispose() — Releases resources used by the controller. Does not shut down the shared AACommServer — call MotionController.Shutdown explicitly for that.
    • aamotion_release — Frees the session and its resources. Other sessions and the shared AACommServer are not affected. The handle is invalid afterwards; a NULL handle is ignored.
