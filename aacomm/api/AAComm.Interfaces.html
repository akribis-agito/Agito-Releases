Namespace AAComm.Interfaces

Interfaces

ICommService

Phase 1 interface over CommAPI for consumers that want to mock or substitute the controller boundary (e.g., headless Core libraries, unit and integration tests).

IIdentityContainer

Read-only view of ControllerIdentityContainer for consumers that need controller identity metadata without depending on the concrete container type.

IMessagesContainer

Read-only view of ControllerMessagesContainer for consumers that need parameter metadata (mnemonics, descriptions) without depending on the concrete container type.
