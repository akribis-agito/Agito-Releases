    PCSuite controls and API mapping¶

    Find a familiar button or field in PCSuite, then look up the SDK arguments and call order. Select a numbered marker to jump to its explanation, or select the image to enlarge it.

    CNC paths¶

    1 Arc segment · A and B endpoints, CCW
    When the two group axes map to the XY plane, use ArcXY / aamotion_arc_xy. A and B are the endpoint. Pass the absolute centre. For G-code offsets I and J, add them to the segment start first. The list shows the endpoint and direction.
    2 Set vector profile · speed percentage, acceleration, deceleration
    Use SetMotionProfile to queue the profile. Acceleration and deceleration are in CNC units/s². The percentage scales speed, and the motion segment supplies the segment speed.
    3 Start CNC / Pause CNC / Stop CNC
    On the selected group, call IGroupAxis.Begin, Pause, or Stop. Start executes the queued path. If you use SetStartPositions, put it first in an empty queue, before the profile and motion segments. If omitted, start with a straight motion segment.

    Download the PCSuite trajectory configuration CNCDemoFiles.acnc. Load the XML trajectory in the PCSuite CNC tool and check group, path, start and travel. Select Create User Program and use the exported plain-text source with RunCNCProgramFromFile. The supplied configuration places Set Start Positions after a line. If retaining that segment, put it first in an empty queue and confirm the axes are at the stated start before exporting. The SDK file demo ships with its own short linear path.

    Vector motion¶

    1 Linear / Arc
    Use VectorLinear / aamotion_vector_linear_with_mask or VectorArc / aamotion_vector_arc. Arc motion uses two axes and an absolute centre.
    2 Axis checkboxes and target fields
    The checkboxes select the member axes. Enter each axis's absolute target. Start from the lowest-numbered member, A in this example.
    3 Speed, acceleration, deceleration
    Pass the profile for the resultant path to the vector move. The segment uses one speed, acceleration and deceleration. Use SetVectorParam to write the profile alone.
    4 Start Vector / Stop Vector
    VectorLinear or VectorArc configures and starts the segment. For Stop, call StopVec / aamotion_stop_vec on the starting axis.

    Electronic gearing¶

    One call writes the whole configuration and starts the follower: C# AAMotionAPI.GearBegin or C aamotion_gear_begin.

    1 Port, category and keyword / Master
    For example, select A and PosRef and set C# GearMotionConfig.Master or C aamotion_gear_config.master to APosRef. Pass the follower, for example B, as the axis to the start call.
    2 Input factor and master modulus
    The numerator and denominator map to RatioNumerator and RatioDenominator, or ratioNumerator and ratioDenominator in C. 65536 / 65536 gives 1:1. The master modulus maps to MasterModRev / masterModRev; enter 0 when there is no modulus.
    3 Direct / Indirect (profile) mode
    Set MotionMode / motionMode to 5 or 6. Indirect gearing tracks through the follower's profile. Set the pictured speed, acceleration and deceleration separately on the follower.
    4 Start Motion / Stop
    Use C# AAMotionAPI.GearBegin or C aamotion_gear_begin. Send Stop to the follower, for example with aamotion_stop. Read back its state to verify startup or stop.

    DataLogger capture¶

    1 Duration / Gap / Actual gap
    Set the requested values in DataLoggerConfiguration.DurationSec (seconds) and GapMs (milliseconds). The controller determines the actual gap. Use the captured time axis after upload.
    2 Trigger / Source / Mask / Value
    These map to DataLoggerTrigger.Type, Source, Mask, and Value. Here ?PosRef uses the active-port placeholder. Pass a concrete channel such as APosRef; put the captured signals separately in ParamsToRecord.
    3 Trigger position
    Set TriggerPosition. A value of 10 reserves 10% of the recording window for pre-trigger samples.
    4 Start / Force Trigger / Upload / Stop / F5
    See the step-by-step API. Call ConfigureDataLogger, then StartDataRecording. For manual triggering, wait for state 2 and call ForceDataLoggerTrigger. After normal completion (state 4), call UploadDataLoggerData. Use StopDataRecording to stop. F5 combines capture, upload, and plotting in PCSuite. An SDK application can capture with RecordData / aamotion_data_rec_record and plot the result itself.

    Homing¶

    1 Homing mode
    Use HomeToIndex for a direct index search, HomeToLimitThenIndex for a limit switch followed by index, HomeToHardStopThenIndex for a position-error-based hard stop followed by index, HomeToHardStopByStuckThenIndex for a hard stop detected by motor stuck followed by index, or HomeToHardStop for the hard stop alone. Check LockSrcZeroSupported before latching the main encoder index. See searching and latching.
    2 Direction / fast and slow speeds / acceleration / timeout
    Set direction to +1 or −1. fastSpeed searches for the limit and slowSpeed searches for the index. Pass acceleration as accel and timeout in milliseconds as timeoutMs. Speeds and acceleration are in controller units (counts/s, counts/s²), never User Units; timeoutMs applies to each motion step.
    3 Configure and Apply / homing sequence
    PCSuite expands the quick settings into a sequence. HomeToHardStopByStuckThenIndex / aamotion_home_to_hard_stop_by_stuck_then_index uses velocity (counts/s), current (mA) and duration (ms) thresholds. The pictured position-error method uses its own separate threshold.
    4 Run Homing / homing status and last step
    With a homing table configured on the controller, run it with Home / aamotion_home. Monitor HomingStep for progress, then confirm success with IsHomed or HomingStat = 100.

    PVAJ¶

    PCSuite · PVAJ

    The control names come from PCSuite. The C# equivalents are the AAMotionAPI.Pvaj* methods of the same names.

    1 Load List
    Pass the trajectory header and P/V/A/J points to aamotion_pvaj_write_header and aamotion_pvaj_write_point. PCSuite reads and downloads a file; with the SDK the application supplies the points.
    2 Validation Mode / Validate / Arm
    Use mode 1 with aamotion_pvaj_validate for full validation. Check aamotion_pvaj_is_validated before calling aamotion_pvaj_arm. After editing the list, validate again before the next arm.
    3 Group Member / Start Motion / Status
    Use mode 22 for a single axis and 23 for group members. When the member axes are ready, call aamotion_pvaj_begin and read the execution index and remaining rows through aamotion_pvaj_get_status. See the PVAJ arguments and workflow.

    Electronic cam ECAM¶

    1 Active ECAM Table / cycle counter
    The selected table is tableNum (1–10). Use ECAM_GetCycleCount to read the cycle count at runtime.
    2 Start and end indices / cycle indices and count
    Use ECAM_SetTableRange and ECAM_SetCycleParams. The table range is indexed in GenData; the cycle range selects the part to repeat.
    3 Master / initial position / gap
    Use ECAM_SetMaster, ECAM_SetMasterIni, and ECAM_SetGap. Gap is the number of master counts per table point. ECAM_ConfigureTable can set the table range, cycle and master together.
    4 Start Motion / Stop ECAM
    Use ECAM_Start / ECAM_Stop, then check the follower with ECAM_IsActive.
    5 Open ECAM Editor
    Use the PCSuite editor to prepare points and preview the curve. When your application already has table values, write the follower’s table with ECAM_SetTableData.
