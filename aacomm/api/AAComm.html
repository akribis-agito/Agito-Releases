CommAPI
An API for handling communication with the AACommServer executable.


The API provides low-level send/receive capabilities + special functionality.


All *synchronous* functions are mutually-locking, and should not be called from multiple threads


Proper work-flow: (see usage details at every function description)


0. subscribe to events: Reset: <xref href="AAComm.CommAPI.OnResetProgress" data-throw-if-not-resolved="false"></xref>, General Error: <xref href="AAComm.CommAPI.OnCommsError" data-throw-if-not-resolved="false"></xref>, Push: <xref href="AAComm.CommAPI.OnPushMessageReceived" data-throw-if-not-resolved="false"></xref> (TBD)


1. <xref href="AAComm.CommAPI.StartAACommServer(System.String)" data-throw-if-not-resolved="false"></xref><p></p>

2. <xref href="AAComm.CommAPI.TestConnection(AAComm.Services.ConnectionData%2cSystem.Boolean)" data-throw-if-not-resolved="false"></xref> (not mandatory, can be used to determine <xref href="AAComm.Services.ConnectionData.ControllerType" data-throw-if-not-resolved="false"></xref>)


3. <xref href="AAComm.CommAPI.Connect(AAComm.Services.ConnectionData%2cSystem.Boolean)" data-throw-if-not-resolved="false"></xref><p></p>

4. <xref href="AAComm.CommAPI.Send(AAComm.Services.AACommMessage)" data-throw-if-not-resolved="false"></xref> and/or <xref href="AAComm.CommAPI.SendReceive(AAComm.Services.AACommMessage)" data-throw-if-not-resolved="false"></xref> (both safe from any thread, in any combination — independent FIFO pipelines for ordinary messages)


5. <xref href="AAComm.CommAPI.Disconnect" data-throw-if-not-resolved="false"></xref><p></p>

6. <xref href="AAComm.CommAPI.CloseAACommServer(System.Boolean)" data-throw-if-not-resolved="false"></xref> (not mandatory)
