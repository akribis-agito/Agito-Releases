    Pause¶

    bool Pause()

    Begin runs the buffered segments (the AAMotionAPI.Begin(c) overload without an axis is the CNC start); Pause decelerates along the path and holds on it, Resume continues from there; GroupStop / Stop stop the CNC motion; ClearBuffer drops the segments not yet run. Clear the buffer before writing a new path.

    Begin, pause, stop and clear

    SDK summary: Pause CNC motion

    Parameters: none.

    Return type: bool

    Returns: Returns true if pause command is sent successfully, otherwise false

    true when accepted.

    ClearBuffer¶

    bool ClearBuffer()

    Begin runs the buffered segments (the AAMotionAPI.Begin(c) overload without an axis is the CNC start); Pause decelerates along the path and holds on it, Resume continues from there; GroupStop / Stop stop the CNC motion; ClearBuffer drops the segments not yet run. Clear the buffer before writing a new path.

    Begin, pause, stop and clear

    SDK summary: Clear CNC motion buffer. A segment push that fails partway leaves the segment open, and the controller refuses every later push (error 122) until the buffer is cleared. Stop the group if needed, clear the buffer and rebuild the path.

    Parameters: none.

    Return type: bool

    Returns: Returns true if buffer is cleared successfully, otherwise false

    true when accepted.

    LinearAbsolute¶

    bool LinearAbsolute(int? aPos, int? bPos, int? cPos, int velCruise, int velEnd)

    Appends a straight line to an absolute end point. The letters in the name are the axes that move; in LinearAbsolute(aPos, bPos, cPos, …) a coordinate can be null (in C#), meaning that axis stays.

    Linear segments

    SDK summary: Perform multi-axis CNC absolute linear motion

    Parameter Type Direction Default Description
    aPos int? input by value required Axis A end; null keeps it
    bPos int? input by value required Axis B end; null keeps it
    cPos int? input by value required Axis C end; null keeps it
    velCruise int input by value required The cruise (path) speed of the segment, counts/s
    velEnd int input by value required The speed at the segment end; 0 stops there, above 0 runs into the next segment

    Return type: bool

    Returns: Returns true if command is sent successfully, otherwise false

    true when the segment was accepted; false when refused, with the reason at the error hook.

    SetMotionProfile¶

    bool SetMotionProfile(int percentage, int accel, int decel, double sfactor)

    These are segments in the buffer too, applied when the path reaches them, so settings can change along the way:

    • 'SetMotionProfile: speed percentage, acceleration, deceleration, smoothing factor.'
    • 'SetCornerParams / AutoCorner: how corners are handled (corner radius or allowed error, minimum angle, acceleration limit); AutoCorner inserts a smoothing arc between the current two-axis line and the next segment.'
    • 'SetStartPositions: the path''s start coordinates; SetCurrPositions: assigns coordinates to the current position.'
    • 'SetMaxVelJumpParams / SetMaxAccelParams: each axis''s largest allowed velocity jump and acceleration, limiting the shock at corners.'

    Profile, corners and start

    SDK summary: Set CNC motion parameters

    Parameter Type Direction Default Description
    percentage int input by value required The speed percentage (100 = the segments' cruise speeds)
    accel int input by value required The path acceleration
    decel int input by value required The path deceleration
    sfactor double input by value required The smoothing factor

    Return type: bool

    Returns: Returns true if parameters are set successfully, otherwise false

    void RunCNCProgramFromFile(string filePath)

This can occur before startup, after normal completion, or after a stop or interruption. Confirm the download result, runtime errors, and final position to verify that the full path succeeded.

    IsCNCCompleted¶

    bool IsCNCCompleted(AxisRef axisRef)

    RunCNCProgramFromFile reads the file generated by the PCSuite CNC tool and sends commands in file order. IsCNCCompleted reads the live CNC status word and returns true when motion bit 0 is clear. This can occur before startup, after normal completion, or after a stop or interruption. Confirm the download result, runtime errors, and final position to verify that the full path succeeded.

    Run a CNC program file

    SDK summary: Determine whether the CNC movement has been completed. This is a poll-until-flips helper: it reads the status live on every call, never through the FastReadCache.

    Parameter Type Direction Default Description
    axisRef AxisRef input by value required The group's axis

    Return type: bool

    Returns: The CNC movement is completed and returns true; otherwise, it returns false.

    IsCNCCompleted returns true when the CNC motion bit is clear.

    T:AAMotion.ControllerCommandException: The controller refused the status read, or answered with something that is not a number. A poll cannot answer the question over a link that did not reply, so it raises rather than reporting and leaving a wait loop to spin.
