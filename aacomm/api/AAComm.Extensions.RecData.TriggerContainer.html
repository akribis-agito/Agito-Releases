TriggerContainer(ICommService, int, int, double, long, double) 

Rx-path constructor: converts trigger values FROM controller units TO user units.


Used when parsing trigger setup from controller upload or recording header.


Applies <xref href="AAComm.Services.FloatHelper.ApplyUserUnits(System.Double%2cSystem.Int32%2cAAComm.Interfaces.ICommService)" data-throw-if-not-resolved="false"></xref> to scale values to display units.


Counterpart to the string-based Tx-path constructor which divides by factor.


Backwards-compatibility validation (double support, 64-bit masks) is intentionally skipped:
values originate from the controller and are already in a valid format.

TriggerContainer(int, double, long, double) 

Sourceless constructor for trigger types with no source parameter (None, ManuallyForced).


No API needed, no UU scaling — no source parameter means no UU factor.

GetDownloadCommands(RecParamsResolver, int) works uniformly with this constructor.

Recording trigger parameters always use axis "A" prefix (not motor-axis-related).
