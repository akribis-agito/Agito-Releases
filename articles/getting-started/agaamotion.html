Overview

AGAAMotion is a C++ syntax sugar library for AAMotion motion controllers, providing an intuitive way to access axis properties and controller functions. It offers C#-like property access syntax such as controller.A.Speed = 10000.

Key Features

  • Fluid Property Access: Use controller.A.Speed instead of SendCommandString(controller, "ASpeed", ...)
  • Type Safety: Compile-time type checking to reduce runtime errors
  • Complete Property Support: Support for all axis properties and controller-level arrays
  • Event-Driven Error Handling: Unified error handling mechanism
  • Multi-Controller Support: Support for managing multiple controllers simultaneously

Quick Start

Basic Usage Flow

#include "AGAAMotion.h"
#include "AxisProps.h"

using namespace AxisPropsDSL;

int main() {
    // 1. Initialize controller
    MotionController controller = Initialize(AGM800);
    if (!controller) {
        printf("Controller initialization failed\n");
        return -1;
    }
    
    // 2. Create property access wrapper
    Controller ctl(controller);
    
// 3. Connect to device
if (!Connect(controller, "172.1.1.101")) {
    printf("Connection failed\n");
    return -1;
}

// 3.1 Check connection state (new)
Controller ctl(controller);
if (!ctl.isConnected()) {
    printf("Controller not connected after Connect()\n");
    return -1;
}
    
    // 4. Use property access
    ctl.A.Speed = 10000;        // Set speed
    int speed = ctl.A.Speed;    // Read speed
    
    // 5. Disconnect
    Disconnect(controller);
    return 0;
}

Error Handling

Setting Error Handling Callbacks

AGAAMotion provides two error handling approaches:

1. C# Layer Error Handling (Recommended)

void OnErrorOccurred(int errorCode, const char* message, const char* exception) {
    printf("\n=== Error Event Triggered ===\n");
    printf("Error Code: %d\n", errorCode);
    printf("Error Message: %s\n", message);
    if (strlen(exception) > 0) {
        printf("Exception Info: %s\n", exception);
    }
    printf("=============================\n\n");
}

int main() {
    MotionController controller = Initialize(AGM800);
    
    // Set error handling callback
    SetErrorOccurredHandler(controller, OnErrorOccurred);
    
    // Use controller...
    
    // Clear error handling callback
    ClearErrorOccurredHandler(controller);
    return 0;
}

2. Simple Error Handling

void OnError(const char* functionName, const char* errorMessage) {
    printf("Error: %s - %s\n", functionName, errorMessage);
}

int main() {
    // Set global error callback
    SetErrorCallback(OnError);
    
    // Use controller...
    
    // Clear error callback
    ClearErrorCallback();
    return 0;
}

Error Code Reference

  • Error Code 13: C# layer command error (e.g., invalid command)
  • Error Code 8001: C++ wrapper error (e.g., null pointer)

Example Code

Complete Example: Basic Motion Control

#include <iostream>
#include <cstdio>
#include "../AGAAMotion/AGAAMotion.h"
#include "../AGAAMotion/AxisProps.h"
#include <thread>
#include <chrono>

using namespace AxisPropsDSL;

void OnErrorOccurred(int errorCode, const char* message, const char* exception) {
    printf("\n=== Error Event Triggered ===\n");
    printf("Error Code: %d\n", errorCode);
    printf("Error Message: %s\n", message);
    if (strlen(exception) > 0) {
        printf("Exception Info: %s\n", exception);
    }
    printf("=============================\n\n");
}

int main() {
    printf("=== AGAAMotion Complete Example ===\n\n");

    // 1. Initialize controller
    MotionController controller = Initialize(AGM800);
    if (!controller) {
        printf("Controller initialization failed\n");
        return -1;
    }

    // 2. Create property access wrapper
    Controller ctl(controller);

    // 3. Set error handling
    SetErrorOccurredHandler(controller, OnErrorOccurred);

    // 4. Connect to device
    if (!Connect(controller, "172.1.1.101")) {
        printf("Connection failed\n");
        return -1;
    }
    printf("Connected successfully\n");

    // 5. Configure axis parameters
    ctl.A.Speed = 10000;            // Set speed
    ctl.A.Accel = 5000;             // Set acceleration
    ctl.A.Decel = 5000;             // Set deceleration
    ctl.A.MaxVel = 20000;           // Set maximum velocity

    // 6. Turn on motor
    MotorOn(controller, A);
    printf("Motor turned on\n");

    // 7. Execute homing
    printf("Starting homing...\n");
    Home(controller, A);
    
    // Wait for homing completion
    while (ctl.A.HomingStat != 4) {
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    printf("Homing completed\n");

    // 8. Execute absolute motion
    printf("Executing absolute motion to position 50000...\n");
    MoveAbsAndWait(controller, A, 50000, 10000, 10000, 10000);
    printf("Current position: %d\n", ctl.A.Pos);

    // 9. Execute relative motion
    printf("Executing relative motion +20000...\n");
    MoveRelAndWait(controller, A, 20000, 10000, 10000, 10000);
    printf("Current position: %d\n", ctl.A.Pos);

    // 10. Jog motion
    printf("Executing jog motion...\n");
    Jog(controller, A, 5000);       // Positive jog
    std::this_thread::sleep_for(std::chrono::seconds(2));
    Stop(controller, A);            // Stop

    // 11. Operate GenData
    printf("Operating GenData array...\n");
    ctl.GenData[0] = 12345;
    ctl.GenData[1] = 67890;
    printf("GenData[0] = %d\n", ctl.GenData[0]);
    printf("GenData[1] = %d\n", ctl.GenData[1]);

    // 12. Read status information
    printf("Reading status information...\n");
    printf("Motion status: %d\n", ctl.A.MotionStat);
    printf("In-target status: %d\n", ctl.A.InTargetStat);
    printf("Current position: %d\n", ctl.A.Pos);
    printf("Current velocity: %d\n", ctl.A.Vel[1]);

    // 13. Turn off motor
    MotorOff(controller, A);
    printf("Motor turned off\n");

    // 14. Disconnect
    Disconnect(controller);
    printf("Disconnected successfully\n");

    // 15. Clear error handling
    ClearErrorOccurredHandler(controller);

    printf("\nExample completed\n");
    return 0;
}

Multi-Axis Coordinated Motion Example

void MultiAxisExample() {
    MotionController controller = Initialize(AGM800);
    Controller ctl(controller);
    
    Connect(controller, "172.1.1.101");
    
    // Configure multi-axis parameters
    ctl.A.Speed = 10000;
    ctl.B.Speed = 8000;
    ctl.C.Speed = 6000;
    
    ctl.A.Accel = 5000;
    ctl.B.Accel = 4000;
    ctl.C.Accel = 3000;
    
    // Turn on all axis motors
    MotorOn(controller, A);
    MotorOn(controller, B);
    MotorOn(controller, C);
    
    // Three-axis linear interpolation motion
    LinearAbsolute(controller, 10000, 20000, 30000, 8000, 1000);
    
    // Wait for motion completion
    while (ctl.A.InTargetStat != 4 || ctl.B.InTargetStat != 4 || ctl.C.InTargetStat != 4) {
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    
    printf("Multi-axis motion completed\n");
    printf("A-axis position: %d\n", ctl.A.Pos);
    printf("B-axis position: %d\n", ctl.B.Pos);
    printf("C-axis position: %d\n", ctl.C.Pos);
    
    // Turn off all axis motors
    MotorOff(controller, A);
    MotorOff(controller, B);
    MotorOff(controller, C);
    
    Disconnect(controller);
}

Frequently Asked Questions

Q1: How to handle connection failures?

if (!Connect(controller, "172.1.1.101")) {
    printf("Connection failed, please check:\n");
    printf("1. Network connection is normal\n");
    printf("2. Controller IP address is correct\n");
    printf("3. Controller is started\n");
    return -1;
}

Q2: How to check if motion is completed?

// Method 1: Use InTargetStat property
while (ctl.A.InTargetStat != 4) {
    std::this_thread::sleep_for(std::chrono::milliseconds(100));
}

// Method 2: Use Wait functions
MoveAbsAndWait(controller, A, 10000, 5000, 10000, 10000);

Q3: How to handle error commands?

char response[256];
if (SendCommandString(controller, "ASpeed = 10000", response, sizeof(response))) {
    printf("Command successful: %s\n", response);
} else {
    printf("Command failed: %s\n", response);
}

Q4: How to operate multiple controllers simultaneously?

MotionController ctrl1 = Initialize(AGM800);

Controller ctl1(ctrl1);

Q5: How to optimize performance?

// 1. Use property access instead of SendCommandString
// Good practice
int speed = ctl.A.Speed;

// Avoid this
char response[64];
SendCommandString(controller, "ASpeed", response, sizeof(response));
int speed = std::atoi(response);

// 2. Batch operations on GenData
for (int i = 0; i < 100; i++) {
    ctl.GenData[i] = i * 1000;  // Faster than individual SendCommandString calls
}

Q6: Memory management considerations

// Correct practice: Ensure resource release
MotionController controller = Initialize(AGM800);
// ... use controller ...
Disconnect(controller);  // Automatically calls Release

// Incorrect practice: Forgetting to disconnect
MotionController controller = Initialize(AGM800);
// ... use controller ...
// Forgetting to call Disconnect may cause resource leaks

Summary

AGAAMotion provides a powerful and intuitive C++ API that makes it easy to control AAMotion motion controllers. By using property access syntax and event-driven error handling, you can write cleaner and more reliable code.

Always remember to:

  1. Set error handling callbacks
  2. Check function return values
  3. Properly manage controller lifecycle
  4. Use property access instead of raw command strings
  5. Disconnect when finished

For questions, please refer to the example code or contact technical support.
