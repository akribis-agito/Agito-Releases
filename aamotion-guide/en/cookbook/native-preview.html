    C++ examples: PVAJ, gearing and stuck homing¶

    These three C++17 programs call the native SDK's PVAJ, gearing and stuck-homing functions. Build and link them with the header, library and server of one native SDK package.

    Configure the standalone projects below from the guide source directory. Targets are pvaj, gearing, and stall_home, for Windows or Linux x64. The programs select AGM800. Verify the model, firmware capability, mapping, units and travel in PCSuite. Commutate and enable the selected axes and finish other commanding applications before starting. Each demo checks that its execution axis is enabled and idle.

    cmake -S samples/preview/cpp -B build/preview -DAAMOTION_SDK_DIR=/path/to/agito-aamotion-native-sdk
cmake --build build/preview --config Release

    Download and execute PVAJ¶

    PCSuite · PVAJ trajectory tool

    Use this for a discrete position, velocity, acceleration and jerk trajectory, on an AGM800 with firmware 5.3.0 or later. Run pvaj <AGM800 IP> <trajectory.txt> for single-axis playback on A.

    The first line is the gap in base scan periods (1–32) and the position mode (0 absolute, 1 relative). Each following line is a P, V, A, J point in counts, counts/s, counts/s² and counts/s³. Supply a trajectory for the actual start, period and travel. Use full validation (mode 1), arm and begin, then read progress and final position. If validation fails, check range, continuity and units. After editing the list, validate again before the next arm. Every value is one round trip, so a long list takes a while to write.

    if (!aamotion_pvaj_arm(h, axis, false) ||
    !aamotion_pvaj_write_header(h, axis, static_cast<int>(points.size()), gap, mode))
    return 4;
for (std::size_t i = 0; i < points.size(); ++i) {
    const Point& p = points[i];
    if (!aamotion_pvaj_write_point(h, axis, static_cast<int>(i + 1), p.p, p.v, p.a, p.j))
        return 4;
}
if (!aamotion_pvaj_validate(h, axis, 1) || !aamotion_pvaj_is_validated(h, axis) ||
    !aamotion_pvaj_arm(h, axis, true))
    return 4;
if (!aamotion_pvaj_begin(h, axis, false)) {
    aamotion_pvaj_arm(h, axis, false);
    return 5;
}

int state, index, remaining;
for (int attempt = 0; attempt < 300; ++attempt) {
    if (!aamotion_pvaj_get_status(h, axis, &state, &index, &remaining))
        break;
    if (state != 3 && remaining == 0) {
        std::cout << "PVAJ ended. Check the final position and MotionReason.\n";
        return aamotion_pvaj_arm(h, axis, false) ? 0 : 6;
    }
    std::this_thread::sleep_for(std::chrono::milliseconds(100));
}

    Direct and indirect electronic gearing¶

    PCSuite · Gearing

    Use this when B follows axis A's position reference APosRef. Run gearing <AGM800 IP>, then enter the mode and ratio numerator. The denominator is 65536. For example, a numerator of 32768 gives 1:2, and a negative numerator reverses follower direction. Verify travel and ratio first. The program starts B. The operator controls A separately.

    Mode 5 uses the scaled and optionally filtered master for the follower's position reference. Mode 6 uses the master to form a position target and the follower's profile to track it. filter=64 passes the direct input without extra smoothing. Indirect mode leaves it unchanged. masterModRev=0 assumes a non-modulo master. Check the firmware limits for the ratio and source. Read follower mode, motion status and position trend to confirm operation. Press Enter to request Stop and verify the follower state afterwards.

    aamotion_gear_config field Value
    master Axis-prefixed signal such as APosRef for commanded position or APos for encoder feedback. Include the index for a supported array signal.
    ratioNumerator and ratioDenominator Integer numerator and positive integer denominator. Firmware without MasterFactDen uses the fixed denominator 65536. Check the target firmware ranges.
    filter Direct mode filter coefficient from 1 to 64. Smaller values filter more slowly.
    masterModRev Master signal modulus. Use 0 for no modulus. A nonzero value requires firmware support and must match the master.
    motionMode 5 for direct or 6 for indirect gearing. 
    const aamotion_gear_config config{"APosRef", numerator, 65536, 64, 0, mode};
if (!aamotion_gear_begin(h, axis, &config)) {
    std::cerr << "Start failed. Check the follower configuration and state.\n";
    return 4;
}
double motion_mode, motion_status;
if (aamotion_get_value(h, axis, AAMOTION_KEYWORD_MOTION_MODE, 0, &motion_mode) &&
    aamotion_get_value(h, axis, AAMOTION_KEYWORD_MOTION_STAT, 0, &motion_status))
    std::cout << "Follower mode " << motion_mode << ", motion status " << motion_status << '\n';
std::cin.ignore(1024, '\n');
std::cout << "Press Enter to stop the follower. The demo does not command the master.\n";
std::cin.get();
if (!aamotion_stop(h, axis)) {
    std::cerr << "Stop was not confirmed. Check the follower at the machine.\n";
    return 5;
}

    Home to a stall, then find Index¶

    PCSuite · Homing

    Use this when the machine permits contact with its mechanical stop, has no usable limit switch, and needs an encoder Index reference. Use the thresholds commissioned in PCSuite. Run stall_home <AGM800 IP> and enter direction, low-velocity threshold, current threshold, hold time in ms, fast speed, reverse Index search speed, acceleration, and timeout in ms. Enter speeds in counts/s, current in mA and acceleration in counts/s²: homing values are controller units, never User Units. The timeout applies to each motion step. The demo uses axis A and its main encoder Index.

    The controller searches in the selected direction. It declares a stall after low speed and high current persist for the specified time, then reverses slowly to find the latch signal. HomingStat = 100 confirms success. For a negative status, inspect HomingStep, MotionReason and ConFlt. See Homing API.

    if (!aamotion_lock_src_zero_supported(h, axis) ||
    !aamotion_home_to_hard_stop_by_stuck_then_index(h, axis, 0, direction,
        stuck_vel, stuck_curr, stuck_ms, fast, slow, accel, timeout_ms))
    return 4;

const auto deadline = std::chrono::steady_clock::now() + std::chrono::milliseconds(timeout_ms);
while (std::chrono::steady_clock::now() < deadline) {
    double status;
    if (!aamotion_get_value(h, axis, AAMOTION_KEYWORD_HOMING_STAT, 0, &status))
        break;
    if (status == 100) {
        std::cout << "Homing completed.\n";
        return 0;
    }
    if (status < 0) {
        std::cerr << "Homing failed, HomingStat=" << status << '\n';
        return 5;
    }
    std::this_thread::sleep_for(std::chrono::milliseconds(50));
}
aamotion_stop(h, axis);
std::cerr << "Homing could not be confirmed. Check the actual axis state.\n";
return 6;
