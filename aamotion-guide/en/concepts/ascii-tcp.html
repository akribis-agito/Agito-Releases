    Read and write ASCII keywords over TCP¶

    Connect an application TCP client directly to the controller. The customer sample uses port 50000. Use the port configured on the target. This connection goes to the controller and requires no AACommServer. Send one request and finish reading its reply before sending another on the same connection.

    Operation ASCII request and terminator Reply
    Single read AASpeed + 00 00 00 00 03 E8 3E means 1000. The first byte is reserved, followed by a signed big-endian 32-bit integer.
    Single write AAGenData[800]=799 + 00 The captured success reply is 00 3E.
    Batch read LASpeed;BSpeed;CSpeed + 00 1000>2000>3000>, in request order.
    Batch write LAGenData[800]=1;AGenData[801]=2 + 00 The customer test returned OK>OK>. Check each result and read back the values.

    In AASpeed, the first A selects single mode. The second belongs to the axis keyword ASpeed. Batch requests start with L. Separate commands with semicolons. Write one NUL byte (0x00) immediately after the last command.

    TCP can split replies. Read all six bytes for an integer query. A value byte can itself be 0x3E. A short binary error consists of a reserved byte, a two-byte big-endian error code and 0x3E. The demo reports a short error after a read timeout or disconnect and closes the connection to prevent leftover bytes from being mistaken for the next reply. The examples use integer keywords. For other data types, consult the keyword definition.

    Read each batch field through its > terminator. In the current communication implementation, L continues after errors and I stops on an error. Batch writes can take effect partially. After a timeout, reconnect and read back before deciding whether to resend. Use a dedicated GenData index from the firmware map that no running program or process uses.

    C# C++ and Python demos¶

    Source is under samples/app/ascii. By default, the demos read ASpeed, AMotorOn and AMotionStat. The optional index and value enable a GenData write with before-and-after readback. The examples below assume index 800 is reserved for testing.

    python keyword_tcp.py HOST --port 50000
python keyword_tcp.py HOST --port 50000 --write 800 799

dotnet run --project KeywordTcp.csproj -- HOST 50000
dotnet run --project KeywordTcp.csproj -- HOST 50000 800 799

cl /EHsc /std:c++17 keyword_tcp.cpp
keyword_tcp.exe IPV4 50000
keyword_tcp.exe IPV4 50000 800 799

    C# targets .NET 8. Build C++ from a Windows Visual Studio Developer Command Prompt. Replace HOST or IPV4 with the controller address.
