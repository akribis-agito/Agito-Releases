    术语表¶

    手册中常用的术语。正文中出现这些词时，把鼠标停在上面也能看到简短的解释。

    术语 说明 相关
    AACommServer 本机的通信服务器，所有程序经它连接控制器；每台控制器一条连接、一个队列 查看
    AACommServerNative 无窗口、不需要 .NET 运行时的 AACommServer，随 .NET 8/10 程序和原生 SDK 提供 查看
    ABI 原生库的二进制接口；aamotion_abi_version() 返回它的版本号 查看
    用户单位 / User Units 把计数换算成毫米、度等单位的系数和单位名，按轴、按参数组设置 查看
    计数 / counts 编码器的原始单位
    关键字 / keyword 控制器上的一个参数或命令，如 Pos、Speed、Begin 查看
    CAN 编号 / CAN code 关键字在通信中的编号，随产品和固件不同 查看
    命令表 / message table 控制器支持的全部关键字及其编码，连接时读取并按固件缓存
    PosRef 参考位置：运动规划器给出的位置；相对运动以它为起点
    PosErr 跟随误差：参考位置与实际位置之差
    到位 / in target 运动结束后误差在 InTargetTol 内保持 InTargetTime；InTargetStat = 4 查看
    换相 / commutation 同步电机找到电角度的过程（自动定相） 查看
    回零 / homing 确定轴零点的过程，由 HomingDef[] 描述 查看
    PTP 点到点运动 查看
    Jog 以给定速度持续运动，直到停止 查看
    Jerk 平滑参数：2^Jerk 个控制周期的滑动平均，使速度曲线变成 S 形
    CNC 多轴插补：由直线、圆弧段组成的连续路径 查看
    矢量运动 / vector motion 多轴沿直线或圆弧的单段同步运动 查看
    ECAM 电子凸轮：从轴按表跟随主轴 查看
    PEG 位置事件输出：到达设定位置时输出脉冲 查看
    锁存 / Lock 输入信号到来时记录当时的位置 查看
    GenData / UserParam 控制器上的通用数组，用于和用户程序交换数据 查看
    用户程序 / user program 在 PCSuite IDE+ 中编写、在控制器上运行的程序 查看
    批量命令 / bulk command 一次发送最多 50 条命令，用 ; 分隔 查看
    快速读缓存 / FastReadCache 后台批量刷新登记的关键字，属性读取直接取缓存 查看
    fastArk Connect 的第三个参数，实际含义是不开启 PC 端 TCP 立即确认 查看
    错误钩子 / error hook 控制器或 SDK 报错时调用的回调 查看
    Central-i Agito 的分布式多轴架构 查看
    仿真器 / simulator 在电脑上运行的固件 firmware_sim.exe 查看
    NativeAOT 把 .NET 代码提前编译成原生库的技术，C 接口由它生成
