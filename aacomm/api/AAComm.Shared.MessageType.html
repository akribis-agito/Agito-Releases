public enum MessageType

BulkMessage = 7
Special type to send multiple messages at once over Ethernet ONLY


Usage example: <xref href="AAComm.Services.AACommMessage.Message" data-throw-if-not-resolved="false"></xref> = "APos;BPos;AVel[2];AGenData[4]=123...etc".


Reply: a sequence of replies separated by '>', i.e. "123>-11>6700>OK>"


In case one of the bulk messages results in an error, all the messages AFTER the error are NOT performed.


The reply will include the error code in the last "element": "123>-11>6700>OK>ERR XX>"
