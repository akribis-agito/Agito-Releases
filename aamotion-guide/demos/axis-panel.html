    轴控制面板¶

    在 C#、C++ 和 Python 的同一个面板中运行基础轴控和高级功能示例。

    Python 版（tkinter）在 Linux 上的截图，未连接控制器；C# 版用 WPF，C++ 版用 Win32 对话框，截图展示基础轴控区域。

    界面¶

    区域 内容
    连接 Target 默认是控制器出厂 IP 172.1.1.101；填 firmware_sim.exe 的完整路径则连接仿真器
    状态 选中轴的 Pos、PosRef、MotorOn、MotionStat、InTargetStat、ConFlt、是否换相、HomingStat，每 250 ms 刷新，状态值附说明文字
    电机 换相、使能、断使能
    运动 速度、加速度、减速度、目标或距离；绝对运动、相对运动、Jog −/+、停止（Decel）、急停（EmrgDec）
    回零 按控制器中已配置的流程回零
    日志 每条命令的结果，以及错误回调报告的错误码与说明

    按钮只发出命令：换相、回零、运动是否完成，看状态面板（例如 InTargetStat 变为 4、HomingStat 变为 100）。这与小 Demo 中“命令被接受不等于动作完成”是同一件事。

    按钮会让真实轴运动

    先在仿真器上试；真机先在 PCSuite 中调好参数，确认行程与急停。关闭窗口时程序会对选中的轴请求停止并断使能，再断开连接，但断开通信不能证明设备已停止。

    高级功能¶

    在同一窗口的「高级功能」下拉框选择操作，按提示填参数，用英文逗号分隔，再点「执行」。单轴操作使用左侧选中的轴，CNC 和矢量插补固定使用 A/B。日志显示回复、错误及导出文件的路径。

    功能 操作与结果
    DataLogger 以 1 ms 间隔采集所选轴的 Pos，持续 1 s，导出时间（秒）与位置（counts）到 CSV。
    SlowLogger 依次开始、上传和停止。上传保存 FIFO 返回的原始文本，可查询丢包数。
    CNC 输入 A、B 的相对位移（counts）并启动直线段，圆弧则输入绝对终点、绝对圆心和方向。可暂停、继续、停止和查询完成。路径输出示例在终点给 A 的输出 1 发 200 ms 脉冲再返回，运行停止后核对输出状态。也可运行现有的 CNC 文本文件。
    电子齿轮 选从轴，输入主轴参数的复合 CAN 代码及比例分子，分母为 65536。直接和间接模式各有入口。启动从轴后，可读状态或停止从轴。
    电子凸轮 在 PCSuite 配置好表和主轴，选从轴并输入表号 1–10。面板可启动或停止从轴，并读该表的循环数。
    双速、两轴和矢量插补 双速输入正向距离与切速距离；两轴批量定位与矢量直线都输入 A/B 绝对目标。矢量圆弧另需绝对圆心和方向。观察两根轴的到位状态，可用「停止 A 和 B」请求停止。
    I/O、锁存、PEG 和用户程序 读输入、置位或清除输出、读写锁存使能、配置单点 PEG、读计数和关闭触发，以及运行或停止已下载的程序。
    控制器诊断 读运动模式、Central-i 链路状态及指定的 GenData 下标，也可发送一条文本命令。

    正弦点位与 PVAJ¶

    完整流程见 PVAJ 轨迹运动。

    • 正弦点位支持单次（模式 20）、往复（模式 21，RptMode=0）、预巡航和在线改目标。示例巡航速度为 2000 counts/s，加减速度为 10000 counts/s²，加减速 jerk 参数为 100000 counts/s³。预巡航终点应在当前 PosRef 与绝对终点之间，预巡航速度至少等于巡航速度。 PreCruiseSpd=0 关闭预巡航。往复运动使用 StopRep 结束。
    • 在线改目标先写入完整运动参数，再使用 CommitMotion 提交。面板在改目标前关闭预巡航并保持当前运动模式。单次运动的拼接由规划器后台计算，往复修改在该段结束时生效。检查 InTargetStat、ConFlt 和规划器错误 380–389。C# 使用 SinePtpBegin 与 SinePtpCommit，C++ 和 Python 使用发布版的文本命令接口。
    • PVAJ需要支持该功能的 AGM800（Central-i v5）固件。输入相对位移（counts）、间隔（1–32 个控制周期）和控制器实际基本周期（µs）。面板按四段等时长的常 jerk 生成五行 P,V,A,J，首尾速度与加速度为零。以 T = 间隔 × 基本周期（秒）积分生成每行，采用 +j, −j, −j, +j，其中 j = 位移 / (2T³)。例如间隔 32、基本周期 1000 µs 时，T=0.032 s，总时长为 128 ms。位移、速度和加速度须满足实机限制。
    • PVAJ 写入与校验先写三项表头（长度、间隔、相对模式 1），再每行写四个数据。完整校验模式 1 检查范围及位置和速度连续性，通过后设置模式 22、Arm、Begin。连续性出错时核对实际控制周期及 PVAJPosTol、PVAJVelTol。Gap 大于 1 时，控制器在点间做五次样条插值。
    • PVAJ 状态显示状态、执行索引、剩余点。状态 0、1、2、3 分别表示未校验、已校验、已 Arm、执行中。正常完成会解除 Arm 并回到 0，结合 ConFlt、运动状态和最终位置判断结果。轨迹写入和校验失败时查日志，再重新写表和校验。

    三种语言的流程分别在 AxisOperations.cs、AxisOperations.cpp、axis_operations.py，菜单来自 samples/app/operations.tsv。运行 C# 和 C++ 时该文件由构建复制到程序旁。关闭前先停止正在执行的 A/B 组、从轴或用户程序，并停止本次启用的 SlowLogger。

    按钮对应的 API¶

    界面控件 C# C++ Python
    连接 / Target AAMotionAPI.Connect(c, target) aamotion_connect(h, target, true, false) am.connect(h, target, True, False)
    断开 AAMotionAPI.Disconnect(c) aamotion_disconnect(h) am.disconnect(h)
    换相 a.AutoPhase() aamotion_auto_phase(h, axis) am.auto_phase(h, axis)
    使能 / 断使能 a.MotorOn = 1 / 0 aamotion_motor_on(h, axis) / aamotion_motor_off(h, axis) am.motor_on(h, axis) / am.motor_off(h, axis)
    绝对运动 a.MoveAbs(value, speed, accel, decel) aamotion_move_abs(h, axis, value, speed, accel, decel) am.move_abs(h, axis, value, speed, accel, decel)
    相对运动 a.MoveRel(value, speed, accel, decel) aamotion_move_relative(h, axis, value, speed, accel, decel) am.move_relative(h, axis, value, speed, accel, decel)
    Jog −/+ a.Jog(direction * speed) aamotion_jog(h, axis, direction * speed) am.jog(h, axis, direction * speed)
    停止 a.Stop() aamotion_stop(h, axis) am.stop(h, axis)
    Abort 按钮 a.Abort() aamotion_abort(h, axis) am.abort(h, axis)
    回零 a.Home() aamotion_home(h, axis) am.home(h, axis)

    a 是选中的轴对象，axis 是轴编号。速度、加速度和减速度框依次传入 speed、accel、decel。目标框在绝对运动中是目标坐标，在相对运动中是位移。位置读数对应 Pos。用仿真器时调用相应的仿真连接 API。

    窗口和后台通信源码随交付 ZIP 的 samples/app/ 提供。练习单个功能可从完整入门工程开始。

    运行¶

    1. 用 Visual Studio 打开 samples/app/csharp/AxisPanel/AxisPanel.csproj。
    2. 确认 MainViewModel.cs 中 Target 的默认值，也可以运行后在界面中修改。
    3. 按 F5。需要 .NET Framework 4.8 开发工具；首次生成会还原本手册对应版本的 NuGet 包 Agito.AAMotion。
    1. 解压原生 SDK agito-aamotion-native-sdk-<version>.zip。
    2. Visual Studio「打开本地文件夹」打开 samples/app/cpp/AxisPanel，在 CMakePresets.json 中把 AAMOTION_SDK_DIR 改成 SDK 目录。
    3. 选择 AxisPanel.exe 后按 F5；生成时会把 aamotion.dll 与 AACommServerNative.exe 复制到程序旁。只支持 Windows。
    1. 安装 64 位 Python 3.9 或更新版本（自带 tkinter）。
    2. 在 samples/app/python 中运行一次 python get_sdk.py，下载并校验 SDK，把库与 AACommServerNative 放到 aamotion.py 旁边。
    3. 运行 python axis_panel.py。
