    Reading and writing parameters¶

    Every setting and status on the controller is a keyword (Pos, Speed, MotionStat, …); the full list with every keyword's description is in the Keyword reference. There are three ways to read and write one, from simplest to most general:

    Way C# C Use it for
    Object property a.Pos, a.Speed = 20000 — the usual C# way, typed and converted by User Units
    Read / write by keyword c.GetValue(AxisRef.A, eKeyword.Pos), c.SetValue(AxisRef.A, eKeyword.Speed, 20000) aamotion_get_value, aamotion_set_value when you know only the keyword name; the usual C / Python way, converted as the property is
    Raw command SendCommandString("ASpeed=20000") aamotion_send_command_string any keyword or command, including commands with no dedicated function

    To send several commands together, use a bulk command: up to 50 per packet, much faster than one by one.

    Axis, I/O and group objects¶

    In C# the controller is reached through objects: c.GetAxis(AxisRef.A) returns the axis object ISingleAxis (keyword properties and motion methods), c.GetIO(...) the I/O module IIOModule, and c.GetGroup(...) / c.GetCiGroup(...) a CNC group. They are lightweight; get them whenever needed or keep them. The C interface has no objects; every function takes the axis.

    Standalone demo: Axis object properties

    When to use it

    In C#, when working with one axis in several ways, get its object first; the code is shorter and clearer.

    Signatures

    // MotionController
// Gets the single axis control interface for the specified axis.
// axis: The axis; for `GetCiGroup`, AxisRef.B gives group B on an AGM800
// Returns: An instance of `ISingleAxis` interface for the specified axis.
ISingleAxis GetAxis(AxisRef axis);

// Gets the interface for the specified IO module.
// axis: The axis; for `GetCiGroup`, AxisRef.B gives group B on an AGM800
// Returns: An instance of `IIOModule` interface for the specified IO module.
IIOModule GetIO(AxisRef axis);

// Gets the interface for the specified Ci group axis.
// axis: The axis; for `GetCiGroup`, AxisRef.B gives group B on an AGM800
// Returns: An instance of `ICiGroupAxis` interface for the specified Ci group axis.
ICiGroupAxis GetCiGroup(AxisRef axis);

    Parameters

    Parameter Type Description
    axis AxisRef The axis; for GetCiGroup, AxisRef.B gives group B on an AGM800

    Example

    ISingleAxis a = c.GetAxis(AxisRef.A);
double pos = a.Pos;           // read
a.Speed = 20000;              // write
double avg = a.Vel[1];        // array keyword: Vel[1] is the filtered velocity
    SDK comments (original)
    • GetAxis(AxisRef) — Gets the single axis control interface for the specified axis. Returns: An instance of ISingleAxis interface for the specified axis.
    • GetIO(AxisRef) — Gets the interface for the specified IO module. Returns: An instance of IIOModule interface for the specified IO module.
    • GetCiGroup(AxisRef) — Gets the interface for the specified Ci group axis. Returns: An instance of ICiGroupAxis interface for the specified Ci group axis.

    Send a raw command¶

    Sends one command string and returns the controller's reply. The format is the same as in the PCSuite terminal: a prefix A…L picks the axis (non-axis keywords always take A), = assigns, [i] indexes an array. A read replies with the value as text, a write and a command (such as ABegin) reply OK.

    Standalone demo: Raw commands

    When to use it

    When a keyword has no dedicated function, when reusing a command tried in the PCSuite terminal, and for writes from C / Python.

    Signatures

    // AAMotionAPI
// Send raw command string to the controller
// controller: The controller object / handle
// rawCommand: The command string, such as `"APos"`, `"ASpeed=20000"`, `"ALoggerParams[1]=24"`
// response: The reply (an out parameter in C#; in C a caller-supplied buffer, NUL-terminated and cut when too long)
// Returns: Returns true if send is successful, otherwise false
static bool SendCommandString(MotionController controller, string rawCommand, out string response);

// MotionController
// Sends a raw command string to the controller.
// rawCommand: The command string, such as `"APos"`, `"ASpeed=20000"`, `"ALoggerParams[1]=24"`
// response: The reply (an out parameter in C#; in C a caller-supplied buffer, NUL-terminated and cut when too long)
// Returns: True if command is sent successfully and no errors occur; otherwise false.
bool SendCommandString(string rawCommand, out string response);

    // Sends one raw command, exactly as typed in the PCSuite terminal (e.g. "APos" or "ASpeed=1000"), and writes the reply into response (truncated on a character boundary, NUL-terminated). @return true when the controller answered without an error.
// controller: The controller object / handle
// rawCommand: The command string, such as `"APos"`, `"ASpeed=20000"`, `"ALoggerParams[1]=24"`
// response: The reply (an out parameter in C#; in C a caller-supplied buffer, NUL-terminated and cut when too long)
// responseSize: The C reply buffer size in bytes
bool aamotion_send_command_string(aamotion_controller controller, const char* rawCommand, char* response, int responseSize);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    rawCommand const char* / string The command string, such as "APos", "ASpeed=20000", "ALoggerParams[1]=24"
    response char* / string The reply (an out parameter in C#; in C a caller-supplied buffer, NUL-terminated and cut when too long)
    responseSize int The C reply buffer size in bytes

    Returns

    true when sent and the reply is not an error; false when the controller replies ERR (the error hook runs).

    Notes

    • With User Units on for the axis, raw and bulk commands are converted too: values written and read are in user units, as with the object properties.
    • Command keywords (Begin, Save, Reset, …) run when sent, and "reading" one runs it too.

    Example

    if (AAMotionAPI.SendCommandString(c, "ASpeed=20000", out string reply))
    Console.WriteLine("write: " + reply);           // "OK"

if (c.SendCommandString("APos", out reply))
    Console.WriteLine("APos = " + reply);           // the value, as text

c.SendCommandString("ALoggerParams[1]", out reply); // array element: [index]

    char reply[256];
if (aamotion_send_command_string(h, "ASpeed=20000", reply, sizeof reply))
    printf("write: %s\n", reply);            /* "OK" */

if (aamotion_send_command_string(h, "APos", reply, sizeof reply))
    printf("APos = %s\n", reply);            /* the value, as text */
    SDK comments (original)
    • SendCommandString(MotionController, string, string) — Send raw command string to the controller Returns: Returns true if send is successful, otherwise false
    • SendCommandString(string, string) — Sends a raw command string to the controller. Returns: True if command is sent successfully and no errors occur; otherwise false.
    • aamotion_send_command_string — Sends one raw command, exactly as typed in the PCSuite terminal (e.g. "APos" or "ASpeed=1000"), and writes the reply into response (truncated on a character boundary, NUL-terminated). @return true when the controller answered without an error.

    Bulk commands¶

    Sends several commands at once, separated by ;, at most 50 per packet; the replies come back in order separated by >, such as "123>-11>6700>OK>". When one command fails, the commands after it are not run and the last segment is the error, such as "123>-11>ERR 24>". BulkCommandParser(i, reply) returns the reply of command i (from 1).

    Standalone demo: Bulk read

    When to use it

    Reading or writing many values at once: a batch of settings at start-up, several states for one UI refresh. Up to 50 commands.

    Signatures

    // AAMotionAPI
// Special type to send multiple messages at once, on Ethernet and Simulation channels only Reply: one reply per message, separated by '>', i.e. "123>-11>6700>OK" In case one of the bulk messages results in an error, all the messages AFTER the error are NOT performed. The reply will include the error code in the last "element": "123>-11>6700>OK>ERR XX" A reply that is not one answer per message, nor stops at an error, returns false.
// controller: The controller object / handle
// rawCommand: Commands separated by `;`, such as `"APos;BPos;AVel[1]"`
// response: The replies separated by `>`
// Returns: Returns true if send is successful, otherwise false
static bool SendBulkCommandString(MotionController controller, string rawCommand, out string response);

// MotionController
// Sends a bulk command string to the controller.
// rawCommand: Commands separated by `;`, such as `"APos;BPos;AVel[1]"`
// response: The replies separated by `>`
// Returns: True if bulk command is sent successfully and no errors occur; otherwise false.
bool SendBulkCommandString(string rawCommand, out string response);

// Parses a bulk command string response and returns the specified index value.
// index: Which reply to take, from 1; 0 or out of range returns null
// response: The replies separated by `>`
// Returns: The value at the specified index in the response, or null if the index is out of range, the response is empty, or it has a blank answer (`AAComm.Services.BulkReply.TrySplit`).
string BulkCommandParser(int index, string response);

    // Sends several commands in one packet (Ethernet and simulation only). The reply holds one answer per command separated by '>', e.g. "123>-11>6700>OK"; when one command fails, the commands after it are NOT performed and the reply ends with its error ("...>ERR XX"). @return false for a reply that is neither one answer per command nor stopped at an error.
// controller: The controller object / handle
// rawCommand: Commands separated by `;`, such as `"APos;BPos;AVel[1]"`
// response: The replies separated by `>`
// responseSize: The C reply buffer size in bytes
bool aamotion_send_bulk_command_string(aamotion_controller controller, const char* rawCommand, char* response, int responseSize);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    rawCommand const char* / string Commands separated by ;, such as "APos;BPos;AVel[1]"
    response char* / string The replies separated by >
    index int Which reply to take, from 1; 0 or out of range returns null
    responseSize int The C reply buffer size in bytes

    Returns

    true when every command succeeded; false when any segment is an error. BulkCommandParser returns that segment's text.

    Notes

    • Only Ethernet and simulator links support bulk commands.

    Example

    // several commands in one packet; replies come back separated by '>'
if (c.SendBulkCommandString("APos;BPos;AVel[1];BVel[1]", out string reply))
{
    double aPos = double.Parse(c.BulkCommandParser(1, reply));   // 1-based
    double bPos = double.Parse(c.BulkCommandParser(2, reply));
    Console.WriteLine($"A={aPos} B={bPos}  raw: {reply}");
}

    char reply[1024];
if (aamotion_send_bulk_command_string(h, "APos;BPos;AVel[1];BVel[1]", reply, sizeof reply))
    printf("%s\n", reply);                   /* e.g. "1200>-300>15>0>" */
    SDK comments (original)
    • SendBulkCommandString(MotionController, string, string) — Special type to send multiple messages at once, on Ethernet and Simulation channels only Reply: one reply per message, separated by '>', i.e. "123>-11>6700>OK" In case one of the bulk messages results in an error, all the messages AFTER the error are NOT performed. The reply will include the error code in the last "element": "123>-11>6700>OK>ERR XX" A reply that is not one answer per message, nor stops at an error, returns false. Returns: Returns true if send is successful, otherwise false
    • SendBulkCommandString(string, string) — Sends a bulk command string to the controller. Returns: True if bulk command is sent successfully and no errors occur; otherwise false.
    • BulkCommandParser(int, string) — Parses a bulk command string response and returns the specified index value. Returns: The value at the specified index in the response, or null if the index is out of range, the response is empty, or it has a blank answer (AAComm.Services.BulkReply.TrySplit).
    • aamotion_send_bulk_command_string — Sends several commands in one packet (Ethernet and simulation only). The reply holds one answer per command separated by '>', e.g. "123>-11>6700>OK"; when one command fails, the commands after it are NOT performed and the reply ends with its error ("...>ERR XX"). @return false for a reply that is neither one answer per command nor stopped at an error.

    Read a value by keyword¶

    Reads a keyword on one axis, converted by that axis's User Units (counts when none apply). Every call reads from the controller; the FastReadCache is not used. TryGetValue returns false instead of throwing on failure.

    Standalone demo: Read by keyword

    When to use it

    Reading a keyword known only by name (from a configuration file, say); reading any keyword from C / Python.

    Signatures

    // MotionController
// The value `keyword` holds on `axis`, read through the controller, in the units that axis reads it in — `MotionController.GetUserUnits` says which, and answers counts when nothing scales it. `index` 0 reads a scalar parameter; 1 and up read one element of an array parameter, in the parameter's own indexing — an array parameter has no reading at 0, and a scalar one none at 1. Keyed by keyword so a caller can read a parameter it knows only by name, rather than through the member that happens to expose it. `axis` names one axis; a combined mask is an `System.ArgumentException`, and so is a keyword the message table flags as a controller command — reading one would SEND it. An index the parameter does not have throws. A read the controller refuses, or answers with something that is not a number, is a `ControllerCommandException`; `MotionController.TryGetValue` reports the same failure as instead.
// axis: One axis (`AxisRef.A` / `AAMOTION_AXIS_REF_A`, …); a combination of axes is not allowed
// keyword: The keyword (`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`). Command keywords are refused, since reading one would run it
// index: 0 reads a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. `TryReadArray` indexes from 1
double GetValue(AxisRef axis, eKeyword keyword, int index = 0);

// `MotionController.GetValue` that reports whether the read succeeded instead of throwing on a failure. Always a controller round trip, never the FastReadCache. False — with `value` 0 — when the controller replied with an error or with something that is not a number; `MotionController.LastReadError` then names the failure and `MotionController.ReadFailures` is incremented. The argument checks are `MotionController.GetValue`'s and throw the same way.
// axis: One axis (`AxisRef.A` / `AAMOTION_AXIS_REF_A`, …); a combination of axes is not allowed
// keyword: The keyword (`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`). Command keywords are refused, since reading one would run it
// value: The value read (a C# out parameter / a C pointer)
// index: 0 reads a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. `TryReadArray` indexes from 1
bool TryGetValue(AxisRef axis, eKeyword keyword, out double value, int index = 0);

// ISingleAxis
// Reads `keyword` from the controller and reports whether the read succeeded, instead of throwing the way the typed properties do on a failure. Always a controller round trip, never the FastReadCache, in the units the axis reads in. False — with `value` 0 — when the controller replied with an error or with something that is not a number; `MotionController.LastReadError` then names the failure and `MotionController.ReadFailures` is incremented. A keyword the SDK knows as a controller command is an `System.ArgumentException`: reading one would send it.
// keyword: The keyword (`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`). Command keywords are refused, since reading one would run it
// value: The value read (a C# out parameter / a C pointer)
bool TryRead(eKeyword keyword, out double value);

// Array-element twin of `ISingleAxis.TryRead`: reads element `index` (1 and up) of an array parameter.
// keyword: The keyword (`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`). Command keywords are refused, since reading one would run it
// index: 0 reads a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. `TryReadArray` indexes from 1
// value: The value read (a C# out parameter / a C pointer)
bool TryReadArray(eKeyword keyword, int index, out double value);

    // Any controller parameter can be read and written by keyword with aamotion_get_value / aamotion_set_value; the dedicated calls below cover the GenData/UserParam arrays and whole-file transfers. To read a whole digital port at once, read AAMOTION_KEYWORD_DIN_PORT, AAMOTION_KEYWORD_DIN_PORT_HIGH or AAMOTION_KEYWORD_DOUT_PORT with aamotion_get_value. Reads the parameter keyword on axis, in the units that axis reads it in (aamotion_get_units says which). Values are doubles: read a register into uint32_t (via int64_t), not a C (int) cast. @param keyword An aamotion_keyword_t value. @param index 0 reads a scalar parameter; 1 and up read one element of an array parameter. @return false, *value untouched: bad handle, NULL value, axis not A..L, keyword unknown or naming a COMMAND (reading would send it), an index the parameter lacks, a refused read, or a reply that is not a number.
// controller: The controller handle
// axis: One axis (`AxisRef.A` / `AAMOTION_AXIS_REF_A`, …); a combination of axes is not allowed
// keyword: The keyword (`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`). Command keywords are refused, since reading one would run it
// index: 0 reads a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. `TryReadArray` indexes from 1
// value: The value read (a C# out parameter / a C pointer)
bool aamotion_get_value(aamotion_controller controller, int axis, int keyword, int index, double* value);

    Parameters

    Parameter Type Description
    axis AxisRef / int One axis (AxisRef.A / AAMOTION_AXIS_REF_A, …); a combination of axes is not allowed
    keyword eKeyword / int The keyword (eKeyword.Pos / AAMOTION_KEYWORD_POS). Command keywords are refused, since reading one would run it
    index int 0 reads a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. TryReadArray indexes from 1
    value double* / double The value read (a C# out parameter / a C pointer)
    controller aamotion_controller The controller handle

    Returns

    GetValue returns the value and throws ControllerCommandException on failure. TryGetValue / the C version return true on success and false on failure; in C# the reason is in LastReadError.

    Notes

    • C values are doubles; read a bit register into uint32_t, not an int cast.

    Example

    double pos = c.GetValue(AxisRef.A, eKeyword.Pos);          // scalar: index 0
double vel = c.GetValue(AxisRef.A, eKeyword.Vel, 1);       // array: index 1 and up
UserUnitAxis u = c.GetUserUnits(AxisRef.A, eKeyword.Pos);
Console.WriteLine($"APos = {pos} {u.Units} (factor {u.Factor})");

    double pos, vel, factor;
char unit[32];
if (aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_POS, 0, &pos) &&
    aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_VEL, 1, &vel) &&
    aamotion_get_units(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_POS, unit, sizeof unit, &factor))
{
    printf("APos = %g %s (factor %g), AVel[1] = %g\n", pos, unit, factor, vel);
}

Keyed by keyword so a caller can read a parameter it knows only by name, rather than through the member that happens to expose it. axis names one axis; a combined mask is an System.ArgumentException, and so is a keyword the message table flags as a controller command — reading one would SEND it. An index the parameter does not have throws. A read the controller refuses, or answers with something that is not a number, is a ControllerCommandException; MotionController.TryGetValue reports the same failure as instead.
    • TryGetValue(AxisRef, eKeyword, double, int) — MotionController.GetValue that reports whether the read succeeded instead of throwing on a failure. Always a controller round trip, never the FastReadCache. False — with value 0 — when the controller replied with an error or with something that is not a number; MotionController.LastReadError then names the failure and MotionController.ReadFailures is incremented.     • TryRead(eKeyword, double) — Reads keyword from the controller and reports whether the read succeeded, instead of throwing the way the typed properties do on a failure.     • TryReadArray(eKeyword, int, double) — Array-element twin of ISingleAxis.TryRead: reads element index (1 and up) of an array parameter.
    • aamotion_get_value — Any controller parameter can be read and written by keyword with aamotion_get_value / aamotion_set_value; the dedicated calls below cover the GenData/UserParam arrays and whole-file transfers.     Write a parameter by keyword¶

    The write twin of GetValue / aamotion_get_value. The value is in the units that axis reads the keyword in (GetUserUnits / aamotion_get_units says which) and goes out through the same path as the typed property that exposes the parameter, so the type conversion and the User Units scaling are that property's. The array index rule is the same as for reading.

    When to use it

    Writing a parameter you know only by keyword, such as items read from a configuration file. In C#, a typed property (a.Speed = 20000) is more direct for a parameter you know.

    Signatures

    // MotionController
// Writes `value` to `keyword` on `axis`, the write twin of `MotionController.GetValue`: `value` is in the units that axis reads in — `MotionController.GetUserUnits` says which — and goes out through the same path as the typed property that exposes the parameter, so the type conversion and the User Units scaling are that property's. Keyed by keyword so a caller can write a parameter it knows only by name. `index` 0 writes a scalar parameter; 1 and up write one element of an array parameter — an array parameter has no value at 0, and a scalar one none at 1. `axis` names one axis; a combined mask is an `System.ArgumentException`, and so is a keyword the message table flags as a controller command. Nothing is sent when an argument is refused. A write the controller refuses is a `ControllerCommandException`.
// axis: One axis (`AxisRef.A` / `AAMOTION_AXIS_REF_A`, …, A–L); a combination of axes is not allowed
// keyword: The keyword (`eKeyword.Speed` / `AAMOTION_KEYWORD_SPEED`). Command keywords are refused
// value: The value to write, in the same units as a read
// index: 0 writes a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. In C# it is the last argument, 0 by default; in C it comes before `value`
void SetValue(AxisRef axis, eKeyword keyword, double value, int index = 0);

    // Writes value to the parameter keyword on axis, the write twin of aamotion_get_value: value is in the units that axis reads it in, converted and User-Units-scaled as the C# typed property writes it; same index rule. @return true only when the controller accepted the write. False, nothing sent: bad handle, axis not A..L, keyword unknown or a COMMAND, an index the parameter lacks.
// controller: The controller object / handle
// axis: One axis (`AxisRef.A` / `AAMOTION_AXIS_REF_A`, …, A–L); a combination of axes is not allowed
// keyword: The keyword (`eKeyword.Speed` / `AAMOTION_KEYWORD_SPEED`). Command keywords are refused
// index: 0 writes a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. In C# it is the last argument, 0 by default; in C it comes before `value`
// value: The value to write, in the same units as a read
bool aamotion_set_value(aamotion_controller controller, int axis, int keyword, int index, double value);

    Parameters

    Parameter Type Description
    axis AxisRef / int One axis (AxisRef.A / AAMOTION_AXIS_REF_A, …, A–L); a combination of axes is not allowed
    keyword eKeyword / int The keyword (eKeyword.Speed / AAMOTION_KEYWORD_SPEED). Command keywords are refused
    value double The value to write, in the same units as a read
    index int 0 writes a scalar; an array keyword starts at 1, in its own indexing. An array has no 0, a scalar no 1. In C# it is the last argument, 0 by default; in C it comes before value
    controller aamotion_controller The controller object / handle

    Returns

    C#: nothing. A combined axis mask or a command keyword throws ArgumentException, and a negative index or index 0 on an array parameter throws ArgumentOutOfRangeException; neither sends anything. A write the controller refuses throws ControllerCommandException.

    C: true only when the controller accepted the write. A bad handle, an axis outside A–L, an unknown keyword, a command keyword or an index the parameter lacks return false and send nothing; a refusal also returns false, with the reason on the error callback.

    Example

    // the write twin of GetValue: the units GetValue reads in, index 0 for a scalar
try
{
    c.SetValue(AxisRef.A, eKeyword.Speed, 20000);
    c.SetValue(AxisRef.A, eKeyword.GenData, 5, 10);      // AGenData[10] = 5
}
catch (ControllerCommandException ex)
{
    Console.WriteLine($"refused: ERR {ex.ErrorCode} {ex.Command}");
}

    /* the write twin of aamotion_get_value: User Units applied, index 0 for a scalar */

    Read User Units¶

    Tells the unit a keyword is read and written in on an axis, its name and factor (displayed value = counts × factor). With User Units off on the axis, a keyword outside every unit group, or UseUserUnits = false, it answers an empty name and factor 1, that is counts.

    Choose one conversion owner: (1) enable the SDK c.UseUserUnits switch and pass user units, letting the SDK convert using axis settings; or (2) disable SDK conversion and let the host convert values to counts on writes and back on reads. Apply one approach consistently to avoid double conversion. No customer configuration file is assumed.

    If one user unit is 1000 counts, approach 1 passes target 2 and the SDK converts it to 2000 counts; approach 2 disables SDK conversion and passes host-converted 2000. Convert feedback in the same layer, and use the appropriate velocity and acceleration factors as well.

    When to use it

    Showing the unit name in a UI, or checking whether an axis uses User Units before writing raw counts.

    Upload and download parameter files¶

    The same as PCSuite's parameter upload / download. Upload reads every controller parameter and saves it, with a header (product, firmware / FPGA version, date, checksum), to a .par file. Download reads a .par file, validates it against the connected controller, writes each parameter, and optionally runs CalcFilters and Save to keep it in flash. Ethernet links use bulk commands (50 per packet). AAComm runs the transfer: the two C# methods return at once and report through callbacks, the completion callback receiving AAComm's ParamHandlingSummary (namespace AAComm.Extensions); the C functions block until the transfer ends. An uploaded file's header line reads // AAComm version: with AAComm's version.

    Standalone demo: Upload a parameter file

    When to use it

    Backing up before shipping, restoring after a controller swap, loading one set of parameters into many machines.

    Signatures

    // AAMotionAPI

A parameter the controller refuses is left out of the file, named in a `// Not uploaded:` header line and in `AAComm.Extensions.ParamHandlingSummary.Rejections`; an empty reply fails the upload and writes no file.     Parameter Type Description
    controller MotionController / aamotion_controller A connected controller

    Returns

    C#: nothing; the outcome arrives in onDone. C: true only when the transfer finished with no error, refused parameter or cancel; on false the reason is in message.

    Notes

    • The C# callbacks run on a background thread. Download rewrites controller parameters; some cannot be written with the motor on, so disable it first.
    • For a replacement controller, use PCSuite to verify the target model, firmware, axis mapping, and backup source. Back up the target first. Wait for the completion callback of each transfer. Percentage reports transfer progress.
    • {'For an initial restore, use calcAndSave': "false and verify the results in RAM. Check the completion error and summary's ErrorCount, then read back key settings such as axis mapping, units, direction and limits. Once verified, follow the equipment procedure to calculate filters and save to flash."}
    • If the transfer is interrupted, earlier settings may already be active in RAM. Check the summary and read the controller back before deciding which configuration to restore.

    Example

    // Restore a previously verified backup to RAM. The caller keeps c connected.
AAMotionAPI.DownloadParameters(c, @"C:\backup\axis.par", calcAndSave: false,
    percent => Console.WriteLine($"download {percent}%"),
    (summary, error) =>
    {
        if (!string.IsNullOrEmpty(error))
            Console.WriteLine(error);
        else if (summary == null || summary.ErrorCount != 0)
            Console.WriteLine($"Check the download summary. Rejected rows: {summary?.ErrorCount}");
        else
            Console.WriteLine("Download finished. Verify the settings in RAM.");
    });

    char message[512];
/* blocks until done; false with the reason in message */
if (!aamotion_upload_parameters(h, "C:\\backup\\axis.par", message, sizeof message))
    printf("upload failed: %s\n", message);

/* write the file back; true = recalculate filters and save to flash */
if (!aamotion_download_parameters(h, "C:\\backup\\axis.par", true, message, sizeof message))
    printf("download failed: %s\n", message);
    SDK comments (original)
    • UploadParameters(MotionController, string, Action<int>, Action<ParamHandlingSummary, string>) — Asynchronously reads all controller parameters and saves them to a .par file (controller disk -> local file). Follows the PCSuite "Parameters Upload" convention: queries every supported parameter, writes them with header (product type, firmware/FPGA version, date, file checksum) to a plain ASCII .par file. A parameter the controller refuses is left out of the file, named in a // Not uploaded: header line and in AAComm.Extensions.ParamHandlingSummary.Rejections; an empty reply fails the upload and writes no file. Ethernet connections use bulk messages (up to 50 per packet); other channels send one by one. The call is non-blocking; subscribe to the callbacks to be notified of progress and completion.
    • DownloadParameters(MotionController, string, bool, Action<int>, Action<ParamHandlingSummary, string>) — Asynchronously writes controller parameters from a .par file (local file -> controller disk). Follows the PCSuite "Parameters Download" convention: reads the .par file, validates parameters against the connected controller, then sends each as a SET command. Ethernet connections use bulk messages (up to 50 per packet); other channels send one by one. After a successful download, optionally sends "ASave" plus per-axis "CalcFilters" to persist parameters to flash. The call is non-blocking; subscribe to the callbacks to be notified of progress and completion.
