SOURCE == 1 (User Program):

For VERSION_DATA = 1, the DATA section contains raw binary data (little-endian) with multiple printf messages.

Binary packet structure (after the header, before the messages slots):

  • uint8 n: number of printf messages
  • uint16 missed: messages dropped since last flush
  • uint16 freeBytesMsgQueue: remaining free bytes in FW printf buffer
  • uint8 freeDescSlots: remaining free descriptor slots

Then n times:

  • uint32 timeSec: seconds since power-on
  • uint32 timeTick: sub-second tick
  • uint8 thread: thread ID
  • uint16 len: text length in bytes
  • byte[len] textBytes: raw ASCII text (NOT null-terminated)
