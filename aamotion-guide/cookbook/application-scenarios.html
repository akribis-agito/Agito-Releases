    按工艺选择 API¶

    建立坐标与重复定位¶

    设备条件 选用 如何确认结果
    PCSuite 已交付回零表 普通 Home，启动后等待 HomingStat = 100。 核对轴、方向、零点和实际参考位置。
    正常起点离 Index 很近，且只会经过一个有效脉冲 直接找 Index。 先检查主编码器 Index 锁存能力。连续从同一点回零，比较重复位置。
    初始位置不确定且有机械限位开关 先找限位开关，再反向慢速找 Index。 检查限位输入极性和减速余量。超时先看实际运动方向与输入变化。
    装置允许触碰硬限位且没有开关 采用已调好的硬限位搜索。需要精确 Index 时，再慢速反向捕获。 用 HomingStep 区分搜索、接触和反向。电流、速度和保持时间按装置试验确认。

    运动前核对实际位置、坐标单位和目标。单轴到目标后才允许下步时，用 MoveAbsAndWait 或轮询 InTargetStat；给两独立轴同时下发时，分别确认到位。只看到 MotionStat 停止时，还要读终点、InTargetStat 与 MotionReason 来判断是否正常整定。命令已发出却等不到回复时，先读目标和当前位置再决定是否补发。详见上电到第一次运动和两轴批量启动。

    选路径和段间衔接¶

    目的 方法 关键区别
    独立定位两轴 多轴点位 各轴独立规划，分别等到位。
    只做一条协调直线或一个圆弧 矢量运动 由参与轴中的最低轴发起；圆心填绝对坐标。
    连续直线、圆弧、中途等信号或路径输出 CNC 先设模式、清旧队列，确认实际起点后下发。圆心传绝对坐标。
    已有每个采样点的 P/V/A/J PVAJ 下载点表，校验、Arm、Begin，再确认执行状态和最终位置。

    CNC 示例中，上一段终点就是下一段起点。直线接圆弧时先核两个半径；圆弧接 Delay 或换参与轴时，将前段末速设为 0。附加整圈的圆弧也用零末速。连续过角时检查相同参与轴、角点与固件轨迹限制，再选择足够低的衔接速度。首个拒绝应停止下发，确认停止后再清缓冲区重建。参见 CNC 排查。

    带工艺信号的运动¶

    • 飞拍或测量。 PEG 按位置输出，单点用于一次拍照，固定间距用于规则扫描，点表用于不等距特征。要测某个传感器沿发生时的位置，用 Lock 并检查 LockCntr 有新计数，再取 LockVal。共享引脚的产品上先确认启用的是哪一个功能。PEG 和 Lock
    • 压装。 先调低速接近和切换条件，再配置力源、目标、持续时间和退回。接近阶段观察位置与速度，切换看触发条件和控制模式，保压看实际力或电流，退回看目标与末端状态。力传感器标定、方向、限流和最大行程按设备确认。力控
    • 同步跟随。 固定比例跟随用电子齿轮，主轴一段行程内需要不同从轴位置曲线时用 ECAM。ECAM 先核对主轴信号、表范围、重复区间、主轴每点间距和起始相位；先试单次再配置循环。主信号选反馈还是参考位置取决于业务要跟随的是实际位置还是命令轨迹。电子齿轮 · 电子凸轮 · C++ 示例

    完整入门工程¶

    从交付 ZIP 解压整个 samples/。下面每个示例都有 C#、C++ 和 Python 程序。运动前先在 PCSuite 完成换相、使能，确认轴空闲以及目标和行程。传入你的 AGM800 地址或 firmware_sim.exe 的绝对路径。先从只读的 ReadInput 开始。

    语言 从解压目录运行
    C# dotnet run --project samples/app/quick/csharp/ReadInput/ReadInput.csproj -- <地址>，需要 .NET Framework 4.8 开发工具。
    C++ 用 Visual Studio 生成器运行 cmake -S samples/app/quick/cpp -B quick-build -A x64 -DAAMOTION_SDK_DIR=<SDK目录> 和 cmake --build quick-build --target ReadInput。运行 quick-build/ReadInput/Debug/ReadInput.exe <地址>。
    Python 先在 samples/single/python/ 运行 python get_sdk.py，或把 SDK 对应平台的库和服务器复制到该目录。再用 64 位 Python 运行 python samples/app/quick/python/read_input.py <地址>。

    使用本手册对应的 SDK 版本。把命令里的工程名换成相应示例。

    读数字输入¶

    读取输入 1，位号从 0 开始。切换输入后重跑，比较 0/1。Native 和 Python 的位读取失败时也可能返回 0，需要区分时读整个 DInPort 并检查读取结果。 工程 ReadInput (C# / C++), read_input.py (Python).

    var io = c.GetIO(AxisRef.A);
Console.WriteLine($"Input 1 = {io.GetDInPort(0)}");

    std::printf("Input 1 = %d\n", aamotion_get_d_in_port(h, A, 0));

    print("Input 1 =", am.get_d_in_port(h, A, 0))

    两轴批量定位¶

    A 到 10000，B 到 5000。C# 调用多轴 MoveAbs，Native 12 使用一个文本批次。两轴分别检查到位。 工程 MoveTwoAxes (C# / C++), move_two_axes.py (Python).

    var a = c.GetAxis(AxisRef.A);
var b = c.GetAxis(AxisRef.B);
Demo.Check(AAMotionAPI.MoveAbs(c, 10000, 2000, 10000, a, 10000, b, 5000), "MoveAbs");
Demo.Wait(() => a.InTargetStat == 4 && b.InTargetStat == 4, "Both axes in target");
Console.WriteLine($"A={a.Pos}, B={b.Pos}");

    char reply[256] = {};
check(aamotion_send_bulk_command_string(h,
    "AMotionMode=1;ARelTrgt=0;ASpeed=2000;AAccel=10000;ADecel=10000;AAbsTrgt=10000;"
    "BMotionMode=1;BRelTrgt=0;BSpeed=2000;BAccel=10000;BDecel=10000;BAbsTrgt=5000;ABegin;BBegin",
    reply, sizeof reply), "Two-axis batch refused");
wait_until([&] { return read(h, A, AAMOTION_KEYWORD_IN_TARGET_STAT) == 4 &&
                        read(h, B, AAMOTION_KEYWORD_IN_TARGET_STAT) == 4; }, "Both axes: settle timeout");
std::printf("A=%g, B=%g\n", read(h, A, AAMOTION_KEYWORD_POS), read(h, B, AAMOTION_KEYWORD_POS));

    commands = (
    "AMotionMode=1;ARelTrgt=0;ASpeed=2000;AAccel=10000;ADecel=10000;AAbsTrgt=10000;"
    "BMotionMode=1;BRelTrgt=0;BSpeed=2000;BAccel=10000;BDecel=10000;BAbsTrgt=5000;ABegin;BBegin"
)
check(am.send_bulk_command_string(h, commands) is not None, "Two-axis batch refused")
wait_until(lambda: all(read(am, h, axis, am.KEYWORD_IN_TARGET_STAT) == 4 for axis in (A, B)),
           "Both axes: settle timeout")
print("A =", read(am, h, A, am.KEYWORD_POS), "B =", read(am, h, B, am.KEYWORD_POS))

    按预设流程回零¶

    先在 PCSuite 保存 A 轴回零表。HomingStat = 100 后打印位置。 工程 HomeAxis (C# / C++), home_axis.py (Python).

    var axis = c.GetAxis(AxisRef.A);
axis.Home();
Demo.Wait(() =>
{
    double status = c.GetValue(AxisRef.A, eKeyword.HomingStat);
    Demo.Check(status >= 0, $"Homing failed: {status}");
    return status == 100;
}, "Homing");
Console.WriteLine($"Home complete: position = {axis.Pos}");

    check(aamotion_home(h, A), "Home refused");
wait_until([&] {
    const double status = read(h, A, AAMOTION_KEYWORD_HOMING_STAT);
    check(status >= 0, "Homing failed");
    return status == 100;
}, "Homing timeout");
std::printf("Home complete: position = %g\n", read(h, A, AAMOTION_KEYWORD_POS));

    check(am.home(h, A), "Home refused")

def homed():
    status = read(am, h, A, am.KEYWORD_HOMING_STAT)
    check(status >= 0, f"Homing failed: {status}")
    return status == 100

wait_until(homed, "Homing timeout")
print("Home complete: position =", read(am, h, A, am.KEYWORD_POS))

    双速定位¶

    相对走 10000。前 8000 用速度 4000，剩余距离用速度 1000。 工程 TwoSpeed (C# / C++), two_speed.py (Python).

    var axis = c.GetAxis(AxisRef.A);
Demo.Check(axis.MoveRelTwoSpeedAndWait(10000, 4000, 1000, 8000,
    accel: 50000, decel: 50000, timeout: 10000), "Two-speed move");
Console.WriteLine($"In target: position = {axis.Pos}");

    check(aamotion_move_rel_two_speed_and_wait(h, A, 10000, 4000, 1000, 8000,
    50000, 50000, -1, 10000), "Two-speed move failed");
std::printf("In target: position = %g\n", read(h, A, AAMOTION_KEYWORD_POS));

    check(am.move_rel_two_speed_and_wait(h, A, 10000, 4000, 1000, 8000,
                                     50000, 50000, -1, 10000), "Two-speed move failed")
print("In target: position =", read(am, h, A, am.KEYWORD_POS))

    CNC 直线¶

    以实际位置为起点，两轴各走 1000 counts，末速为 0。某一段推段中途失败时，先清空缓冲区并重建路径，再推下一段。工程 CncLine (C# / C++), cnc_line.py (Python).

    var group = c.GetGroup(AxisRef.A);
int x = (int)c.GetAxis(AxisRef.A).Pos;
int y = (int)c.GetAxis(AxisRef.B).Pos;
Demo.Check(group.ClearBuffer(), "ClearBuffer");
Demo.Check(group.SetStartPositions(x, y, null), "SetStartPositions");
Demo.Check(group.SetMotionProfile(100, 10000, 10000, 0), "SetMotionProfile");
Demo.Check(group.LinearAbsoluteXY(x + 1000, y + 1000, 1000, 0), "LinearAbsoluteXY");
Demo.Check(c.SendCommandString("AMotionMode=11", out _) &&
           c.SendCommandString("BMotionMode=11", out _), "Set CNC mode");
Demo.Check(group.Begin(), "Begin");
try { Demo.Wait(() => group.IsCNCCompleted(AxisRef.A), "CNC completion"); }
catch { group.Stop(); throw; }
Console.WriteLine($"CNC complete: A={c.GetAxis(AxisRef.A).Pos}, B={c.GetAxis(AxisRef.B).Pos}");

    const int x = static_cast<int>(read(h, A, AAMOTION_KEYWORD_POS));
const int y = static_cast<int>(read(h, B, AAMOTION_KEYWORD_POS));
check(aamotion_clear_buffer(h), "ClearBuffer");
check(aamotion_set_start_positions(h, A | B, x, y, 0), "SetStartPositions");
check(aamotion_set_motion_profile(h, 100, 10000, 10000, 0), "SetMotionProfile");
check(aamotion_linear_absolute_xy(h, x + 1000, y + 1000, 1000, 0), "LinearAbsoluteXY");
char reply[128] = {};
check(aamotion_send_command_string(h, "AMotionMode=11", reply, sizeof reply) &&
      aamotion_send_command_string(h, "BMotionMode=11", reply, sizeof reply), "Set CNC mode");
check(aamotion_cnc_begin(h), "Begin");
try { wait_until([&] { return aamotion_is_cnc_completed(h, A); }, "CNC completion timeout"); }
catch (...) { aamotion_group_stop(h); throw; }
std::printf("CNC complete: A=%g, B=%g\n", read(h, A, AAMOTION_KEYWORD_POS), read(h, B, AAMOTION_KEYWORD_POS));

    x = int(read(am, h, A, am.KEYWORD_POS))
y = int(read(am, h, B, am.KEYWORD_POS))
check(am.clear_buffer(h), "ClearBuffer")
check(am.set_start_positions(h, A | B, x, y, 0), "SetStartPositions")
check(am.set_motion_profile(h, 100, 10000, 10000, 0), "SetMotionProfile")
check(am.linear_absolute_xy(h, x + 1000, y + 1000, 1000, 0), "LinearAbsoluteXY")
check(am.send_command_string(h, "AMotionMode=11") is not None
      and am.send_command_string(h, "BMotionMode=11") is not None, "Set CNC mode")
check(am.cnc_begin(h), "Begin")
try:
    wait_until(lambda: am.is_cnc_completed(h, A), "CNC completion timeout")
except BaseException:
    am.group_stop(h)
    raise
print("CNC complete: A =", read(am, h, A, am.KEYWORD_POS), "B =", read(am, h, B, am.KEYWORD_POS))

    DataLogger 短记录¶

    立即记录 APos 1 秒，间隔 1 ms，打印点数。最短间隔取决于扫描周期，部分配置约为 61 µs。 工程 DataLogger (C# / C++), data_logger.py (Python).

    var config = new MotionController.DataLoggerConfiguration { DurationSec = 1, GapMs = 1 };
config.ParamsToRecord.Add("APos");
string error = c.ConfigureDataLogger(config);
Demo.Check(string.IsNullOrEmpty(error), error);
error = c.StartDataRecording();
Demo.Check(string.IsNullOrEmpty(error), error);
error = c.WaitForDataRecordingToEnd(5000);
Demo.Check(string.IsNullOrEmpty(error), error);
error = c.UploadDataLoggerData(out var result);
Demo.Check(string.IsNullOrEmpty(error), error);
var values = result.Vectors[0].Values;
Demo.Check(values.Count > 0, "No APos samples");
Console.WriteLine($"APos: {values.Count} samples");

    check(aamotion_data_rec_record(h, "APos", 1, 1, 0, 0, nullptr, 0, 0, false, 5000),
      "Record and upload APos");
int length = 0, gap = 0, vectors = 0, samples = 0;
check(aamotion_data_rec_info(h, &length, &gap, &vectors, &samples), "Read recording info");
check(vectors == 1 && samples > 0, "No APos samples");
std::printf("APos: %d samples\n", samples);

    check(am.data_rec_record(h, "APos", 1, 1, 0, 0, None, 0, 0, False, 5000),
      "Record and upload APos")
info = am.data_rec_info(h)
check(info is not None, "Read recording info")
_, _, vectors, samples = info
check(vectors == 1 and samples > 0, "No APos samples")
print(f"APos: {samples} samples")

    SlowLogger 慢记录¶

    记录 APos 约 2 秒，保存到 slow-logger.txt。最短间隔约 1 ms，长时间记录需定时上传 FIFO。 工程 SlowLogger (C# / C++), slow_logger.py (Python).

    c.ConfigureSlowLogger(10, 0, "APos");
c.LoggerOn = 1;
try
{
    Thread.Sleep(2000);
    string text = c.LoggerUpload();
    Demo.Check(!string.IsNullOrEmpty(text), "No logger data");
    File.WriteAllText("slow-logger.txt", text);
}
finally { c.LoggerOn = 0; }
Console.WriteLine("Saved slow-logger.txt");

    const char* signals[] = {"APos"};
check(aamotion_configure_slow_logger(h, 10, 0, signals, 1), "Configure SlowLogger");
check(aamotion_set_logger_on(h, 1), "Start SlowLogger");
std::this_thread::sleep_for(std::chrono::seconds(2));
char text[8192] = {};
const bool uploaded = aamotion_logger_upload(h, text, sizeof text);
check(aamotion_set_logger_on(h, 0), "Stop SlowLogger");
check(uploaded && text[0], "No logger data");
std::ofstream output("slow-logger.txt");
output << text;
output.close();
check(static_cast<bool>(output), "Write slow-logger.txt");
std::puts("Saved slow-logger.txt");

    check(am.configure_slow_logger(h, 10, 0, ["APos"]), "Configure SlowLogger")
check(am.set_logger_on(h, 1), "Start SlowLogger")
try:
    time.sleep(2)
    text = am.logger_upload(h)
    check(text, "No logger data")
    Path("slow-logger.txt").write_text(text, encoding="utf-8")
finally:
    check(am.set_logger_on(h, 0), "Stop SlowLogger")
print("Saved slow-logger.txt")
