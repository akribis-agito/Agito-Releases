Class AACommMnemonicHelper

Namespace
AAComm.Services
Assembly
AAComm.dll
SDK helper for controller-message string manipulation: axis letters, mnemonics,
array indexes and assignment separation, plus ordinal-ignore-case string helpers.


Controller messages have the shape <code><axis-letter><Mnemonic>[index]=value</code>
(e.g. <code>"APos"</code>, <code>"BGain[3]=5"</code>).
