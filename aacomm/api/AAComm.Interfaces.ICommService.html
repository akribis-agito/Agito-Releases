Phase 1 interface over CommAPI for consumers that want to mock or substitute the controller boundary (e.g., headless Core libraries, unit and integration tests).

public interface ICommService

Remarks

The interface intentionally exposes a small, additive subset of CommAPI's public surface — only what is required by the first canary (Terminal). Members will be added as new Core extractions surface new needs. CommAPI implements this interface natively; no adapter is required for production wiring (ICommService comm = CommAPIWrapper.Instance;).

DownloadArray(string, int, IReadOnlyList<double>, bool, int, bool)

Downloads contiguous floating-point array values and blocks for one final result. Ethernet only: on any other channel type it throws NotSupportedException. Uses Zynq stream transport when advertised by both peers; otherwise uses legacy bulk messages, or one message per element for a parameter not allowed in bulk. A timeout or disconnect is never retried because part of the array may already have been applied. Every element is checked against the controller's message table first: one whose index or value the table rules out ends the call as Rejected with that element's index and error code, and nothing is sent. A parameter the table refuses outright (unknown, read-only, not an array) throws ArgumentException.

ArrayDownloadResult DownloadArray(string parameter, int firstIndex, IReadOnlyList<double> values, bool continueOnError = false, int timeoutMs = 60000, bool skipUserUnits = false)

Parameters

parameter string

Axis-qualified array parameter without an index, for example BPVAJList.

firstIndex int

One-based array index receiving values[0].

values IReadOnlyList<double>

Contiguous values to download.

continueOnError bool

Continue applying values after a controller error.

timeoutMs int

Budget for each request and reply. The server arms the same budget against the controller and tears the channel down as fatal when it expires, so a stalled download also stalls whatever is queued behind it for every client on that channel.

skipUserUnits bool

Bypass User Units conversion for this download.

Returns

ArrayDownloadResult

Remarks

On ProtocolError with CrcMismatch the controller verifies the payload checksum only after applying every element, so the result reports a full AppliedCount for a write whose integrity check failed. Read the array back rather than trusting that count. Wire format: Firmware-Main docs/features/Array-Stream-Download.md.
