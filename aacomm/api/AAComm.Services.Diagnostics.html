AACommDebugLog

Process-wide, zero-config, always-on diagnostic log for the AAComm client — the client-side counterpart of AACommServer's debug log. Session-lifecycle events (construction, connect outcomes, sync-timeout expiries, FATALs, disconnects) accumulate in an in-memory ring; healthy steady state does zero file IO. A severe event (sync phase-2 teardown, FATAL, comms error) snapshots the ring to %LocalAppData%\PCSuite\AAComm_DebugLogs{yyyy_MM_dd_HH-mm-ss}{process}{pid}_{trigger}.log off the hot path (debounced, 5 s), because a library in the customer's process has no reliable exit hook to save on. Never per-message traffic — that is the AACommServer comm log's job.

Every line is tagged HH:mm:ss.fff [api#N/conn#M] text: api#N identifies the CommAPI instance, conn#M its successive channel opens; the connect line carries the full endpoint (and the socket's local port, which AACommServer's log can join against its per-client UserId).
