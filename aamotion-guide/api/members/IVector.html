    StopVec¶

    bool StopVec()

    VectorPause 沿路径减速并暂停（VecPause=1），VectorContinue 继续（VecPause=0），StopVec 停止矢量运动。

    暂停、继续与停止

    SDK 说明： Stop vector motion.

    参数： 无。

    返回类型： bool

    返回说明： Returns true if stopped successfully, otherwise false.

    命令被接受返回 true。

    VectorLinear¶

    bool VectorLinear(AxisRef axisRef, double? aPos, double? bPos, double? cPos, double? dPos, double? ePos, double? fPos, double? gPos, double? hPos, double speed, double accel, double decel, double emrgdec, int smooth)

    让掩码中的各轴以同一个矢量速度直线运动到各自的目标，同时启动、同时到达。函数写入 VecMemberAxes、VecType=0、矢量速度参数和各轴目标，把各轴设为 MotionMode=16，然后从发起轴 Begin。SetVectorParam 只写矢量速度参数。

    直线矢量运动

    SDK 说明： Perform linear vector motion. Note: The vector motion must be initiated from the axis object with the lowest index among the participating axes. For example, for (B, C) use axis B; for (D, E, F) use axis D. Start exercising

    参数 类型 方向 默认值 说明
    axisRef AxisRef 输入（值传递） 必传 参与运动的轴的掩码
    aPos double? 输入（值传递） 必传 A 轴目标；null 表示不参与
    bPos double? 输入（值传递） 必传 B 轴目标
    cPos double? 输入（值传递） 必传 C 轴目标
    dPos double? 输入（值传递） 必传 D 轴目标
    ePos double? 输入（值传递） 必传 E 轴目标
    fPos double? 输入（值传递） 必传 F 轴目标
    gPos double? 输入（值传递） 必传 G 轴目标
    hPos double? 输入（值传递） 必传 H 轴目标
    speed double 输入（值传递） 必传 矢量速度
    accel double 输入（值传递） 必传 矢量加速度
    decel double 输入（值传递） 必传 矢量减速度
    emrgdec double 输入（值传递） 必传 矢量急停减速度
    smooth int 输入（值传递） 必传 平滑系数 VecJerk（0–9，2^n 个周期的滑动平均）

    返回类型： bool

    返回说明： Returns true if executed successfully, otherwise false.

    运动启动返回 true。

    补充说明（SDK 原文）： A vector move requires its axes to agree on their User Units. One VecSpeed, VecAccel and VecDecel are applied across the whole move while each axis's target is in that axis's own units, which only means something if they measure the same quantity: every axis must carry the same unit name in the position, velocity and acceleration groups. Different scaling factors under one name are fine — two encoder resolutions on the same gantry still measure millimetres — but a rad axis and a cm axis have no common vector length, and an axis with User Units off is on controller counts, which does not match a scaled one. Every member is checked in all three groups; the axis this call was made on is one of them. A move needs at least two members, all among axes A..H (the controller's VecMemberAxes reaches H), and the axis this call was made on must be one of them and the lowest: it carries the profile and receives Begin, and the controller rejects any other shape. A call that breaks that is refused before anything is written — it returns false and raises MotionController.ErrorOccurred. Axes that disagree make the call return false and command nothing — before any parameter is read from or written to the controller — and raise MotionController.ErrorOccurred with code -1, the name of the method called, and a message naming the axes and the group. Setting MotionController.UseUserUnits to false puts every axis back on controller counts, which always matches.

    VectorArc¶

    bool VectorArc(AxisRef axis1, AxisRef axis2, double center1, double center2, double pos1, double pos2, int dir, int circles, double speed, double accel, double decel, double emrgdec, int smooth)

    在 axis1（X）和 axis2（Y）组成的平面里沿圆弧运动到终点。圆心是绝对坐标（VecArcCenter）。circles 是额外的整圈数（VecNumCircles），0 表示只走这段圆弧。

    圆弧矢量运动

    SDK 说明： Execute arc vector motion. Note: The vector motion must be initiated from the axis object with the lowest index among the participating axes. For example, for (B, C) use axis B; for (D, E, F) use axis D. /// Start exercising

    参数 类型 方向 默认值 说明
    axis1 AxisRef 输入（值传递） 必传 平面的第一个轴（X）
    axis2 AxisRef 输入（值传递） 必传 平面的第二个轴（Y）
    center1 double 输入（值传递） 必传 圆心在第一个轴上的绝对坐标
    center2 double 输入（值传递） 必传 圆心在第二个轴上的绝对坐标
    pos1 double 输入（值传递） 必传 第一个轴的终点
    pos2 double 输入（值传递） 必传 第二个轴的终点
    dir int 输入（值传递） 必传 方向，写入 VecArcDir：0 逆时针，1 顺时针
    circles int 输入（值传递） 必传 额外的整圈数；0 只走圆弧
    speed double 输入（值传递） 必传 矢量速度
    accel double 输入（值传递） 必传 矢量加速度
    decel double 输入（值传递） 必传 矢量减速度
    emrgdec double 输入（值传递） 必传 矢量急停减速度
    smooth int 输入（值传递） 必传 平滑系数
