    Pause¶

    bool Pause()

    Begin 开始执行缓冲区中的段（AAMotionAPI.Begin(c) 不带轴的重载就是 CNC 启动）；Pause 沿路径减速并保持在路径上，Resume 从原处继续；GroupStop / Stop 停止 CNC 运动；ClearBuffer 清空尚未执行的段。开始写新路径前先 ClearBuffer。

    启动、暂停、停止与清空

    SDK 说明： Pause CNC motion

    参数： 无。

    返回类型： bool

    返回说明： Returns true if pause command is sent successfully, otherwise false

    命令被接受返回 true。

    ClearBuffer¶

    bool ClearBuffer()

    Begin 开始执行缓冲区中的段（AAMotionAPI.Begin(c) 不带轴的重载就是 CNC 启动）；Pause 沿路径减速并保持在路径上，Resume 从原处继续；GroupStop / Stop 停止 CNC 运动；ClearBuffer 清空尚未执行的段。开始写新路径前先 ClearBuffer。

    启动、暂停、停止与清空

    SDK 说明： Clear CNC motion buffer. A segment push that fails partway leaves the segment open, and the controller refuses every later push (error 122) until the buffer is cleared. Stop the group if needed, clear the buffer and rebuild the path.

    参数： 无。

    返回类型： bool

    返回说明： Returns true if buffer is cleared successfully, otherwise false

    命令被接受返回 true。

    LinearAbsolute¶

    bool LinearAbsolute(int? aPos, int? bPos, int? cPos, int velCruise, int velEnd)

    向缓冲区追加一段直线，终点是绝对坐标。函数名中的字母表示参与运动的轴；LinearAbsolute(aPos, bPos, cPos, …) 的坐标可以为 null（C# 中），表示这个轴不动。

    直线插补

    SDK 说明： Perform multi-axis CNC absolute linear motion

    参数 类型 方向 默认值 说明
    aPos int? 输入（值传递） 必传 A 轴终点；null 表示不动
    bPos int? 输入（值传递） 必传 B 轴终点；null 表示不动
    cPos int? 输入（值传递） 必传 C 轴终点；null 表示不动
    velCruise int 输入（值传递） 必传 这一段的巡航速度（矢量速度），计数/秒
    velEnd int 输入（值传递） 必传 段末速度；0 表示在段末停下，大于 0 表示不停顿地进入下一段

    返回类型： bool

    返回说明： Returns true if command is sent successfully, otherwise false

    段被接受返回 true；被拒绝返回 false，原因见错误钩子。
