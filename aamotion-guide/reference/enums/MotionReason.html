    运动停止原因 MotionReason¶

    关键字 MotionReason：上一次运动为什么结束。运动意外停止时先读它，再根据原因读 MotorReason（电机为什么断使能）或 ConFlt（故障码）。
    C# 类型 AAMotion.MotionReason
    C 类型 aamotion_motion_reason_t
    对应关键字 MotionReason
    转成文字 EnumPropertyHelper.GetMotionReasonDes(int) · aamotion_get_motion_reason_des()

    读取并解释¶

    int v = (int)c.GetValue(AxisRef.A, eKeyword.MotionReason);
MotionReason e = (MotionReason)v;
string text = EnumPropertyHelper.GetMotionReasonDes(v);

    double v;
if (aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_MOTION_REASON, 0, &v)) {
    char text[256];
    aamotion_get_motion_reason_des((int)v, text, sizeof text);
    printf("%d: %s\n", (int)v, text);
}

    v = int(am.get_value(h, am.AXIS_A, am.KEYWORD_MOTION_REASON))
print(v, am.describe("motion_reason", v))

    2 AbortRequest AAMOTION_MOTION_REASON_ABORT_REQUEST 运动因 Abort 指令结束。 Abort request
    3 StopRepRequest AAMOTION_MOTION_REASON_STOP_REP_REQUEST 运动因 StopRep 指令结束。 Stop Rep. request
