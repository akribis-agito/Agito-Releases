Methods

IsUserUnitsConfig(string)

Returns whether the given mnemonic (without axis prefix) is a User Units config parameter: the scaling factor (FactorSuffix, e.g. "PosUnitFct") or the units-name char array (UnitsSuffix, e.g. "PosUnitUnt"). These are written only through the User Units API (ControllerMessagesContainer.TrySetUnitsSync): the units name is a multi-write char array whose adapter cache can't be kept correct by sniffing single raw writes, so raw assignments to them are rejected by the Tx-build gate. The read-only group array (GroupSuffix) and the event-driven enable parameter (UserUnitsEn) are deliberately NOT included.

MessageAssignsUserUnitsConfig(string)

Returns whether a full controller message (single axis prefix + mnemonic + optional [index] + assignment), e.g. "APosUnitFct=0.5" or "BPosUnitUnt[3]=109", assigns a User Units config parameter (see IsUserUnitsConfig(string)). Queries (no '='/',') return false. Provisioning tools use this to decide whether a bulk write needs a post-write CommAPI.RefreshUserUnits to resync the scaling cache the raw write left stale.

TryParseUserUnitsEnAssignment(string, out char, out bool)

Detects a single-axis UserUnitsEn assignment, e.g. "AUserUnitsEn=1" or "BUserUnitsEn,0". Returns false for queries (no '='/',') and for any other mnemonic. Used on the reply path to keep the enabled cache ack-authoritative and to fire the change event. Single-char axis prefix only.
