    .ctor¶

    SDK 说明： Creates a new FastReadCache.

    Enable¶

    void Enable()

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    FastReadCache 对象

    SDK 说明： Enables the cache and starts the refresh thread.

    参数： 无。

    返回类型： void

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。

    RegisterKeywords¶

    void RegisterKeywords(AxisRef axis, params eKeyword[] keywords)

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    FastReadCache 对象

    SDK 说明： Registers keywords to cache for a specific axis. A keyword the controller flags as a command is an System.ArgumentException and the whole call is refused: the refresh ships every registered keyword at the configured interval, so one accepted command registration would re-send it for as long as the cache runs.

    参数 类型 方向 默认值 说明
    axis AxisRef 输入（值传递） 必传 轴
    keywords eKeyword[] 输入（值传递） 必传 关键字列表

    返回类型： void

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。

    RegisterArrayElements¶

    void RegisterArrayElements(AxisRef axis, eKeyword keyword, params int[] indices)

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    FastReadCache 对象

    SDK 说明： Registers array elements to cache for a specific axis. For example: RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2, 3, 4) registers AAInPort[1], AAInPort[2], AAInPort[3], AAInPort[4].

    参数 类型 方向 默认值 说明
    axis AxisRef 输入（值传递） 必传 轴
    keyword eKeyword 输入（值传递） 必传 关键字
    indices int[] 输入（值传递） 必传 数组下标（从 1 开始）

    返回类型： void

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。

    T:System.ArgumentException: keyword is one the controller flags as a command; the refresh would send <axis><keyword>[<index>] at the configured interval.

    GetCachedValue¶

    double? GetCachedValue(AxisRef axis, eKeyword keyword)

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    FastReadCache 对象

    SDK 说明： Gets a cached value for the specified axis and keyword, without taking a lock. Returns null when the value is not registered, not yet refreshed or invalid, when the cache is disabled, and for MotionStat / InTargetStat while a motion just begun on the axis has not yet been seen to start.

    参数 类型 方向 默认值 说明
    axis AxisRef 输入（值传递） 必传 轴
    keyword eKeyword 输入（值传递） 必传 关键字

    返回类型： double?

    返回说明： The cached value, or null if not available.

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。

    RefreshNow¶

    void RefreshNow()

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    FastReadCache 对象

    SDK 说明： Forces an immediate refresh of all cached values on the calling thread. Does nothing while another refresh is in flight: it neither waits for that refresh nor raises FastReadCache.RefreshStarted. An exception thrown by a FastReadCache.RefreshStarted or FastReadCache.RefreshCompleted subscriber is reported on FastReadCache.RefreshError instead of propagating.

    参数： 无。

    返回类型： void

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。

    RefreshCompleted¶

    event Action RefreshCompleted

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    FastReadCache 对象

    SDK 说明： Event raised when cache refresh completes. On an enabled cache it is raised on a pool thread, so a slow subscriber never delays the next refresh, which may already have started when the subscriber runs; FastReadCache.RefreshNow raises it on the calling thread. An exception thrown by a subscriber is reported on FastReadCache.RefreshError.

    值类型： Action

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。
