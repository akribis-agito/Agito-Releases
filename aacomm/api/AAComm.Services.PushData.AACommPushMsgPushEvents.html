SOURCE == 2 (push events):

For VERSION_DATA = 1, the DATA section contains raw binary data (little-endian) with fixed-size event records.

Binary packet structure (after the header, before the records):

  • uint8 n: number of event records
  • uint16 missed: events dropped since the last successful flush
  • uint16 freeRows: remaining free rows in the controller's event queue
  • uint16 reserved: zero

Then n times, exactly 50 bytes each:

  • uint8 type: event type
  • uint8 axis: axis or port, NoAxis when controller-wide
  • uint32 timeSec: seconds since power-on
  • uint32 timeTick: sub-second tick
  • double data1..data5: type-specific values

DATA is validated by arithmetic: it must be exactly 7 + 50n bytes. The packet terminator ('>' CR) may follow it, because the binary IPC path delivers the controller's bytes untrimmed.
