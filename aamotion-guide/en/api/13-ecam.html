    Electronic cam (ECAM)¶

    An electronic cam makes a slave follow a master through a table: each time the master moves gap counts, the slave moves to the next table point, interpolating linearly between points. Tables live in the GenData array, up to 4 of them.

    Concept Meaning
    Master named by a keyword's CAN code, usually the master axis's PosRef (reference position) or Pos (feedback)
    Table GenData[startIndex..endIndex], each element a slave position (counts)
    Gap one table point per gap master counts; negative for the reverse direction
    Cycles cycles times; int.MaxValue repeats forever

    The controller side is under keyword ECAM overview. The C functions take one more argument, tableNum (1–10).

    Build and configure a cam table¶

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable build a linear or sine table in GenData; ECAM_SetTableData writes a table you computed (from ECAMStart to ECAMEnd). ECAM_ConfigureTable sets the range, cycles, master, gap and master start offset at once; or use SetTableRange, SetMaster, SetGap, SetCycleParams and SetMasterIni one by one.

    Standalone demo: A custom cam table

    When to use it

    A follower tracks the master non-linearly in flying shears, cut-to-length and electronic cam applications. See the PCSuite electronic cam controls and parameters.

    Notes

    • The SDK comments disagree on the masterKeyword example ("2 for PosRef" and "24 for PosRef"). Per the keyword manual, PosRef is 24 and Pos is 2 on an AGM800; codes differ by product and firmware, so read them with GetKeywordCANCode.
    • Table values are counts, never converted by User Units.

    Example

    int[] profile = new int[100];
for (int i = 0; i < profile.Length; i++)
    profile[i] = (int)(5000 * (1 - Math.Cos(Math.PI * i / 99.0)));   // a smooth rise of 10000

AAMotionAPI.ECAM_SetTableRange(c, AxisRef.B, 200, 299);
AAMotionAPI.ECAM_SetTableData(c, AxisRef.B, profile);             // written to GenData[200..299]
AAMotionAPI.ECAM_SetMaster(c, AxisRef.B, c.GetKeywordCANCode(eKeyword.PosRef));
AAMotionAPI.ECAM_SetGap(c, AxisRef.B, 200);
AAMotionAPI.ECAM_SetCycleParams(c, AxisRef.B, 200, 299, 1);       // run the table once
AAMotionAPI.ECAM_Start(c, AxisRef.B);
bool running = AAMotionAPI.ECAM_IsActive(c, AxisRef.B);

    Start, stop and status¶

    ECAM_Start makes the slave follow the master through the chosen table; then move the master and the slave follows. ECAM_Stop ends the cam motion, ECAM_IsActive tells whether it is running, ECAM_GetCycleCount reads the cycles done.

    Standalone demo: Follow a sine cam

    When to use it

    Starting and stopping cam following and monitoring the cycle count.

bool aamotion_ecam_start(aamotion_controller controller, int axis, int tableNum);

// Stops ECAM motion.
// controller: The controller object
// axis: The slave axis
bool aamotion_ecam_stop(aamotion_controller controller, int axis);

// @return true while ECAM motion is active.
// controller: The controller object
// axis: The slave axis
bool aamotion_ecam_is_active(aamotion_controller controller, int axis);

// Reads the table's current cycle count into *count; *count is written only when the read succeeded.
// controller: The controller object
// axis: The slave axis
// tableNum: Cam table number, 1–10 (C# may omit it for 1; C must pass it)
// count: Number of values in `data`
bool aamotion_ecam_get_cycle_count(aamotion_controller controller, int axis, int tableNum, int* count);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object
    axis AxisRef / int The slave axis
    tableNum int Cam table number, 1–10 (C# may omit it for 1; C must pass it)
    count int* Number of values in data

    Returns

    ECAM_Start / ECAM_Stop return true when accepted; ECAM_IsActive true while running; ECAM_GetCycleCount the count.

    Example

    ISingleAxis slave = c.GetAxis(AxisRef.B);
int posRefCode = c.GetKeywordCANCode(eKeyword.PosRef);   // follow the master's reference position

// 360 points of a sine cam stored in GenData from index 100
slave.ECAM_CreateSinusoidalTable(amplitude: 20000, offset: 0, numPoints: 360, startIndex: 100);
// one cam point every 100 master counts, master = axis A's PosRef, repeat forever
slave.ECAM_ConfigureTable(startIndex: 100, endIndex: 459, startCycIndex: 100, endCycIndex: 459,
    cycles: int.MaxValue, masterKeyword: posRefCode, gap: 100);
slave.ECAM_Start();

AAMotionAPI.Jog(c, AxisRef.A, 10000);                     // move the master
Thread.Sleep(5000);
Console.WriteLine("cycles: " + slave.ECAM_GetCycleCount());
slave.ECAM_Stop();

    aamotion_ecam_start(h, AAMOTION_AXIS_REF_B, 1);
aamotion_jog(h, AAMOTION_AXIS_REF_A, 10000);          /* move the master for 5 s */
sleep_ms(5000);
int cycles = 0;
if (aamotion_ecam_is_active(h, AAMOTION_AXIS_REF_B) && aamotion_ecam_get_cycle_count(h, AAMOTION_AXIS_REF_B, 1, &cycles))
    printf("cycles: %d\n", cycles);
aamotion_stop(h, AAMOTION_AXIS_REF_A);
aamotion_ecam_stop(h, AAMOTION_AXIS_REF_B);
