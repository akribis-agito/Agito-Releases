a container class that contains connected controller messages data


automatically initialized by <xref href="AAComm.CommAPI.Connect(AAComm.Services.ConnectionData%2cSystem.Boolean)" data-throw-if-not-resolved="false"></xref><p></p>

automatically cleared by <xref href="AAComm.CommAPI.Disconnect" data-throw-if-not-resolved="false"></xref> (or any event that leads to disconnection)


may be re-initialized (if need) by using <xref href="AAComm.Services.ControllerMessagesContainer.InitContainerFromFile(System.String)" data-throw-if-not-resolved="false"></xref><p></p>

NOTE: CTOR will throw if failed initializing container with default messages (indicates API package corruption)


In case of <xref href="AAComm.Shared.ConnectResult.CorruptAboutFile" data-throw-if-not-resolved="false"></xref>, see <xref href="AAComm.Services.ControllerMessagesContainer.InitErr" data-throw-if-not-resolved="false"></xref> for "corruption" reason
