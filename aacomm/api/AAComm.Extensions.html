AACommBinFwInfo

Helper class for parsing AGM800 binary firmware files (.bin) to extract identity and version information. Uses magic markers embedded in the Zynq binary format.

AACommDownloadFPGA
Asynchronous service class used for downloading FPGA to controller (NOT in BOOT mode)


When starting the DL process, the API state must be NOT connected.


Process ends with API state: Disconnected (success or error)
AACommDownloadFPGAEtherCat
Asynchronous service class used for downloading FPGA to controller (NOT in BOOT mode)


When starting the DL process, the API state must be NOT connected.


Process ends with API state: Disconnected (success or error)
AACommDownloadFPGARemote
Asynchronous service class used for downloading FPGA to AGM400 and AGM800 products Remote Unit


Make sure to set the correct <xref href="AAComm.Extensions.AACommRemoteFpgaInfo.Port" data-throw-if-not-resolved="false"></xref> and <xref href="AAComm.Extensions.AACommRemoteFpgaInfo.AllowForce" data-throw-if-not-resolved="false"></xref> (if need)
When starting the DL process, the API state must be NOT connected.


Process ends with API state: Disconnected (success or error)


Process can't be canceled in the middle.
AACommDownloadFW
Asynchronous service class used for downloading FW to controller (in regular or BOOT mode)


When starting the DL process, the API state must be NOT connected.


Process ends with API state: Disconnected (success or error)


NOTE: non - AGM800 products do NOT support flashing FW on other than 172.1.1 subnets


NOTE: FW download is NOT supported over CAN — download over Ethernet (AGM800) or RS-232 (serial)
AACommDownloadUP
Asynchronous service class used for downloading User Program to controller


The API object passed in CTOR must be connected, and NOT used during download process
AACommFwInfo
Helper class used to read HEX files FW info, and to validate HEX/BIN and VER files prior to FW download <xref href="AAComm.Extensions.AACommDownloadFW" data-throw-if-not-resolved="false"></xref><p></p>

For reading FW info, create an instance of this class <xref href="AAComm.Extensions.AACommFwInfo.%23ctor(System.String%2cAAComm.Services.ConnectionData)" data-throw-if-not-resolved="false"></xref><p></p>

For validating FW files prior to FW download, use the method <xref href="AAComm.Extensions.AACommFwInfo.ValidateFwFiles(AAComm.Services.ConnectionData%2cSystem.String)" data-throw-if-not-resolved="false"></xref><p></p>

Older FW HEX files don't contain FW information. Opening such files will result in all the properties being invalid.


Use <xref href="AAComm.Extensions.AACommFwInfo.DataValid" data-throw-if-not-resolved="false"></xref> to verify that the FW information was read successfully.
