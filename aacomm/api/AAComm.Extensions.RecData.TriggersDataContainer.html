TriggersDataContainer(List<TriggerContainer>, MultiTriggerModes, int, List<LogicalTriggerRelation>) 

Constructor for using complex triggers for Rec. System A


Throws on invalid arguments


Triggers list should contain at least one trigger


Argument "triggersMode" should get values 1 (for LogicalMode) or 2 (for SerialMode), other values will throw exception


triggersLogicalConnection defines the logic between the triggers, keep 'null' for single and <xref href="AAComm.Extensions.RecData.MultiTriggerModes.Serial" data-throw-if-not-resolved="false"></xref> triggers


triggersLogicalConnection[0] - logical connection (AND, OR) between trigger1 / trigger2


triggersLogicalConnection[1] - logical connection (AND, OR) between trigger2 / trigger3
