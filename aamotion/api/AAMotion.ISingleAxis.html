ComtMode 

Commutation mode parameter array


Index 1: Auto-phasing method

  • 0: Jump to zero phase
  • 1: Reserved
  • 2: Absolute encoder + preset offset
  • 3: Special encoder and Hall switch
  • 4: Encoder and Hall/encoder switch
  • 5: Minimum jump search
  • 6: Hall commutation only
Index 2: Voltage for each step of auto-phasing in jump to zero phase method


Index 3: Duration for each step of auto-phasing in jump to zero phase method


Index 4: Absolute encoder reading when defining zero electrical angle in auto-phasing based on absolute encoder


Index 5: Set to 1282 to start auto-phasing process


Index 6: Jump to zero phase auto-phasing process mode, 0 for jump, 1 for smooth (recommended)


Index 7~17: Reserved


Index 18: Required accuracy for auto-phasing completion


Index 19: Event for auto-execution of auto-phasing

  • 0: Automatic on power-up
  • 1: Manual request only
  • 2: Automatic when motor is enabled after power-up (if needed)
  • 3: Automatic on power-up and when motor is enabled

EventType 

Event type, readable and writable.


The event generates a pulse on the specified output when the actual feedback position equals the required compare position.


EventType = 0: A pulse is generated when the feedback position equals the position in EventBegPos.


EventType = 1: Interval event. The first pulse is generated when the position equals EventBegPos.


Another pulse is generated each time the distance defined by EventGap is passed. When the position exceeds EventEndPos, pulses stop.


EventType = 2: Table event. The positions at which events should be generated are input into the GenData[] array.


ETStart is the start index of the event table, ETEnd is the end index. The positions in the table must be sorted from low to high.

Sequence: Motor On → Configure Lock (300 ms) → Jog to Hard Stop → Jog to Index → Move to Lock → Disable Lock (300 ms) → Wait (300 ms) → Set Position (300 ms) → End.


Direction logic:


- <code>direction = 1</code> (Positive): Jog to hard stop at <code>+fastSpeed</code>, jog to index at <code>+slowSpeed</code>, move to lock at <code>-slowSpeed</code>.
