    点位运动与 Jog¶

    最常用的运动：移动到一个绝对位置、移动一段距离、以一个速度持续运动（Jog）。这些函数把运动参数写进控制器再发 Begin，例如 MoveAbs(c, AxisRef.A, 100000, 20000) 实际发送：

    ASpeed=20000
AMotionMode=1
ARelTrgt=0
AAbsTrgt=100000
ABegin

    位置、速度、加速度的单位是轴的用户单位（没有启用时是计数、计数/秒、计数/秒²）。运动前轴必须已使能、已换相（如需要）；运动中不能再发新的 Begin。

    运动结束与整定到位¶

    MotionStat == 0 表示运动结束，InTargetStat == 4 表示整定到位。两者含义不同；异常停止也可能让 MotionStat 回到 0，应结合 MotionReason 与错误信息判断。

    绝对运动¶

    把一个轴移动到指定的绝对位置，发出命令后立即返回，不等运动结束。速度、加速度、减速度可选：C# 中不传就沿用控制器里当前的 Speed、Accel、Decel。多轴启动行为见本章“多轴批量启动点位”。

    什么时候用

    移动到一个已知位置（取放位置、工位）。需要等到位再做下一步时用 MoveAbsAndWait。

    实际发送的命令

    {Axis}Speed = {speed}//If 'speed' is not empty

    返回值

    单轴 C# 方法无返回值，失败时按异常处理；C 返回 bool。多轴重载返回 true 表示批量命令被接受，不表示已到位；数组长度不匹配、轴不属于同一控制器或命令被拒绝时失败。

    注意

    • C 接口没有“沿用当前值”：速度、加速度、减速度三个参数每次都会写入控制器，必须传实际要用的值。
    • 函数返回时运动刚刚开始。要等到位，用 MoveAbsAndWait，或轮询 InTargetStat。

    示例

    ISingleAxis a = c.GetAxis(AxisRef.A);
a.MoveAbs(100000, speed: 20000, accel: 200000, decel: 200000);
Console.WriteLine("absolute move requested; inspect errors and actual state");
// Alternative: AAMotionAPI.MoveAbs(c, AxisRef.A, 100000, 20000).

    /* C has no "keep current": always pass the speed, accel and decel you want */
if (!aamotion_move_abs(h, AAMOTION_AXIS_REF_A, 100000, 20000, 200000, 200000))

    绝对运动并等待到位¶

    发出绝对运动后等待整定到位：InTargetStat == 4。这表示满足控制器配置的 InTargetTol、InTargetTime，不要求 Pos 与目标浮点数完全相等。MotionStat == 0 只表示运动结束。等待超时或状态读取失败返回 false。C 接口为 aamotion_move_abs_and_wait。

    什么时候用

    顺序流程中，下一步必须等轴到位（例如到位后才触发相机）。界面程序放到后台线程。

    函数原型

    // AAMotionAPI
// Move the specified axis to an absolute position and wait until the move is completed或超时。 Like `AAMotionAPI.MoveAbs`, it disarms a pending two-speed change.
// controller: 控制器对象
// axis: 一个轴
// position: 目标绝对位置
// speed: 可选，速度
// accel: 可选，加速度
// decel: 可选，减速度
// timeout: 最长等待毫秒数，默认 300000（5 分钟）
// 返回值: True when the controller accepted `Begin` and the axis reached the target within the timeout; false at once when `Begin` was refused, otherwise false at the timeout
static bool MoveAbsAndWait(MotionController controller, AxisRef axis, double position, double? speed = null, double? accel = null, double? decel = null, int timeout = 300000);

// ISingleAxis
// Performs an absolute position move and waits until the move is completed or a timeout occurs.
// position: 目标绝对位置
// speed: 可选，速度
// accel: 可选，加速度
// decel: 可选，减速度
// timeout: 最长等待毫秒数，默认 300000（5 分钟）
// 返回值: Returns true if the axis reaches the target position within the timeout period; otherwise, returns false — on the timeout, or at once when a poll of the in-target status fails (an error reply or a dead link), which `MotionController.LastReadError` distinguishes from a timeout.
bool MoveAbsAndWait(double position, double? speed = null, double? accel = null, double? decel = null, int timeout = 300000);

    // aamotion_move_abs, then waits for the axis to reach the target. @param timeout Milliseconds to wait for the axis to report in-target. @return false at once when the controller refuses Begin, or at the timeout when the axis has not arrived; on a timeout the motion KEEPS RUNNING (call aamotion_stop to abort).
// controller: 控制器对象
// axis: 一个轴
// position: 目标绝对位置
// speed: 可选，速度
// accel: 可选，加速度
// decel: 可选，减速度

bool aamotion_move_abs_and_wait(aamotion_controller controller, int axis, double position, double speed, double accel, double decel, int timeout);

    axis AxisRef / int 一个轴 —
    position double 目标绝对位置 AbsTrgt
    speed double? / double 可选，速度 Speed

    实际发送的命令

    {Axis}RelTarget = 0
{Axis}AbsTarget = {position}
{Axis}SpeedChgOn = 0 (where the controller has it: disarms a pending two-speed change)
{Axis}MotionMode = 1
{Axis}Speed = {speed} (if speed is specified)
{Axis}Accel = {accel} (if accel is specified)
{Axis}Decel = {decel} (if decel is specified)
{Axis}Begin

    返回值

    在超时内到位返回 true；超时或读状态失败返回 false，原因可从 c.LastReadError 区分。

    注意

    • 返回 false 时运动还在继续，轴不会自动停止；需要的话自己调用 Stop。
    • 这个调用会阻塞到到位或超时，不要在界面线程里调用。

    示例

    bool arrived = AAMotionAPI.MoveAbsAndWait(c, AxisRef.A, 100000, 20000, 200000, 200000, timeout: 10000);
Console.WriteLine("absolute move arrived: " + arrived);
if (!arrived)
{
    // timed out, or a status poll failed: the motion may still be running
    AAMotionAPI.Stop(c, AxisRef.A);
    Console.WriteLine("not in target: " + c.LastReadError?.Message);
}

    if (!aamotion_move_abs(h, AAMOTION_AXIS_REF_A, 100000, 20000, 200000, 200000))
    return;
/* poll the settling status live; aamotion_move_abs_and_wait does the same */
for (int i = 0; i < 200; ++i)
{
    double stat = 0;
    if (!aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_IN_TARGET_STAT, 0, &stat))
        break;
    if (stat == AAMOTION_IN_TARGET_STAT_TARGET_REACHED)
        return;
    sleep_ms(50);
}
aamotion_stop(h, AAMOTION_AXIS_REF_A);
fprintf(stderr, "not in target: timeout or status read failed; stop requested\n");
/* move and wait in target, at most 10000 ms; false on timeout: the motion may still be running */
if (!aamotion_move_abs_and_wait(h, AAMOTION_AXIS_REF_A, 100000, 20000, 200000, 200000, 10000))
    aamotion_stop(h, AAMOTION_AXIS_REF_A);

    相对运动¶

    从当前目标位置再移动一段距离（ARelTrgt=distance），正负号决定方向。AAMotionAPI.MoveRelative 是单轴版本；AAMotionAPI.MoveRel 是 2–6 轴和数组的多轴版本；ISingleAxis.MoveRel 是轴对象上的单轴版本。MoveRelAndWait 等到位后返回，规则同 MoveAbsAndWait。

    多轴批量启动点位¶

    当前 docs/aamotion-guide 分支的多轴 MoveAbs / MoveRel 把各轴参数和目标批量下发，最后发送各轴 Begin，使各轴一起启动。speed、accel、decel 原样用于每根轴，不按距离比例分配，所以不保证同时到达，也不保证直线路径。C# 这三个参数传 null 时分别保留各轴现有值。需要协调轨迹时使用固件支持的 CNC、矢量或相应龙门功能。

    独立小 Demo：两轴批量启动

    什么时候用

    多根独立轴一起启动，随后分别确认各轴是否完成和整定到位。

    函数原型

    // Moves several axes of one controller to absolute positions: every target is written first and every Begin last, in one packet on Ethernet/simulation. RS-232/CAN send each command alone, so there the axes begin one after another. The controller executes each Begin separately; use vector motion for same-sample or coordinated straight-line motion. Each axis gets the same speed, accel and decel. @param axes count axis values, each one AAMOTION_AXIS_REF_* bit, none repeated. @param positions count targets, in the order of axes. @return false, nothing sent, for a bad handle, a NULL array, count outside 1..the axis count, or an entry that is not one axis bit or is repeated. A false from the controller does not prove no axis started: an earlier axis may have accepted its Begin, so stop all of them on failure.
// controller: 控制器句柄
// axes: 轴数组，每个元素是一个 `AAMOTION_AXIS_REF_*`
// positions: 每根轴的目标位置，和 `axes` 一一对应
// count: 数组长度（1 到轴数）
// speed: 每根轴的速度，原样写入
// accel: 每根轴的加速度，原样写入
// decel: 每根轴的减速度，原样写入
bool aamotion_move_abs_multi(aamotion_controller controller, const int* axes, const double* positions, int count, double speed, double accel, double decel);

// As aamotion_move_abs_multi with relative distances; an axis given a 0 distance is left untouched.
// controller: 控制器句柄
// axes: 轴数组，每个元素是一个 `AAMOTION_AXIS_REF_*`
// distances: 每根轴的相对距离；0 表示不动这根轴
// count: 数组长度（1 到轴数）
// speed: 每根轴的速度，原样写入
// accel: 每根轴的加速度，原样写入
// decel: 每根轴的减速度，原样写入
bool aamotion_move_rel_multi(aamotion_controller controller, const int* axes, const double* distances, int count, double speed, double accel, double decel);

    参数

    参数 类型 说明
    controller aamotion_controller 控制器句柄
    axes const int* 轴数组，每个元素是一个 AAMOTION_AXIS_REF_*
    positions const double* 每根轴的目标位置，和 axes 一一对应
    count int 数组长度（1 到轴数）
    speed double 每根轴的速度，原样写入
    accel double 每根轴的加速度，原样写入
    decel double 每根轴的减速度，原样写入
    distances const double* 每根轴的相对距离；0 表示不动这根轴

    注意

    • C 中调用 aamotion_move_abs_multi 或 aamotion_move_rel_multi：轴和目标分别传为一一对应的数组，count 为轴数，最后三个参数依次是速度、加速度、减速度。
    • “一起启动”指各轴的 Begin 在同一个批量命令里发出，不是在同一个采样周期：固件逐个处理每条 Begin。需要各轴在同一采样周期启动或走直线时，用矢量运动。
    • 以太网和仿真支持批量发送；超过单包命令数时会拆包。不支持批量的通道逐条发送，不能承诺相同的启动时刻。
    • 批量命令遇首个错误会停止后续命令。如果后面的 Begin 失败，前面的轴可能已经启动；返回 false 不会自动停止已运动的轴，须检查各轴并按需 Stop。

/* Arguments after count: speed, acceleration, deceleration. */

    Jog（持续运动）¶

    以给定速度持续运动，直到 Stop、Abort、限位或故障。速度的正负决定方向。实际发送 ASpeed=velocity、AMotionMode=0、ABegin。

    参数 类型 说明 写入的关键字

    开始运动（Begin）¶

    按当前已经写好的 MotionMode、目标和速度参数启动运动，相当于发送 ABegin。上面的运动函数内部都会调用它；只有自己逐个设置参数时才需要直接用。AAMotionAPI.Begin(controller)（不带轴）的重载用于启动 CNC 运动，见 CNC 章节。
