    用户程序¶

    控制器可以运行在 PCSuite IDE+ 中编写、下载的用户程序，多个线程（thread）同时运行，每个线程执行一个任务（task）。上位机程序可以启动、暂停、复位这些线程，通过 GenData / UserParam 数组和程序交换数据，并接收程序中 printf 的输出。

    典型分工：实时性要求高的动作（IO 联动、等待信号、计数）放在用户程序里；配方、界面、数据记录放在上位机程序里。

    运行、暂停和复位线程¶

    函数 命令 作用
    ProgRun(thread, task) ProgRun 让线程从头运行一个任务（已暂停的线程继续运行）
    ProgHalt(thread) ProgHalt 暂停一个线程
    ProgHaltAll ProgHaltAll 暂停所有线程
    ProgReset(thread) ProgReset 复位线程，下次从头运行
    AutoExec(true) AutoExec=1 上电后自动运行用户程序；保存到 Flash 后生效

    独立小 Demo：运行、暂停与复位线程

    独立小 Demo：暂停所有线程

    什么时候用

    启动、暂停、复位控制器上的用户程序；做成“开始 / 暂停 / 复位”按钮。

    函数原型

    // AAMotionAPI
// Start IDE+ program execution
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// threadNumber: 线程号
// taskNumber: 任务号（程序中的任务标签）
// 返回值: Returns true if started successfully, otherwise false
static bool ProgRun(MotionController controller, AxisRef axis, int threadNumber, int taskNumber);

// Pause IDE+ program
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// threadNumber: 线程号
// 返回值: Returns true if paused successfully, otherwise false
static bool ProgHalt(MotionController controller, AxisRef axis, int threadNumber);

// Pause all IDE+ programs
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// 返回值: Returns true if paused successfully, otherwise false
static bool ProgHaltAll(MotionController controller, AxisRef axis);

// Reset IDE+ program
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// threadNumber: 线程号
// 返回值: Returns true if reset successfully, otherwise false
static bool ProgReset(MotionController controller, AxisRef axis, int threadNumber);

// Enable or disable IDE+ auto execution
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// enable: true 开启上电自动运行
// 返回值: Returns true if set successfully, otherwise false
static bool AutoExec(MotionController controller, AxisRef axis, bool enable);

// ISingleAxis
// Run a task on the specified thread.
// threadNumber: 线程号
// taskNumber: 任务号（程序中的任务标签）
// 返回值: Returns true if the task started successfully, otherwise false.
bool ProgRun(int threadNumber, int taskNumber);

// Pause the specified thread.
// threadNumber: 线程号
// 返回值: Returns true if the thread was paused successfully, otherwise false.
bool ProgHalt(int threadNumber);

// Pause all threads.
// 返回值: Returns true if all threads were paused successfully, otherwise false.
bool ProgHaltAll();

// Reset the specified thread.
// threadNumber: 线程号
// 返回值: Returns true if the thread was reset successfully, otherwise false.
bool ProgReset(int threadNumber);

// Enable or disable auto-execution of IDE program on power-up.
// enable: true 开启上电自动运行
// 返回值: Returns true if auto-execution mode was set successfully, otherwise false.
bool AutoExec(bool enable);

    // Programs written in the PCSuite IDE run on the controller in numbered threads. Runs task taskNumber on thread threadNumber.
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// threadNumber: 线程号
// taskNumber: 任务号（程序中的任务标签）
bool aamotion_prog_run(aamotion_controller controller, int axis, int threadNumber, int taskNumber);

// Pauses thread threadNumber.
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// threadNumber: 线程号
bool aamotion_prog_halt(aamotion_controller controller, int axis, int threadNumber);

// Pauses all threads.
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
bool aamotion_prog_halt_all(aamotion_controller controller, int axis);

// Resets thread threadNumber.
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// threadNumber: 线程号
bool aamotion_prog_reset(aamotion_controller controller, int axis, int threadNumber);

// Enables or disables running the user program at power-up.
// controller: 控制器对象 / 句柄
// axis: 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
// enable: true 开启上电自动运行
bool aamotion_auto_exec(aamotion_controller controller, int axis, bool enable);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    axis AxisRef / int 发命令用的轴前缀（用户程序是控制器级的，一般用 A）
    threadNumber int 线程号
    taskNumber int 任务号（程序中的任务标签）
    enable bool true 开启上电自动运行

    实际发送的命令

    {Axis}ProgRun[{threadNumber}],{taskNumber}

    返回值

    命令被接受返回 true。

    注意

    • 线程状态、任务号的含义见关键字 ProgRun。下载用户程序用 PCSuite 或 aacomm.cli。
    • 在 PCSuite IDE+ 按目标固件编译并下载程序，确认下载完成后，从实际工程中核对线程号和任务号。先订阅打印事件再调用 ProgRun，用状态和日志确认启动的是预期任务。确认设备确实需要上电自启后再配置 AutoExec。

    示例

    AAMotionAPI.ProgRun(c, AxisRef.A, threadNumber: 1, taskNumber: 1);   // AProgRun[1],1
// ...
AAMotionAPI.ProgHalt(c, AxisRef.A, 1);       // pause thread 1
AAMotionAPI.ProgReset(c, AxisRef.A, 1);      // back to the start of its task
AAMotionAPI.ProgHaltAll(c, AxisRef.A);       // pause every thread
AAMotionAPI.AutoExec(c, AxisRef.A, true);    // run the program at power-up (save to keep it)

    aamotion_prog_run(h, AAMOTION_AXIS_REF_A, 1, 1);    /* thread 1 runs task 1 */
aamotion_prog_halt(h, AAMOTION_AXIS_REF_A, 1);
aamotion_prog_reset(h, AAMOTION_AXIS_REF_A, 1);
aamotion_prog_halt_all(h, AAMOTION_AXIS_REF_A);
aamotion_auto_exec(h, AAMOTION_AXIS_REF_A, true);
    SDK 原文注释（英文）
    • ProgRun(MotionController, AxisRef, int, int) — Start IDE+ program execution Returns: Returns true if started successfully, otherwise false {Axis}ProgRun[{threadNumber}],{taskNumber}
    • ProgHalt(MotionController, AxisRef, int) — Pause IDE+ program Returns: Returns true if paused successfully, otherwise false {Axis}ProgHalt[{threadNumber}]
    • ProgHaltAll(MotionController, AxisRef) — Pause all IDE+ programs Returns: Returns true if paused successfully, otherwise false {Axis}ProgHaltAll
    • ProgReset(MotionController, AxisRef, int) — Reset IDE+ program Returns: Returns true if reset successfully, otherwise false {Axis}ProgReset[{threadNumber}]
    • AutoExec(MotionController, AxisRef, bool) — Enable or disable IDE+ auto execution Returns: Returns true if set successfully, otherwise false {Axis}AutoExec={value} //where value is 1 for enable, 0 for disable
    • ProgRun(int, int) — Run a task on the specified thread. Returns: Returns true if the task started successfully, otherwise false.
    • ProgHalt(int) — Pause the specified thread. Returns: Returns true if the thread was paused successfully, otherwise false.
    • ProgHaltAll() — Pause all threads. Returns: Returns true if all threads were paused successfully, otherwise false.
    • ProgReset(int) — Reset the specified thread. Returns: Returns true if the thread was reset successfully, otherwise false.
    • AutoExec(bool) — Enable or disable auto-execution of IDE program on power-up. Returns: Returns true if auto-execution mode was set successfully, otherwise false.
    • aamotion_prog_run — Programs written in the PCSuite IDE run on the controller in numbered threads. Runs task taskNumber on thread threadNumber.
    • aamotion_prog_halt — Pauses thread threadNumber.
    • aamotion_prog_halt_all — Pauses all threads.
    • aamotion_prog_reset — Resets thread threadNumber.
    • aamotion_auto_exec — Enables or disables running the user program at power-up.

    接收程序的 printf 输出¶

    用户程序中每输出一行 printf，控制器就主动推送一次，SDK 调用这个回调。UserProgramPrintMessage 带有控制器时间（TimeSec、TimeTick）、换算后的电脑时间 Timestamp、线程号 Thread、原始文本 Message 和适合显示的 DisplayText。

    独立小 Demo：接收程序 printf 输出

    什么时候用

    调试用户程序：把程序里 printf 的输出显示在上位机界面或日志中。

    函数原型

    // AAMotionAPI
// Raised once per user-program `printf` line on the specified controller (FW v5+, AGM800 Ethernet).
// controller: 控制器对象
// handler: 回调；取消时传同一个委托实例
static void SetUserProgramPrintHandler(MotionController controller, Action<UserProgramPrintMessage> handler);

// Remove a user-program printf handler from the specified controller.
// controller: 控制器对象
// handler: 回调；取消时传同一个委托实例
static void ClearUserProgramPrintHandler(MotionController controller, Action<UserProgramPrintMessage> handler);

// MotionController
// Raised once per formatted line from a user-program `printf` push (FW v5+, AGM800 Ethernet). Each `UserProgramPrintMessage` carries wire fields plus Console-friendly `UserProgramPrintMessage.Timestamp` and `UserProgramPrintMessage.DisplayText`. Other push sources are ignored. Delivery is on a background thread (same as AAComm push). Adding the first handler while connected queries `ATime` once for the wall-clock boot; the same query runs on connect when a handler is already subscribed. A successful `MotionController.TryReconnect` that rebuilt the link reopens delivery and re-queries `ATime` when a handler is still subscribed; the already-connected short-circuit only reactivates delivery.
event Action<UserProgramPrintMessage> UserProgramPrintReceived;

    // Installs the user-program print callback, replacing any previous one.
// controller: 控制器对象
// callback: 回调函数；取消时调用 clear 函数
// user: 传入回调的用户上下文数据，SDK 原样回传；不需要时传 NULL。
void aamotion_set_user_program_print_handler(aamotion_controller controller, aamotion_user_program_print_cb callback, void* user);

// Removes the user-program print callback.
// controller: 控制器对象
void aamotion_clear_user_program_print_handler(aamotion_controller controller);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象
    handler Action<UserProgramPrintMessage> 回调；取消时传同一个委托实例
    callback aamotion_user_program_print_cb 回调函数；取消时调用 clear 函数
    user void* 传入回调的用户上下文数据，SDK 原样回传；不需要时传 NULL。

    注意

    • 需要 v5 固件、AGM800、以太网连接。
    • 回调在后台线程上执行。
    • 注册第一个回调时 SDK 读一次 ATime，用来把控制器时间换算成电脑时间；重连后会重新读。

    示例

    Action<UserProgramPrintMessage> onPrint = m =>
    Console.WriteLine($"{m.Timestamp:HH:mm:ss.fff} [T{m.Thread}] {m.DisplayText}");

AAMotionAPI.SetUserProgramPrintHandler(c, onPrint);   // same as c.UserProgramPrintReceived += onPrint
// ... the user program's printf lines arrive here ...
AAMotionAPI.ClearUserProgramPrintHandler(c, onPrint);

    /* one printf line of the user program; called on a background thread */
static void on_print(unsigned int timeSec, unsigned int timeTick, int thread,
                     const char* message, void* user)
{
    (void)user;
    printf("[%u.%u T%d] %s\n", timeSec, timeTick, thread, message);
}

void example_print(aamotion_controller h)
{
    aamotion_set_user_program_print_handler(h, on_print, NULL);
    /* ... the user program's printf lines arrive in on_print ... */
    aamotion_clear_user_program_print_handler(h);
}
    SDK 原文注释（英文）
    • SetUserProgramPrintHandler(MotionController, Action<UserProgramPrintMessage>) — Raised once per user-program printf line on the specified controller (FW v5+, AGM800 Ethernet).
    • ClearUserProgramPrintHandler(MotionController, Action<UserProgramPrintMessage>) — Remove a user-program printf handler from the specified controller.
    • UserProgramPrintReceived() — Raised once per formatted line from a user-program printf push (FW v5+, AGM800 Ethernet). Each UserProgramPrintMessage carries wire fields plus Console-friendly UserProgramPrintMessage.Timestamp and UserProgramPrintMessage.DisplayText. Other push sources are ignored. Delivery is on a background thread (same as AAComm push). Adding the first handler while connected queries ATime once for the wall-clock boot; the same query runs on connect when a handler is already subscribed. A successful MotionController.TryReconnect that rebuilt the link reopens delivery and re-queries ATime when a handler is still subscribed; the already-connected short-circuit only reactivates delivery.
    • aamotion_set_user_program_print_handler — Installs the user-program print callback, replacing any previous one.
    • aamotion_clear_user_program_print_handler — Removes the user-program print callback.

    和用户程序交换数据¶

    上位机和用户程序之间最简单可靠的交换方式是约定 GenData 的几个下标：一个放参数，一个当“开始”标志，一个放结果。上位机写参数、置标志；程序检测到标志后执行，写结果、清标志；上位机等标志被清掉后读结果。读写函数见参数读写。

    独立小 Demo：和用户程序交换数据

    什么时候用

    上位机和用户程序配合完成一个流程：上位机给参数、程序执行、上位机读结果。

    示例

    // the PC hands a recipe number to the program and waits for its answer
AAMotionAPI.WriteGenData(c, 1, 7);           // AGenData[1] = recipe 7
AAMotionAPI.WriteGenData(c, 2, 1);           // AGenData[2] = 1: "start" flag the program polls
while (AAMotionAPI.ReadGenData(c, 2) != 0)   // the program clears it when done
    Thread.Sleep(50);
int result = AAMotionAPI.ReadGenData(c, 3);
