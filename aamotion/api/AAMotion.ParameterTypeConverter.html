AAMotion.dll

Parameter type converter - handles type conversion for controller parameters

Core functionality:

  • All data in controller is stored as int (32-bit)
  • float: uses IEEE 754 encoding in int
  • double/long: requires additional commands to get full 64-bit value
  • Automatically detects type and converts (based on XML metadata or cache)
