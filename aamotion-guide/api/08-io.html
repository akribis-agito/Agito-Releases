    数字输入输出¶

    控制器的数字输入输出按轴（模块）分组，AxisRef 选择哪一组。

    编号的起点不一样

    • '写输出（DOutSetBit / DOutClearBit / DOutToggleBit）的编号从 1 开始，和控制器命令 DOutPortSBit[n] 相同。写 0 会得到 ERR 20。'
    • '读位（GetDOutPort / GetDInPort）的参数是寄存器的位号，从 0 开始。输出 n 对应位 n − 1。'

    整个寄存器可以一次读出：C# 用 io.DInPort、io.DOutPort，C 用 aamotion_get_value(h, axis, AAMOTION_KEYWORD_DIN_PORT, 0, &v)。输入的逻辑电平（取反）由 DInLog、DOutLog 决定，见关键字 DInPort。

    写数字输出¶

    置位、清零或翻转一个数字输出，并可以读回某一位的状态。写入只改动指定的那一位，不影响其它输出。

    独立小 Demo：置位与清零输出

    独立小 Demo：翻转输出

    什么时候用

    控制气缸、指示灯、继电器等离散输出。

    函数原型

    // AAMotionAPI
// Set digital output bit of IO module
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// index: 输出编号，从 1 开始
// 返回值: Returns true if set successfully, otherwise false
static bool DOutSetBit(MotionController controller, AxisRef axis, int index);

// Clear digital output bit of IO module
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// index: 输出编号，从 1 开始
// 返回值: Returns true if cleared successfully, otherwise false
static bool DOutClearBit(MotionController controller, AxisRef axis, int index);

// Toggle digital output bit of IO module
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// index: 输出编号，从 1 开始
// 返回值: Returns true if toggled successfully, otherwise false
static bool DOutToggleBit(MotionController controller, AxisRef axis, int index);

// Gets the current state of a specific digital output bit
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// bit: 寄存器位号，从 0 开始（输出 n 是位 n − 1）
// 返回值: State of the specified bit (0 = Off, 1 = On).It is also necessary to refer to `IIOModule.DInLog`
static int GetDOutPort(MotionController controller, AxisRef axis, int bit);

// IIOModule
// Set the specified digital output bit
// index: 输出编号，从 1 开始
// 返回值: Returns true if the command is sent successfully, otherwise false
bool DOutSetBit(int index);

// Clear the specified digital output bit
// index: 输出编号，从 1 开始
// 返回值: Returns true if the command is sent successfully, otherwise false
bool DOutClearBit(int index);

// Toggle the specified digital output bit
// index: 输出编号，从 1 开始
// 返回值: Returns true if the command is sent successfully, otherwise false
bool DOutToggleBit(int index);

// Gets the current state of a specific digital output bit
// bit: 寄存器位号，从 0 开始（输出 n 是位 n − 1）
// 返回值: State of the specified bit (0 = Off, 1 = On).It is also necessary to refer to `IIOModule.DInLog`
int GetDOutPort(int bit);

    // Outputs are numbered from 1; in a port word, output n is bit n-1. To read a whole port in one call, read AAMOTION_KEYWORD_DIN_PORT, AAMOTION_KEYWORD_DIN_PORT_HIGH or AAMOTION_KEYWORD_DOUT_PORT with aamotion_get_value. Sets digital output index (from 1) of axis.
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// index: 输出编号，从 1 开始
bool aamotion_d_out_set_bit(aamotion_controller controller, int axis, int index);

// Clears digital output index (from 1) of axis.
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// index: 输出编号，从 1 开始
bool aamotion_d_out_clear_bit(aamotion_controller controller, int axis, int index);

// Toggles digital output index (from 1) of axis.
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// index: 输出编号，从 1 开始
bool aamotion_d_out_toggle_bit(aamotion_controller controller, int axis, int index);

// Reads one bit of the digital output port. @param bit 0..31; output n is bit n-1. @return 0 or 1, and 0 on ANY failure (use aamotion_get_value when that matters). This is the raw port bit; see DOutLog for inverted outputs.
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// bit: 寄存器位号，从 0 开始（输出 n 是位 n − 1）
int aamotion_get_d_out_port(aamotion_controller controller, int axis, int bit);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    axis AxisRef / int IO 所属的轴（模块）
    index int 输出编号，从 1 开始
    bit int 寄存器位号，从 0 开始（输出 n 是位 n − 1）

    返回值

    写入成功返回 true。GetDOutPort 返回 0 或 1；C 版本失败时也返回 0。

    示例

    AAMotionAPI.DOutSetBit(c, AxisRef.A, 1);      // output 1 on (1-based)
AAMotionAPI.DOutToggleBit(c, AxisRef.A, 2);
AAMotionAPI.DOutClearBit(c, AxisRef.A, 1);

int out1 = AAMotionAPI.GetDOutPort(c, AxisRef.A, 0);   // output 1 is register bit 0

    aamotion_d_out_set_bit(h, AAMOTION_AXIS_REF_A, 1);      /* output 1 on (1-based) */
aamotion_d_out_toggle_bit(h, AAMOTION_AXIS_REF_A, 2);
aamotion_d_out_clear_bit(h, AAMOTION_AXIS_REF_A, 1);
int out1 = aamotion_get_d_out_port(h, AAMOTION_AXIS_REF_A, 0);   /* output 1 is bit 0; 0 also on failure */

    • GetDOutPort(int) — Gets the current state of a specific digital output bit Returns: State of the specified bit (0 = Off, 1 = On).It is also necessary to refer to IIOModule.DInLog

    读数字输入¶

    读一个数字输入位的状态。要同时判断多个输入，读整个 DInPort 寄存器再按位与，比逐位读快（一次通信）。

    独立小 Demo：读数字输入

    独立小 Demo：读整个 IO 寄存器

    什么时候用

    读取传感器、按钮、安全门等离散输入。频繁轮询时用快速读缓存。

    函数原型

    // AAMotionAPI
// Gets the current state of a specific digital input bit
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// bit: 寄存器位号，从 0 开始
// 返回值: State of the specified bit (0 = Off, 1 = On).It is also necessary to refer to `IIOModule.DOutLog`
static int GetDInPort(MotionController controller, AxisRef axis, int bit);

// IIOModule
// Gets the current state of a specific digital input bit
// bit: 寄存器位号，从 0 开始
// 返回值: State of the specified bit (0 = Off, 1 = On).It is also necessary to refer to `IIOModule.DOutLog`
int GetDInPort(int bit);

    // Reads one bit of the digital input port. @param bit 0..31; input n is bit n-1. @return 0 or 1, and 0 on ANY failure (use aamotion_get_value when that matters). This is the raw port bit; see DInLog for inverted inputs.
// controller: 控制器对象 / 句柄
// axis: IO 所属的轴（模块）
// bit: 寄存器位号，从 0 开始
int aamotion_get_d_in_port(aamotion_controller controller, int axis, int bit);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    axis AxisRef / int IO 所属的轴（模块）
    bit int 寄存器位号，从 0 开始

    返回值

    0 或 1。C 版本失败时也返回 0，需要区分时用原始命令读 ADInPort 并检查返回值。

    注意

    • 频繁轮询输入时，考虑用快速读缓存，读缓存不占用通信。

    示例

    IIOModule io = c.GetIO(AxisRef.A);
int in3 = io.GetDInPort(2);           // input 3 is register bit 2
int all = io.DInPort;                 // the whole input register
bool in3Again = ((all >> 2) & 1) == 1;

    int in3 = aamotion_get_d_in_port(h, AAMOTION_AXIS_REF_A, 2);     /* input 3 is register bit 2 */

/* when a failed read must not look like 0, read the register through a raw command */
char reply[64];
if (aamotion_send_command_string(h, "ADInPort", reply, sizeof reply))
    printf("inputs: %s\n", reply);

    • aamotion_get_d_in_port — Reads one bit of the digital input port. @param bit 0..31; input n is bit n-1. @return 0 or 1, and 0 on ANY failure (use aamotion_get_value when that matters). This is the raw port bit; see DInLog for inverted inputs.
