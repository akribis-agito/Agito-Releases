Remarks

In direct gearing (MotionMode 5) the geared master, filtered by Filter, is the axis's position command. In indirect gearing (MotionMode 6) it is the profiler's absolute target, so the axis's Speed, Accel, Decel and jerk limit the motion. Stop it with Stop(MotionController, AxisRef).

Properties

Filter

Input filter in 64ths (MasterFilt), 1 to 64: 64 passes the geared master unfiltered, a smaller value filters more slowly. Direct gearing only; indirect gearing leaves MasterFilt alone.

public int Filter { get; set; }

int

Master

The parameter the axis follows, named with its axis prefix: "BPos" (B's encoder), "APosRef" (A's position command), "AAuxPos", "AVel[2]".
