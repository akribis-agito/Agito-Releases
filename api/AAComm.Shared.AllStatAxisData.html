Struct AllStatAxisData

Namespace
AAComm.Shared
Assembly
AAComm.dll
Container for AllStat data, per axis. Used by <xref href="AAComm.Services.AllStatInterpreter" data-throw-if-not-resolved="false"></xref>.


Shared between AAComm (C#) and AACommNative (C++) via preprocessor directives.


Groups (wire order per axis):
 1  (13): MotorOn, InjectType, Pos, Vel_1, PosErr, VelErr, MotionStat, ConFlt, MotionReason, StatReg, LimitStat, HomingStat, DInPort
 2  (10): Vel_2, Vel_3, Vel_4, MotorCurr, ScheduleSet, MotionSamples_1, MotionSamples_2, MotionSamples_3, InTargetStat, ComtStatus_1
 3  (16): ProgStat_1..8, ProgErr_1..8
 4  (17): FifoStatus_1..5, CNCAStatus_1..12
 5   (7): CiStatus_1..7
 6 (15+): Ia, Ib, Id, Iq, Va, Vb, Vc, AInPort_1..4, VBus, VLogic, PwrTemp, [MotorTemp (FW>=1.3.0)], Time
 7   (6): PosRef, VelRef, CurrRef, dPosRef, CNCAPosRef, CNCAdPosRef
 8   (7): LockEn, LockCntr, LockVal, EventOn, EventCntr, EventNextPos, EventSelect
 9   (5): UserParam_1..5
10   (2): DInPortHigh, BoardTemp
Please refer to the user manual for more information.
