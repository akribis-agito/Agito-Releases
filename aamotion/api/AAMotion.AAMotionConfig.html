When FastReadCache is enabled, this interval controls how often data is refreshed from the controller. Default: 1ms

Property Value

FastReadEnabled

Global switch to enable/disable fast read cache for all controllers. When true, reading Speed, Pos, MotionStat, InTargetStat etc. will read from a local cache that is refreshed every FastReadCacheRefreshIntervalMs milliseconds, instead of sending commands to the controller. This significantly reduces latency. Default: false (disabled for backward compatibility).

public static bool FastReadEnabled { get; set; }

Property Value

bool

Remarks

Set to true before or after connecting to enable fast cached reads. The cache is automatically populated with common parameters (A/B/C axes) on connection.

UseNativeDataTypes

Control the behavior of the data type of the dynamic properties returned values

false (default)：Backward compatibility mode

  • float parameter returns int (rounded)
  • long parameter returns int if it is in the int range, otherwise returns long
  • Ensure type compatibility for old code

true：Native type mode

  • float parameter returns the real float value
  • double parameter returns double value
  • long parameter returns long value
  • Ensure full precision for new code
