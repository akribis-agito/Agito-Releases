Namespace AAComm.Services.PushData

Classes

AACommPushMsgBase

Base type for controller push messages.

Expected raw message format:

[VERSION_PUSH].[SOURCE],[VERSION_DATA].[DATA]

Where:

  • VERSION_PUSH: integer protocol version for the overall push feature
  • SOURCE: integer enum value (PushSources) telling which derived message type to create
  • VERSION_DATA: integer version for the payload format
  • DATA: raw payload (may be ASCII string or raw binary bytes depending on SOURCE/VERSION_DATA)
AACommPushMsgError

Error/fallback push message type. Created when parsing or constructing a derived type fails. Holds the original raw bytes and the exception for logging/debugging.

AACommPushMsgUP

SOURCE == 1 (User Program):

For VERSION_DATA = 1, the DATA section contains raw binary data (little-endian) with multiple printf messages.

Binary packet structure (after the header, before the messages slots):

  • uint8 n: number of printf messages
  • uint16 missed: messages dropped since last flush
  • uint16 freeBytesMsgQueue: remaining free bytes in FW printf buffer
  • uint8 freeDescSlots: remaining free descriptor slots

Then n times:

  • uint32 timeSec: seconds since power-on
  • uint32 timeTick: sub-second tick
  • uint8 thread: thread ID
  • uint16 len: text length in bytes
  • byte[len] textBytes: raw ASCII text (NOT null-terminated)
