    C++ 实战：PVAJ、电子齿轮与堵转回零¶

    下列三个 C++17 程序调用原生 SDK 的 PVAJ、电子齿轮和堵转回零函数。编译和链接使用同一个原生 SDK 发布包里的头文件、运行库和服务器。

    在手册源码目录配置以下独立工程。目标名为 pvaj、gearing、stall_home。程序集面向 Windows x64 或 Linux x64。示例选择 AGM800，首次测试前在 PCSuite 确认控制器型号、固件能力、轴映射、运动单位及允许行程。先换相并使能所选轴，结束其他发令程序。代码会检查执行轴已使能且静止。

    cmake -S samples/preview/cpp -B build/preview -DAAMOTION_SDK_DIR=/path/to/agito-aamotion-native-sdk
cmake --build build/preview --config Release

    PVAJ 下载与执行¶

    PCSuite · PVAJ 轨迹工具

    选择场景：已有离散轨迹，希望在固件 5.3.0 或以上的 AGM800 上按给定的位置、速度、加速度和加加速度运行。示例接收 pvaj <AGM800 IP> <trajectory.txt>，执行 A 轴单轴轨迹。

    输入第一行填点间隔（控制器扫描周期数，1–32）和位置模式（0 绝对、1 相对），后续每行依次填 P、V、A、J，单位依次为 counts、counts/s、counts/s²、counts/s³。使用与当前起点、周期和行程匹配的轨迹。写表后用完整校验（模式 1），再 Arm 并启动；回读进度和最终位置。校验失败时检查越界、相邻点连续性和单位。修改点表后，下一次 Arm 之前要重新校验。每个值一次往返，长点表的写入需要一段时间。

    if (!aamotion_pvaj_arm(h, axis, false) ||
    !aamotion_pvaj_write_header(h, axis, static_cast<int>(points.size()), gap, mode))
    return 4;
for (std::size_t i = 0; i < points.size(); ++i) {
    const Point& p = points[i];
    if (!aamotion_pvaj_write_point(h, axis, static_cast<int>(i + 1), p.p, p.v, p.a, p.j))
        return 4;
}
if (!aamotion_pvaj_validate(h, axis, 1) || !aamotion_pvaj_is_validated(h, axis) ||
    !aamotion_pvaj_arm(h, axis, true))
    return 4;
if (!aamotion_pvaj_begin(h, axis, false)) {
    aamotion_pvaj_arm(h, axis, false);
    return 5;
}

int state, index, remaining;
for (int attempt = 0; attempt < 300; ++attempt) {
    if (!aamotion_pvaj_get_status(h, axis, &state, &index, &remaining))
        break;
    if (state != 3 && remaining == 0) {
        std::cout << "PVAJ ended. Check the final position and MotionReason.\n";
        return aamotion_pvaj_arm(h, axis, false) ? 0 : 6;
    }
    std::this_thread::sleep_for(std::chrono::milliseconds(100));
}

    直接和间接电子齿轮¶

    PCSuite · 齿轮

    选择场景：B 轴要跟随 A 轴位置参考 APosRef。输入 gearing <AGM800 IP>，程序要求选择模式和比例分子。分母为 65536，例如分子 32768 表示 1:2，负分子会反转从轴方向。先确认 A、B 的机械行程和比例；程序启动 B 轴，A 轴由操作者单独控制。

    模式 5 将主信号经比例和可选滤波送入从轴位置参考。模式 6 根据主信号形成位置目标，由控制器按从轴的轨迹参数追随。filter=64 表示直接齿轮不额外平滑，间接模式不写该参数。masterModRev=0 用于无模长主信号。比例和主信号需符合固件支持范围。读取从轴模式、运动状态和位置趋势核对跟随，按 Enter 请求停止，随后确认从轴状态。

    aamotion_gear_config 字段 填什么
    master 带轴前缀的信号名，例如 APosRef 或 APos。前者跟随命令位置，后者跟随编码器反馈。支持的阵列信号须写下标。
    ratioNumerator、ratioDenominator 整数分子与正整数分母。旧固件没有 MasterFactDen 时用固定分母 65536，其他范围按目标固件。
    filter 直接模式的滤波系数，1–64。较小的值滤得更慢。
    masterModRev 主信号的模长。无模长填 0。有模长需固件支持，按主信号的实际配置填写。
    motionMode 5 直接齿轮，6 间接齿轮。 
    const aamotion_gear_config config{"APosRef", numerator, 65536, 64, 0, mode};
if (!aamotion_gear_begin(h, axis, &config)) {
    std::cerr << "Start failed. Check the follower configuration and state.\n";
    return 4;
}
double motion_mode, motion_status;
if (aamotion_get_value(h, axis, AAMOTION_KEYWORD_MOTION_MODE, 0, &motion_mode) &&
    aamotion_get_value(h, axis, AAMOTION_KEYWORD_MOTION_STAT, 0, &motion_status))
    std::cout << "Follower mode " << motion_mode << ", motion status " << motion_status << '\n';
std::cin.ignore(1024, '\n');
std::cout << "Press Enter to stop the follower. The demo does not command the master.\n";
std::cin.get();
if (!aamotion_stop(h, axis)) {
    std::cerr << "Stop was not confirmed. Check the follower at the machine.\n";
    return 5;
}

    堵转检测后搜索 Index¶

    PCSuite · 回零

    选择场景：机械硬限位允许接触，没有可用的限位开关，最终零点要由编码器 Index 确定。先按 PCSuite 已调好的回零方案确定阈值。运行 stall_home <AGM800 IP> 后输入方向、低速阈值、电流阈值、持续毫秒数、搜索速度、反向 Index 慢速、加速度和超时毫秒数。速度单位 counts/s，电流单位 mA，加速度单位 counts/s²：回零参数都是控制器单位，不按用户单位换算。超时是每一步运动的超时。示例使用 A 轴和主编码器 Index。

    控制器先沿指定方向搜索，低速度和高电流条件持续达到设定时间后才判定堵转，随后反向慢速搜索锁存信号。HomingStat = 100 才表示成功。负值表示中止，可结合 HomingStep、MotionReason 和 ConFlt 排查。每一步的详细含义见回零 API。

    if (!aamotion_lock_src_zero_supported(h, axis) ||
    !aamotion_home_to_hard_stop_by_stuck_then_index(h, axis, 0, direction,
        stuck_vel, stuck_curr, stuck_ms, fast, slow, accel, timeout_ms))
    return 4;

const auto deadline = std::chrono::steady_clock::now() + std::chrono::milliseconds(timeout_ms);
while (std::chrono::steady_clock::now() < deadline) {
    double status;
    if (!aamotion_get_value(h, axis, AAMOTION_KEYWORD_HOMING_STAT, 0, &status))
        break;
    if (status == 100) {
        std::cout << "Homing completed.\n";
        return 0;
    }
    if (status < 0) {
        std::cerr << "Homing failed, HomingStat=" << status << '\n';
        return 5;
    }
    std::this_thread::sleep_for(std::chrono::milliseconds(50));
}
aamotion_stop(h, axis);
std::cerr << "Homing could not be confirmed. Check the actual axis state.\n";
return 6;
