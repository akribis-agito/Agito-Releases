ECAM_ConfigureTable(int, int, int, int, int, int, int, int, int)

Configure ECAM table parameters for electronic cam motion.

void ECAM_ConfigureTable(int startIndex, int endIndex, int startCycIndex, int endCycIndex, int cycles, int masterKeyword, int gap, int tableNum = 1, int masterIni = 0)

Parameters

startIndex int

Start index in GenData array where ECAM table data begins

endIndex int

End index in GenData array where ECAM table data ends

startCycIndex int

Start cycle index for repetition (0-based)

endCycIndex int

End cycle index for repetition (0-based)

cycles int

Number of cycles (positive for forward, negative for bidirectional, 2147483647 for infinite)

masterKeyword int

Master axis keyword code (e.g., 2 for PosRef, 24 for PosRef)

gap int

Gap between master positions (negative for reverse direction)

tableNum int

ECAM table number (1-10, default: 1)

masterIni int

Master initial position compensation (default: 0)

Remarks

This method configures all the necessary parameters for ECAM motion. The ECAM table data should be stored in GenData array from startIndex to endIndex.

ECAM_CreateLinearTable(int, int, int, int, int)

Create a simple ECAM table with linear interpolation between start and end positions.

void ECAM_CreateLinearTable(int startPos, int endPos, int numPoints, int startIndex, int tableNum = 1)

Parameters

startPos int

Starting position

endPos int

Ending position

numPoints int

Number of interpolation points

startIndex int

Start index in GenData array

tableNum int

ECAM table number (1-10, default: 1)

Remarks

This method automatically generates a linear ECAM table and stores it in the GenData array. The table will contain numPoints positions linearly interpolated between startPos and endPos.

ECAM_CreateSinusoidalTable(int, int, int, int, int)

ECAM_SetGap(int, int)

Set ECAM gap between master positions.

void ECAM_SetGap(int gap, int tableNum = 1)

Parameters

gap int

Gap between master positions (negative for reverse direction)

tableNum int

ECAM table number (1-10, default: 1)

Remarks

The gap determines the step size for master position increments during ECAM motion. Negative values reverse the direction of motion.

ECAM_SetMaster(int, int)

Set ECAM master axis (typically the main axis being followed).

void ECAM_SetMaster(int masterKeyword, int tableNum = 1)

Parameters

masterKeyword int

Master axis keyword code (e.g., 2 for PosRef, 24 for PosRef)

tableNum int

ECAM table number (1-10, default: 1)

Remarks

The master axis is the reference axis that the slave axis follows during ECAM motion. Common master keywords: 2 (PosRef), 24 (PosRef), etc.

ECAM_SetTableData(int[], int)

Set ECAM table data using GenData array. Data will be written starting from ECAMStart[tableNum] to ECAMEnd[tableNum].

void ECAM_SetTableData(int[] data, int tableNum = 1)

Parameters

data int[]

Array of position data to set in GenData

tableNum int

ECAM table number (1-10, default: 1)

Remarks

The data array will be written to the GenData array starting from the configured start index. Make sure the data array size matches the configured table range.

ECAM_Start(int)

Start ECAM motion with specified table.

bool ECAM_Start(int tableNum = 1)

Parameters

tableNum int

ECAM table number to use (1-10, default: 1)

Returns

bool

Returns true if ECAM motion started successfully, otherwise false.

Remarks

Before starting ECAM motion, ensure that:

  1. ECAM table is properly configured with ECAM_ConfigureTable
  2. ECAM table data is set with ECAM_SetTableData
  3. Master axis is properly configured

ECAM_Stop()

Stop ECAM motion.

bool ECAM_Stop()

Returns

bool

Returns true if ECAM motion stopped successfully, otherwise false.

Remarks

This will immediately stop the current ECAM motion and return the axis to normal operation.
