UploadRecDataNonblocking(ICommService) 

Asynchronous function, uploads recorded data using the sequential RecUploadNext protocol.


Unlike <xref href="AAComm.Extensions.RecData.AACommDataRecManager.UploadRecData(AAComm.Interfaces.ICommService)" data-throw-if-not-resolved="false"></xref>, this method does not block the communication channel
with a single large response — data is received in sequential packets.


The API object passed must be connected!


Use <xref href="AAComm.Extensions.RecData.AACommDataRecManager.OnUploadRecData" data-throw-if-not-resolved="false"></xref> event to get the uploaded data.


Use <xref href="AAComm.Extensions.RecData.AACommDataRecManager.OnRecUploadNextProgress" data-throw-if-not-resolved="false"></xref> to track upload progress.

public void UploadRecDataNonblocking(ICommService api)
