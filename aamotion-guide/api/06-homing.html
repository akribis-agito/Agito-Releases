    回零¶

    回零确定轴的零点。所有回零函数都只是启动控制器里的回零流程，然后立即返回；回零在控制器里执行，程序要轮询 IsHomed（即 HomingStat == 100）判断完成。HomingStat 为负数表示失败，每个值的含义见枚举：回零状态。

    控制器的回零流程是一张最多 20 步的表 HomingDef[]，每步 10 个参数：第 1 个是步骤类型（找限位、找 Index、碰硬限位……），后面是速度、加速度、急停减速度、超时等。下面的函数按常见方式自动填好这张表再启动；也可以在 PCSuite 的回零工具里配置好，程序只调用 Home(c, axis)。

    方式 函数 适合
    使用控制器里已配置的流程 Home(c, axis) 已在 PCSuite 中配置好回零
    限位 / Index / 限位 + Index Home(c, axis, isHomeToLimit, isHomeToIndex, …) 最常用
    碰硬限位 HomeToHardStop 没有限位开关、有机械硬限位
    只找 Index、限位 + Index、硬限位 + Index、堵转 + Index HomeToIndex 等 需要指定锁存源和方向
    从文件读流程 Home(c, axis, filePath) 回零流程随产品配置分发

    按已配置的流程回零¶

    三种重载：

    • 'Home(c, axis)：直接启动控制器里已经配置好的回零流程（AHomingOn=1）。'
    • 'Home(c, axis, isHomeToLimit, isHomeToIndex, …)：按参数生成流程：只找限位、只找 Index，或先找限位再找 Index；找到的位置加上 homeoffset 设为零点。'
    • 'Home(c, axis, filePath)：从文本文件读 HomingDef[n]=value 行写入控制器，再启动。以 // 开头的行是注释。'

    回零前轴要已使能（同步电机还要已换相）。

    上电后建立坐标零点；使用增量编码器的轴每次上电都需要。

    判断回零完成¶

    实时读 HomingStat（不经过快速读缓存），等于 100 时返回 true。等待回零时用它轮询；同时检查 HomingStat 是否变成负数，负数表示失败，不必等到超时。

    独立小 Demo：读回零状态

    什么时候用

    回零开始后轮询；或者运动前确认零点有效。

    函数原型

    // AAMotionAPI
// Check if the axis is homed
// controller: 控制器对象 / 句柄
// axis: 一个轴
// 返回值: Returns true if homed, otherwise false
static bool IsHomed(MotionController controller, AxisRef axis);

// ISingleAxis
// Check if the axis has completed homing.
// 返回值: Returns true if the axis has completed homing, otherwise false.
bool IsHomed();

    // @return true when the axis has completed homing.
// controller: 控制器对象 / 句柄
// axis: 一个轴
bool aamotion_is_homed(aamotion_controller controller, int axis);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    axis AxisRef / int 一个轴

    返回值

    已回零返回 true。

    注意

    • 等待时同时记录当前 HomingStep 和 HomingStat。状态 0 表示上电或复位后尚未回零，正常运行中的正数表示当前步骤，100 才表示成功。
    • 状态 -2 表示某一步超时，结合该步及配置检查搜索方向、输入信号和超时。状态 -3 表示过程中电机意外失能，读 ConFlt 查看原因。状态 -4 表示实际停下的原因与该步骤预期不同，检查搜索的限位或锁存信号。

    示例

    DateTime deadline = DateTime.UtcNow.AddMilliseconds(timeoutMs);
while (DateTime.UtcNow < deadline)
{
    if (AAMotionAPI.IsHomed(c, axis))
        return true;                                   // HomingStat == 100
    int stat = (int)c.GetValue(axis, eKeyword.HomingStat);
    if (stat < 0)
    {
        Console.WriteLine("homing failed: " + EnumPropertyHelper.GetHomingStatDes(stat));
        return false;
    }
    Thread.Sleep(100);
}
return false;

    static bool wait_homed(aamotion_controller h, int axis, int timeout_ms)
{
    for (int waited = 0; waited < timeout_ms; waited += 100)
    {
        if (aamotion_is_homed(h, axis))
            return true;                                   /* HomingStat == 100 */
        double stat;
        if (aamotion_get_value(h, axis, AAMOTION_KEYWORD_HOMING_STAT, 0, &stat) && stat < 0)
        {
            char text[256];
            aamotion_get_homing_stat_des((int)stat, text, sizeof text);
            fprintf(stderr, "homing failed: %s\n", text);
            return false;
        }
        sleep_ms(100);
    }
    return false;
}

    • IsHomed(MotionController, AxisRef) — Check if the axis is homed Returns: Returns true if homed, otherwise false
    • IsHomed() — Check if the axis has completed homing. Returns: Returns true if the axis has completed homing, otherwise false.
    • aamotion_is_homed — @return true when the axis has completed homing.

    碰硬限位回零¶

    没有限位开关时，让轴低速运动直到顶住机械硬限位：位置误差超过 threshold 就认为到了硬限位，以此位置加 homeoffset 作为零点。

    Index 回零¶

    找锁存信号（通常是编码器 Index）作为零点，可以先快速找一个粗略的参考，再慢速找锁存信号：

    函数 第一阶段
    HomeToIndex 没有，直接慢速找锁存信号
    HomeToLimitThenIndex 快速找限位开关
    HomeToHardStopThenIndex 快速碰机械硬限位，位置误差超过 hardStopThreshold 即判定到达
    HomeToHardStopByStuckThenIndex 快速碰机械硬限位，按电机堵转判定：速度低于 stuckVel、电流高于 stuckCurr，并持续 stuckTimeMs

    这些函数填好 HomingDef[] 后启动控制器里的回零流程，然后返回；用 IsHomed 轮询完成（见本章开头）。lockSource 为 0 时使用主编码器 Index（需要 LockSrcZeroSupported 返回 true，否则 C# 抛 NotSupportedException）。

    见 PCSuite 回零控件与参数对照。

    独立小 Demo：Index 回零

    什么时候用

    需要很高的零点重复精度：先粗找限位或硬限位，再精找编码器 Index。没有限位开关时用两种硬限位方法之一，按 PCSuite 回零页面上已调好的判定方式选择。

    返回值

    C# 的回零函数没有返回值；参数不对时抛异常（例如 ArgumentOutOfRangeException，或 lockSource 为 0 而控制器不支持时的 NotSupportedException）。C 的回零函数在流程表写入并启动、没有出错时返回 true；参数不对或控制器拒绝写入时返回 false。

    LockSrcZeroSupported 在控制器支持用主编码器 Index 作锁存源时返回 true（来自控制器的功能位 Identity[62] 的 0x10）。

    注意

    • HomingDef 不按用户单位换算：所有速度、加速度和阈值都是控制器单位（counts、counts/s、counts/s²、mA），即使轴启用了用户单位。
    • 在两阶段方法中，direction 选择第一阶段寻找限位或硬限位的方向，第二阶段用相反方向慢速寻找锁存信号。速度、加速度和阈值都传正值。
    • 使用主编码器 Index 前检查 LockSrcZeroSupported。返回 false 时，先确认硬件和固件支持的锁存源，再配置回零。
    • 堵转检测和位置误差检测都会让电机顶住机械硬限位出力。第一次使用时用低速和保守的电流阈值验证。

    从文件读回零流程¶

    Home(c, axis, filePath) / aamotion_home_from_file 读取文本文件中的 HomingDef[n]=value 行写入控制器，然后启动回零。适合把回零流程和机器配置放在一起分发：在 PCSuite 中调好回零后，把 HomingDef 的各元素抄进文件即可。下标超出范围或格式不对的行会被忽略。

    什么时候用

    回零流程随机器配置一起分发，程序不写死参数。

    示例

    // homing.txt: one HomingDef element per line ("HomingDef[1]=1", "HomingDef[2]=5000", ...); "//" starts a comment
AAMotionAPI.Home(c, AxisRef.A, @"C:\MyApp\homing.txt");

    if (!aamotion_home_from_file(h, AAMOTION_AXIS_REF_A, "C:\\MyApp\\homing.txt"))
    fprintf(stderr, "could not read the homing file or start homing\n");

    按步骤读写回零表¶

    HomingDef[] 每 10 个元素是一步。a.GetHomingDefStep(n) 返回第 n 步（从 1 开始，最多 20 步）的视图：Type 是步骤类型，Param1…Param9 是这一步的参数，读写它们就是读写对应的 HomingDef 元素，不用自己计算下标。

    独立小 Demo：读取回零流程表

    什么时候用

    程序里要读或修改回零表的某一步，不想自己计算 HomingDef 下标时。

    函数原型

    // ISingleAxis
// A step-addressed view over `ISingleAxis.HomingDef`, naming the step type and its nine parameters instead of leaving the caller to compute slot indices.
// step: 步骤号，从 1 开始，最多 20
HomingDefStep GetHomingDefStep(int step);

    参数

    参数 类型 说明
    step int 步骤号，从 1 开始，最多 20

    返回值

    HomingDefStep 对象。
