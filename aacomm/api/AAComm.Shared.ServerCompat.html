Enum ServerCompat

Namespace
AAComm.Shared
Assembly
AAComm.dll
Classification of the AACommServer this client attached to, reported by
<xref href="AAComm.CommAPI.ServerCompat" data-throw-if-not-resolved="false"></xref> after a successful <code>Connect</code>.


The version floor CLASSIFIES the attach, it never rejects: a legacy server still
connects (compat mode), because a new client must coexist with a server started by an
older SDK application on the same machine — but the degraded mode is queryable here
instead of silent. A client must never shut down a server it did not spawn.

public enum ServerCompat

Fields

Current = 1

Binary server at or above the client's floor — full feature set (correlated reply routing, channel events, version-gated features).

LegacyAscii = 3

ASCII-only server: arrival-order reply routing, no channel events. The client's ASCII pipeline is frozen (deprecated) and kept solely for this compat mode.

LegacyBinary = 2

Binary server below the floor (or reporting no parseable version): correlated routing works, but features behind newer version gates silently skip. Dormant while the floor equals the typed-payloads shipping version — a pre-typed binary server fails the handshake gate and attaches as ASCII (LegacyAscii); this value becomes reachable again at the next floor raise, for older-but-typed servers.

Unknown = 0

Not connected (or connection not yet classified).
