    Central-i multi-axis¶

    Central-i is Agito's distributed multi-axis architecture: one master controller drives several slave drives over a bus. In the SDK slave axes work like local ones; the extras are bringing slaves online / offline (CiConnect / CiDisconnect), CNC interpolation over more axes (4, 6, 12, and combinations with a rotary axis T), and Central-i group outputs.

    The first argument (axis) of the Central-i CNC functions picks the group: A for group A, B for group B; positions and speeds are integer counts as in CNC. The system side is under keyword Central-i.

    In this chapter
    • Slave online and offline
    • Central-i CNC interpolation
    • Central-i group outputs

    Run this chapter's demo

    Slave online and offline¶

    Brings a Central-i slave (and its I/O) online or offline (the CiConnect / CiDisconnect commands). Read keyword CIStatus for the slave state.

    Standalone demo: Bring a slave online and offline

    When to use it

    In a Central-i system, bringing a slave online before using it.

    Signatures

    // AAMotionAPI
// Connect to Central-I interface IO module
// controller: The controller object / handle
// axis: The axis of the slave
// Returns: Returns true if connection is successful, otherwise false
static bool CiConnect(MotionController controller, AxisRef axis);

// Disconnect from Central-I interface IO module
// controller: The controller object / handle
// axis: The axis of the slave
// Returns: Returns true if disconnection is successful, otherwise false
static bool CiDisconnect(MotionController controller, AxisRef axis);

// ICiSlave
// Connect Central-I device
// Returns: Returns true if the command is sent successfully, otherwise false
bool CiConnect();

// Disconnect Central-I device
// Returns: Returns true if the command is sent successfully, otherwise false
bool CiDisconnect();

    // Central-I group command. axis selects the group: AAMOTION_AXIS_REF_A for group A, AAMOTION_AXIS_REF_B for group B. Connects to the Central-I interface IO module.
// controller: The controller object / handle
// axis: The axis of the slave
bool aamotion_ci_connect(aamotion_controller controller, int axis);

// Disconnects from the Central-I interface IO module.
// controller: The controller object / handle
// axis: The axis of the slave
bool aamotion_ci_disconnect(aamotion_controller controller, int axis);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    axis AxisRef / int The axis of the slave

    Commands sent

    {Axis}CiConnect

    Returns

    true when accepted.

    Example

    AAMotionAPI.CiConnect(c, AxisRef.E);               // bring a Central-i slave online
ICiGroupAxis g = c.GetCiGroup(AxisRef.A);          // Central-i CNC group A
g.ClearBuffer();
g.LinearAbsoluteXYT(100000, 50000, 9000, 40000, 0); // X, Y and the T (rotary) axis together
g.CiGroupDOutSetBit(AxisRef.A, 2);                 // output 2 on at this point (1-based number)
g.Begin();

    aamotion_ci_connect(h, AAMOTION_AXIS_REF_E);
aamotion_linear_absolute_xyt(h, AAMOTION_AXIS_REF_A, 100000, 50000, 9000, 40000, 0);
aamotion_ci_group_d_out_set_bit(h, AAMOTION_AXIS_REF_A, 2);
aamotion_cnc_begin(h);

    Central-i CNC interpolation¶

    Extends CNC interpolation with a fourth coordinate T (usually a rotary axis) and lines over more axes. The letters in a name are the coordinates that move; in the multi-axis LinearAbsolute overloads (4, 6, 12 axes) a null coordinate stays. Arcs such as ArcXT run in the plane of X/Y/Z and T. Segment rules (cruise speed, end speed, buffer, Begin) are those of plain CNC.

    When to use it

    Central-i CNC paths with more than 3 axes or with a rotary axis T.

    Signatures

    // AAMotionAPI
// Central-I controller CNC T-axis linear interpolation motion

    Central-i group outputs¶

    Inserts digital-output segments into a Central-i CNC path, as in the CNC chapter's "Actions on the path": the controller outputs them when the path gets there.

    Standalone demo: A Central-i path with an output

    When to use it

    Outputs on a Central-i CNC path.

    Signatures

    // AAMotionAPI
// Set Central-I interface CNC digital output bit
// controller: The controller object / handle
// axisRef: The axis the outputs belong to
// bitMask: The output number, **from 1** (named bitMask, but not a mask)
// Returns: Returns true if set successfully, otherwise false
static bool CiGroupDOutSetBit(MotionController controller, AxisRef axisRef, int bitMask);

// Clear Central-I interface CNC digital output bit
// controller: The controller object / handle
// axisRef: The axis the outputs belong to
// bitMask: The output number, **from 1** (named bitMask, but not a mask)
// Returns: Returns true if cleared successfully, otherwise false
static bool CiGroupDOutClearBit(MotionController controller, AxisRef axisRef, int bitMask);

// Toggle Central-I interface CNC digital output bit
// controller: The controller object / handle
// axisRef: The axis the outputs belong to
// bitMask: The output number, **from 1** (named bitMask, but not a mask)
// Returns: Returns true if toggled successfully, otherwise false
static bool CiGroupDOutToggleBit(MotionController controller, AxisRef axisRef, int bitMask);

// Write to Central-I controller CNC group axis digital output port
