    Optical coupling light finding¶

    GenData addresses, start values, status codes, result areas and sample layouts depend on the firmware/light-finding program. Named APIs and tables below describe one SDK mapping, not a universal protocol. Confirm model, firmware, program and mapping match; otherwise use string commands with the firmware GenData table.

    Coupling optical parts means moving a fibre or device to where the optical power peaks. These functions talk to the light-finding algorithm on the controller through GenData: the PC writes the configuration and starts it by writing AGenData[500] (1 spiral, 5 single-axis); the algorithm scans and returns to the best point inside the controller, and leaves its result in AGenData[602] (result), [650] (error) and [736] (last sample), with the position and power curves in GenData[1000…15999].

    The controller needs the matching light-finding program. Result and error codes are in Enums: light-finding result and light-finding errors.

    Create, configure and start¶

    For firmware matching the SDK built-in mapping only. Two steps: write the configuration (SpiralConfig for a spiral scan, SingleAxisConfig for a single-axis scan), then start. Starting returns at once and the scan runs in the controller; poll the result code and read the result once it is not 0. EmergencyStop writes AGenData[501] to stop at once and leave the light-finding logic. In C, release the handle with aamotion_optical_coupling_release when done (releasing the controller handle releases it too).

    Standalone demo: Spiral light finding

    When to use it

    Optical coupling stations: finding the maximum-power position automatically.

    Returns

    The C# configure and start functions return nothing; CreateOpticalCouplingLightFinding returns the object. C create returns a handle, or NULL on failure; the start functions return true on success.

    Notes

    • Clear AGenData[602] before starting so the previous result is not read.
    • Try the motion settings (speeds, radius) over a small range first, to keep the fibre and parts from colliding.

    Example

    OpticalCouplingLightFinding oc = AAMotionAPI.CreateOpticalCouplingLightFinding(c);
oc.ApplySpiralConfig(new SpiralConfig
{
    NumOfAInPort = 1,        // power read on analog input 1
    NumOfXAxis = 0,          // coupling axes, as numbered by the algorithm (0, 1, 2)
    NumOfYAxis = 1,
    SpiralPitch = 50,
    SpiralMaxRadius = 2000,
    SpiralAngleCoeff = 10,
    SpiralScanSpeed = 2000,
    SpiralRtnSpeed = 5000,
    PowerTh = 1000,
});

c.WriteGenData(602, 0);      // clear the previous result before starting
oc.StartSpiralScan();        // AGenData[500] = 1

DateTime deadline = DateTime.UtcNow.AddSeconds(60);
while (oc.CouplingResultCode == 0 && DateTime.UtcNow < deadline)
    Thread.Sleep(100);

if (oc.CouplingResultCode == 0)
{
    oc.EmergencyStop();
    Console.WriteLine("scan timed out; stop requested, verify actual state");
    return false;
}

SpiralScanResult r = oc.GetSpiralScanResult();
if (r.IsSuccess)
    Console.WriteLine($"max power {r.MaxPower} at ({r.MaxPowerXPos}, {r.MaxPowerYPos})");
else
    Console.WriteLine($"failed: {r.CouplingResult}, error {r.ErrCode}");
return r.IsSuccess;

    aamotion_optical_coupling oc = aamotion_optical_coupling_create(h);
if (!oc)
    return;
aamotion_optical_coupling_apply_spiral_config(oc, 1, 0, 1, 50, 2000, 10, 2000, 5000, 1000);
aamotion_write_gen_data(h, 602, 0);                      /* clear the previous result */
if (!aamotion_optical_coupling_start_spiral_scan(oc))
{
    aamotion_optical_coupling_release(oc);
    return;
}
/* Only for firmware matching this SDK mapping: result 602, stop 501. */
int result = 0;
bool finished = false;
for (int i = 0; i < 600; ++i)
{
    if (!optical_read_firmware_data(h, 602, &result)) break;
    if (result != 0) { finished = true; break; }
    sleep_ms(100);
}
if (!finished)
{
    aamotion_optical_coupling_emergency_stop(oc);
    fprintf(stderr, "scan timeout/read failure; stop requested, verify actual state\n");
    aamotion_optical_coupling_release(oc);
    return;
}
if (aamotion_optical_coupling_is_success(oc))
    printf("max power %d at (%d, %d)\n", aamotion_optical_coupling_get_max_power(oc),
           aamotion_optical_coupling_get_max_power_x_pos(oc), aamotion_optical_coupling_get_max_power_y_pos(oc));
else
    printf("failed, error %d\n", aamotion_optical_coupling_get_error_code(oc));
aamotion_optical_coupling_release(oc);

    Read the result¶

    For firmware matching the SDK built-in mapping only. GetSpiralScanResult / GetSingleAxisScanResult read the whole result at once: result code, error code, last sample, peak power and its position; single-axis scans add each channel's peak, the two-channel intersection and the levelling angle. Separate functions read each item. A positive result code is a success, a negative one a failure; then read the error code.

    When to use it

    After light finding: success or failure, the peak power and its position.

    Read the scan curves¶

    For firmware matching the SDK built-in mapping only. Each sample's position and channel powers are kept in GenData:

    Data Spiral Single-axis
    Position X 1000–3499, Y 3500–5999 1000–3999
    Channel 1 power 6000–8499 4000–6999
    Channel 2 power 8500–10999 7000–9999
    Channel 3 power 11000–13499 10000–12999
    Channel 4 power 13500–15999 13000–15999

    SyncAllGenData first reads GenData into a local copy in bulk; then each *Array function takes the range you need, far faster than reading one by one. The valid length is the result's LastSampleIndex.

    Firmware-specific GenData string commands¶

    Confirm the axis prefix, readable/writable GenData indices and types, units, start/stop commands, busy/done/error codes and valid result length with the firmware provider. Record the firmware and address-table versions. Never reuse indices 500, 501, 602, 650, 736 or sample ranges across unrelated firmware.

    Read with AGenData[index] and write with AGenData[index]=value, using the confirmed axis prefix. Helpers below require an explicit index and have no default scan address. Check send success before parsing the reply; trim the terminator and parse integers independently of locale. A failed read must not turn output zero into valid data.

    Read prerequisites, write parameters and verify them, clear old results as specified, then send the start value. Poll live state using that firmware busy/done/error codes with a total timeout and a sleep. Read only the valid result range after completion. On ERR, parse failure, disconnect or timeout, report the failure and use the documented stop operation; do not replay start automatically. A successful send is not proof that light finding succeeded.

    Standalone demo: Read GenData by the firmware table

    When to use it

    When the firmware mapping differs from the named API, or to inspect exact GenData replies.

    Example

    // index must come from the address table for the installed firmware.
// This example uses axis A; change the prefix only after checking that table.
public static bool TryReadFirmwareData(MotionController c, int index, out int value)
{
    value = 0;
    if (index < 0) return false;
    if (!c.SendCommandString($"AGenData[{index}]", out string reply))
        return false;
    string number = reply.Trim().TrimEnd('>').Trim();
    return int.TryParse(number, NumberStyles.Integer, CultureInfo.InvariantCulture, out value);
}

public static bool WriteFirmwareData(MotionController c, int index, int value)
{
    if (index < 0) return false;
    string command = "AGenData[" + index.ToString(CultureInfo.InvariantCulture) + "]="
        + value.ToString(CultureInfo.InvariantCulture);
    return c.SendCommandString(command, out string reply);
}

    /* Indices and the axis A prefix must be confirmed against the installed firmware. */
bool optical_read_firmware_data(aamotion_controller h, int index, int *value)
{
    char command[64], reply[256], *end;
    if (index < 0 || !value) return false;
    snprintf(command, sizeof command, "AGenData[%d]", index);
    if (!aamotion_send_command_string(h, command, reply, sizeof reply)) return false;
    errno = 0;
    long parsed = strtol(reply, &end, 10);
    if (end == reply || errno == ERANGE || parsed < INT_MIN || parsed > INT_MAX) return false;
    while (isspace((unsigned char)*end)) ++end;
    if (*end == '>') ++end;
    while (isspace((unsigned char)*end)) ++end;
    if (*end != '\0') return false;
    *value = (int)parsed;  /* output is valid only when this function returns true */
    return true;
}

bool optical_write_firmware_data(aamotion_controller h, int index, int value)
{
    char command[80], reply[256];
    if (index < 0) return false;
    snprintf(command, sizeof command, "AGenData[%d]=%d", index, value);
    return aamotion_send_command_string(h, command, reply, sizeof reply);
}
