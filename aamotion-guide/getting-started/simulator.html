    仿真器¶

    • 需要 仿真包（整个解压，firmware_sim.exe 旁边要有 starter.par）
    • 先读 安装
    • 完成后 能在没有硬件时连接仿真器

    固件仿真器 firmware_sim.exe 是在电脑上运行的控制器固件。它认识和真机一样的命令、返回一样的错误码，所以没有硬件时可以先在仿真器上写程序、调流程，再换成真机。

    连接仿真器¶

    和连接真机只差一个函数：

    MotionController c = AAMotionAPI.Initialize(ControllerType.AGM800);
c.Init();                                   // 确保 AACommServer 已启动
bool ok = AAMotionAPI.ConnectSimulation(c, @"D:\sim\AGM800\firmware_sim.exe");

    aamotion_controller h = aamotion_initialize(AAMOTION_CONTROLLER_TYPE_AGM800);
bool ok = aamotion_connect_simulation(h, "D:\\sim\\AGM800\\firmware_sim.exe",
                                      "AGM800", nullptr, nullptr);

    h = am.initialize(am.CONTROLLER_AGM800)
ok = am.lib.aamotion_connect_simulation(h, rb"D:\sim\AGM800\firmware_sim.exe", b"AGM800", None, None)

    完整的可运行版本就是示例 01-connect：参数传 firmware_sim.exe 的路径即可。

    仿真包要整个解压

    firmware_sim.exe 旁边必须有 starter.par（仿真的初始参数）。只拷 exe 会连接失败（连接结果 52：缺少 starter.par）。

    参数¶

    参数 必填 说明
    simExePath 是 firmware_sim.exe 的绝对路径。服务器从自己的目录启动仿真，相对路径会直接返回 false
    simProduct 否 产品名，如 "AGM800"、"AGD301orAGC301"。写了就等于声明了控制器型号，不再探测；仿真器型号和它不一致时连接失败。传 NULL / 不传则连接后自动识别
    simVersion 否 仿真固件的版本标签，NULL 用默认
    simMotorProfile 否 电机配置文本，空则用通用默认电机

    C# 的长重载 ConnectSimulation(c, path, product, version, motorProfile, enableAutoReconnect) 参数含义相同。

    仿真会话的生命周期¶

    每次连接仿真器，服务器都会新建一个临时目录，在里面运行仿真；断开时整个目录删除。点下面的按钮看看：

    这带来三个直接的结果：

    1. 参数不保留。在仿真器上执行 ASave 只写进这次的临时目录；断开后就没了。下次连接又是初始参数。需要固定的参数，在程序启动后自己写一遍。
    2. 可以同时开多个仿真。每个会话有自己的目录，互不影响。
    3. 要重连，先断开再重新初始化。C 接口里 aamotion_disconnect 会释放句柄，所以顺序是：aamotion_disconnect → 新的 aamotion_initialize → aamotion_connect_simulation。不要用 aamotion_try_reconnect，也不要在已经连着的句柄上再调一次 connect_simulation（会返回 false）。

    仿真和真机的区别¶

    真机 仿真
    连接超时 以太网 10 秒 20 秒（要先启动进程）
    参数保存 ASave 写进控制器 Flash 断开即丢失
    运动 真实电机、编码器 仿真模型，不代表真实机械的响应
    命令表、错误码 — 和同版本固件一致
    平台 — firmware_sim.exe 是 Windows 程序

    第一次连接会慢一点

    连接时 SDK 要读这个固件的命令表。读到后按固件版本缓存在 文档\PCSuite\ApplicationData\<产品编号>\<固件版本>\ 下，同一版本的仿真器第二次连接直接读缓存文件。
