    往复、双速与正弦运动¶

    点位运动的几种变化：

    运动 函数 MotionMode 用途
    往复 MoveAbsRepetitive 等 2 老化、跑合、重复定位精度测试
    双速 MoveAbsTwoSpeed 等 1 + SpeedChgOn 快速接近、慢速到位（压装、对位）
    正弦点位 SinePtpBegin 20 / 21 正弦加速度曲线，冲击更小
    运动中修改 SinePtpCommit、CommitMotion — 运动中改目标或速度，多轴同步生效
    PVAJ PvajWriteHeader … PvajBegin 22 / 23 按上位机给出的位置、速度、加速度、加加速度点表运动
    电子齿轮 GearBegin 5 / 6 按固定比例跟随主轴参数

    用示例的 Stopwatch 测量命令返回与运动到位时间，结合控制器实际状态核对。

    PVAJ 轨迹运动¶

    上位机已经算好每个轨迹点的位置、速度、加速度和加加速度时，用 PVAJ 运动让轴按这张点表运动（单轴 MotionMode 22，多轴组成员 23）。PVAJ 需要固件 5.3.0 或以上的 AGM800。支持与否是控制器的能力，不是某个轴的：控制器的命令表里有 PVAJList 时，所有运动轴都支持。先用 PvajSupported / aamotion_pvaj_supported 检查；不支持时，其他 PVAJ 调用在发送任何指令之前就拒绝，错误说明会指出缺少的功能。

    正常的调用顺序：

    1. PvajWriteHeader：点数（1 到 MaxPvajPoints / AAMOTION_PVAJ_MAX_POINTS，8192）、点间隔（1 到 MaxPvajGap / AAMOTION_PVAJ_MAX_GAP，32 个基本采样周期；大于 1 时控制器在点之间做五次样条插值）和位置模式（枚举：PVAJ 位置模式）。
    2. PvajWritePoint：逐点写入，点号从 1 开始。所有值都必须是有限数。
    3. PvajValidate：通常用完整校验（枚举：PVAJ 校验方式）。修改点表后，下一次 Arm 之前必须重新校验；正在执行的轨迹快照会继续执行完。
    4. PvajArm：Arm 轴。运动结束时轴会自动解除 Arm，所以每次运动之前都要重新 Arm。
    5. PvajBegin：设置 MotionMode（22，或 groupMember 为 true 时 23）并启动。
    6. PvajGetStatus：读取状态（枚举：PVAJ 状态）、正在执行的点号和剩余点数。它总是实时读取控制器，不经过快速读缓存。

    ISingleAxis 另有对应关键字的属性：PVAJList、PVAJValidate、PVAJArm、PVAJStatus、PVAJPosTol 和 PVAJVelTol。关键字格式和多轴组的行为见 PVAJList 和 PVAJStatus。

    见 PCSuite PVAJ 控件对照及 PVAJ 实战。

    什么时候用

    轨迹由上位机规划（例如从 CAD 或测量数据生成），每个点的速度、加速度和加加速度都已给定，需要控制器原样跟随时。点到点运动和正弦点位运动由控制器规划轨迹，不需要 PVAJ。

    函数原型

    // AAMotionAPI
// Whether the connected controller advertises PVAJList, available on AGM800 from firmware 5.3.0.
// controller: 控制器对象 / 句柄
static bool PvajSupported(MotionController controller);

// Write the three header slots of an axis's PVAJ list.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// length: 点表的点数，1 到 8192
// gap: 点间隔，基本采样周期数，1 到 32
// mode: `PvajWriteHeader`：位置模式，C# 为 `PvajPositionMode`，C 为 `AAMOTION_PVAJ_POSITION_*`（0 绝对，1 相对）。`PvajValidate`：校验方式，C# 为 `PvajValidationMode`（默认 `Full`），C 为 `AAMOTION_PVAJ_VALIDATE_*`（1 完整，2 不检查直接通过，3 只检查范围）
static void PvajWriteHeader(MotionController controller, AxisRef axis, int length, int gap, PvajPositionMode mode);

// Write one point of an axis's PVAJ list, at the four indices that point occupies.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// k: 点号，从 1 开始，最大 8192
// position: 位置，counts；必须是有限数
// velocity: 速度，counts/s；必须是有限数
// acceleration: 加速度，counts/s²；必须是有限数
// jerk: 加加速度，counts/s³；必须是有限数
static void PvajWritePoint(MotionController controller, AxisRef axis, int k, double position, double velocity, double acceleration, double jerk);

// Validate the PVAJ list an axis holds, and report whether it passed.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// mode: `PvajWriteHeader`：位置模式，C# 为 `PvajPositionMode`，C 为 `AAMOTION_PVAJ_POSITION_*`（0 绝对，1 相对）。`PvajValidate`：校验方式，C# 为 `PvajValidationMode`（默认 `Full`），C 为 `AAMOTION_PVAJ_VALIDATE_*`（1 完整，2 不检查直接通过，3 只检查范围）
// 返回值: True if the list is validated afterwards; otherwise false, with what failed on `MotionController.ErrorOccurred`, for example 393 (position out of range) or 396 (position continuity).
static bool PvajValidate(MotionController controller, AxisRef axis, PvajValidationMode mode = PvajValidationMode.Full);

// Whether the controller reports a validated, armed or executing trajectory. After editing the list, validate it again before arming even if an earlier snapshot is still executing.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// 返回值: True when `PVAJStatus[1]` is 1 or more, false while the list is not validated
static bool PvajIsValidated(MotionController controller, AxisRef axis);

// Arm or disarm an axis for PVAJ motion.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// arm: true Arm（C# 默认），false 解除
// 返回值: True when accepted, false if unsupported or refused.
static bool PvajArm(MotionController controller, AxisRef axis, bool arm = true);

// Read an axis's PVAJ status.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// execIndex: 输出：正在执行的点号；C 中不能为 NULL
// remaining: 输出：运动结束前剩余的点数；C 中不能为 NULL
// 返回值: The state: 0 not validated, 1 validated, 2 armed, 3 executing
static PvajState PvajGetStatus(MotionController controller, AxisRef axis, out int execIndex, out int remaining);

// Put an axis into a PVAJ motion mode and start the motion. The axis must be armed (`AAMotionAPI.PvajArm`).
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// groupMember: false（C# 默认）按单轴启动（MotionMode 22）；true 作为多轴 PVAJ 组成员启动（MotionMode 23）
// 返回值: True if the motion started; otherwise false, with the refusal on `MotionController.ErrorOccurred`: 400 for an unarmed axis, 401 / 402 for a group.
static bool PvajBegin(MotionController controller, AxisRef axis, bool groupMember = false);

// controller: 控制器对象 / 句柄
bool aamotion_pvaj_supported(aamotion_controller controller);

// Writes the list header. @param length Points in the list, 1..AAMOTION_PVAJ_MAX_POINTS. @param gap Base sample periods between points, 1..AAMOTION_PVAJ_MAX_GAP; above 1 the controller spline-interpolates between points. @param mode 0 = absolute positions, 1 = relative. @return false, nothing written, for a value out of range.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// length: 点表的点数，1 到 8192
// gap: 点间隔，基本采样周期数，1 到 32
// mode: `PvajWriteHeader`：位置模式，C# 为 `PvajPositionMode`，C 为 `AAMOTION_PVAJ_POSITION_*`（0 绝对，1 相对）。`PvajValidate`：校验方式，C# 为 `PvajValidationMode`（默认 `Full`），C 为 `AAMOTION_PVAJ_VALIDATE_*`（1 完整，2 不检查直接通过，3 只检查范围）
bool aamotion_pvaj_write_header(aamotion_controller controller, int axis, int length, int gap, int mode);

// Writes point k of the list. @param k Point index, from 1. @param position Counts. @param velocity Counts/s. @param acceleration Counts/s^2. @param jerk Counts/s^3.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// k: 点号，从 1 开始，最大 8192
// position: 位置，counts；必须是有限数
// velocity: 速度，counts/s；必须是有限数
// acceleration: 加速度，counts/s²；必须是有限数
// jerk: 加加速度，counts/s³；必须是有限数
bool aamotion_pvaj_write_point(aamotion_controller controller, int axis, int k, double position, double velocity, double acceleration, double jerk);

// Validates the list. @param mode 1 = full check, 2 = force the list through unchecked, 3 = range checks only. @return false when the list is not validated afterwards; the error callback names what failed (ERR 393-395 out of range, 396/397 position/velocity continuity).
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// mode: `PvajWriteHeader`：位置模式，C# 为 `PvajPositionMode`，C 为 `AAMOTION_PVAJ_POSITION_*`（0 绝对，1 相对）。`PvajValidate`：校验方式，C# 为 `PvajValidationMode`（默认 `Full`），C 为 `AAMOTION_PVAJ_VALIDATE_*`（1 完整，2 不检查直接通过，3 只检查范围）
bool aamotion_pvaj_validate(aamotion_controller controller, int axis, int mode);

// @return true while the controller reports a validated, armed or executing trajectory. After editing the list, validate it again before arming even if an earlier snapshot is still executing.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
bool aamotion_pvaj_is_validated(aamotion_controller controller, int axis);

// Arms (arm = true) or disarms the axis for PVAJ motion.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// arm: true Arm（C# 默认），false 解除
bool aamotion_pvaj_arm(aamotion_controller controller, int axis, bool arm);

// Reads the PVAJ status live (never from the fast read cache). @param state Receives 0 not validated, 1 validated, 2 armed, 3 executing. @param execIndex Receives the point being executed. @param remaining Receives the points left.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// state: C 输出：状态，`AAMOTION_PVAJ_STATE_*`（0 未校验，1 已校验，2 已 Arm，3 正在执行）；不能为 NULL。C# 中是返回值
// execIndex: 输出：正在执行的点号；C 中不能为 NULL
// remaining: 输出：运动结束前剩余的点数；C 中不能为 NULL
bool aamotion_pvaj_get_status(aamotion_controller controller, int axis, int* state, int* execIndex, int* remaining);

// Starts the PVAJ motion; the axis must be armed. @param groupMember false for a single axis (MotionMode 22), true for a member of a multi-axis group (MotionMode 23). An unarmed axis is refused with ERR 400, a group with 401/402.
// controller: 控制器对象 / 句柄
// axis: 执行的轴
// groupMember: false（C# 默认）按单轴启动（MotionMode 22）；true 作为多轴 PVAJ 组成员启动（MotionMode 23）
bool aamotion_pvaj_begin(aamotion_controller controller, int axis, bool groupMember);

    实际发送的命令

    {Axis}PVAJList[1] = {length}; {Axis}PVAJList[2] = {gap}; {Axis}PVAJList[3] = {mode}

    返回值

    C#：

    • PvajSupported：控制器有 PVAJList 时返回 true。
    • PvajWriteHeader、PvajWritePoint：没有返回值。值越界或不是有限数时抛 ArgumentOutOfRangeException，不写入；控制器不支持 PVAJ 时先在 ErrorOccurred 上报告，再抛 NotSupportedException；控制器拒绝写入时抛 ControllerCommandException。
    • PvajValidate：校验后点表处于已校验状态返回 true；否则返回 false，失败原因在 ErrorOccurred 上，例如 393（位置越界）或 396（位置不连续）。控制器拒绝或不支持时也返回 false。mode 不是 1、2、3 时抛 ArgumentOutOfRangeException。
    • PvajIsValidated：PVAJStatus[1] 为 1 或以上（已校验、已 Arm 或正在执行）时返回 true。
    • PvajArm：控制器接受返回 true；不支持或被拒绝返回 false。
    • PvajGetStatus：返回状态，点号和剩余点数在 out 参数里。控制器不支持时抛 NotSupportedException。
    • PvajBegin：运动已启动返回 true；不支持或 Begin 被拒绝返回 false，原因在 ErrorOccurred 上：400 表示轴没有 Arm，401 / 402 是组的问题。控制器拒绝写入 MotionMode 时抛 ControllerCommandException。

    C：每个函数成功返回 true，参数越界、值不是有限数、控制器不支持或拒绝时返回 false；不支持和控制器拒绝的原因由错误回调给出。aamotion_pvaj_write_header 返回 false 时不写入任何值。aamotion_pvaj_validate 只有在点表校验后处于已校验状态时才返回 true（ERR 393–395 越界，396 / 397 位置 / 速度不连续）。

    注意

    • 点表逐值写入，每个值一次往返：8192 个点约 32,000 次往返。长点表的写入时间要计入流程。
    • 校验失败时检查越界、相邻点的连续性和单位。点表单位是 counts。
    • 启动前确认轴已使能、静止、没有其他程序在发令；结束后读回最终位置和 MotionReason。

    示例

    // points[k - 1] = { position, velocity, acceleration, jerk } in counts, counts/s, /s², /s³
if (!AAMotionAPI.PvajSupported(c))
    return;                         // needs an AGM800 with firmware 5.3.0 or later
AAMotionAPI.PvajArm(c, AxisRef.A, false);
AAMotionAPI.PvajWriteHeader(c, AxisRef.A, points.Length, 1, PvajPositionMode.Absolute);
for (int k = 1; k <= points.Length; k++)
{
    double[] p = points[k - 1];
    AAMotionAPI.PvajWritePoint(c, AxisRef.A, k, p[0], p[1], p[2], p[3]);
}
if (!AAMotionAPI.PvajValidate(c, AxisRef.A, PvajValidationMode.Full)
    || !AAMotionAPI.PvajArm(c, AxisRef.A)
    || !AAMotionAPI.PvajBegin(c, AxisRef.A))
    return;                         // the reason is on ErrorOccurred

for (int attempt = 0; attempt < 300; attempt++)
{
    PvajState state = AAMotionAPI.PvajGetStatus(c, AxisRef.A, out int index, out int left);
    if (state != PvajState.Executing && left == 0)
        break;                      // ended: check the position and MotionReason
    Thread.Sleep(100);
}

    /* points in counts, counts/s, counts/s^2, counts/s^3; count 1..AAMOTION_PVAJ_MAX_POINTS */
const int a = AAMOTION_AXIS_REF_A;
if (!aamotion_pvaj_supported(h))
    return 1;                      /* needs an AGM800 with firmware 5.3.0 or later */
if (!aamotion_pvaj_arm(h, a, false) ||
    !aamotion_pvaj_write_header(h, a, count, 1, AAMOTION_PVAJ_POSITION_ABSOLUTE))
    return 2;
for (int k = 1; k <= count; k++)
{
    const pvaj_point* p = &points[k - 1];
    if (!aamotion_pvaj_write_point(h, a, k, p->p, p->v, p->a, p->j))
        return 2;
}
if (!aamotion_pvaj_validate(h, a, AAMOTION_PVAJ_VALIDATE_FULL) ||
    !aamotion_pvaj_arm(h, a, true) ||
    !aamotion_pvaj_begin(h, a, false))
    return 3;                      /* the error callback names the refusal */

int state = 0, index = 0, left = 0;
for (int attempt = 0; attempt < 300; attempt++)
{
    if (!aamotion_pvaj_get_status(h, a, &state, &index, &left))
        return 4;
    if (state != AAMOTION_PVAJ_STATE_EXECUTING && left == 0)
        return 0;                  /* ended: check the position and MotionReason */
    sleep_ms(100);
}
aamotion_stop(h, a);
return 5;

    电子齿轮¶

    让一根轴按 RatioNumerator / RatioDenominator（C：ratioNumerator / ratioDenominator）的比例跟随一个主轴参数，并一次写完整套配置后启动。配置是 C# 的 AAMotionAPI.GearMotionConfig 或 C 的 aamotion_gear_config：

    字段 含义
    Master / master 跟随的参数，带轴前缀："BPos"（B 轴编码器）、"APosRef"（A 轴位置指令）、"AAuxPos"；必填
    RatioNumerator、RatioDenominator 比例（写入 MasterFact / MasterFactDen），65536 / 65536 为 1:1，范围取控制器为参数给出的范围。没有 MasterFactDen 的固件固定除以 65536，分母只能是 65536
    Filter / filter 输入滤波，单位 1/64（MasterFilt），1–64；64 表示不滤波，值越小滤得越慢。只用于直接齿轮
    MasterModRev / masterModRev 主轴参数的模长：主轴自己有 ModRev 时填它，没有填 0
    MotionMode / motionMode 5 直接齿轮：齿轮化后的主轴值就是位置指令；6 间接齿轮：它是轨迹规划器的目标，运动受轴的速度、加速度、减速度和加加速度限制

    依次写入 GearMaster、MasterFact、MasterFactDen（固件有时）、MasterModRev（固件有时）、MasterFilt（仅直接齿轮）、MotionMode，然后 Begin。用 Stop / aamotion_stop 停止。

    见 PCSuite 齿轮运动的按钮和参数对照。

    什么时候用

    一根轴按固定比例跟随另一根轴或另一个信号。从轴位置需要随主轴行程按曲线变化时改用 ECAM。

    往复运动¶

    重复点位运动使用 MotionMode = 2，每一程间隔 msDwellTime 毫秒。Abs 指定第一个绝对目标，Rel 指定第一程相对距离。普通重载使用轴上已有的 RptMode 和 RptCycles。RptMode = 0 在起点和目标之间往返，RptMode = 1 按相同位移逐次累加。要执行有界往返，调用 MoveAbsRepetitiveCycle，它设置双向模式和单程数。也可用 StopRep 在当前单程结束后停止。

    双速运动¶

    以 speed1 运动，经过换速位置后改为 speed2 继续到目标。由控制器在穿过换速位置时切换（SpeedChgOn、SpeedChgPos、SpeedChgNew），切换时刻准确，不受通信延迟影响。Abs 版本的换速点是绝对位置，Rel 版本是距起点的距离。

    什么时候用

    快速接近、慢速到位：压装、插件、对位，减少接触时的冲击。

    正弦点位运动¶

    正弦加速度曲线的点位运动（MotionMode = 20 单次，21 往复），加速度连续变化，对机械的冲击比梯形曲线小。SinePtpBegin 把 SinePtpMotionConfig 中的全部参数写入轴并启动；SinePtpCommit 在运动中写入新参数并立即生效（运动中不能改 MotionMode，所以 Commit 不写它）。C 接口没有这组函数，用原始命令写参数后发 ABegin / ACommitMotion。

    什么时候用

    对振动敏感的负载（精密平台、长悬臂），需要加速度连续变化时。

    多轴同步修改运动¶

    先给每个轴写好新的正弦点位参数，再一次 CommitMotion(A | B …)：控制器在同一个控制周期里校验并重新计算所有轴的曲线，保证多轴同时切换。只要掩码里有一个轴不在正弦点位运动中，整个提交被拒绝。实际发送 ACommitMotion=<轴掩码>。

    独立小 Demo：写参数后提交

    什么时候用

    运动中修改目标或速度，并要求多个轴在同一时刻切换。

    函数原型

    // AAMotionAPI
// Commit the Sine PTP parameters already written to every axis in the mask, splicing them onto their running motions in one synchronised step
// controller: 控制器对象
// axes: 轴掩码，例如 `AxisRef.A | AxisRef.B`；单个轴只提交这个轴
// 返回值: Returns true if the controller accepted the commit, otherwise false.
static bool CommitMotion(MotionController controller, AxisRef axes);

// MotionController
// Commit the Sine PTP parameters written to every axis in `axes` in one synchronised step: the controller validates them all, recalculates each, and splices every new profile onto its running motion together. `axes` is a mask (`AxisRef.A | AxisRef.B`); the whole commit is refused when any axis it names is not in a Sine PTP motion. `ISingleAxis.CommitMotion` is the one-axis form.
// axes: 轴掩码，例如 `AxisRef.A | AxisRef.B`；单个轴只提交这个轴
// 返回值: True if the controller accepted the commit; a rejection is reported through `MotionController.ErrorOccurred`.
bool CommitMotion(AxisRef axes);

// ISingleAxis
// Commit the Sine PTP parameters currently written to the axis so the controller splices them onto the motion already running (an on-the-fly change). The controller validates the new profile within 16 control cycles (about 1 ms) and then joins the two profiles; position and velocity stay continuous across the splice, acceleration does not. Every kinematic parameter is read as one complete set describing the new motion, so write PreCruiseSpd = 0 to drop a pre-cruise phase the new motion no longer needs. A non-zero RelTrgt is measured from where the axis is at the splice, not from where the motion began. The controller's command names the axes it commits by mask, so this sends ACommitMotion=<this axis's bit>; MotionController.CommitMotion(AxisRef) commits several axes in one synchronised step.
// 返回值: Returns true if the controller accepted the commit, otherwise false. A rejection is reported through MotionController.ErrorOccurred, for example error 48 (the axis is not in a Sine PTP motion), 387 (the motion ends before the splice could happen) or 388 (the recalculation did not finish in time).
bool CommitMotion();

    // Commits the Sine PTP parameters already written to every axis in a mask in one synchronised step: the controller validates them all and splices every new profile on together. @param axes A mask of AAMOTION_AXIS_REF_* bits; the whole commit is refused when any of them is not in a Sine PTP motion.
// controller: 控制器对象
// axes: 轴掩码，例如 `AxisRef.A | AxisRef.B`；单个轴只提交这个轴
