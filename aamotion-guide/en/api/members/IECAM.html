    ECAM_ConfigureTable¶

    void ECAM_ConfigureTable(int startIndex, int endIndex, int startCycIndex, int endCycIndex, int cycles, int masterKeyword, int gap, int tableNum = 1, int masterIni = 0)

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable build a linear or sine table in GenData; ECAM_SetTableData writes a table you computed (from ECAMStart to ECAMEnd). ECAM_ConfigureTable sets the range, cycles, master, gap and master start offset at once; or use SetTableRange, SetMaster, SetGap, SetCycleParams and SetMasterIni one by one.

    Build and configure a cam table

    SDK summary: Configure ECAM table parameters for electronic cam motion.

    Parameter Type Direction Default Description
    startIndex int input by value required The table start in GenData
    endIndex int input by value required The table end in GenData
    startCycIndex int input by value required The start of the repeated part
    endCycIndex int input by value required The end of the repeated part
    cycles int input by value required Cycles: positive one way, negative back and forth, int.MaxValue (2147483647) forever
    masterKeyword int input by value required The CAN code of the master keyword; read it with c.GetKeywordCANCode(eKeyword.PosRef). The C interface cannot look up a CAN code, so write the value: on an AGM800 PosRef is 24 and Pos is 2; for other products see the keyword manual
    gap int input by value required Master counts per table point; negative for reverse
    tableNum int input by value 1 Cam table number, 1–10 (C# may omit it for 1; C must pass it)
    masterIni int input by value 0 The master start offset

    Return type: void

    SDK remarks: This method configures all the necessary parameters for ECAM motion. The ECAM table data should be stored in GenData array from startIndex to endIndex.

    ECAM_SetTableData¶

    void ECAM_SetTableData(int[] data, int tableNum = 1)

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable build a linear or sine table in GenData; ECAM_SetTableData writes a table you computed (from ECAMStart to ECAMEnd). ECAM_ConfigureTable sets the range, cycles, master, gap and master start offset at once; or use SetTableRange, SetMaster, SetGap, SetCycleParams and SetMasterIni one by one.

    Build and configure a cam table

    SDK summary: Set ECAM table data using GenData array. The points are written from ECAMStart[tableNum] up to and including ECAMEnd[tableNum] or the last GenData index, whichever comes first; surplus values are ignored.

    Parameter Type Direction Default Description
    data int[] input by value required The table (slave positions, counts)
    tableNum int input by value 1 Cam table number, 1–10 (C# may omit it for 1; C must pass it)

    Return type: void

    SDK remarks: The data array will be written to the GenData array starting from the configured start index, up to and including ECAMEnd[tableNum] or the GenData array's last index, whichever comes first. A range that starts below the GenData array's first index is rejected without writing anything. Make sure the data array size matches the configured table range.

    ECAM_Start¶

    bool ECAM_Start(int tableNum = 1)

    ECAM_Start makes the slave follow the master through the chosen table; then move the master and the slave follows. ECAM_Stop ends the cam motion, ECAM_IsActive tells whether it is running, ECAM_GetCycleCount reads the cycles done.

    Start, stop and status

    SDK summary: Start ECAM motion with specified table.

    Parameter Type Direction Default Description
    tableNum int input by value 1 Cam table number, 1–10 (C# may omit it for 1; C must pass it)

    Return type: bool

    Returns: Returns true if ECAM motion started successfully, otherwise false.

    ECAM_Start / ECAM_Stop return true when accepted; ECAM_IsActive true while running; ECAM_GetCycleCount the count.

    SDK remarks: Before starting ECAM motion, ensure that: 1. ECAM table is properly configured with ECAM_ConfigureTable 2. ECAM table data is set with ECAM_SetTableData 3. Master axis is properly configured This writes ECAMTableNum, sets MotionMode to 7 (ECAM direct), writes MotorOn = 1, and then sends Begin. A refused Begin leaves the axis enabled; turn the motor off explicitly if the motion did not start.

    SDK summary: Set ECAM master axis (typically the main axis being followed).

    Parameter Type Direction Default Description

    ECAM_CreateLinearTable¶

    void ECAM_CreateLinearTable(int startPos, int endPos, int numPoints, int startIndex, int tableNum = 1)

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable build a linear or sine table in GenData; ECAM_SetTableData writes a table you computed (from ECAMStart to ECAMEnd).     Build and configure a cam table

    SDK summary: Create a simple ECAM table with linear interpolation between start and end positions.

    Parameter Type Direction Default Description
    startPos int input by value required The start position
    endPos int input by value required The end position
    numPoints int input by value required The number of points
    startIndex int input by value required The table start in GenData

    Return type: void

    SDK remarks: This method automatically generates a linear ECAM table and stores it in the GenData array. The table will contain numPoints positions linearly interpolated between startPos and endPos.

    ECAM_CreateSinusoidalTable¶

    void ECAM_CreateSinusoidalTable(int amplitude, int offset, int numPoints, int startIndex, int tableNum = 1)

    ECAM_CreateLinearTable / ECAM_CreateSinusoidalTable build a linear or sine table in GenData; ECAM_SetTableData writes a table you computed (from ECAMStart to ECAMEnd). ECAM_ConfigureTable sets the range, cycles, master, gap and master start offset at once; or use SetTableRange, SetMaster, SetGap, SetCycleParams and SetMasterIni one by one.

    Build and configure a cam table

    SDK summary: Create a sinusoidal ECAM table.

    Parameter Type Direction Default Description
    amplitude int input by value required The sine amplitude
    offset int input by value required The position offset
    numPoints int input by value required The number of points
    startIndex int input by value required The table start in GenData
    tableNum int input by value 1 Cam table number, 1–10 (C# may omit it for 1; C must pass it)

    Return type: void

    SDK remarks: This method automatically generates a sinusoidal ECAM table and stores it in the GenData array. The table will contain numPoints positions following a sinusoidal pattern with specified amplitude and offset. The last point repeats the first, so the sweep closes exactly for any offset.

    ECAMMaster¶

    AAValueArray<double> ECAMMaster { get; }

    SDK summary: Composite CAN code of the master source for each ECAM table. Bits 0-9 carry the keyword's CAN code, bits 10-14 the master axis (0 = axis A) and bits 16-31 the array index. A bare 2 therefore means axis A's Pos, not Pos on any axis. Use MotionController.GetKeywordCANCode to resolve a keyword on a chosen axis; PCSuite's ECAM master picker writes the same code.

    Keyword, units and value contract

    Access: get;

    Value type: AAValueArray<double>
