Remarks

Each keyword corresponds to a parameter on the motion controller that can be read or written using the AAMotion API. The keyword IDs are sequential integers that map to the controller's internal parameter table.

Keywords are divided into several categories:

  • Position/Encoder: Pos, AuxPos, PDPos, IndexPos, etc.
  • Velocity: Vel, AuxVel, VelRef, VelErr, etc.
  • Current: Ia, Ib, Id, Iq, CurrRef, etc.
  • Motion Status: MotionStat, InTargetStat, HomingStat, etc.
  • Configuration: MotorType, EncType, UsrUnits, Accel, Speed, etc.
  • I/O: DInPort, AInPort, DOutPort, etc.
  • System: Identity, VBus, PwrTemp, BoardTemp, etc.
