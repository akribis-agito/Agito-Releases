    Choose an API for the application¶

    Establish coordinates and repeat a move¶

    Equipment condition Choice How to confirm
    PCSuite already provides a commissioned homing table Call Home and wait until HomingStat = 100. Check the axis, search direction, zero and reference position.
    The normal starting region is near one usable Index Search Index directly. Check support for the main encoder latch. Repeat from the same point and compare the reference positions.
    The starting location is uncertain and a limit switch is available Find the switch and reverse slowly toward Index. Check switch polarity and deceleration travel. On timeout, check the observed direction and input transition.
    The mechanism permits contact with a hard stop and has no switch Use a commissioned hard-stop method. Reverse toward Index where needed. Use HomingStep to distinguish search, contact and reverse. Commission current, velocity and hold time on the actual machine.

    Check actual position, units and target before motion. Use MoveAbsAndWait or poll InTargetStat when the next step depends on one axis settling. When batch-starting two independent axes, confirm each separately. If MotionStat shows a stop, read the final position, InTargetStat and MotionReason to distinguish settling from interruption. After a reply timeout, inspect the current target and position before resending. See first motion after power-up and two-axis bulk start.

    Choose the path and segment transitions¶

    Goal API Key behavior
    Position two independent axes Multi-axis point-to-point Each axis plans independently and must be checked for settling.
    One coordinated line or arc Vector motion The lowest participating axis initiates it. Arc centres are absolute.
    Linked lines and arcs, waits or outputs on a path CNC Select the mode, clear the old queue, and confirm the physical start. Pass absolute arc centre coordinates.
    Play back calculated P/V/A/J points PVAJ Download the table, validate, arm, begin, and confirm progress and final position.

    The previous CNC segment's endpoint is the next start. Before linking a line and an arc, check both radii. Set zero end speed before Delay, a change of participating axes, or an arc with extra revolutions. For continuous corners, check the participating axes, corner geometry and firmware trajectory limits before choosing a junction speed. Stop sending on the first refusal. Confirm the group stopped before clearing and rebuilding the queue. See CNC troubleshooting.

    Move with process signals¶

    • Imaging or measuring. Use PEG for position-based outputs. Single events suit one exposure, fixed gaps suit regular scans, and tables suit uneven feature positions. Use Lock to capture position at a sensor edge. Check that LockCntr advanced before reading LockVal. Check which function is enabled on devices with shared pins. PEG and Lock
    • Press fitting. Commission slow approach and switching first, then configure force source, target, duration and retract. Observe position and velocity during approach, trigger and control mode at switching, measured force or current while holding, and target and final state on retract. Verify calibration, direction, current limits and travel on the machine. Force control
    • Synchronized following. Use electronic gearing for a fixed ratio and ECAM when the follower position varies across the master travel. Check source, table extent, repeat range, master gap and starting phase. Verify one cycle before enabling repetition. Choose feedback or reference according to whether the process follows actual or commanded position. Electronic gearing · Electronic cam · C++ examples

    Complete beginner projects¶

    Extract the whole samples/ folder from the delivery ZIP. Each example has a C#, C++ and Python program. For motion, configure commutation and enable the axes in PCSuite, then verify that the axes are idle and the travel is clear. Pass your AGM800 address or the absolute path to firmware_sim.exe. Start with the read-only ReadInput project.

    Language Run from the extracted folder
    C# dotnet run --project samples/app/quick/csharp/ReadInput/ReadInput.csproj -- <address> with the .NET Framework 4.8 development tools installed.
    C++ With the Visual Studio generator, run cmake -S samples/app/quick/cpp -B quick-build -A x64 -DAAMOTION_SDK_DIR=<SDK-folder> and cmake --build quick-build --target ReadInput. Run quick-build/ReadInput/Debug/ReadInput.exe <address>.
    Python Run python get_sdk.py in samples/single/python/, or copy the matching SDK library and server to that directory. Run python samples/app/quick/python/read_input.py <address> with 64-bit Python.

    Use the SDK version this guide documents. Substitute the project or script name for the example you want.

    Read a digital input¶

    Read input 1 with bit index 0. Toggle the input and rerun to compare the printed bit. Native and Python may also return 0 on a failed bit read. To distinguish failure, read the full DInPort register and check the result. Project ReadInput (C# / C++), read_input.py (Python).

    var io = c.GetIO(AxisRef.A);
Console.WriteLine($"Input 1 = {io.GetDInPort(0)}");

    std::printf("Input 1 = %d\n", aamotion_get_d_in_port(h, A, 0));

    print("Input 1 =", am.get_d_in_port(h, A, 0))

    Batch-start two axes¶

    Send A to 10000 and B to 5000. C# calls multi-axis MoveAbs; Native 12 sends one text batch. Check both axes for in-target status. Project MoveTwoAxes (C# / C++), move_two_axes.py (Python).

    var a = c.GetAxis(AxisRef.A);
var b = c.GetAxis(AxisRef.B);
Demo.Check(AAMotionAPI.MoveAbs(c, 10000, 2000, 10000, a, 10000, b, 5000), "MoveAbs");
Demo.Wait(() => a.InTargetStat == 4 && b.InTargetStat == 4, "Both axes in target");
Console.WriteLine($"A={a.Pos}, B={b.Pos}");

    char reply[256] = {};
check(aamotion_send_bulk_command_string(h,
    "AMotionMode=1;ARelTrgt=0;ASpeed=2000;AAccel=10000;ADecel=10000;AAbsTrgt=10000;"
    "BMotionMode=1;BRelTrgt=0;BSpeed=2000;BAccel=10000;BDecel=10000;BAbsTrgt=5000;ABegin;BBegin",
    reply, sizeof reply), "Two-axis batch refused");
wait_until([&] { return read(h, A, AAMOTION_KEYWORD_IN_TARGET_STAT) == 4 &&
                        read(h, B, AAMOTION_KEYWORD_IN_TARGET_STAT) == 4; }, "Both axes: settle timeout");
std::printf("A=%g, B=%g\n", read(h, A, AAMOTION_KEYWORD_POS), read(h, B, AAMOTION_KEYWORD_POS));

    commands = (
    "AMotionMode=1;ARelTrgt=0;ASpeed=2000;AAccel=10000;ADecel=10000;AAbsTrgt=10000;"
    "BMotionMode=1;BRelTrgt=0;BSpeed=2000;BAccel=10000;BDecel=10000;BAbsTrgt=5000;ABegin;BBegin"
)
check(am.send_bulk_command_string(h, commands) is not None, "Two-axis batch refused")
wait_until(lambda: all(read(am, h, axis, am.KEYWORD_IN_TARGET_STAT) == 4 for axis in (A, B)),
           "Both axes: settle timeout")
print("A =", read(am, h, A, am.KEYWORD_POS), "B =", read(am, h, B, am.KEYWORD_POS))

    Home with the configured sequence¶

    Save the axis A homing table in PCSuite. Print the position when HomingStat = 100. Project HomeAxis (C# / C++), home_axis.py (Python).

    var axis = c.GetAxis(AxisRef.A);
axis.Home();
Demo.Wait(() =>
{
    double status = c.GetValue(AxisRef.A, eKeyword.HomingStat);
    Demo.Check(status >= 0, $"Homing failed: {status}");
    return status == 100;
}, "Homing");
Console.WriteLine($"Home complete: position = {axis.Pos}");

    check(aamotion_home(h, A), "Home refused");
wait_until([&] {
    const double status = read(h, A, AAMOTION_KEYWORD_HOMING_STAT);
    check(status >= 0, "Homing failed");
    return status == 100;
}, "Homing timeout");
std::printf("Home complete: position = %g\n", read(h, A, AAMOTION_KEYWORD_POS));

    check(am.home(h, A), "Home refused")

def homed():
    status = read(am, h, A, am.KEYWORD_HOMING_STAT)
    check(status >= 0, f"Homing failed: {status}")
    return status == 100

wait_until(homed, "Homing timeout")
print("Home complete: position =", read(am, h, A, am.KEYWORD_POS))

    Two-speed positioning¶

    Move by 10000. Use speed 4000 for the first 8000 and 1000 for the remainder. Project TwoSpeed (C# / C++), two_speed.py (Python).

    var axis = c.GetAxis(AxisRef.A);
Demo.Check(axis.MoveRelTwoSpeedAndWait(10000, 4000, 1000, 8000,
    accel: 50000, decel: 50000, timeout: 10000), "Two-speed move");
Console.WriteLine($"In target: position = {axis.Pos}");

    check(aamotion_move_rel_two_speed_and_wait(h, A, 10000, 4000, 1000, 8000,
    50000, 50000, -1, 10000), "Two-speed move failed");
std::printf("In target: position = %g\n", read(h, A, AAMOTION_KEYWORD_POS));

    check(am.move_rel_two_speed_and_wait(h, A, 10000, 4000, 1000, 8000,
                                     50000, 50000, -1, 10000), "Two-speed move failed")
print("In target: position =", read(am, h, A, am.KEYWORD_POS))

    Run a CNC line¶

    Start at the actual position and advance both axes by 1000 counts with a zero end speed. If a segment push fails partway, clear the buffer and rebuild the path before the next push. Project CncLine (C# / C++), cnc_line.py (Python).

    var group = c.GetGroup(AxisRef.A);
int x = (int)c.GetAxis(AxisRef.A).Pos;
int y = (int)c.GetAxis(AxisRef.B).Pos;
Demo.Check(group.ClearBuffer(), "ClearBuffer");
Demo.Check(group.SetStartPositions(x, y, null), "SetStartPositions");
Demo.Check(group.SetMotionProfile(100, 10000, 10000, 0), "SetMotionProfile");
Demo.Check(group.LinearAbsoluteXY(x + 1000, y + 1000, 1000, 0), "LinearAbsoluteXY");
Demo.Check(c.SendCommandString("AMotionMode=11", out _) &&
           c.SendCommandString("BMotionMode=11", out _), "Set CNC mode");
Demo.Check(group.Begin(), "Begin");
try { Demo.Wait(() => group.IsCNCCompleted(AxisRef.A), "CNC completion"); }
catch { group.Stop(); throw; }
Console.WriteLine($"CNC complete: A={c.GetAxis(AxisRef.A).Pos}, B={c.GetAxis(AxisRef.B).Pos}");

    const int x = static_cast<int>(read(h, A, AAMOTION_KEYWORD_POS));
const int y = static_cast<int>(read(h, B, AAMOTION_KEYWORD_POS));
check(aamotion_clear_buffer(h), "ClearBuffer");
check(aamotion_set_start_positions(h, A | B, x, y, 0), "SetStartPositions");
check(aamotion_set_motion_profile(h, 100, 10000, 10000, 0), "SetMotionProfile");
check(aamotion_linear_absolute_xy(h, x + 1000, y + 1000, 1000, 0), "LinearAbsoluteXY");
char reply[128] = {};
check(aamotion_send_command_string(h, "AMotionMode=11", reply, sizeof reply) &&
      aamotion_send_command_string(h, "BMotionMode=11", reply, sizeof reply), "Set CNC mode");
check(aamotion_cnc_begin(h), "Begin");
try { wait_until([&] { return aamotion_is_cnc_completed(h, A); }, "CNC completion timeout"); }
catch (...) { aamotion_group_stop(h); throw; }
std::printf("CNC complete: A=%g, B=%g\n", read(h, A, AAMOTION_KEYWORD_POS), read(h, B, AAMOTION_KEYWORD_POS));

    x = int(read(am, h, A, am.KEYWORD_POS))
y = int(read(am, h, B, am.KEYWORD_POS))
check(am.clear_buffer(h), "ClearBuffer")
check(am.set_start_positions(h, A | B, x, y, 0), "SetStartPositions")
check(am.set_motion_profile(h, 100, 10000, 10000, 0), "SetMotionProfile")
check(am.linear_absolute_xy(h, x + 1000, y + 1000, 1000, 0), "LinearAbsoluteXY")
check(am.send_command_string(h, "AMotionMode=11") is not None
      and am.send_command_string(h, "BMotionMode=11") is not None, "Set CNC mode")
check(am.cnc_begin(h), "Begin")
try:
    wait_until(lambda: am.is_cnc_completed(h, A), "CNC completion timeout")
except BaseException:
    am.group_stop(h)
    raise
print("CNC complete: A =", read(am, h, A, am.KEYWORD_POS), "B =", read(am, h, B, am.KEYWORD_POS))

    Short DataLogger capture¶

    Record APos for 1 second at a 1 ms interval and print the sample count. The minimum interval follows the scan period, about 61 µs on some configurations. Project DataLogger (C# / C++), data_logger.py (Python).

    var config = new MotionController.DataLoggerConfiguration { DurationSec = 1, GapMs = 1 };
config.ParamsToRecord.Add("APos");
string error = c.ConfigureDataLogger(config);
Demo.Check(string.IsNullOrEmpty(error), error);
error = c.StartDataRecording();
Demo.Check(string.IsNullOrEmpty(error), error);
error = c.WaitForDataRecordingToEnd(5000);
Demo.Check(string.IsNullOrEmpty(error), error);
error = c.UploadDataLoggerData(out var result);
Demo.Check(string.IsNullOrEmpty(error), error);
var values = result.Vectors[0].Values;
Demo.Check(values.Count > 0, "No APos samples");
Console.WriteLine($"APos: {values.Count} samples");

    check(aamotion_data_rec_record(h, "APos", 1, 1, 0, 0, nullptr, 0, 0, false, 5000),
      "Record and upload APos");
int length = 0, gap = 0, vectors = 0, samples = 0;
check(aamotion_data_rec_info(h, &length, &gap, &vectors, &samples), "Read recording info");
check(vectors == 1 && samples > 0, "No APos samples");
std::printf("APos: %d samples\n", samples);

    check(am.data_rec_record(h, "APos", 1, 1, 0, 0, None, 0, 0, False, 5000),
      "Record and upload APos")
info = am.data_rec_info(h)
check(info is not None, "Read recording info")
_, _, vectors, samples = info
check(vectors == 1 and samples > 0, "No APos samples")
print(f"APos: {samples} samples")

    SlowLogger capture¶

    Record APos for about 2 seconds and save it to slow-logger.txt. The minimum interval is about 1 ms. Upload the FIFO periodically for longer runs. Project SlowLogger (C# / C++), slow_logger.py (Python).

    c.ConfigureSlowLogger(10, 0, "APos");
c.LoggerOn = 1;
try
{
    Thread.Sleep(2000);
    string text = c.LoggerUpload();
    Demo.Check(!string.IsNullOrEmpty(text), "No logger data");
    File.WriteAllText("slow-logger.txt", text);
}
finally { c.LoggerOn = 0; }
Console.WriteLine("Saved slow-logger.txt");

    const char* signals[] = {"APos"};
check(aamotion_configure_slow_logger(h, 10, 0, signals, 1), "Configure SlowLogger");
check(aamotion_set_logger_on(h, 1), "Start SlowLogger");
std::this_thread::sleep_for(std::chrono::seconds(2));
char text[8192] = {};
const bool uploaded = aamotion_logger_upload(h, text, sizeof text);
check(aamotion_set_logger_on(h, 0), "Stop SlowLogger");
check(uploaded && text[0], "No logger data");
std::ofstream output("slow-logger.txt");
output << text;
output.close();
check(static_cast<bool>(output), "Write slow-logger.txt");
std::puts("Saved slow-logger.txt");

    check(am.configure_slow_logger(h, 10, 0, ["APos"]), "Configure SlowLogger")
check(am.set_logger_on(h, 1), "Start SlowLogger")
try:
    time.sleep(2)
    text = am.logger_upload(h)
    check(text, "No logger data")
    Path("slow-logger.txt").write_text(text, encoding="utf-8")
finally:
    check(am.set_logger_on(h, 0), "Stop SlowLogger")
print("Saved slow-logger.txt")
