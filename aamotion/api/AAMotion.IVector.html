VectorArc(AxisRef, AxisRef, double, double, double, double, int, int, double, double, double, double, int)

Execute arc vector motion.

Note: The vector motion must be initiated from the axis object with the lowest index among the participating axes.

For example, for (B, C) use axis B; for (D, E, F) use axis D.

/// Start exercising Begin()

bool VectorArc(AxisRef axis1, AxisRef axis2, double center1, double center2, double pos1, double pos2, int dir, int circles, double speed, double accel, double decel, double emrgdec, int smooth)

Second axis.

center2 double

Center point of the second axis.

Target position of the first axis.

Target position of the second axis.

Vector motion direction.

circles int

Number of circles for vector motion.

Vector motion speed.

Vector acceleration.

Vector deceleration.

Vector emergency deceleration.

Vector smoothing factor.

Returns

Returns true if executed successfully, otherwise false.

Remarks

A vector move requires its axes to agree on their User Units. One VecSpeed, VecAccel and VecDecel are applied across the whole move while each axis's target is in that axis's own units, which only means something if they measure the same quantity: every axis must carry the same unit name in the position, velocity and acceleration groups. Different scaling factors under one name are fine — two encoder resolutions on the same gantry still measure millimetres — but a rad axis and a cm axis have no common vector length, and an axis with User Units off is on controller counts, which does not match a scaled one.

Every member is checked in all three groups; the axis this call was made on is one of them.

A move needs at least two members, all among axes A..H (the controller's VecMemberAxes reaches H), and the axis this call was made on must be one of them and the lowest: it carries the profile and receives Begin, and the controller rejects any other shape. A call that breaks that is refused before anything is written — it returns false and raises ErrorOccurred.

Axes that disagree make the call return false and command nothing — before any parameter is read from or written to the controller — and raise ErrorOccurred with code -1, the name of the method called, and a message naming the axes and the group. Setting UseUserUnits to false puts every axis back on controller counts, which always matches.
