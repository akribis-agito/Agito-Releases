    参数读写¶

    控制器上的一切设置和状态都是关键字（Pos、Speed、MotionStat……），完整列表和每个关键字的说明见关键字参考。读写关键字有三种方式，从简单到通用：

    方式 C# C 适合
    对象属性 a.Pos、a.Speed = 20000 — C# 中最常用，有类型、有用户单位换算
    按关键字读写 c.GetValue(AxisRef.A, eKeyword.Pos)、c.SetValue(AxisRef.A, eKeyword.Speed, 20000) aamotion_get_value、aamotion_set_value 只知道关键字名时；C / Python 的常用方式，单位换算与属性相同
    原始命令 SendCommandString("ASpeed=20000") aamotion_send_command_string 任何关键字和命令，包括没有对应函数的命令

    多条命令要一起发时用批量命令，一包最多 50 条，比逐条发送快得多。

    轴、IO 和组对象¶

    C# 中按对象访问控制器：c.GetAxis(AxisRef.A) 得到轴对象 ISingleAxis（关键字属性和运动方法），c.GetIO(...) 得到 IO 模块 IIOModule，c.GetGroup(...) / c.GetCiGroup(...) 得到 CNC 组。这些对象是轻量的，可以随时获取，也可以保存下来反复使用。C 接口没有对象，所有函数都直接带轴参数。

    独立小 Demo：轴对象属性读写

    什么时候用

    C# 中操作一个轴的多项功能时，先拿到轴对象再调用，代码更短、更清楚。

    函数原型

    // MotionController
// Gets the single axis control interface for the specified axis.
// axis: 轴；对 `GetCiGroup`，AGM800 用 `AxisRef.B` 得到组 B
// 返回值: An instance of `ISingleAxis` interface for the specified axis.
ISingleAxis GetAxis(AxisRef axis);

// Gets the interface for the specified IO module.
// axis: 轴；对 `GetCiGroup`，AGM800 用 `AxisRef.B` 得到组 B
// 返回值: An instance of `IIOModule` interface for the specified IO module.
IIOModule GetIO(AxisRef axis);

// Gets the interface for the specified Ci group axis.
// axis: 轴；对 `GetCiGroup`，AGM800 用 `AxisRef.B` 得到组 B
// 返回值: An instance of `ICiGroupAxis` interface for the specified Ci group axis.
ICiGroupAxis GetCiGroup(AxisRef axis);

    参数

    参数 类型 说明
    axis AxisRef 轴；对 GetCiGroup，AGM800 用 AxisRef.B 得到组 B

    示例

    ISingleAxis a = c.GetAxis(AxisRef.A);
double pos = a.Pos;           // read
a.Speed = 20000;              // write
double avg = a.Vel[1];        // array keyword: Vel[1] is the filtered velocity
    SDK 原文注释（英文）
    • GetAxis(AxisRef) — Gets the single axis control interface for the specified axis. Returns: An instance of ISingleAxis interface for the specified axis.
    • GetIO(AxisRef) — Gets the interface for the specified IO module. Returns: An instance of IIOModule interface for the specified IO module.
    • GetCiGroup(AxisRef) — Gets the interface for the specified Ci group axis. Returns: An instance of ICiGroupAxis interface for the specified Ci group axis.

    发送原始命令¶

    发送一条命令字符串，返回控制器的回复。格式与 PCSuite 终端相同：A 到 L 前缀选择轴（非轴关键字固定写 A），赋值写 =，数组下标写 [i]。读取回复数值的文本，写入回复 OK，命令（如 ABegin）回复 OK。

    独立小 Demo：发送原始命令

    什么时候用

    关键字没有专门的函数时；照搬 PCSuite 终端里试过的命令；C / Python 中写参数。

    函数原型

    // AAMotionAPI
// Send raw command string to the controller
// controller: 控制器对象 / 句柄
// rawCommand: 命令字符串，例如 `"APos"`、`"ASpeed=20000"`、`"ALoggerParams[1]=24"`
// response: 控制器的回复（C# 为 out 参数；C 为调用方提供的缓冲区，结果以 NUL 结尾，过长时截断）
// 返回值: Returns true if send is successful, otherwise false
static bool SendCommandString(MotionController controller, string rawCommand, out string response);

// MotionController
// Sends a raw command string to the controller.
// rawCommand: 命令字符串，例如 `"APos"`、`"ASpeed=20000"`、`"ALoggerParams[1]=24"`
// response: 控制器的回复（C# 为 out 参数；C 为调用方提供的缓冲区，结果以 NUL 结尾，过长时截断）
// 返回值: True if command is sent successfully and no errors occur; otherwise false.
bool SendCommandString(string rawCommand, out string response);

    // Sends one raw command, exactly as typed in the PCSuite terminal (e.g. "APos" or "ASpeed=1000"), and writes the reply into response (truncated on a character boundary, NUL-terminated). @return true when the controller answered without an error.
// controller: 控制器对象 / 句柄
// rawCommand: 命令字符串，例如 `"APos"`、`"ASpeed=20000"`、`"ALoggerParams[1]=24"`
// response: 控制器的回复（C# 为 out 参数；C 为调用方提供的缓冲区，结果以 NUL 结尾，过长时截断）
// responseSize: C 回复缓冲区的字节数
bool aamotion_send_command_string(aamotion_controller controller, const char* rawCommand, char* response, int responseSize);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    rawCommand const char* / string 命令字符串，例如 "APos"、"ASpeed=20000"、"ALoggerParams[1]=24"
    response char* / string 控制器的回复（C# 为 out 参数；C 为调用方提供的缓冲区，结果以 NUL 结尾，过长时截断）
    responseSize int C 回复缓冲区的字节数

    返回值

    发送成功且回复不是错误时返回 true；控制器回复 ERR 时返回 false（错误钩子会被调用）。

    注意

    • 轴启用了用户单位时，原始命令和批量命令同样按用户单位换算：写入的值和读回的值都是用户单位，和对象属性一致。
    • 命令关键字（Begin、Save、Reset 等）发送即执行，读它也会执行。

    示例

    if (AAMotionAPI.SendCommandString(c, "ASpeed=20000", out string reply))
    Console.WriteLine("write: " + reply);           // "OK"

if (c.SendCommandString("APos", out reply))
    Console.WriteLine("APos = " + reply);           // the value, as text

c.SendCommandString("ALoggerParams[1]", out reply); // array element: [index]

    char reply[256];
if (aamotion_send_command_string(h, "ASpeed=20000", reply, sizeof reply))
    printf("write: %s\n", reply);            /* "OK" */

if (aamotion_send_command_string(h, "APos", reply, sizeof reply))
    printf("APos = %s\n", reply);            /* the value, as text */
    SDK 原文注释（英文）
    • SendCommandString(MotionController, string, string) — Send raw command string to the controller Returns: Returns true if send is successful, otherwise false
    • SendCommandString(string, string) — Sends a raw command string to the controller. Returns: True if command is sent successfully and no errors occur; otherwise false.
    • aamotion_send_command_string — Sends one raw command, exactly as typed in the PCSuite terminal (e.g. "APos" or "ASpeed=1000"), and writes the reply into response (truncated on a character boundary, NUL-terminated). @return true when the controller answered without an error.

    批量命令¶

    一次发送多条命令，命令之间用 ; 分隔，一包最多 50 条，回复按顺序用 > 分隔，例如 "123>-11>6700>OK>"。某一条出错时，它后面的命令都不再执行，回复的最后一段是错误，例如 "123>-11>ERR 24>"。BulkCommandParser(i, reply) 取出第 i 条（从 1 开始）的回复。

    独立小 Demo：批量读取

    什么时候用

    一次读或写多个值：初始化时写一批参数、界面上一次刷新多个状态。最多 50 条。

    函数原型

    // AAMotionAPI
// Special type to send multiple messages at once, on Ethernet and Simulation channels only Reply: one reply per message, separated by '>', i.e. "123>-11>6700>OK" In case one of the bulk messages results in an error, all the messages AFTER the error are NOT performed. The reply will include the error code in the last "element": "123>-11>6700>OK>ERR XX" A reply that is not one answer per message, nor stops at an error, returns false.
// controller: 控制器对象 / 句柄
// rawCommand: 用 `;` 分隔的多条命令，例如 `"APos;BPos;AVel[1]"`
// response: 用 `>` 分隔的回复
// 返回值: Returns true if send is successful, otherwise false
static bool SendBulkCommandString(MotionController controller, string rawCommand, out string response);

// MotionController
// Sends a bulk command string to the controller.
// rawCommand: 用 `;` 分隔的多条命令，例如 `"APos;BPos;AVel[1]"`
// response: 用 `>` 分隔的回复
// 返回值: True if bulk command is sent successfully and no errors occur; otherwise false.
bool SendBulkCommandString(string rawCommand, out string response);

// Parses a bulk command string response and returns the specified index value.
// index: 要取的回复序号，从 1 开始；0 或越界返回 null
// response: 用 `>` 分隔的回复
// 返回值: The value at the specified index in the response, or null if the index is out of range, the response is empty, or it has a blank answer (`AAComm.Services.BulkReply.TrySplit`).
string BulkCommandParser(int index, string response);

    // Sends several commands in one packet (Ethernet and simulation only). The reply holds one answer per command separated by '>', e.g. "123>-11>6700>OK"; when one command fails, the commands after it are NOT performed and the reply ends with its error ("...>ERR XX"). @return false for a reply that is neither one answer per command nor stopped at an error.
// controller: 控制器对象 / 句柄
// rawCommand: 用 `;` 分隔的多条命令，例如 `"APos;BPos;AVel[1]"`
// response: 用 `>` 分隔的回复
// responseSize: C 回复缓冲区的字节数
bool aamotion_send_bulk_command_string(aamotion_controller controller, const char* rawCommand, char* response, int responseSize);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象 / 句柄
    rawCommand const char* / string 用 ; 分隔的多条命令，例如 "APos;BPos;AVel[1]"
    response char* / string 用 > 分隔的回复
    index int 要取的回复序号，从 1 开始；0 或越界返回 null
    responseSize int C 回复缓冲区的字节数

    返回值

    全部成功返回 true；任一段是错误返回 false。BulkCommandParser 返回那一段的文本。

    注意

    • 只有以太网和仿真连接支持批量命令。

    示例

    // several commands in one packet; replies come back separated by '>'
if (c.SendBulkCommandString("APos;BPos;AVel[1];BVel[1]", out string reply))
{
    double aPos = double.Parse(c.BulkCommandParser(1, reply));   // 1-based
    double bPos = double.Parse(c.BulkCommandParser(2, reply));
    Console.WriteLine($"A={aPos} B={bPos}  raw: {reply}");
}

    char reply[1024];
if (aamotion_send_bulk_command_string(h, "APos;BPos;AVel[1];BVel[1]", reply, sizeof reply))
    printf("%s\n", reply);                   /* e.g. "1200>-300>15>0>" */
    SDK 原文注释（英文）
    • SendBulkCommandString(MotionController, string, string) — Special type to send multiple messages at once, on Ethernet and Simulation channels only Reply: one reply per message, separated by '>', i.e. "123>-11>6700>OK" In case one of the bulk messages results in an error, all the messages AFTER the error are NOT performed. The reply will include the error code in the last "element": "123>-11>6700>OK>ERR XX" A reply that is not one answer per message, nor stops at an error, returns false. Returns: Returns true if send is successful, otherwise false
    • SendBulkCommandString(string, string) — Sends a bulk command string to the controller. Returns: True if bulk command is sent successfully and no errors occur; otherwise false.
    • BulkCommandParser(int, string) — Parses a bulk command string response and returns the specified index value. Returns: The value at the specified index in the response, or null if the index is out of range, the response is empty, or it has a blank answer (AAComm.Services.BulkReply.TrySplit).
    • aamotion_send_bulk_command_string — Sends several commands in one packet (Ethernet and simulation only). The reply holds one answer per command separated by '>', e.g. "123>-11>6700>OK"; when one command fails, the commands after it are NOT performed and the reply ends with its error ("...>ERR XX"). @return false for a reply that is neither one answer per command nor stopped at an error.

    按关键字读数值¶

    按关键字读一个轴上的数值，按这个轴的用户单位换算后返回（没有启用用户单位时是计数）。每次调用都向控制器读一次，不使用快速读缓存。TryGetValue 失败时返回 false 而不抛异常。

    独立小 Demo：按关键字读数值

    什么时候用

    只知道关键字名（例如来自配置文件）时读值；C / Python 中读任何关键字。

    函数原型

    // MotionController
// The value `keyword` holds on `axis`, read through the controller, in the units that axis reads it in — `MotionController.GetUserUnits` says which, and answers counts when nothing scales it. `index` 0 reads a scalar parameter; 1 and up read one element of an array parameter, in the parameter's own indexing — an array parameter has no reading at 0, and a scalar one none at 1. Keyed by keyword so a caller can read a parameter it knows only by name, rather than through the member that happens to expose it. `axis` names one axis; a combined mask is an `System.ArgumentException`, and so is a keyword the message table flags as a controller command — reading one would SEND it. An index the parameter does not have throws. A read the controller refuses, or answers with something that is not a number, is a `ControllerCommandException`; `MotionController.TryGetValue` reports the same failure as instead.
// axis: 一个轴（`AxisRef.A` / `AAMOTION_AXIS_REF_A` 等），不能组合多个轴
// keyword: 关键字（`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`）。不能是命令关键字：读命令会执行它，所以会被拒绝
// index: 0 读标量；数组关键字从 1 开始，按该关键字自己的下标。数组没有 0，标量没有 1。`TryReadArray` 的下标从 1 开始
double GetValue(AxisRef axis, eKeyword keyword, int index = 0);

// `MotionController.GetValue` that reports whether the read succeeded instead of throwing on a failure. Always a controller round trip, never the FastReadCache. False — with `value` 0 — when the controller replied with an error or with something that is not a number; `MotionController.LastReadError` then names the failure and `MotionController.ReadFailures` is incremented. The argument checks are `MotionController.GetValue`'s and throw the same way.
// axis: 一个轴（`AxisRef.A` / `AAMOTION_AXIS_REF_A` 等），不能组合多个轴
// keyword: 关键字（`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`）。不能是命令关键字：读命令会执行它，所以会被拒绝
// value: 读到的值（C# out 参数 / C 指针）
// index: 0 读标量；数组关键字从 1 开始，按该关键字自己的下标。数组没有 0，标量没有 1。`TryReadArray` 的下标从 1 开始
bool TryGetValue(AxisRef axis, eKeyword keyword, out double value, int index = 0);

// ISingleAxis
// Reads `keyword` from the controller and reports whether the read succeeded, instead of throwing the way the typed properties do on a failure. Always a controller round trip, never the FastReadCache, in the units the axis reads in. False — with `value` 0 — when the controller replied with an error or with something that is not a number; `MotionController.LastReadError` then names the failure and `MotionController.ReadFailures` is incremented. A keyword the SDK knows as a controller command is an `System.ArgumentException`: reading one would send it.
// keyword: 关键字（`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`）。不能是命令关键字：读命令会执行它，所以会被拒绝
// value: 读到的值（C# out 参数 / C 指针）
bool TryRead(eKeyword keyword, out double value);

// Array-element twin of `ISingleAxis.TryRead`: reads element `index` (1 and up) of an array parameter.
// keyword: 关键字（`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`）。不能是命令关键字：读命令会执行它，所以会被拒绝
// index: 0 读标量；数组关键字从 1 开始，按该关键字自己的下标。数组没有 0，标量没有 1。`TryReadArray` 的下标从 1 开始
// value: 读到的值（C# out 参数 / C 指针）
bool TryReadArray(eKeyword keyword, int index, out double value);

    // Any controller parameter can be read and written by keyword with aamotion_get_value / aamotion_set_value; the dedicated calls below cover the GenData/UserParam arrays and whole-file transfers. To read a whole digital port at once, read AAMOTION_KEYWORD_DIN_PORT, AAMOTION_KEYWORD_DIN_PORT_HIGH or AAMOTION_KEYWORD_DOUT_PORT with aamotion_get_value. Reads the parameter keyword on axis, in the units that axis reads it in (aamotion_get_units says which). Values are doubles: read a register into uint32_t (via int64_t), not a C (int) cast. @param keyword An aamotion_keyword_t value. @param index 0 reads a scalar parameter; 1 and up read one element of an array parameter. @return false, *value untouched: bad handle, NULL value, axis not A..L, keyword unknown or naming a COMMAND (reading would send it), an index the parameter lacks, a refused read, or a reply that is not a number.
// controller: 控制器句柄
// axis: 一个轴（`AxisRef.A` / `AAMOTION_AXIS_REF_A` 等），不能组合多个轴
// keyword: 关键字（`eKeyword.Pos` / `AAMOTION_KEYWORD_POS`）。不能是命令关键字：读命令会执行它，所以会被拒绝
// index: 0 读标量；数组关键字从 1 开始，按该关键字自己的下标。数组没有 0，标量没有 1。`TryReadArray` 的下标从 1 开始
// value: 读到的值（C# out 参数 / C 指针）
bool aamotion_get_value(aamotion_controller controller, int axis, int keyword, int index, double* value);

    参数

    参数 类型 说明
    axis AxisRef / int 一个轴（AxisRef.A / AAMOTION_AXIS_REF_A 等），不能组合多个轴
    keyword eKeyword / int 关键字（eKeyword.Pos / AAMOTION_KEYWORD_POS）。不能是命令关键字：读命令会执行它，所以会被拒绝
    index int 0 读标量；数组关键字从 1 开始，按该关键字自己的下标。数组没有 0，标量没有 1。TryReadArray 的下标从 1 开始
    value double* / double 读到的值（C# out 参数 / C 指针）
    controller aamotion_controller 控制器句柄

    返回值

    GetValue 返回数值，失败抛 ControllerCommandException。TryGetValue / C 版本成功返回 true；失败返回 false，C# 中原因在 LastReadError。

    注意

    • C 中数值都是 double；读位寄存器时转成 uint32_t，不要直接转 int。

    示例

    double pos = c.GetValue(AxisRef.A, eKeyword.Pos);          // scalar: index 0
double vel = c.GetValue(AxisRef.A, eKeyword.Vel, 1);       // array: index 1 and up
UserUnitAxis u = c.GetUserUnits(AxisRef.A, eKeyword.Pos);
Console.WriteLine($"APos = {pos} {u.Units} (factor {u.Factor})");

    double pos, vel, factor;
char unit[32];
if (aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_POS, 0, &pos) &&
    aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_VEL, 1, &vel) &&
    aamotion_get_units(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_POS, unit, sizeof unit, &factor))
{
    printf("APos = %g %s (factor %g), AVel[1] = %g\n", pos, unit, factor, vel);
}
    SDK 原文注释（英文）

An index the parameter does not have throws. A read the controller refuses, or answers with something that is not a number, is a ControllerCommandException; MotionController.TryGetValue reports the same failure as instead.
    • TryGetValue(AxisRef, eKeyword, double, int) — MotionController.GetValue that reports whether the read succeeded instead of throwing on a failure.     读用户单位¶

    查询某个关键字在某个轴上的读写单位：单位名和换算系数（显示值 = 计数 × 系数）。轴没有启用用户单位、关键字不属于任何单位组，或 UseUserUnits = false 时，返回空名称和系数 1，即计数。

    客户单位转换有两种方式：① 打开 控制器对象的 c.UseUserUnits 开关，由 SDK 按轴的单位设置转换，调用方传用户单位；② 关闭 SDK 转换，由客户上位机完成用户单位与计数的换算后下发，并自行转换反馈。选择一种贯穿读写，避免重复换算。单位参数按实际轴设置确认。

    例如：1 用户单位对应 1000 计数时，方式一传目标 2，由 SDK 转为 2000 计数；方式二关闭 SDK 转换后由上位机传 2000。反馈也由所选的一层转换回来。速度和加减速应使用对应的单位系数，不能只换算位置。

    什么时候用

    界面上显示单位名；或者在写原始计数前确认这个轴是不是启用了用户单位。

Check `Factor == 1` before treating a value as counts — a scaled axis may carry no unit name. `axis` names one axis; a combined mask is an `System.ArgumentException`.

// keyword: 关键字

// axis: 一个轴

    • aamotion_read_gen_data 失败时返回 0，和真实的 0 无法区分；0 有意义时用 aamotion_send_command_string(h, "AGenData[10]", ...) 读取并检查返回值。

    参数文件上传与下载¶

    和 PCSuite 的“参数上传 / 下载”相同。上传：读出控制器的全部参数，连同文件头（产品型号、固件 / FPGA 版本、日期、校验和）保存为 .par 文件。下载：读取 .par 文件，按已连接控制器校验后逐个写入，可选地再执行 CalcFilters 和 Save 保存到 Flash。以太网连接用批量命令（每包 50 条）。传输由 AAComm 执行：C# 的两个方法都立即返回，结果通过回调通知，完成回调收到的统计是 AAComm 的 ParamHandlingSummary（命名空间 AAComm.Extensions）；C 函数阻塞到传输结束。上传的文件头一行写的是 // AAComm version: 和 AAComm 的版本号。

    什么时候用

    出厂前备份参数、更换控制器后恢复参数、批量给多台机器下载同一套参数。

    函数原型

    // AAMotionAPI
// Asynchronously reads all controller parameters and saves them to a .par file (controller disk -> local file). Follows the PCSuite "Parameters Upload" convention: queries every supported parameter, writes them with header (product type, firmware/FPGA version, date, file checksum) to a plain ASCII .par file. A parameter the controller refuses is left out of the file, named in a `// Not uploaded:` header line and in `AAComm.Extensions.ParamHandlingSummary.Rejections`; an empty reply fails the upload and writes no file. Ethernet connections use bulk messages (up to 50 per packet); other channels send one by one. The call is non-blocking; subscribe to the callbacks to be notified of progress and completion.
// controller: 已连接的控制器
// filePath: `.par` 文件的完整路径。上传时创建或覆盖
// onProgress: 可选，进度回调（0–100）
// onDone: 可选，完成回调：统计信息（早期失败时为 null）和错误说明（成功时为空字符串）
static void UploadParameters(MotionController controller, string filePath, Action<int> onProgress = null, Action<ParamHandlingSummary, string> onDone = null);

// Asynchronously writes controller parameters from a .par file (local file -> controller disk). Follows the PCSuite "Parameters Download" convention: reads the .par file, validates parameters against the connected controller, then sends each as a SET command. Ethernet connections use bulk messages (up to 50 per packet); other channels send one by one. After a successful download, optionally sends "ASave" plus per-axis "CalcFilters" to persist parameters to flash. The call is non-blocking; subscribe to the callbacks to be notified of progress and completion.
// controller: 已连接的控制器
// filePath: `.par` 文件的完整路径。上传时创建或覆盖
// calcAndSave: true（默认）：下载完全成功后执行 `ASave` 和各轴 `CalcFilters`，写入 Flash；中途失败的下载不会保存。false：只写入 RAM

static void DownloadParameters(MotionController controller, string filePath, bool calcAndSave = true, Action<int> onProgress = null, Action<ParamHandlingSummary, string> onDone = null);

A parameter the controller refuses is left out and named in the file header. @param filePath The .par file to create or overwrite. @param message Receives the reason when the call returns false. @return true only when it finished with no error, refused parameter or cancel.
// controller: 已连接的控制器
// filePath: `.par` 文件的完整路径。上传时创建或覆盖

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 已连接的控制器
    filePath const char* / string .par 文件的完整路径。上传时创建或覆盖
    onProgress Action<int> 可选，进度回调（0–100）
    onDone Action<ParamHandlingSummary, string> 可选，完成回调：统计信息（早期失败时为 null）和错误说明（成功时为空字符串）
    calcAndSave bool true（默认）：下载完全成功后执行 ASave 和各轴 CalcFilters，写入 Flash；中途失败的下载不会保存。false：只写入 RAM
    message char* 输出：失败时的原因
    messageSize int message 缓冲区的字节数

    返回值

    C#：没有返回值，结果在 onDone。C：只有在没有错误、没有被拒绝的参数、没有取消的情况下完成时才返回 true；返回 false 时原因写入 message。

    注意

    • C# 回调在后台线程上执行。下载会改写控制器参数，电机使能时部分参数不能写入，建议先断使能。
    • 换控制器时，先用 PCSuite 核对目标的型号、固件、轴映射和备份的来源。下载前备份目标原参数；上传和下载分别等各自的完成回调。进度百分比只表示传输进度。
    • {'第一次恢复用 calcAndSave': 'false，先在 RAM 里核对结果。完成时同时检查错误文本和摘要的 ErrorCount，再回读轴映射、单位、方向和限位等关键配置。确认后再按设备流程计算滤波参数并保存到 Flash。'}
    • 传输中断时，较早写入的参数可能已在 RAM 生效。先检查统计和控制器回读，再决定恢复哪份配置。

    // Restore a previously verified backup to RAM. The caller keeps c connected.
AAMotionAPI.DownloadParameters(c, @"C:\backup\axis.par", calcAndSave: false,
    percent => Console.WriteLine($"download {percent}%"),
    (summary, error) =>
    {
        if (!string.IsNullOrEmpty(error))
            Console.WriteLine(error);
        else if (summary == null || summary.ErrorCount != 0)
            Console.WriteLine($"Check the download summary. Rejected rows: {summary?.ErrorCount}");
        else
            Console.WriteLine("Download finished. Verify the settings in RAM.");
    });

    char message[512];
/* blocks until done; false with the reason in message */
if (!aamotion_upload_parameters(h, "C:\\backup\\axis.par", message, sizeof message))
    printf("upload failed: %s\n", message);

/* write the file back; true = recalculate filters and save to flash */
if (!aamotion_download_parameters(h, "C:\\backup\\axis.par", true, message, sizeof message))
    printf("download failed: %s\n", message);
