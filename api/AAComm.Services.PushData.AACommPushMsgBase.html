Class AACommPushMsgBase

Namespace
AAComm.Services.PushData
Assembly
AAComm.dll

Base type for controller push messages.

Expected raw message format:

[VERSION_PUSH].[SOURCE],[VERSION_DATA].[DATA]

Where:

  • VERSION_PUSH: integer protocol version for the overall push feature
  • SOURCE: integer enum value (PushSources) telling which derived message type to create
  • VERSION_DATA: integer version for the payload format
  • DATA: raw payload (may be ASCII string or raw binary bytes depending on SOURCE/VERSION_DATA)
