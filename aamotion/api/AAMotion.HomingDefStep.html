Class HomingDefStep

Namespace
AAMotion
Assembly
AAMotion.dll

One step of HomingDef. The array is 20 steps of 10 slots: slot 1 holds the step type and slots 2-10 are that type's nine parameters, whose meaning depends on it — a speed, an acceleration, a position offset or a timeout in current-loop samples.

HomingDef remains the escape hatch for a firmware step type this SDK does not name.
