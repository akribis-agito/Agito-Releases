    Vector motion¶

    Vector motion moves up to 8 axes (A–H) together along a straight line, or along an arc in the plane of two axes, with the speeds given for the resultant (vector) motion. Unlike CNC it is one segment at a time with no buffer, used much like a point-to-point move; CNC is a continuous multi-segment path.

    A vector move must start from the lowest-numbered member axis: B for (B, C), D for (D, E, F). The controller side is described under keyword Vector overview. See the PCSuite vector controls and parameters.

    In this chapter
    • Linear vector move
    • Arc vector move
    • Pause, continue and stop

    Run this chapter's demo

    Linear vector move¶

    Moves the axes in the mask in a straight line to their targets at one vector speed, starting and arriving together. The function writes VecMemberAxes, VecType=0, the vector speed values and each target, puts every member in MotionMode=16, then sends Begin from the starting axis. SetVectorParam writes only the speed values.

    Standalone demo: Two-axis linear vector move

    When to use it

    A single multi-axis straight move, simpler than CNC, with no buffer.

    Signatures

    Arc vector move¶

    Moves along an arc to the end point in the plane of axis1 (X) and axis2 (Y). The centre is an absolute coordinate (VecArcCenter). circles adds full turns (VecNumCircles); 0 runs just the arc.

    Standalone demo: Vector arc

    When to use it

    A single arc or full circle (one turn around a centre for inspection, say).

    Signatures

    // AAMotionAPI
// Perform arc vector motion. Note: The vector motion must be initiated from the axis object with the lowest index among the participating axes. For example, for (B, C) use axis B; for (D, E, F) use axis D. Go and start vector motion.
// controller: The controller object / handle
// axis: The starting axis (the lowest member)
// axis1: The first axis of the plane (X)
// axis2: The second axis of the plane (Y)
// center1: The centre on the first axis, absolute
// center2: The centre on the second axis, absolute
// pos1: The first axis end
// pos2: The second axis end
// dir: The direction, written to `VecArcDir`: **0 counter-clockwise, 1 clockwise**
// circles: Extra full turns; 0 runs just the arc
// speed: The vector speed
// accel: The vector acceleration
// decel: The vector deceleration
// emrgdec: The vector emergency deceleration
// smooth: The smoothing
// Returns: Returns true if the operation is successful, otherwise false.
static bool VectorArc(MotionController controller, AxisRef axis, AxisRef axis1, AxisRef axis2, double center1, double center2, double pos1, double pos2, int dir, int circles, double speed, double accel, double decel, double emrgdec, int smooth);

    • When the start and end coincide, both 0 and 1 run one full circle.

    Pause, continue and stop¶

    VectorPause decelerates along the path and pauses (VecPause=1), VectorContinue resumes (VecPause=0), StopVec stops the vector move.

    Standalone demo: Pause and continue a vector move

    When to use it

    Pause / Resume / Stop buttons for vector motion.

    Signatures

    // AAMotionAPI
// Pause vector motion
// controller: The controller object / handle
