    Error handling¶

    When the controller refuses a command it replies ERR n; when the SDK finds a problem before sending (an out-of-range value, not connected, a timeout) it reports PC Suite: ERR n. Either way:

    1. the error hook runs (the C# ErrorOccurred event / the C callback) with the code, the command that was sent and the formatted description;
    2. the call fails: C# throws ControllerCommandException (a bool-returning method returns false), a C function returns false (an int-returning one returns 0).

    Every code is described in Appendix: Error codes.

    Error hooks and try/catch¶

    These are complementary mechanisms, not two kinds of hooks. ErrorOccurred centralizes code, command and message reporting, including background errors. try/catch handles exceptions from the current C# call and decides how to end or clean up the operation. Check false from bool-returning calls and the documented convention for error strings. An outer catch cannot catch exceptions on another thread. Register a hook, check results and catch exceptions where calls can throw. The C ABI does not propagate .NET exceptions into C/C++; use results and callbacks.

    Error hook¶

    Registers / removes a function that runs whenever the controller (or the SDK) reports an error. Register it before connecting so connect errors are reported too. It is the easiest place to log every error of a program.

    There are two hooks for the same errors:

    • ErrorOccurred (C: aamotion_set_error_occurred_handler): the code, the command sent and the formatted description.
    • ErrorReported (C: aamotion_set_error_reported_handler): raised right after ErrorOccurred, on the same thread and with the same code, it adds where the error came from (Enums: Error source: the application's own call, a check before sending, a fast read cache background read) and the axis and keyword the failed command names. The C# ControllerErrorEventArgs also carries the command and text, the AAMotion member the application called (Method, such as SingleAxis.MoveAbs or SingleAxis.Speed (set)), Timestamp, ThreadId and Controller. The C callback receives only the code, source, axis and keyword; the text still comes through aamotion_error_occurred_cb. Method, Timestamp, ThreadId and Controller are C# only.

    Standalone demo: Error hook

    When to use it

    Every program should hook ErrorOccurred: log every error in one place and show the latest in the UI. Attach it before connecting. Add ErrorReported when errors must be sorted by call, axis or source.

// Event triggered when an error occurs. Event parameters include error code, sent command, and error message.
event Action<int, string, string> ErrorOccurred;

// Raised for every error `MotionController.ErrorOccurred` is raised for, right after it, on the same thread and with the same code, command and text, plus which AAMotion member the application called, the axis and parameter the command names, where the error came from, and when and on which thread it was raised (`ControllerErrorEventArgs`). The sender is this controller.
event EventHandler<ControllerErrorEventArgs> ErrorReported;

    // Installs the error callback for this session, replacing any previous one. Install it right after aamotion_initialize: a controller ERR otherwise shows up only as a false return.
// controller: The controller object / handle
// callback: The C callback. `aamotion_error_occurred_cb` is `void (*)(int errorCode, const char* message, const char* exception, void* user)`: `message` is the command sent, `exception` the description (English). `aamotion_error_reported_cb` is `void (*)(int errorCode, int source, int axis, int keyword, void* user)`.

// controller: The controller object / handle

// controller: The controller object / handle

// user: The user pointer, passed back unchanged on every callback; NULL when unused. Keep what it points to valid until any callback still running has returned.

// Removes the error-report callback.

void aamotion_clear_error_reported_handler(aamotion_controller controller);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    handler Action<int, string, string> / EventHandler<ControllerErrorEventArgs> The C# handler. ErrorOccurred: (errorCode, messageSent, errorMessage), the code, the command sent and the formatted description (several lines separated by \n). ErrorReported: an EventHandler<ControllerErrorEventArgs> whose sender is this controller. Removing needs the same delegate instance.
    callback aamotion_error_occurred_cb / aamotion_error_reported_cb The C callback. aamotion_error_occurred_cb is void (*)(int errorCode, const char* message, const char* exception, void* user): message is the command sent, exception the description (English). aamotion_error_reported_cb is void (*)(int errorCode, int source, int axis, int keyword, void* user).
    user void* The user pointer, passed back unchanged on every callback; NULL when unused. Keep what it points to valid until any callback still running has returned.

    Notes

    • The callback runs on the thread that raised the error. A controller ERR answering your command runs it on your thread, synchronously, inside that call; the fast read cache's background reads raise it on background threads. Do not assume the UI thread; UI code can compare ThreadId with its own to decide whether to Invoke. Record the information and return promptly.
    • An exception a handler throws reaches the caller, for ErrorOccurred and ErrorReported alike. A program that does not subscribe to ErrorReported pays nothing for it.
    • The C# description language follows LocaleProvider.Instance.Locale ("zh-CN" or "en-US"); the C interface always reports English.
    • The strings a C callback receives are valid only during the callback; copy them to keep them.
    • Each handle has one C callback of each kind; registering again replaces it. Neither aamotion_clear_* nor aamotion_release waits for a callback already running on another thread, so free what a callback uses only once it has returned.

    Example

    LocaleProvider.Instance.Locale = "zh-CN";   // descriptions in Chinese; "en-US" for English

Action<int, string, string> onError = (code, sent, text) =>
    Console.WriteLine($"[ERR {code}] {sent} | {text.Replace("\n", " | ")}");

AAMotionAPI.SetErrorOccurredHandler(c, onError);   // same as c.ErrorOccurred += onError
// ...
AAMotionAPI.ClearErrorOccurredHandler(c, onError); // the same delegate instance
// the same errors as ErrorOccurred, with the AAMotion member that was called
EventHandler<ControllerErrorEventArgs> onReport = (sender, e) =>
    Console.WriteLine($"[{e.Source}] {e.Method ?? "-"} {e.Axis} {e.Keyword}: ERR {e.ErrorCode} {e.Command}");

AAMotionAPI.SetErrorReportedHandler(c, onReport);   // same as c.ErrorReported += onReport
// ...
AAMotionAPI.ClearErrorReportedHandler(c, onReport);

    static char g_last_error[512];

/* called on the SDK's thread; the strings are valid only during the call */
static void on_error(int code, const char* message, const char* exception,
                     void* user)
{
    (void)user;   /* the pointer passed to aamotion_set_error_occurred_handler */
    snprintf(g_last_error, sizeof g_last_error, "ERR %d | %s | %s",
             code, message ? message : "", exception ? exception : "");
    fprintf(stderr, "%s\n", g_last_error);
}

void example_hook(aamotion_controller h)
{
    aamotion_set_error_occurred_handler(h, on_error, NULL);
    /* ... */
    aamotion_clear_error_occurred_handler(h);
}
/* where each error came from; the text arrives through the error-occurred callback */
static void on_error_reported(int code, int source, int axis, int keyword,
                              void* user)
{
    (void)user;
    if (source == AAMOTION_CONTROLLER_ERROR_SOURCE_FAST_READ_REFRESH)
        printf("ERR %d in a cache refresh (axis %d, keyword %d)\n",
               code, axis, keyword);
}

void example_error_reported(aamotion_controller h)
{
    aamotion_set_error_reported_handler(h, on_error_reported, NULL);
    /* ... */
    aamotion_clear_error_reported_handler(h);
}

    Failed calls¶

    In C#, property reads and writes (such as a.MotorOn = 1) and value-returning methods throw ControllerCommandException when the controller refuses. Its ErrorCode is the controller's ERR number, or ControllerCommandException.NoControllerCode (-1) when the failure did not come from the controller (timeout, link lost, …); Command is the command sent and Keyword its keyword. To avoid exceptions on reads, use TryGetValue, which returns false and leaves the reason in LastReadError. In C every function reports success in its return value; the error hook gives the reason.

    Standalone demo: Catch a refused command

    Standalone demo: Safe read

    When to use it

    In C#, catch ControllerCommandException when you need to know why a step failed; use TryGetValue / TryRead when success / failure is enough.

    Notes

    • A reply timeout after a motion or write command can leave the execution result unknown. Read back the motion state, target, or written value before recovering. Retrying a relative move or a CNC segment push can repeat the move or queue the segment twice.
    • C reads that return int (aamotion_read_gen_data, aamotion_get_d_in_port, …) return 0 on failure, which cannot be told from a real 0. When 0 matters, read with aamotion_send_command_string and check its result.

    Example

    ISingleAxis a = c.GetAxis(AxisRef.A);
try
{
    a.MotorOn = 1;
}
catch (ControllerCommandException ex)
{
    // ErrorCode: the controller's ERR number, or ControllerCommandException.NoControllerCode (-1)
    // when the failure did not come from the controller (timeout, link lost, ...)
    Console.WriteLine($"{ex.Command} refused: ERR {ex.ErrorCode} ({ex.Keyword}) {ex.Message}");
}

    char reply[256];
if (!aamotion_send_command_string(h, "AMotorOn=1", reply, sizeof reply))
{
    /* the hook has already been called with the code and the text */
    fprintf(stderr, "motor on refused: %s\n", g_last_error);
}

    Error code to text¶

    Turns an error code into its description, the same text the error hook receives. In C# use LocaleProvider.Instance.GetError(code), in the language of Locale; the C interface returns English.

    Standalone demo: Error code to text

    When to use it

    When a log holds only the code and the user needs the text.

    Signatures

    // Writes the description of a controller error code (the n of "ERR n") into description (UTF-8, truncated on a character boundary, NUL-terminated). Needs no session. @return false for a NULL buffer, a non-positive size or an unknown code.
// errorCode: The error code (a controller ERR number or an SDK PC Suite code)
// description: The buffer for the text; NUL-terminated, cut on a character boundary when too long
// descriptionSize: The buffer size in bytes
bool aamotion_get_error_description_by_code(int errorCode, char* description, int descriptionSize);

    Parameters

    Parameter Type Description
    errorCode int The error code (a controller ERR number or an SDK PC Suite code)
    description char* The buffer for the text; NUL-terminated, cut on a character boundary when too long
    descriptionSize int The buffer size in bytes

    Returns

    true on success.

    Example

    LocaleProvider.Instance.Locale = "zh-CN";
string text = LocaleProvider.Instance.GetError(31);   // the same text the error hook receives
Console.WriteLine("ERR 31: " + text);

    char text[512];
if (aamotion_get_error_description_by_code(31, text, sizeof text))
    printf("ERR 31: %s\n", text);   /* English */
    SDK comments (original)
    • aamotion_get_error_description_by_code — Writes the description of a controller error code (the n of "ERR n") into description (UTF-8, truncated on a character boundary, NUL-terminated). Needs no session. @return false for a NULL buffer, a non-positive size or an unknown code.

    Status value to text¶

    Turns the value of a status keyword (MotionStat, MotionReason, ConFlt, …) into English text. For bit masks (MotionStat, StatReg) the descriptions of every set bit are joined with commas. The C# equivalents are EnumPropertyHelper.GetMotionStatDes(int) and so on. Every value's meaning, in Chinese and English, is in Enums.

    Standalone demo: Status value to text

    When to use it

    Showing MotionStat, MotionReason, ConFlt and similar readings to the user or in a log.
