Properties

Mask

Trigger mask (RecTrigMask) (掩码). Bitwise mask for filtering which bits of the trigger source are used. Use -1 (all bits set) to use all bits, or specify a bit mask for bitwise parameters. For example, with MotionStat, use -1 to check all status bits, or use specific bit masks to check only certain status flags.

public long Mask { get; set; }

Property Value

long

MaxValue

Maximum trigger value (RecTrigValMax) (最大触发值). Optional parameter, used for range-based trigger types. Some trigger types use this to define an upper bound for the trigger condition. For example, for range triggers: trigger when Value <= Source <= MaxValue. Set to 0 if not needed (for most trigger types like rising edge, this is not used).

public double MaxValue { get; set; }

Property Value

double

Source

Trigger source parameter (触发源) (full message, e.g., "APos", "AVel[3]", "AMotionStat"). The parameter to monitor for the trigger condition. For bitwise parameters like MotionStat, the mask should be used to select specific bits.

public string Source { get; set; }

Property Value

string

Type

Trigger type (RecTrigTyp) (触发类型). Common trigger types: 1 = Motor Enabled (电机使能) 2 = Start Motion (开始运动) 3 = End Motion (结束运动) 4 = Axis Fault (轴故障) 5 = Greater or Equal / Rising Edge (大于等于 / 上升沿) Refer to controller documentation for complete list.

public int Type { get; set; }

Property Value

int

Value

Trigger value (RecTrigVal) (触发值). The threshold value to compare against the trigger source. For bitwise parameters, this is combined with the mask for comparison.

public double Value { get; set; }
