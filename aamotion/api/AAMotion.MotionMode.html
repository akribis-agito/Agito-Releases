Jog = 0

Jog: The motor moves continuously at the speed set by Speed until a Stop command is received. Acceleration and deceleration are controlled by Accel and Decel, and can be smoothed by Jerk.

PTP = 1

PTP: Point-to-point motion, moves to the position specified by RelTrgt or AbsTrgt (if RelTrgt=0, then AbsTrgt). Parameters are controlled by Accel, Speed, Decel, and Jerk.

PTPRepeat = 2

PTP Repeat: Reciprocating motion between current and target position, waits RptWait time at each end, use StopRep to stop.

PulseDirDirect = 3

Pulse/Direction Direct Mode: Position loop reference is directly from pulse/direction input.

PulseDirIndirect = 4

Pulse/Direction Indirect Mode: Pulses are accumulated to the target, the analyzer generates a smooth trajectory according to Accel, Decel, Speed, and Jerk.
