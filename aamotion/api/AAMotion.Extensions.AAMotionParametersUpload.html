Asynchronously uploads (saves) controller parameters to a .par file.


"Upload" in this context follows the PCSuite convention: controller disk contents are read and persisted to a local file.


Mirrors the PCSuite "Parameters Upload" tool: queries every supported parameter, writes them with header (product type,
firmware/FPGA version, date, checksum) to a plain ASCII .par file.


Ethernet connections use Bulk messages (up to 50 per packet); other channels send one by one.
