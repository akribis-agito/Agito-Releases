    捕获被拒绝的命令¶

    C# 中读写属性和返回数值的方法在控制器拒绝时抛 ControllerCommandException：ErrorCode 是控制器的 ERR 编号，非控制器原因（超时、断线）为 -1。本例在未换相时请求使能，让控制器拒绝；已经换相时不发送，避免真的使能。

    1. 连接
    2. 本次操作：CommandException
    3. 断开

    C# samples/single/csharp/02-Errors/CommandException · C++ samples/single/cpp/02-Errors/CommandException · Python samples/single/python/02_command_exception.py

    运行前提¶

    需要尚未换相的轴：仿真器每次连接都是新的，满足这个条件。运行时需输入 RUN 确认。

    核心代码¶

    // 2. 本次操作
ISingleAxis a = c.GetAxis(AxisRef.A);
if (AAMotionAPI.IsAutoPhase(c, AxisRef.A))
{
    Console.WriteLine("axis A already commutated; nothing sent");
    return 1;
}
try
{
    a.MotorOn = 1;   // 未换相时控制器拒绝
    Console.WriteLine("motor-on accepted; switching it off");
    a.MotorOn = 0;
}

{

    // 超时、断线等非控制器原因为 -1
    Console.WriteLine($"{ex.Command} refused: ERR {ex.ErrorCode}");
}

    aamotion_motor_off(h, A);

    C++ / Python

    C 接口没有异常：被拒绝的命令返回 false，ERR 编号与说明由错误回调给出。

    如何确认结果¶

    输出 MotorOn=1 refused: ERR ...。轴已换相时输出提示并以退出码 1 结束。

    退出码：0 成功；1 未确认或不适用；2 连接失败；3 换相超时；4 使能被拒绝；5 命令失败或异常；6 等待或结果检查失败。

    运行¶

    1. 用 Visual Studio 2019 或更新版本打开 samples/single/csharp/AAMotionDemos.sln，也可以只打开本工程的 CommandException.csproj。
    2. 打开 Program.cs，确认顶部的 Target：默认是控制器出厂 IP 172.1.1.101；用仿真器时可将 firmware_sim.exe 的绝对路径作为第一个调试参数。
    3. 在解决方案资源管理器中右键 CommandException →“设为启动项目”，按 F5 运行。
    4. 核对提示后输入 RUN 并回车。
    5. 需要 .NET Framework 4.8 开发工具；首次生成会自动还原 NuGet 包 Agito.AAMotion 13.0.0。
    1. 解压原生 SDK agito-aamotion-native-sdk-13.0.0.zip。
    2. 用 Visual Studio 2022「打开本地文件夹」打开 samples/single/cpp，在 CMakePresets.json 中把 AAMOTION_SDK_DIR 改成 SDK 目录。
    3. 打开 samples/single/cpp/02-Errors/CommandException/main.cpp，确认顶部的 Target。
    4. 在启动项中选择 CommandException.exe，按 F5。生成时会把 aamotion.dll 与 AACommServerNative.exe 复制到程序旁。

    Linux：cmake --preset linux-x64，cmake --build out/build/linux-x64，再运行 out/build/linux-x64/bin/CommandException。

    1. 安装 64 位 Python 3.9 或更新版本。
    2. 在 samples/single/python 中运行一次 python get_sdk.py：从 Agito 发布页下载 SDK、按 SHA256 校验，并把 aamotion.dll 与 AACommServerNative 放到 aamotion.py 旁边。也可以从已解压的 SDK 手动复制。
    3. 确认 02_command_exception.py 顶部的 TARGET，运行 python 02_command_exception.py；也可以在 VS Code 中打开该文件按 F5。

    对应 API：捕获被拒绝的命令

    using System;
using System.IO;
using AAMotion;
// 捕获被拒绝的命令 / Catch a refused command
// 顺序：连接 → 本次操作 → 断开。轴不运动。
internal static class Program
{
    // 控制器 IP（出厂默认 172.1.1.101）；用仿真器时改成 firmware_sim.exe 的完整路径
    private const string Target = "172.1.1.101";

    private static int Main(string[] args)
    {
        string connectionTarget = args.Length == 0 ? Target : args[0];
        Console.WriteLine("Requests motor-on on axis A before commutation.");
        Console.WriteLine("Type RUN to continue:");
        if (Console.ReadLine() != "RUN") return 1;
        MotionController c = AAMotionAPI.Initialize(ControllerType.AGM800);
        c.ErrorOccurred += (code, command, message) =>
            Console.WriteLine($"[ERR] {code}: {command} | {message}");
        try
        {
            // 1. 连接：Target 是 IP 时连接控制器；以 .exe 结尾时连接仿真器
            Console.WriteLine(connectionTarget);
            bool connected;
            bool simulation = connectionTarget.EndsWith(".exe",
                StringComparison.OrdinalIgnoreCase);
            if (!simulation)
                connected = AAMotionAPI.Connect(c, connectionTarget);
            else if (File.Exists(connectionTarget))
            {
                c.Init();   // 仿真器需要先启动 AACommServer
                connected = AAMotionAPI.ConnectSimulation(c, connectionTarget);
            }
            else
            {
                Console.WriteLine("simulator not found; edit Target");
                return 2;
            }
            if (!connected)
            {
                Console.WriteLine("failed; check Target and the cable");
                return 2;
            }

            // 2. 本次操作
            ISingleAxis a = c.GetAxis(AxisRef.A);
            if (AAMotionAPI.IsAutoPhase(c, AxisRef.A))
            {
                Console.WriteLine("axis A already commutated; nothing sent");
                return 1;
            }
            try
            {
                a.MotorOn = 1;   // 未换相时控制器拒绝
                Console.WriteLine("motor-on accepted; switching it off");
                a.MotorOn = 0;
            }
            catch (ControllerCommandException ex)
            {
                // ErrorCode：控制器的 ERR 编号
                // 超时、断线等非控制器原因为 -1
                Console.WriteLine($"{ex.Command} refused: ERR {ex.ErrorCode}");
            }
            return 0;
        }
        catch (ControllerCommandException ex)
        {
            Console.WriteLine($"{ex.Command} refused: ERR {ex.ErrorCode}");
            return 5;
        }
        catch (Exception ex)
        {
            Console.WriteLine(ex.Message);
            return 5;
        }
        finally
        {
            // 3. 断开：AACommServer 继续为其他程序服务
            AAMotionAPI.Disconnect(c);
            Console.WriteLine("done");
        }
    }
}

    // 捕获被拒绝的命令 / Catch a refused command
// 顺序：连接 → 本次操作 → 断开。轴不运动。
#include "aamotion.h"
#include <chrono>
#include <cmath>
#include <cstdio>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
#include <thread>
// 控制器 IP（出厂默认 172.1.1.101）；用仿真器时改成 firmware_sim.exe 的完整路径
static const std::string Target = "172.1.1.101";
static const char* Step = "2/3 CommandException";
static const int A = AAMOTION_AXIS_REF_A;

static void Log(const char* step, const std::string& text)
{
    std::printf("[%s] %s\n", step, text.c_str());
}

static void OnError(int code, const char* message, const char* exception,
                    void* user)
{
    Log("ERR", std::to_string(code) + ": " + (message ? message : "") + " | " +
        (exception ? exception : ""));
}

static bool IsSimulator(const std::string& target)
{
    return target.size() > 4 && target.compare(target.size() - 4, 4, ".exe") == 0;
}

static int Operate(aamotion_controller h)
{
    // 1. 连接：Target 是 IP 时连接控制器；以 .exe 结尾时连接仿真器
    Log("1/3 Connect", Target);
    bool simulator = IsSimulator(Target);
    bool connected;
    if (!simulator)
        connected = aamotion_connect(h, Target.c_str(), true, false);
    else if (std::filesystem::exists(std::filesystem::u8path(Target)))
    {
        aamotion_init(h);   // 仿真器需要先启动 AACommServer
        connected = aamotion_connect_simulation(h, Target.c_str(),
            nullptr, nullptr, nullptr);
    }
    else
    {
        Log("1/3 Connect", "simulator not found; edit Target");
        return 2;
    }
    if (!connected)
    {
        Log("1/3 Connect", "failed; check Target and the cable");
        return 2;
    }

    // 2. 本次操作
    if (aamotion_is_auto_phase(h, A))
    {
        Log(Step, "axis A already commutated; nothing sent");
        return 1;
    }
    // 未换相时使能：控制器拒绝，返回 false，ERR 编号由错误回调给出
    if (aamotion_motor_on(h, A))
    {
        Log(Step, "motor-on accepted; switching it off");
        aamotion_motor_off(h, A);
    }
    else
        Log(Step, "motor_on returned false; see the ERR line");
    return 0;
}

static int Run()
{
    std::printf("Requests motor-on on axis A before commutation.\n");
    std::printf("Type RUN to continue:\n");
    std::string answer;
    if (!std::getline(std::cin, answer) || answer != "RUN") return 1;
    aamotion_controller h = aamotion_initialize(AAMOTION_CONTROLLER_TYPE_AGM800);
    if (!h)
    {
        Log("1/3 Connect", "initialize failed; AACommServerNative missing?");
        return 2;
    }
    aamotion_set_error_occurred_handler(h, OnError, nullptr);
    int result = Operate(h);
    // 3. 断开：同时释放句柄；AACommServer 继续为其他程序服务
    aamotion_disconnect(h);
    Log("3/3 Disconnect", "done");
    return result;
}

int main()
{
    int result = Run();
    std::printf("Exit code %d.\n", result);
    return result;
}

    """捕获被拒绝的命令 / Catch a refused command
顺序：连接 → 本次操作 → 断开。轴不运动。
"""
import os
import sys
import aamotion as am

# 控制器 IP（出厂默认 172.1.1.101）；用仿真器时改成 firmware_sim.exe 的完整路径
TARGET = "172.1.1.101"
STEP = "2/3 CommandException"
A = am.AXIS_REF_A


def log(step, text):
    print(f"[{step}] {text}")


def on_error(code, message, exception):
    log("ERR", f"{code}: {message} | {exception}")


def operate(h):
    # 1. 连接：TARGET 是 IP 时连接控制器；以 .exe 结尾时连接仿真器
    log("1/3 Connect", TARGET)
    if not TARGET.lower().endswith(".exe"):
        connected = am.connect(h, TARGET, True, False)
    elif os.path.isfile(TARGET):
        am.init(h)   # 仿真器需要先启动 AACommServer
        connected = am.connect_simulation(h, TARGET, None, None, None)
    else:
        log("1/3 Connect", "simulator not found; edit TARGET")
        return 2
    if not connected:
        log("1/3 Connect", "failed; check TARGET and the cable")
        return 2

    # 2. 本次操作
    if am.is_auto_phase(h, A):
        log(STEP, "axis A already commutated; nothing sent")
        return 1
    # 未换相时使能：控制器拒绝，返回 False，ERR 编号由错误回调给出
    if am.motor_on(h, A):
        log(STEP, "motor-on accepted; switching it off")
        am.motor_off(h, A)
    else:
        log(STEP, "motor_on returned False; see the ERR line")
    return 0


def run():
    print("Requests motor-on on axis A before commutation.")
    try:
        answer = input("Type RUN to continue:\n")
    except EOFError:
        answer = ""
    if answer != "RUN":
        return 1
    h = am.initialize(am.CONTROLLER_TYPE_AGM800)
    if not h:
        log("1/3 Connect", "initialize failed; AACommServerNative missing?")
        return 2
    am.set_error_occurred_handler(h, on_error)
    try:
        return operate(h)
    except Exception as ex:
        log("Failed", str(ex))
        return 5
    finally:
        # 3. 断开：同时释放句柄；AACommServer 继续为其他程序服务
        am.disconnect(h)
        log("3/3 Disconnect", "done")


def main():
    # 输出被重定向时，编码不了的字符（如中文路径）转义输出，不报错；
    # IDLE、Jupyter 的输出没有 reconfigure
    if hasattr(sys.stdout, "reconfigure"):
        sys.stdout.reconfigure(errors="backslashreplace")
    result = run()
    print(f"Exit code {result}.")
    return result


if __name__ == "__main__":
    sys.exit(main())
