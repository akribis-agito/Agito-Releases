Remarks

The controller reads these parameters as one whole motion, both on SinePtpBegin(MotionController, AxisRef, SinePtpMotionConfig) and on SinePtpCommit(MotionController, AxisRef, SinePtpMotionConfig), so every field is written on every call. A pre-cruise phase exists only while PreCruiseSpd is non-zero, and the pre-cruise target must point in the same direction as the motion target and fall short of it - otherwise the controller refuses the motion with error 381 or 383.
