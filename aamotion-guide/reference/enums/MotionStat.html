    运动状态位 MotionStat¶

    关键字 MotionStat 的各个位，可以同时置位多个。值为 0 表示没有运动。判断某一位用按位与，例如 (stat & MotionStat.InMotion) != 0。

    这是位掩码枚举：一个值可以同时包含多个位。
    C# 类型 AAMotion.MotionStat
    C 类型 aamotion_motion_stat_t
    对应关键字 MotionStat
    转成文字 EnumPropertyHelper.GetMotionStatDes(int) · aamotion_get_motion_stat_des()

    读取并解释¶

    int v = (int)c.GetValue(AxisRef.A, eKeyword.MotionStat);
MotionStat e = (MotionStat)v;
bool on = (e & MotionStat.InMotion) != 0;
string text = EnumPropertyHelper.GetMotionStatDes(v);

    double v;
if (aamotion_get_value(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_MOTION_STAT, 0, &v)) {
    char text[256];
    aamotion_get_motion_stat_des((int)v, text, sizeof text);
    printf("%d: %s\n", (int)v, text);
}

    v = int(am.get_value(h, am.AXIS_A, am.KEYWORD_MOTION_STAT))
print(v, am.describe("motion_stat", v))
    值 十六进制 C# 名称 C 常量 说明 运行时文本
    0 0x00000000 None AAMOTION_MOTION_STAT_NONE 没有运动（整个状态字为 0） Unknown status
    1 0x00000001 InMotion AAMOTION_MOTION_STAT_IN_MOTION 0x00000001 — 轴处于运动中。在 Begin 时置位；运动（及任何平滑结束等待）完成后清除。 In Motion
    2 0x00000002 RepetitiveWait AAMOTION_MOTION_STAT_REPETITIVE_WAIT 0x00000002 — 轴在点到点重复运动的两次重复之间驻留。上次重复结束时置位，经过 RptWait 个周期后清除。仅在 MotionMode = 2 时使用。 Repetitive Wait
    4 0x00000004 RepetitiveStopRequested AAMOTION_MOTION_STAT_REPETITIVE_STOP_REQUESTED 0x00000004 — 轴在收到 StopRep 指令后正在结束重复运动。 Repetitive stop requested
    8 0x00000008 StopRequested AAMOTION_MOTION_STAT_STOP_REQUESTED 0x00000008 — 已请求 Stop（减速停止）；目标速度正在斜坡至零。 Stop requested
    16 0x00000010 Accelerating AAMOTION_MOTION_STAT_ACCELERATING 0x00000010 — 轴正在加速（曲线速度上升）。位 4 与位 5 互斥：在匀速巡航阶段（曲线速度已达到 Speed 且既不上升也不下降），两个位均清除。 Accelerating
    32 0x00000020 Decelerating AAMOTION_MOTION_STAT_DECELERATING 0x00000020 — 轴正在减速（曲线速度下降，或朝向异号目标反向运动）。只要曲线速度被钳制至软件限位减速曲线，该位也强制置位——即即使未发出 Stop 指令，也会报告朝向 FwdPLim/RevPLim 的预先制动。 Decelerating
    64 0x00000040 LastSmoothing AAMOTION_MOTION_STAT_LAST_SMOOTHING 0x00000040 — 轴处于曲线平滑尾段：目标已到达，但急动/平滑滤波器仍在冲刷 2^Jerk 个周期后才宣告运动完成。请参阅 Jerk。 Last smoothing
    128 0x00000080 ECAMStop AAMOTION_MOTION_STAT_ECAMSTOP 0x00000080 — 轴正在结束 ECAM 运动（在 StopECAM 指令之后）。 ECAM stop
    256 0x00000100 FIFOStop AAMOTION_MOTION_STAT_FIFOSTOP 0x00000100 — 轴正在结束 FIFO 运动（在 StopFIFO 指令之后）。 FIFO stop
    512 0x00000200 WaitingForInputToStart AAMOTION_MOTION_STAT_WAITING_FOR_INPUT_TO_START 0x00000200 — 运动已暂停，等待配置的数字量输入上的上升沿。由 BeginDInOn 置位；沿到达时清除。 Waiting for input to start
    1024 0x00000400 CNCAMember AAMOTION_MOTION_STAT_CNCAMEMBER 0x00000400 — 轴是 CNCA 组的成员。 CNCA member
    2048 0x00000800 CNCAMotion AAMOTION_MOTION_STAT_CNCAMOTION 0x00000800 — 轴当前参与活动的 CNCA 运动。 CNCA motion
    4096 0x00001000 CNCAStop AAMOTION_MOTION_STAT_CNCASTOP 0x00001000 — 轴正在结束 CNCA 运动（在 StopCNCA 指令之后）。 CNCA stop
    8192 0x00002000 CNCBMember AAMOTION_MOTION_STAT_CNCBMEMBER 0x00002000 — 轴是 CNCB 组的成员。 CNCB member
    16384 0x00004000 CNCBMotion AAMOTION_MOTION_STAT_CNCBMOTION 0x00004000 — 轴当前参与活动的 CNCB 运动。 CNCB motion
    32768 0x00008000 CNCBStop AAMOTION_MOTION_STAT_CNCBSTOP 0x00008000 — 轴正在结束 CNCB 运动（在 StopCNCB 指令之后）。 CNCB stop
    65536 0x00010000 ControlledStop AAMOTION_MOTION_STAT_CONTROLLED_STOP 0x00010000 — 因故障条件（如异常检测、数字量输入故障）请求了带电机关闭的受控停止。 Controlled stop
    131072 0x00020000 BufferStop AAMOTION_MOTION_STAT_BUFFER_STOP 0x00020000 — 轴正在结束样条缓冲区运动（在 StopBuff 指令之后）。 Buffer stop
    262144 0x00040000 VectorStop AAMOTION_MOTION_STAT_VECTOR_STOP 0x00040000 — 轴正在结束向量运动（在 StopVec 指令之后）。 Vector stop
    524288 0x00080000 VectorMember AAMOTION_MOTION_STAT_VECTOR_MEMBER 0x00080000 — 轴是向量运动组的成员。 Vector member
    1048576 0x00100000 JOGStopPLIM AAMOTION_MOTION_STAT_JOGSTOP_PLIM 0x00100000 — 轴正在结束点动运动，因为正在接近软件位置限位。仅限 v5（见下文）。 JOG stop PLIM

    “运行时文本”是 EnumPropertyHelper.GetMotionStatDes 返回的英文文本。
