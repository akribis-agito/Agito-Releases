Class AACommFwInfo

Namespace
AAComm.Extensions
Assembly
AAComm.dll
Helper class used to read HEX files FW info, and to validate HEX/BIN and VER files prior to FW download <xref href="AAComm.Extensions.AACommDownloadFW" data-throw-if-not-resolved="false"></xref><p></p>

For reading FW info, create an instance of this class <xref href="AAComm.Extensions.AACommFwInfo.%23ctor(System.String%2cAAComm.Services.ConnectionData)" data-throw-if-not-resolved="false"></xref><p></p>

For validating FW files prior to FW download, use the method <xref href="AAComm.Extensions.AACommFwInfo.ValidateFwFiles(AAComm.Services.ConnectionData%2cSystem.String)" data-throw-if-not-resolved="false"></xref><p></p>

Older FW HEX files don't contain FW information. Opening such files will result in all the properties being invalid.


Use <xref href="AAComm.Extensions.AACommFwInfo.DataValid" data-throw-if-not-resolved="false"></xref> to verify that the FW information was read successfully.

ValidateFwFiles(ConnectionData, string) 

Validates FW hex/bin and ver files: (THROWS on errors)


Can be called if <xref href="AAComm.Extensions.AACommFwInfo.DataValid" data-throw-if-not-resolved="false"></xref> is 'false' => will skip internal FW file data checks


0. files existence, extensions, FW and ver names matching


1. only bin files can be flashed to AGM800


FOR AGM800: If .ver file exists, performs validation (MD5, version, type). If not, download proceeds without validation (backward compatible).


FOR NON-AGM800:


2. fw vs. ver file version (if fw file supports this feature)


3. fw product type vs. defined connection product type (if fw file supports)


4. ver MD5 vs fw computed hash (if supported)


5. ver product type vs. defined connection product type (if ver file supports)


public void ValidateFwFiles(ConnectionData cd, string verFile)
