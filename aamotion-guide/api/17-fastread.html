    快速读缓存（FastReadCache）¶

    仅在需要高频读取多个位置、速度或状态时启用 FastReadCache。一般入门连接、单次读取不需要开启。后台批量刷新已登记的关键字；设置 AAMotionConfig.FastReadEnabled = true 后，相应属性可使用缓存。

    Begin 之后由缓存跟踪运动的启动与到位：启动尚未确认时，MotionStat / InTargetStat 不使用旧的缓存值，而是实时读取。应用不需要自己先等读到 2 再接受 4。

    GetValue / TryGetValue / TryRead、IsHomed、IsAutoPhase、IsCNCCompleted 和 *AndWait 的等待使用实时读取。缓存年龄应实测；通信排队、断线、刷新失败可能使数据比配置间隔更旧，不能把设置 5 ms 当作实时保证。

    登记、启用与读取¶

    先登记要缓存的关键字（每个轴分别登记），再启用缓存并设定刷新间隔。之后在 FastReadEnabled = true 时，属性读取直接返回缓存值。RefreshCacheNow 立即刷新一次（已有刷新在进行时什么也不做）。

    独立小 Demo：快速读缓存

    什么时候用

    高频读取多个轴状态时按需使用。C 接口没有读取缓存值的函数，aamotion_get_value 总是实时读取。

    函数原型

    // AAMotionAPI
// Register which keywords should be cached for a given axis. Must be called before EnableFastReadCache().
// controller: 控制器对象
// axis: 轴
// keywords: 要缓存的关键字；命令关键字会被拒绝（`ArgumentException`）
static void RegisterCacheKeywords(MotionController controller, AxisRef axis, params eKeyword[] keywords);

// Enable the fast read cache for high-frequency parameter reads. Must call RegisterCacheKeywords() first to specify which parameters to cache.
// controller: 控制器对象
// refreshIntervalMs: 刷新间隔，毫秒，声明默认值 1。高频状态读取建议 1–5 ms，最大建议 5 ms；超过 5 ms 不建议用于高频状态机。这是使用建议，不是 API 硬限制。
static void EnableFastReadCache(MotionController controller, int refreshIntervalMs = 1);

// Disable the fast read cache.
// controller: 控制器对象
static void DisableFastReadCache(MotionController controller);

// Gets the age of a cached value in milliseconds since the last refresh.
// controller: 控制器对象
// axis: 轴
// keyword: 要查询的关键字
// 返回值: Age in milliseconds, or -1 if not cached
static double GetCacheAgeMs(MotionController controller, AxisRef axis, eKeyword keyword);

// Immediately refresh all cached values from the controller. Does nothing while another refresh is in flight: it neither waits for that refresh nor raises `FastReadCache.RefreshStarted`. An exception thrown by a `FastReadCache.RefreshStarted` or `FastReadCache.RefreshCompleted` subscriber is reported on `FastReadCache.RefreshError` instead of propagating.
// controller: 控制器对象
static void RefreshCacheNow(MotionController controller);

// MotionController
// Registers keywords to be cached for a specific axis. Must be called before EnableFastReadCache().
// axis: 轴
// keywords: 要缓存的关键字；命令关键字会被拒绝（`ArgumentException`）
void RegisterCacheKeywords(AxisRef axis, params eKeyword[] keywords);

// Enables the fast read cache with the specified refresh interval. When enabled, registered parameters are read from cache instead of sending commands to controller.
// refreshIntervalMs: 刷新间隔，毫秒，声明默认值 1。高频状态读取建议 1–5 ms，最大建议 5 ms；超过 5 ms 不建议用于高频状态机。这是使用建议，不是 API 硬限制。
void EnableFastReadCache(int refreshIntervalMs = 1);

// Disables the fast read cache.
void DisableFastReadCache();

// Gets the age of a cached value in milliseconds.
// axis: 轴
// keyword: 要查询的关键字
// 返回值: Age in milliseconds, or -1 if not cached.
double GetCacheAgeMs(AxisRef axis, eKeyword keyword);

// Forces an immediate refresh of all cached values. Does nothing while another refresh is in flight: it neither waits for that refresh nor raises `FastReadCache.RefreshStarted`. An exception thrown by a `FastReadCache.RefreshStarted` or `FastReadCache.RefreshCompleted` subscriber is reported on `FastReadCache.RefreshError` instead of propagating.
void RefreshCacheNow();

    // Starts the background refresh. @param refreshIntervalMs The refresh period in milliseconds; applies at once to an already running cache.
// controller: 控制器对象
// refreshIntervalMs: 刷新间隔，毫秒，声明默认值 1。高频状态读取建议 1–5 ms，最大建议 5 ms；超过 5 ms 不建议用于高频状态机。这是使用建议，不是 API 硬限制。
bool aamotion_enable_fast_read_cache(aamotion_controller controller, int refreshIntervalMs);

// Stops the background refresh; reads go to the controller again.
// controller: 控制器对象
bool aamotion_disable_fast_read_cache(aamotion_controller controller);

// Refreshes every cached value at once. Does nothing while another refresh is in progress.
// controller: 控制器对象
bool aamotion_refresh_cache_now(aamotion_controller controller);

// A background refresh that keeps chosen parameters current, so aamotion_get_value of them returns at once without a controller round trip. Register the keywords first, then enable. Registers parameters to cache on one axis. @param keywords count aamotion_keyword_t values; a COMMAND keyword is refused (the refresh would send it repeatedly) and nothing is registered.
// controller: 控制器对象
// axis: 轴
// keywords: 要缓存的关键字；命令关键字会被拒绝（`ArgumentException`）
// count: `keywords` 的元素个数
bool aamotion_register_cache_keywords(aamotion_controller controller, int axis, const int* keywords, int count);

// Writes the age, in milliseconds since its last refresh, of one cached value into *ageMs; -1 for a value that is not cached.
// controller: 控制器对象
// axis: 轴
// keyword: 要查询的关键字
// ageMs: 输出：缓存值的年龄（毫秒），没有缓存时为 -1
bool aamotion_get_cache_age_ms(aamotion_controller controller, int axis, int keyword, double* ageMs);

    参数

    参数 类型 说明
    controller MotionController / aamotion_controller 控制器对象
    axis AxisRef / int 轴
    keywords const int* / eKeyword[] 要缓存的关键字；命令关键字会被拒绝（ArgumentException）
    refreshIntervalMs int 刷新间隔，毫秒，声明默认值 1。高频状态读取建议 1–5 ms，最大建议 5 ms；超过 5 ms 不建议用于高频状态机。这是使用建议，不是 API 硬限制。
    keyword eKeyword / int 要查询的关键字
    count int keywords 的元素个数
    ageMs double* 输出：缓存值的年龄（毫秒），没有缓存时为 -1

    返回值

    GetCacheAgeMs 返回距上次刷新的毫秒数，没有缓存时返回 -1。

    注意

    • 按需开启：只有高频读取才启用，普通单次读取保持实时。
    • 刷新间隔建议 1–5 ms，最大建议 5 ms；不要靠加大间隔来掩盖高频状态读取问题。
    • 只登记必要的轴和关键字，实测刷新耗时与数据年龄；通信负荷太高时减少读取量。
    • 监测 RefreshError、断线与缓存年龄；关键步骤失败时走错误处理，不能把旧值当作新结果。

    示例

    AAMotionConfig.FastReadEnabled = true;                    // property reads may use the cache
AAMotionAPI.RegisterCacheKeywords(c, AxisRef.A, eKeyword.Pos, eKeyword.MotionStat);
c.FastReadCache.RegisterArrayElements(AxisRef.A, eKeyword.Vel, 1);
AAMotionAPI.EnableFastReadCache(c, 5);                   // refresh every 5 ms in the background

ISingleAxis a = c.GetAxis(AxisRef.A);
var sw = Stopwatch.StartNew();
for (int i = 0; i < 1000; i++)
{
    double pos = a.Pos;                                   // from the cache: no round trip
}
Console.WriteLine($"1000 reads: {sw.ElapsedMilliseconds} ms, value age {AAMotionAPI.GetCacheAgeMs(c, AxisRef.A, eKeyword.Pos)} ms");

c.DisableFastReadCache();
AAMotionConfig.FastReadEnabled = false;

    const int keywords[] = { AAMOTION_KEYWORD_POS, AAMOTION_KEYWORD_MOTION_STAT };
aamotion_register_cache_keywords(h, AAMOTION_AXIS_REF_A, keywords, 2);
aamotion_enable_fast_read_cache(h, 5);          /* refresh every 5 ms in the background */

/* the C interface has no cached-value read: aamotion_get_value always asks the controller */
double age = -1;
aamotion_get_cache_age_ms(h, AAMOTION_AXIS_REF_A, AAMOTION_KEYWORD_POS, &age);   /* -1: not cached */
printf("cached APos is %.0f ms old\n", age);

aamotion_refresh_cache_now(h);                    /* one refresh at once, outside the interval */
aamotion_disable_fast_read_cache(h);

    FastReadCache 对象¶

    c.FastReadCache 提供更细的控制：登记数组元素（RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2)）、取消登记、直接读取缓存值（GetCachedValue 返回 double?，未缓存时为 null），以及刷新开始、完成、出错三个事件。事件在后台线程上触发；RefreshCompleted 适合用来驱动界面刷新。

    独立小 Demo：缓存刷新事件

    什么时候用

    需要缓存数组元素、监听刷新事件、或者直接读缓存值时。

    函数原型

    // FastReadCache
// Registers keywords to cache for a specific axis. A keyword the controller flags as a command is an `System.ArgumentException` and the whole call is refused: the refresh ships every registered keyword at the configured interval, so one accepted command registration would re-send it for as long as the cache runs.
// axis: 轴
// keywords: 关键字列表
void RegisterKeywords(AxisRef axis, params eKeyword[] keywords);

// Registers array elements to cache for a specific axis. For example: RegisterArrayElements(AxisRef.A, eKeyword.AInPort, 1, 2, 3, 4) registers AAInPort[1], AAInPort[2], AAInPort[3], AAInPort[4].
// axis: 轴
// keyword: 关键字
// indices: 数组下标（从 1 开始）
void RegisterArrayElements(AxisRef axis, eKeyword keyword, params int[] indices);

// Unregisters keywords from cache for a specific axis.
// axis: 轴
// keywords: 关键字列表
void UnregisterKeywords(AxisRef axis, params eKeyword[] keywords);

// Checks if a keyword is registered for caching, without taking a lock.
// axis: 轴
// keyword: 关键字
// 返回值: True if registered, false otherwise.
bool IsRegistered(AxisRef axis, eKeyword keyword);

// Checks if an array element is registered for caching, without taking a lock.
// axis: 轴
// keyword: 关键字
// index: 数组下标
// 返回值: True if registered, false otherwise.
bool IsArrayElementRegistered(AxisRef axis, eKeyword keyword, int index);

// Gets a cached value for the specified axis and keyword, without taking a lock. Returns null when the value is not registered, not yet refreshed or invalid, when the cache is disabled, and for `MotionStat` / `InTargetStat` while a motion just begun on the axis has not yet been seen to start.
// axis: 轴
// keyword: 关键字
// 返回值: The cached value, or null if not available.
double? GetCachedValue(AxisRef axis, eKeyword keyword);

// Gets a cached array element value for the specified axis, keyword, and index, without taking a lock. Returns null if the value is not available or the cache is disabled.
// axis: 轴
// keyword: 关键字
// index: 数组下标
// 返回值: The cached value, or null if not available.
double? GetCachedArrayValue(AxisRef axis, eKeyword keyword, int index);

// Gets the age of a cached value in milliseconds.
// axis: 轴
// keyword: 关键字
// 返回值: Age in milliseconds, or -1 if not cached.
double GetCacheAgeMs(AxisRef axis, eKeyword keyword);

// Enables the cache and starts the refresh thread.
void Enable();

// Disables the cache and stops refreshing.
void Disable();

// Forces an immediate refresh of all cached values on the calling thread. Does nothing while another refresh is in flight: it neither waits for that refresh nor raises `FastReadCache.RefreshStarted`. An exception thrown by a `FastReadCache.RefreshStarted` or `FastReadCache.RefreshCompleted` subscriber is reported on `FastReadCache.RefreshError` instead of propagating.
void RefreshNow();

// Marks every cached value invalid; registrations are kept, and reads miss until the next refresh.
void ClearCache();

// Disposes the cache and stops its threads.
void Dispose();

// Event raised when cache refresh starts.
event Action RefreshStarted;

// Event raised when cache refresh completes. On an enabled cache it is raised on a pool thread, so a slow subscriber never delays the next refresh, which may already have started when the subscriber runs; `FastReadCache.RefreshNow` raises it on the calling thread. An exception thrown by a subscriber is reported on `FastReadCache.RefreshError`.
event Action RefreshCompleted;

// Event raised on a refresh or `InTargetStat` poll error. Raised on a background thread.
event Action<Exception> RefreshError;

    参数

    参数 类型 说明
    axis AxisRef 轴
    keywords eKeyword[] 关键字列表
    keyword eKeyword 关键字
    indices int[] 数组下标（从 1 开始）
    index int 数组下标

    返回值

    GetCachedValue / GetCachedArrayValue 返回缓存值，没有时返回 null。

    示例

    FastReadCache cache = c.FastReadCache;
cache.RefreshCompleted += () =>
{
    double? pos = cache.GetCachedValue(AxisRef.A, eKeyword.Pos);
    if (pos.HasValue) Console.WriteLine("APos = " + pos.Value);
};
cache.RefreshError += ex => Console.WriteLine("refresh failed: " + ex.Message);
