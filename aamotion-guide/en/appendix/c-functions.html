    aamotion_initialize¶

    aamotion_controller aamotion_initialize(aamotion_controller_type_t controllerType);

    Creates a session for one controller of the given type and makes sure the shared AACommServer is running.     aamotion_get_value¶

    bool aamotion_get_value(aamotion_controller controller, int axis, int keyword, int index, double* value);

    Any controller parameter can be read and written by keyword with aamotion_get_value / aamotion_set_value; the dedicated calls below cover the GenData/UserParam arrays and whole-file transfers.
