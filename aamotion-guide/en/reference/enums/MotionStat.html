    Motion status bits MotionStat¶

    The bits of keyword MotionStat; several can be set at once. 0 means no motion. Test a bit with a bitwise AND, such as (stat & MotionStat.InMotion) != 0.

    A bit-mask enum: one value can hold several bits.
    C# type AAMotion.MotionStat
    C type aamotion_motion_stat_t
    Keyword MotionStat
    To text EnumPropertyHelper.GetMotionStatDes(int) · aamotion_get_motion_stat_des()

    Read and decode¶

    int v = (int)c.GetValue(AxisRef.A, eKeyword.MotionStat);

bool on = (e & MotionStat.InMotion) != 0;
string text = EnumPropertyHelper.GetMotionStatDes(v);

    Value Hex C# name C constant Meaning Run-time text
    0 0x00000000 None AAMOTION_MOTION_STAT_NONE No motion (the whole word is 0) Unknown status
    1 0x00000001 InMotion AAMOTION_MOTION_STAT_IN_MOTION 0x00000001 — Axis is in motion. Set at Begin; cleared when the motion (and any end-of-smoothing wait) completes. In Motion
    2 0x00000002 RepetitiveWait AAMOTION_MOTION_STAT_REPETITIVE_WAIT 0x00000002 — Axis is dwelling between repetitions of point-to-point repetitive motion. Set when the previous repetition ends, cleared after RptWait cycles. Only used when MotionMode = 2. Repetitive Wait
    4 0x00000004 RepetitiveStopRequested AAMOTION_MOTION_STAT_REPETITIVE_STOP_REQUESTED 0x00000004 — Axis is ending its repetitive motion following a StopRep command. Repetitive stop requested
    8 0x00000008 StopRequested AAMOTION_MOTION_STAT_STOP_REQUESTED 0x00000008 — A Stop (decelerate-to-stop) has been requested; the target speed is ramped to zero. Stop requested
    16 0x00000010 Accelerating AAMOTION_MOTION_STAT_ACCELERATING 0x00000010 — Axis is accelerating (profile speed rising). Bits 4 and 5 are mutually exclusive: during constant-velocity cruise (the profile speed has reached Speed and is neither rising nor falling) both bits are cleared. Accelerating
    32 0x00000020 Decelerating AAMOTION_MOTION_STAT_DECELERATING 0x00000020 — Axis is decelerating (profile speed falling, or reversing toward an opposite-sign target). This bit is also forced on whenever the profile speed is clamped to the deceleration-to-software-limit profile — i.e. it reports the pre-emptive braking toward FwdPLim/RevPLim even when no Stop has been commanded. Decelerating
    64 0x00000040 LastSmoothing AAMOTION_MOTION_STAT_LAST_SMOOTHING 0x00000040 — Axis is in the profile-smoothing tail: the target has been reached but the jerk/smoothing filter is still flushing for 2^Jerk cycles before the motion is declared finished. See Jerk. Last smoothing
    128 0x00000080 ECAMStop AAMOTION_MOTION_STAT_ECAMSTOP 0x00000080 — Axis is ending its ECAM motion (following a StopECAM command). ECAM stop
    256 0x00000100 FIFOStop AAMOTION_MOTION_STAT_FIFOSTOP 0x00000100 — Axis is ending its FIFO motion (following a StopFIFO command). FIFO stop
    512 0x00000200 WaitingForInputToStart AAMOTION_MOTION_STAT_WAITING_FOR_INPUT_TO_START 0x00000200 — Motion is suspended until a rising edge on the configured digital input. Set by BeginDInOn; cleared when the edge arrives. Waiting for input to start
    1024 0x00000400 CNCAMember AAMOTION_MOTION_STAT_CNCAMEMBER 0x00000400 — Axis is a member of the CNCA group. CNCA member
    2048 0x00000800 CNCAMotion AAMOTION_MOTION_STAT_CNCAMOTION 0x00000800 — Axis is currently involved in an active CNCA motion. CNCA motion
    4096 0x00001000 CNCAStop AAMOTION_MOTION_STAT_CNCASTOP 0x00001000 — Axis is ending its CNCA motion (following a StopCNCA command). CNCA stop
    8192 0x00002000 CNCBMember AAMOTION_MOTION_STAT_CNCBMEMBER 0x00002000 — Axis is a member of the CNCB group. CNCB member
    16384 0x00004000 CNCBMotion AAMOTION_MOTION_STAT_CNCBMOTION 0x00004000 — Axis is currently involved in an active CNCB motion. CNCB motion
    32768 0x00008000 CNCBStop AAMOTION_MOTION_STAT_CNCBSTOP 0x00008000 — Axis is ending its CNCB motion (following a StopCNCB command). CNCB stop
    65536 0x00010000 ControlledStop AAMOTION_MOTION_STAT_CONTROLLED_STOP 0x00010000 — A controlled stop with motor-off has been requested due to a fault condition (e.g. anomaly detection, fault from a digital input). Controlled stop
    131072 0x00020000 BufferStop AAMOTION_MOTION_STAT_BUFFER_STOP 0x00020000 — Axis is ending its spline-buffer motion (following a StopBuff command). Buffer stop
    262144 0x00040000 VectorStop AAMOTION_MOTION_STAT_VECTOR_STOP 0x00040000 — Axis is ending its vector motion (following a StopVec command). Vector stop
    524288 0x00080000 VectorMember AAMOTION_MOTION_STAT_VECTOR_MEMBER 0x00080000 — Axis is a member of a vector-motion group. Vector member
    1048576 0x00100000 JOGStopPLIM AAMOTION_MOTION_STAT_JOGSTOP_PLIM 0x00100000 — Axis is ending its jog motion because it is approaching a software position limit. v5 only (see below). JOG stop PLIM

    "Run-time text" is what EnumPropertyHelper.GetMotionStatDes returns.
