Class ControllerVersionWord

Namespace
AAComm.Services
Assembly
AAComm.dll
A controller firmware or FPGA version word: <code>Major.Minor.Patch</code> plus an owner and a sub-version.
Owner 0 with sub-version 0 is a final release; owner 0 with a sub-version N is release candidate N of the
release; a non-zero owner is a development build.


Order: by <code>Major.Minor.Patch</code>, then within one release the candidates (by sub-version) before the
final, then the development builds (by owner, then sub-version).
