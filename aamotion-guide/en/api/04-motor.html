    Motor, commutation and stop¶

    Confirm commutation before motor-on, then home and move; stop and disable when finished. Use commutation → motor-on in the simulator too. Skip repeated commutation only after confirming completion.

    C# uses AxisRef; C uses AAMOTION_AXIS_REF_*.

    In this chapter
    • Motor on and off
    • Auto-phasing (commutation)
    • Stop, abort and stop repetition

    Run this chapter's demo

    Motor on and off¶

    Powers the axis (AMotorOn=1) or removes power (AMotorOn=0). In C# you can also write the property a.MotorOn = 1 and read it for the current state. Motor-on can be refused, for instance with an uncleared fault, an active emergency input or an amplifier that is not ready; the reason reaches the error hook, and MotorReason tells why the motor went off.

    Standalone demo: Motor on and off

    Standalone demo: Enable and fault state

    When to use it

    Before motion, to make sure the motor is on; after an emergency-stop reset.

    Signatures

    // AAMotionAPI
// controller: The controller object / handle
// axis: One axis
static void MotorOn(MotionController controller, AxisRef axis);

// Disable the specified axis motor
// controller: The controller object / handle
// axis: One axis
static void MotorOff(MotionController controller, AxisRef axis);

    // Enables the axis (MotorOn = 1). Uses its own timeout, not the default one.
// controller: The controller object / handle
// axis: One axis
bool aamotion_motor_on(aamotion_controller controller, int axis);

// Disables the axis (MotorOn = 0).
// controller: The controller object / handle
// axis: One axis
bool aamotion_motor_off(aamotion_controller controller, int axis);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    axis AxisRef / int One axis

    Commands sent

    {Axis}MotorOn=0

    Returns

    The C# version returns nothing and throws ControllerCommandException when refused; the C version returns true on success.

    Notes

    • Motor-on uses its own timeout, independent of SetDefaultTimeout.
    • Before the first motor-on, make sure the motor is tuned in PCSuite; once enabled the motor holds its position.
    • Related keywords: MotorOn, MotorReason, ConFlt.

    Example

    if (!AAMotionAPI.IsAutoPhase(c, AxisRef.A))
{
    Console.WriteLine("commutate successfully before motor-on");
    return;
}
AAMotionAPI.MotorOn(c, AxisRef.A);          // same as c.GetAxis(AxisRef.A).MotorOn = 1
bool on = c.GetAxis(AxisRef.A).MotorOn == 1;
// ...
AAMotionAPI.MotorOff(c, AxisRef.A);

    if (!aamotion_is_auto_phase(h, AAMOTION_AXIS_REF_A))
{
    fprintf(stderr, "commutate successfully before motor-on\n");
    return;
}
if (!aamotion_motor_on(h, AAMOTION_AXIS_REF_A))
    fprintf(stderr, "motor on refused (see the error hook)\n");
/* ... */
aamotion_motor_off(h, AAMOTION_AXIS_REF_A);
    SDK comments (original)
    • MotorOff(MotionController, AxisRef) — Disable the specified axis motor {Axis}MotorOn=0
    • aamotion_motor_on — Enables the axis (MotorOn = 1). Uses its own timeout, not the default one.
    • aamotion_motor_off — Disables the axis (MotorOn = 0).

    Auto-phasing (commutation)¶

    Complete commutation (auto-phasing) before motor-on and motion. Check and complete commutation in the simulator as well. AutoPhase writes ComtMode[5]=1282 to start it (skipped when ComtStatus[1] is already 100) and returns at once; the method is whatever the controller's ComtMode is set to, usually configured in PCSuite first. IsAutoPhase reads ComtStatus[1] live and returns true when it is 100, 200, 300, 400 or 500.

    A motion command before commutation completes is refused with ERR 31.

    Standalone demo: Auto-phasing

    When to use it

    After power-up and before motor-on, check commutation, start it if necessary and confirm completion within a timeout.

    Signatures

    // AAMotionAPI
// Perform commutation operation Determine whether the Commutate has been completed
// controller: The controller object / handle
// axisRef: One axis
// waitTime: Optional: milliseconds to sleep after starting. It only waits and does not check completion; poll `IsAutoPhase` for that
static void AutoPhase(MotionController controller, AxisRef axisRef, int? waitTime = null);

// Check if commutation is completed
// controller: The controller object / handle
// axisRef: One axis
// Returns: Returns true if commutated, otherwise false
static bool IsAutoPhase(MotionController controller, AxisRef axisRef);

// Start commutation on the axis: the same command as `AAMotionAPI.AutoPhase`. Unless `{Axis}ComtStatus[1]` already reads 100, 200, 300, 400 or 500 (commutated) or 1 (commutation running), writes `{Axis}ComtMode[5] = 1282`, which starts the commutation configured on the axis; it does not mark the axis commutated by itself. Poll `AAMotionAPI.IsCommutated` for the result.
// controller: The controller object / handle
// axisRef: One axis
// waitTime: Optional: milliseconds to sleep after starting. It only waits and does not check completion; poll `IsAutoPhase` for that
static void Commutated(MotionController controller, AxisRef axisRef, int? waitTime = null);

// Check whether commutation is completed: `{Axis}ComtStatus[1]` reads 100, 200, 300, 400 or 500.
// controller: The controller object / handle
// axisRef: One axis
// Returns: Returns true if the axis is commutated, otherwise false
static bool IsCommutated(MotionController controller, AxisRef axisRef);

// ISingleAxis
// Perform Auto-Phase operation.
// waitTime: Optional: milliseconds to sleep after starting. It only waits and does not check completion; poll `IsAutoPhase` for that
void AutoPhase(int? waitTime = null);

// Check if Auto-Phase is completed.
// Returns: Returns true if Auto-Phase is completed, otherwise false.
bool IsAutoPhase();

// Start commutation: the same command as `ISingleAxis.AutoPhase`. Unless `ComtStatus[1]` already reads commutated (as `ISingleAxis.IsCommutated` judges it) or 1 (commutation running), writes `ComtMode[5] = 1282`, which starts the commutation configured on the axis; it does not mark the axis commutated by itself. Poll `ISingleAxis.IsCommutated` for the result.
// waitTime: Optional: milliseconds to sleep after starting. It only waits and does not check completion; poll `IsAutoPhase` for that
void Commutated(int? waitTime = null);

// Check whether commutation is completed: `ComtStatus[1]` reads 100, 200, 300, 400 or 500.
// Returns: Returns true if commutation is completed, otherwise false.
bool IsCommutated();

    // Starts the auto-phasing (commutation) procedure.
// controller: The controller object / handle
// axis: One axis
bool aamotion_auto_phase(aamotion_controller controller, int axis);

// @return true when auto-phasing has completed.
// controller: The controller object / handle
// axis: One axis
bool aamotion_is_auto_phase(aamotion_controller controller, int axis);

// Starts the commutation configured on the axis (writes ComtMode[5] = 1282) unless the axis is already commutated or commutation is running. It does not mark the axis commutated by itself; poll aamotion_is_commutated for the result. @param waitTimeMs > 0 sleeps that long after the command; <= 0 returns at once.
// controller: The controller object / handle
// axis: One axis
// waitTimeMs: Milliseconds to wait after starting commutation when above 0; 0 or less returns at once
bool aamotion_commutated(aamotion_controller controller, int axis, int waitTimeMs);

// @return true when commutation is complete (ComtStatus[1] reads 100, 200, 300, 400 or 500).
// controller: The controller object / handle
// axis: One axis
bool aamotion_is_commutated(aamotion_controller controller, int axis);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    axisRef AxisRef One axis
    waitTime int? Optional: milliseconds to sleep after starting. It only waits and does not check completion; poll IsAutoPhase for that
    axis int One axis
    waitTimeMs int Milliseconds to wait after starting commutation when above 0; 0 or less returns at once

    Commands sent

    {Axis}ComtMode[5] = 1282 // unless ComtStatus[1] already reads commutated or 1 (running)

    Returns

    IsAutoPhase / IsCommutated / aamotion_is_auto_phase return true once commutated.

    Notes

    • Commutated sends the same command as AutoPhase, and IsCommutated reads the same status as IsAutoPhase. Commutated starts the commutation configured on the axis; it does not mark the axis commutated by itself.
    • The motor moves a little while commutating; make sure the mechanics allow it.
    • Read ComtStatus for the reason a commutation failed.

    Example

    AAMotionAPI.AutoPhase(c, AxisRef.A);        // starts commutation; returns at once

DateTime deadline = DateTime.UtcNow.AddSeconds(10);
while (!AAMotionAPI.IsAutoPhase(c, AxisRef.A))
{
    if (DateTime.UtcNow > deadline)
        return false;                       // read AComtStatus[1] for the reason
    Thread.Sleep(100);
}
return true;

    aamotion_auto_phase(h, AAMOTION_AXIS_REF_A);            /* returns at once */
for (int i = 0; i < 100; ++i)                            /* up to 10 s */
{
    if (aamotion_is_auto_phase(h, AAMOTION_AXIS_REF_A))
        return true;
    sleep_ms(100);
}
return false;
/* starts commutation unless already done, then waits up to 5000 ms */
aamotion_commutated(h, AAMOTION_AXIS_REF_A, 5000);
if (!aamotion_is_commutated(h, AAMOTION_AXIS_REF_A))
    printf("not commutated: read AComtStatus[1]\n");

    Stop, abort and stop repetition¶

    Three ways to end a motion:

    Function Keyword Effect
    Stop Stop decelerates to rest at Decel
    Abort Abort decelerates to rest at the emergency deceleration EmrgDec
    StopRep StopRep repetitive motion: finishes the repetition in progress, then ends

    None of them turns the motor off. Afterwards MotionReason holds the reason (1 = Stop, 2 = Abort, 3 = StopRep).

    Standalone demo: Normal stop

    Standalone demo: Emergency deceleration stop

    Standalone demo: Stop after the repetition

    When to use it

    Stop for normal stops; StopRep to end a repetitive move after the current stroke; Abort only when the motion must end at once.

    Signatures

    // AAMotionAPI
// Stop the specified axis motion
// controller: The controller object / handle
// axis: One axis
// Returns: Returns true if stop is successful, otherwise false
static bool Stop(MotionController controller, AxisRef axis);

// Emergency stop the specified axis motion
// controller: The controller object / handle
// axis: One axis
// Returns: Returns true if abort is successful, otherwise false
static bool Abort(MotionController controller, AxisRef axis);

// Stop repetitive motion of the specified axis
// controller: The controller object / handle
// axis: One axis
// Returns: Returns true if stop is successful, otherwise false
static bool StopRep(MotionController controller, AxisRef axis);

// ISingleAxis
// Stop current motion.
// Returns: Returns true if motion stopped successfully, otherwise false.
bool Stop();

// Emergency stop all motion.
// Returns: Returns true if emergency stop was successful, otherwise false.
bool Abort();

// Stop repetitive motion.
// Returns: Returns true if repetitive motion stopped successfully, otherwise false.
bool StopRep();

    // Stops the current motion.
// controller: The controller object / handle
// axis: One axis
bool aamotion_stop(aamotion_controller controller, int axis);

// Emergency-stops all motion on the axis.
// controller: The controller object / handle
// axis: One axis
bool aamotion_abort(aamotion_controller controller, int axis);

// Stops a repetitive motion.
// controller: The controller object / handle
// axis: One axis
bool aamotion_stop_rep(aamotion_controller controller, int axis);

    Parameters

    Parameter Type Description
    controller MotionController / aamotion_controller The controller object / handle
    axis AxisRef / int One axis

    Commands sent

    {Axis}Stop

    Returns

    true when the command was accepted. The axis may still be decelerating when it returns; wait for MotionStat == 0 to know it is at rest.

    Notes

    • Stop uses normal Decel; Abort uses emergency EmrgDec. Check both configured rates.
    • A stop request is not proof of standstill. Check MotionStat == 0 for motion ended; use InTargetStat == 4 when settling is required.

    Example

    AAMotionAPI.Stop(c, AxisRef.A);       // decelerate to a stop with ADecel

    aamotion_stop(h, AAMOTION_AXIS_REF_A);       /* decelerate to a stop with ADecel */
