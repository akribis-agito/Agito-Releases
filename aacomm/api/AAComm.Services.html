AACommMessage
This class describes the message sent to AAComm <xref href="AAComm.CommAPI.Send(AAComm.Services.AACommMessage)" data-throw-if-not-resolved="false"></xref> and <xref href="AAComm.CommAPI.SendReceive(AAComm.Services.AACommMessage)" data-throw-if-not-resolved="false"></xref> methods


Two CTOR sets are available: for the synchronous SendReceive() function, and the asynchronous Send() function


Every CTOR set has 2 "sub-types" regarding <xref href="AAComm.Services.AACommMessage.MessageType" data-throw-if-not-resolved="false"></xref> and <xref href="AAComm.Services.AACommMessage.TimeoutMs" data-throw-if-not-resolved="false"></xref><p></p>

The 'implicit' CTOR resolves these parameters automatically from the <xref href="AAComm.Services.AACommMessage.Message" data-throw-if-not-resolved="false"></xref> argument


The 'explicit' CTOR expects the user to specify these arguments. For expert use only.


To use the "Bulk Message" functionality: use the 'explicit' CTOR, set MessageType to <xref href="AAComm.Shared.MessageType.BulkMessage" data-throw-if-not-resolved="false"></xref> and Timeout to <xref href="AAComm.Shared.TimeoutMs.Default" data-throw-if-not-resolved="false"></xref>
To use the "Special CNCA Bulk Message" functionality: use the 'explicit' CTOR, set MessageType to <xref href="AAComm.Shared.MessageType.BulkMessageCNC" data-throw-if-not-resolved="false"></xref> and Timeout to <xref href="AAComm.Shared.TimeoutMs.Default" data-throw-if-not-resolved="false"></xref>
To use the "Special CNCB Bulk Message" functionality: use the 'explicit' CTOR, set MessageType to <xref href="AAComm.Shared.MessageType.BulkMessageCNCB" data-throw-if-not-resolved="false"></xref> and Timeout to <xref href="AAComm.Shared.TimeoutMs.Default" data-throw-if-not-resolved="false"></xref>
To use the "Special Bulk Message for CNCA" functionality: use the 'explicit' CTOR, set MessageType to <xref href="AAComm.Shared.MessageType.SpecialBulk" data-throw-if-not-resolved="false"></xref> and Timeout to <xref href="AAComm.Shared.TimeoutMs.Default" data-throw-if-not-resolved="false"></xref>
To use the "Special Bulk Message for CNCB" functionality: use the 'explicit' CTOR, set MessageType to <xref href="AAComm.Shared.MessageType.SpecialBulkB" data-throw-if-not-resolved="false"></xref> and Timeout to <xref href="AAComm.Shared.TimeoutMs.Default" data-throw-if-not-resolved="false"></xref>
